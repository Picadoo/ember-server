**噪声**：300 名玩家时 W30 的标准误约 0.35 周（二项 30% 附近、周粒度插值）；同一方案内不同策略之间 W30 相差可达 0.9 周。所以上表 |Δ| ≤ 0.7 周的差别都在 ±2 个标准误内，**不能说成长显著改变了双极品时间线**，只能说"变化 ≤ 0.7 周、方向取决于是否计成本"。
