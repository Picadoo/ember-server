## 结论与调参建议（不改数）

1. **团本整体难度不用动。** 随机组队的基线通关率修正前后没有显著变化：6 个留出池 3 人 R01 / R02 / R03 修正后 − 修正前 = −2.8 / −1.4 / −2.6pp（95% 区间 ±4～5，`out-simfix-m01-m06.md` §1b），4–5 人 ≈ 0。D137 按旧模型定的团本数值，在随机构成下仍然成立。被少算的是"焚烬多的队伍"，不是"平均队伍"。
2. **R02：焚烬越多越好，但没到要调的程度。** 每多 1 名焚烬约 +2～4pp。3 人全焚烬比无焚烬高 +8.3 [+5.8, +10.7]，5 人高 +6.6 [+4.7, +8.4]。都低于"组合差 ≥ 10pp 才调"的线（区间上沿刚碰到）。**建议：不改。**
3. **R03：焚烬略好，+1.5～+4.8pp，不改。**
4. **R01：多焚烬吃亏，而且很明显。** 2 / 3 焚烬时 −7.9 [−10.8, −5.0] / −27.0 [−29.1, −24.8]；4 人全焚烬 −35.9；5 人全焚烬 −28.1。原因是 R01 首领 50% 血量时加怪，单下伤害 79，全焚烬队里没有炽愈回复。这是"R01 要求续航"的团本特色，不是焚烬太弱：同样的焚烬队在 R02 / R03 持平或更好。**数值上不改**：给焚烬加强会让 R02 更偏向焚烬；削 R01 首领会让所有队伍都变容易（强度膨胀）。**建议只改文案**：R01 入口 / 招募提示写"建议队伍里有炽愈（续航）"。
5. 模拟池里自然穿焚烬的只有约 10%，所以随机组队出现 3 人全焚烬的概率约 0.1%。真实玩家的套装分布可能很不一样（例如开黑组全焚烬），所以要用实服数据确认。**上线后的触发线**：按队伍构成统计实际通关率，如果全焚烬（或 ≥2 焚烬）R02 比无焚烬高 ≥ 10pp，并且样本 ≥ 200 局，再考虑"同一目标燃烧施加者上限 = 2"这一类结构性改动（方向，未模拟）；如果 R01 ≥2 焚烬的队伍比无焚烬低 ≥ 10pp，并且这类队伍占比 ≥ 15%，再考虑 R01 加怪段的伤害。
