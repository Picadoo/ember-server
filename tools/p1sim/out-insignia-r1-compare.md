## 4. 推荐

**选 B。**

理由：

1. **对准双痛点**：共用 3 次残响帽下，结余最少策略会把票投向缺货的 Q05–Q07 → 熟练档 W12 调律已 6、两槽 Q07 100%，Q05–Q06 有稳定周流入。  
2. **不增加发放总量**：相对基线 echo/outpost/signin 人均来源行不变（见各 `out-insignia-r1-*-w30.md` src 行）；只是把原进 Q01–Q04 的残响份额改到高图。  
3. **避免 A 的 Q07 通胀死库存**（换件友好过度 → 176 枚闲置）和 **A 解不开调律** 的硬伤。  
4. **比 C 更早达到调律闸门**，且不必先定 live 兑换比；C 可作 R2「消化低图死币」备选（需独立扫参窗）。

**不推荐现在就上 A 或 C。** A 作「只救 Q07 签名」的局部补丁会留下 L10b/L12b；C 留到业主确认要官方跨图兑换后再开 R1-yml。
