## 1. 噪声底（动态 21 格）

指标同 Stage 0：首通前通关率 = 首通数 ÷ 前线进入数，Δpp 相对现行 2 槽。容差 ±2pp。

| 设置 | 每躲避人数 | 95% 半宽（中位 / 最大） | 说明 |
|---|---|---|---|
| 旧做法：800 人、不配对随机流（Stage 0 / D245 表） | 800 | 约 1.9 / 6（按 √n 从下行折算） | 近乎相同的方案之间格子摆动 ±3–5pp —— 就是这个噪声 |
| 不配对：base vs base，两批独立种子 | 4000 vs 4000 | 0.85 / 2.88 | 实测最大 \|Δ\| 1.66pp（理论应为 0）；Q01 躲避 0.3 那格因进入次数长尾最宽 |
| 同种子配对、无 CRN | 4000 | — / 1.40 | rec 点估 16/21 |
| **同种子配对 + CRN（采用）** | **4000** | **≤1.09** | rec 点估 18/21；零权重对照与 base **逐格完全相等**（0/8400 格不同） |

**判定规则（本文统一用）：** 点估 \|Δ\| ≤ 2 为过；点估超出但 95% CI 伸进 ±2 内记为「~ 噪声内」；整个 CI 在 ±2 外记为「✗ 真实偏差」。4000 人配对 + CRN 的半宽 ≤1.09pp，小于 ±2pp 容差，满足任务要求。

工具：`P1SIM_CRN=1 NPROC=8 python3 gear6.py prog '<json>' 4000 OUT.pkl` → `python3 gear6.py entci OUT.pkl`（配对 bootstrap，2000 次）。`GEAR6_SEED0` 换种子起点（不配对对照用）。

## 3. 「零护甲权重对照还剩 ~0.5 周」是什么 —— 随机流错位（模型伪影），不是真实差距

无轮换路线，1200 人，躲避 0.5。`ctl` = 护甲权重 0、护甲费用 0、分解白板 0、护符费用 1.0（在 CRN 下与 2 槽**逐位相同**，真实效应 = 0）。

| 对照 | 不开 CRN（旧做法）W30 · Δ [95% CI] | 开 CRN W30 · Δ [95% CI] |
|---|---|---|
| base（2 槽） | 6.99 | 6.84 |
| ctl（零效应） | 6.62 · **−0.37** [−0.89, +0.20] | 6.84 · **+0.00**（逐位相同） |
| w100（护符 100%，护符 ×0.7 / 甲 ×0.1，旧「零权重对照」） | 6.42 · **−0.57** [−1.11, −0.03] | 6.91 · **+0.07** [−0.15, +0.29] |
| w100，护符 ×1.0 / 甲 ×0.1 | — | 6.91 · +0.08 [−0.15, +0.30] |
| w100，护符 ×0.7 / 甲 ×0、白板 0 | — | 6.52 · −0.32 [−0.58, −0.06] |
| w100，护符 ×1.0 / 甲 ×0、白板 1.0 | — | 6.84 · +0.00（逐位相同） |

**结论：**
1. 旧的「w100 还差 −0.57 周」可以完全复现（6.42），但同样的不配对流程把一个**真实效应为 0** 的对照（ctl）也算出 −0.37 周。原因：不开 CRN 时，每件护甲掉落 / 护甲强化都从 `p.rng`（刃 / 护符掉落和强化共用的流）里抽数，6 槽方案多抽的每一个数都会把之后所有刃 / 护符掉落整体错开，「同种子」实际上变成了独立样本；W30 是 30% 分位穿越时间，1200 人不配对时 95% 半宽约 ±0.55 周 —— 比 ±0.5 周的 gate 还宽。
2. 开 CRN（护甲独立一条流、每局重新播种）后，零权重对照的差距是 **+0.07 [−0.15, +0.29]**，即**没有剩余差距**。白板产出对结果为 0（逐位相同）；护符 ×0.7 的便宜只在护甲完全免费时显出来（−0.32），配上 4 件 × 0.1 的护甲费用就抵消了（合计 1.1 倍）。
3. 所以 rec 的 −0.51 周**全部**来自权重：护符只占生命侧 60%（w100 → rec：+0.07 → −0.51）。机制见 §4。
