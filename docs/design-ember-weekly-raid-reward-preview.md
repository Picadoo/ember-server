## 3. 方案 A / B

| 方案 | 做法摘要 | 利 | 弊 | 本轮 |
|------|----------|----|----|------|
| **A. 双真分页对齐日常（推荐）** | 新建 `ember_weekly_rewards` + `ember_raid_rewards`；周本/团本 P 改 `sound` + `menu:`（**删**空壳 tell）；页内分栏展示通关箱 / 周首通保底 / 战斗或终厅机会；返回各自父菜单；数量与概率 **只展示现网** | 与日常体感一致；专岗清晰；热更；可顺带校正父 lore 口径 | 两文件 + 两处 P；需对照表防抄错 | **推荐** |
| **B. 本轮继续挂 / 仅加厚 tell** | backlog 挂债；或只把 tell 改成多行（仍无子页）；或只做周本一页、团本另挂 | 零 / 更小 diff | 「假预览」债继续；与日常范式仍裂 | 备选 |

### 方案 A · 施工意图（批准后 · 插件可微调同义布局）

**入口（两父菜单 P）：**

```
actions:
  all:
    - 'sound: BLOCK_CHEST_OPEN-1-1'
    - 'menu: ember_weekly_rewards'   # 或 ember_raid_rewards
# 无 tell 空壳；无 enter / 无给物
```

**周本页 `ember_weekly_rewards`（示意分区 · 布局可仿日常 6 行）：**

| 区 | 展示意图（展示名为主；可选附 NI 管理行同日常） |
|----|----------------------------------------------|
| 头 | 周本奖励预览 · 纯展示不进本 |
| 通关箱 | 核心碎片×3 · 附魔晶×2 · 碎片×8 · 骨尘×4 · 原版经验+6 级 |
| 周首通箱装 | **余烬精炼护符**×1（`weekly_t1` first_per_week）；同周再通：刃约 10% · 护符约 8% |
| 战斗/Boss | 摘要：终厅核心必掉；刃约 20% · 精炼护符约 12% · 稳定符约 4%；中核另有较低 T1/T2 刃 |
| 底栏 | 返回 `ember_weekly` |

**团本页 `ember_raid_rewards`：**

| 区 | 展示意图 |

## 4. 验收（≤5）

1. **批准前：** 本稿落盘；DP / MM / `loot.yml` / 体力 / `over_chance*` **零 diff**（本 commit 仅文档）。  
2. **若批 A：** 周本 P 点开 `ember_weekly_rewards`（有声），**非**仅 chat 空壳；底栏返回 `ember_weekly` 且 **未**进本、**未**发物。  
3. **若批 A：** 团本 P 同理 → `ember_raid_rewards` → 返回 `ember_raid`；页内可见通关箱材料 + 周首通团戒语义 + T3 不保底。  
4. **若批 A · 禁项：** 未改掉落/票/体力/进本；玩家路径 **无** 新增斜杠教学；周首通 / 概率口径与 `option`+`loot.yml`+MM **一致**（不得把 `raid_gem` 写成必给）。  
5. **若批 B：** backlog 明文「周本/团本奖励预览本轮不批」；不得把日常真分页 PASS 写成「全进本菜单预览已对齐」。
