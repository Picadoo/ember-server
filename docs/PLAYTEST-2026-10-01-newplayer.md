## 未解决问题（按严重度排序）

1. **高｜深渊掉线后重连，整局层数清零。** `AbyssSession` 只存在内存里，玩家退出时就被清掉。实测：双人打到第 11 层，两人断线后重连回同一实例，撤离显示「最高层 0 <1，无结算箱（已标记结算）」，一整局奖励全丢。需要改代码（退出时保留同一实例的会话，或把层数写进实例），本次没动。
2. **中｜第 4 章「在深渊结算一次 / 再次深入深渊并结算」必须打穿 12 层。** 撤离结算不触发 abyss_clear。提示已改成如实，但规则本身要设计确认，见设计问题。
3. **中｜菜单承诺「按提示填写」，但没有任何输入提示。** 涉及寄售「上架出售」（定价）、盟约「创建盟约」（名称）、好友「添加 / 删除」「师徒」。实际只能手打命令，纯菜单玩家走不通。需要做聊天输入或铁砧输入功能。
4. **中｜分解页一点就分解手持装备，没有二次确认。** EmberNew2 一键把唯一的新手刃分解掉了，靠灰烛每日补领一次才拿回。
5. **中｜周本对新号单人很难。** Lv.22 + T1 +3 单人连续 2 次阵亡（打不过蛮兵·乙，1500 血），失败不退体力，周免被吃掉。3 人一局 94 秒。见设计问题。
6. **低｜刷点散布导致卡块。** guard 已拦住窒息并把怪抬出：EmberDailyZombie（5,65,7，scatter 0.8 落到 6,66,7）×2 次；EmberAbyssWatcher / WatcherDeep（-38,65,276、-42,50,264、-42,28,264）×3 次。check-dp-spawns.py 只检查中心点，不考虑 scatter，也不考虑凋灵骷髅 2.4 格的身高。
7. **低｜副本地图树叶会自然凋落。** 周本、深渊清理时有苹果和树苗掉落物，玩家还会捡到树苗。建议给地图树叶设为不衰减。
8. **低｜玩家可见的提示里有内部 ID 或要求手打命令（在 Java 里，未改）。** 例如「[仓库] 已存入 mat_ember_shard」「可领取 /corerpg bounty claim」「[战令] … /corerpg pass claim」「[邮寄] /corerpg mail …」「誓约 /corerpg covenant set …」。
9. **低｜图录页三个子项都是「暂未开放」，但枢纽 lore 写「集齐有奖（称号/币/天赋点）」。** 商城里「礼包 / 月卡 / 外观」三个入口打开的是同一页，没有礼包，也没有外观货架（lore 已改成如实）。

## 设计问题（未改数值和玩法）

- **深渊结算口径：** 中途撤离要不要算第 4 章的「结算」和 abyss_clear？要不要给战令 / 等级经验？目前只有打穿 12 层才算，新人第 4 章要连续打穿两次。
- **周本难度：** 对 Lv.20～25 单人是否过难？失败要不要退还周免抵扣？菜单写「建议 1～3 人」，但新人很可能第一次单人进本就被吃掉周免。
- **分解确认：** 分解要不要加二次确认，或者禁止分解当前唯一的武器？
- **新手体力账：** 一天体力大约够 3 次日常。新人第一次进日常若站着不动或打输就白扣 30。灰烛说「每天大约开三次」与实际一致，这里只是记录感受。
- **聊天输入：** 是否做聊天或铁砧输入，让寄售定价、盟约命名、好友申请能纯菜单完成？
- **套装激活显示：** 套装页要不要显示真实激活状态（需要新的 PAPI 占位符）？
- **使魔出战：** 使魔页要不要加一键出战？目前按钮只列出使魔。
