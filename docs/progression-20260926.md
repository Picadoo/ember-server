# 成长线：余烬等级 / 战令等级奖励 / 勋阶（2026-09-26 23:05–23:15 CST，CoreRpg 1.6.0）

数值全部在 `plugins/CoreRpg/progress.yml`（热重载：`/corerpg reload`）。

## 1. 余烬等级（emberLevel）
- **规格**：DESIGN-ember-growth-curve §1 规定 1～60 级、新号 10 级、经验来源（挂机有日软顶 / 副本票硬顶 / 签到），但没有曲线数值。天赋点按 talent.yml 的 `points_per_level: 1`、`level_points_from: 2`。
- **曲线（保守）**：从 L 级升到 L+1 需要 `60 + 12 × max(0, L−10)` 经验。
  - Lv10→11 需 60，Lv30→31 需 300，Lv59→60 需 648。
  - Lv10→60 合计 17,700 经验。
- **来源**：

  | 来源 | 经验 | 限制 |
  |------|------|------|
  | 签到 | 20 | 每日 1 次 |
  | 日本通关 | 60 | 受票数限制 |
  | 周本通关 | 200 | 受票数限制 |
  | 深渊通关 | 80 | 受票数限制 |
  | 团本通关 | 250 | 受票数限制 |
  | 盟 Boss 通关 | 100 | 受票数限制 |
  | 精英击杀 | 15 | 精英 + 首领合计每日上限 150 |
  | 首领击杀 | 40 | 同上 |
  | 任意合格击杀（挂机庭等） | 2 | 每日上限 100（= 50 只） |

  勋阶每阶 +1% 经验。
- **节奏**：满勤约 450～500/日，大约 5～6 周满级；休闲约 200/日，大约 3 个月。
- **升级**：每升一级，talentPointsEarned 加 1（等级 ≥2 才加；可花点数仍受 `max_spendable_points: 20` 限制）。新号还是 10 级、9 点，和原来一致。
- **接线**：
  - DP 的日/周/深渊/团本/盟Boss 通关箱改为控制台执行 `corerpg progress <玩家> <来源>`，一次同时给战令经验和余烬经验；原来的 `passxp` 命令保留。
  - 签到在插件内部发放。
  - MM 精英/首领沿用 `xpreward`，现在也会加余烬经验。
  - 击杀在 CoreRpg 的 EntityDeathEvent 里发放。
- **查看**：`/corerpg level`。新 PAPI：`%corerpg_ember_xp%`、`%corerpg_ember_xp_need%`、`%corerpg_vip_title%`。
- **未做**：进本等级软门（规格写的是「后期接线」）；悬赏经验（没有要求）。

## 2. 战令等级奖励 + 赛季
- **Lv1～30 免费轨**：
  - 奇数级 100 币，偶数级 3 碎片；
  - 每 5 级 +1 附魔晶 +1 核心碎片；
  - Lv10、Lv20 各 1 张日票；Lv15 3 魂尘；
  - Lv30：外观碎片 ×1 + 300 币。
  - 免费轨不给任何装备。
- **Lv1～30 付费轨**：
  - 每级 100 币 + 2 骨尘；
  - 日票 ×5（Lv6/12/18/24/30，对应规格「日票×5 分散等级发」）；
  - 保护券 ×3（Lv5/15/25）；孔石：锐 Lv10、稳 Lv20；附魔晶 ×4；
  - Lv30：外观碎片 ×3 + 稳定符 ×1。
  - 不给 T3、不给核心。
- **领取**：`/corerpg pass claim` 按「已领至等级」补发所有未领的等级，每级一封系统邮件；付费轨需本季已解锁。`/corerpg pass rewards` 查看当前及之后两级的奖励。战令菜单加了「等级奖励 · 一键领取」按钮。
- **战令经验新增来源**：深渊 +20、团本 +40、盟Boss +20（每日上限仍是 100）。
- **赛季**：
  - 当前赛季 ID 存在 `plugins/CoreRpg/season.yml`（`current_season_id: S1`），玩家存档里有 `passSeasonId`。
  - 管理员命令 `/corerpg pass season reset <新ID>`：在线玩家立即重置，离线玩家下次访问时重置。重置内容：战令经验、领取进度、付费轨（付费轨按季购买，规格写的是「季内限购 1」）。
  - 老玩家第一次访问时只写入 S1，不会重置。
- **说明**：邮件发的日票不计入每日 6 张的发票硬顶；每季最多 7 张（免费 2 + 付费 5）。

## 3. 勋阶路径
- **规格**：DESIGN-ember-rpg-systems §8.2「充值累进 0～10」，特权是登录币、经验微加成、仓库、专属称号；攻击加成 ≤3% 且可关，本期建议关闭。
- **晋升**：按累计充值晶钻，只升不降。
  - 门槛（规格未给，取常见档位）：68 / 198 / 488 / 988 / 1988 / 3288 / 4988 / 7988 / 12988 / 19988。
  - 目前没有支付网关，`/corerpg cash give <玩家> <数量>` 就是充值入口，会计入累计；发补偿时加 `nocount` 不计。
- **特权**：
  - 日礼：勋阶 ≥1 每日 120 币（数值未改）；勋阶 0 是 20。
  - 余烬经验 +1%/阶。
  - 晋升时一次性加仓库格：每阶 +1，不超过 `max_slots`。
  - 称号：勋阶I～X，在 `/corerpg vip` 和 PAPI `vip_title` 中显示。
  - 攻击加成：未做（本期关闭）。
