## 红线（对玩家可见语气）

- 不卖核心 / 附魔晶 / 成品高强化刃 / 付费伤害宝石。  
- 氪金买 **时间、便利、外观**；战力差来自多打本，不来自钱包直加伤害。  
- 日票硬顶：免费 3 + 晶钻购 + 月卡赠 ≤ **6**/日（总进本）；晶钻 SKU 另限 3/日。周票：免费 1 + 氪 ≤ **2**/周。

## 战令（`ember_pass`）

- **免费轨：** 币、少量碎片、普通称号。  
- **付费轨：** 外观、币、日票×5（赛季内分散）；**无核心**。  
- **经验：** 挂机击杀 / 通关日周本，有日上限。  
- 解锁按钮：占位 48 晶钻 +「支付尚未接线」。

---

## 勋阶（`ember_vip`）

- 累进 **0～10**；登录币、经验微加成、仓库、专属称号。  
- 攻击加成若开：**≤3% 且可关**（本期建议关）。  
- 可跳转商城。
