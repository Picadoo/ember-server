发布包：GitHub Release [`maps-v2-2026-10-03`](https://github.com/Picadoo/ember-server/releases/tag/maps-v2-2026-10-03)（每个模板一份 `.schematic` + 存档文件夹 zip，外加 7 个主线/团本模板的整套 zip `ember-p1-maps-v2-2026-10-03.zip`，路径从 `plugins/DungeonPlus/map/` 开始，内含 `SHA256SUMS.txt`；临时活动图 `ember_fest_gq26_v1` 单独一个 zip + schematic，不在整套 zip 里）。

## 必须遵守的规则

1. **不要移动、也不要堵住**下面每张图列出的任何点和框：出生点/队友落点（spawn/spread）、安全点（safe）、房间触发框（trigger）、刷怪点（points）、门框（door）、首领区（boss area）、首领位置（boss at）和小怪点（adds）、事件区（event area / anchor）、悬浮字位置（holo）。点 = 玩家/怪物脚下那一格：脚和头两格必须是空气（或可穿过的方块），脚下一格必须是能站的实心方块。点周围半径 2 格内别放东西，门框四周 3 格内别放东西，房间之间的通路要留出来。
2. **门框（door）里的方块只能是空气**（模板按“门开着”保存）。CoreRpg 进本时把门框里的空气换成铁栏杆，清完房间再换回空气；门框里放了任何别的方块，那扇门就永远打不开。
3. **只用 Minecraft 1.12.2 里有的方块**（方块 id ≤ 255，带数据值；不能用 1.13+ 的扁平化方块，比如海带、珊瑚、新木头、屏障以外的新方块）。1.12 里会掉落的方块（沙子、沙砾、混凝土粉末）下面必须有实心方块。
4. **首领区**的地面要平、要整片连通：首领技能是以玩家为圆心的圈（Q04 冲击圈半径 2.5；R03“烬核”半径 3，要全队跑到被点名的人身边分摊），所以首领区里不要加掩体、柱子或坑。R03 / Q05 的首领区（`ember_daily_spire_v1`，x −16..16，y 79..94，z 130..162）在 v2 里只换了墙面/地面材质，布局一格没动，以后也请保持。
5. 不要让地图漏：房间、走廊的地板和墙不能有洞通到外面（玩家掉出去或怪跑出去）。Q04 有 `fall_catch_y: 63.5`（掉到 y63.5 以下会被拉回），所以 Q04 的地板不能低于 y63。
6. 不要放刷怪笼（mob_spawner），不要留动物/村民等实体；`server.properties` 里 `spawn-monsters=false`，怪全部由 CoreRpg 按点刷。
7. 一个模板被多个副本共用（比如 `ember_daily_spire_v1` = Q05 + R03，`ember_daily_frost_v1` = Q06 + R02，`ember_daily_rail_v1` = Q07 + R01），改之前把两个副本的点都看一遍。

## 怎么导回服务器

- **存档文件夹 zip**：停服（或确认没有人在打这个副本），在仓库根目录解压，覆盖 `plugins/DungeonPlus/map/<模板名>/`（`region/*.mca` + `level.dat`），然后**重启服务器**。DungeonPlus 开服时把模板复制成 `plugins/DungeonPlus/dungeon-caches/dungeon_<副本id>_*/` 预制缓存，副本实例从缓存加载，所以只换模板不重启，正在用的缓存不会变。
- **.schematic（MCEdit/WorldEdit “Alpha” 格式）**：在一份 1.12.2 的模板存档里 `//schem load <名字>` 然后 `//paste -o`（`-o` = 按 schematic 里记录的原点粘回原坐标，原点见上表）；或在 MCEdit 里 Import 到同一原点。粘完保存存档，再按上一条换模板、重启。
- 导回后一定要跑下面的检查。

## 怎么检查（scripts/check-dp-spawns.py）

```bash
cd <仓库根目录>
# 检查服务器正在用的模板（EmberQ0* = 主线 Q01–Q07、团本 R01–R03，以及以后新加的 EmberQ0*）
python3 scripts/check-dp-spawns.py plugins/DungeonPlus/dungeon/EmberQ0*
# 检查另一份地图（比如解压出来的发布包或你改过的副本），目录下面是 <模板名>/ 文件夹
DP_MAP_ROOT=/path/to/maps python3 scripts/check-dp-spawns.py plugins/DungeonPlus/dungeon/EmberQ0*
```

每个副本一行 `ok`/`WARN`/`BAD`；退出码 1 = 有点的头卡在实心方块里（怪会窒息、被算成击杀）或缺区块；它还检查门框里只能是空气/铁栏杆、运行时栏杆框（rails）不能压在点上。没有第三方依赖。全部 `ok` 才能上线。2026-10-03 v2 发布时 EmberQ01–Q07、EmberQ0R1–R3 这 10 个副本全部 ok（活动本 EmberQ0F1 / `ember_fest_gq26_v1` 也是 ok）。
