## 4. 为什么 T0 很难站桩打过 Q01（按书的数，不改数）

书第 11 章 Q01：近战 36 生命 / 3 伤害 / 间隔 2.5 秒，远程 26 / 3 / 3 秒，重甲 50 / 3 / 3 秒，首领 240 / 普攻 6（3.2 秒）/ 重斩 12（8 秒）。T0：B=12、H=40、M=0.952。

| 段 | 敌方总生命（A 编排） | 理想击杀时间（普攻 20.2 dps + 烬斩） | 站桩挨打（敌人随死随减） |
|---|---:|---:|---:|
| R1 近战 4 | 144 | ≈ 6.5 秒 | ≈ 19 |
| R2 近战 4 + 远程 1 | 170 | ≈ 7.5 秒 | ≈ 26 |
| R3 近战 5 + 远程 1 | 206 | ≈ 9 秒 | ≈ 36 |
| 首领 | 240 | ≈ 10.7 秒 | ≈ 34 |
| 合计 | | ≈ 34 秒（不含走位） | **≈ 115，生命只有 40** |

- 没有回复药（现状）：要躲掉约 65% 的伤害才能打完。
- 有回复药（书的 20% = 8 点，15 秒共享冷却）：一局 60–90 秒最多喝 4–6 瓶 = +32～48，仍要躲掉约 40%。
- 局内没有自然回血（§19.4 按书关闭），房间之间也不回。
- 变体 C 的机器人在 R1/R2 实际掉血只有计算值的 20–45%（会退步），R3 六个敌人同时贴身时躲不开。

**建议（不改数，给策划定）：**
1. 先落地起始补给和 10 币回复药（B2.169，需要策划给补给数量）。
2. 找真人用 T0 打 Q01 记录通关率，再决定要不要动 Q01 的 R3 编排或攻击间隔。
3. 要测 Q02–Q07 的节奏，需要会躲预警的机器人，或者用「每图标准装备角色」逐图测（那就不算自然节奏了）。

## 5. 这次试玩的测试脚本问题（不是游戏 bug）

## 6. 试玩中发现并修掉的游戏 bug

- **B2.168（1.20.4 已修）**：P1 装备会掉原版耐久。起始之刃是铁剑（250 次），约 9 局 Q01 后碎掉（06:25:18，最后一击 attr 1.00）；`cr_p1_item` 行仍是 active。今天早些时候 P1Alpha 的 T2+6 烬爆刃（钻石剑）也是这样没的。修复：带 P1 数据的物品取消 `PlayerItemDamageEvent`。1.20.4 实测：25 次命中后耐久 0；之后 33 局都没有再碎。
- **B2.169（待策划）**：起始包没有基础补给；回复药只能钓鱼熬制，没有 10 币商店。
- 死后回城的生命会被 P1 账本拉回 2.86（「未登记回复 → 回退」），下一局入场 D11 会补满，不影响战斗；只是城里显示的血很低，以后再看。
