## 4. 偏差

1. **Q03、Q04 比书的参考投入难很多**：机器人装备高于参考 1–4 级强化，通关率 Q03 约 14%、Q04 首通前 0/9。
2. **Q04 近战 105 生命卡在 3 刀线上**：T1 Lv20 时 B=24×(1+e)+2，+6 是 33.2、+7 是 34.88，三刀 104.6 < 105，所以书里 Q04 参考的 T1+3～6（甚至 +7）每只近战都要 4 刀；+8（B 36.56）才 3 刀。书的 B_ref=35 正好压在线上。
3. **首领生命 / B_ref 在 Q03 跳了一级**：Q01 20 倍、Q02 37.5 倍、Q03 48 倍、Q04 63 倍（Q05 68、Q06 78、Q07 85）。Q03 死亡 19/20 在首领段。
4. **死亡螺旋**：死亡局没有收入，还消耗药。10:53 机器人把币全用于强化后 0 币 0 药，之后连死 12 局（11:10 发现，脚本问题，已改成留 100 币买药）。
5. **饥饿**：P1 里自然回血关掉了，但饥饿照常掉；机器人一直没吃东西，11:55 起饱食度 0，Q05 里被饥饿扣到 0.37（脚本问题，已改成城里吃面包）。这对真人不是问题，但 P1 局内唯一「不乘 M」的环境伤害就是它，可以留意。

## 6. 脚本 / 测试端说明

- 11:10 接手时机器人在 Q03/Q04 之间死循环：0 币 0 药，连死 12 局。原因是脚本把币全部用于强化（规则「先补药再强化」没有考虑下一局死了就没收入）。已改（driver_g / hk3）：强化前预览花费，强化后不足 100 币（10 瓶药）就不强化。
- 喝药阈值：脚本仍是第一次试玩的「生命 < 27」，那时 H=40；现在 H=95，等于 28% 才喝，死亡局常带着 2–3 瓶没喝。已改成「< 67.5% 最大生命」（就是原来的 27/40）。
- 刷本规则改成逐级回退（driver_f 已写好未启用）：前沿图失败 → 刷上一图；刷本也失败 → 再往下一图。11:13 从 Q02 开始（0 币 0 药）。
- 12:05 Q05 卡住 807 秒：R2 两只断塔卒在楼梯另一侧，机器人没有寻路走不过去，房间不清、R3 不开。已改：一个房间打完还剩本房间的怪（离路点 14 格内、高度差 < 3），控制台 tp 到最近那只旁边再打，最多 2 次，记在「回位」。
- 12:05 机器人饱食度 0（从没吃过东西），在 Q05 被饥饿扣血。已改：每局后在城里吃面包到 18。

- 12:20 喝药阈值第二处：P1 世界里客户端的最大生命属性一直是 40（服务器改的是基础值，机器人端没更新），fight6 第二个房间起退回到「本房间开始时的生命」，阈值又偏低。已改：每局后从 `/corerpg p1 status` 读 H，阈值 = 0.675×H。
- 12:40 Q04 首通后刃已升 T2；护符 T1→T2 只差币（110/1500，其他材料够）。脚本原来会先把币花在 +7→+8 强化上。已改：升阶只差币时先攒升阶的钱（强化后要剩「升阶价 + 100」）。
- Q03 第一次卡住（10:06）：躲预警把机器人带下了首领台（y60 → y50），之后 7 分钟够不到首领。已改：落点必须有地面、路径不穿墙，找不到就原地不动；掉下去 15 秒自动回位（见上）。
