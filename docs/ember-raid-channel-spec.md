# 团本「通道 → 终厅」+ 团戒套装短规格（优先级 3）

**日期：** 2026-09-13（Asia/Shanghai）  
**作者岗：** 余烬-策划  
**背景：** 灾厄公共窗刷怪点已冒烟；日箱限 1 **可后补**。团本 DP 已有四波骨架（`STATUS-ember-raid-pets.md`），本刀把「换皮周本」做成**协作通道感 + 戒指有用**。  
**承接：** `docs/ember-dungeon-gameplay-diff.md` §5 · `docs/ember-gear-drop-t0-t3.md` §3.6 · `DESIGN-ember-map-plan.md` §3.5

## 0. 一句话

三人进本 → **通道两段清杂（文案逼分路）** → 精英门 → 终厅使徒；通关 **周首通必给 `acc_ember_raid_ring`**；戴戒+刃（或护符）触发 **2 件套**。

## 1. 相对现状要改什么

| 项 | 现状 | 目标 |
|----|------|------|
| 结构 | wave1→2→3→boss 已有 | **保留**；补分路播报 + 可选左右刷点 |

| 票 | 余烬团本票 · 3～5 人 | 维持 |

## 2. 通道机制（最小可感知）

不必真分图；用 **文案 + 刷点左右错开** 做出分路压力：

| 波 | 组名 | 播报 | 刷点意图 |
|----|------|------|----------|
| 1 | wave1 | `§9【左道】卫兵压上——左边清！` | 偏左坐标刷卫兵 |
| 2 | wave2 | `§9【右道】射手就位——右边先压远程！` | 卫兵左、射手右 |
| 3 | wave3 | `§d【汇合】通道精英挡住终厅门` | 中央精英+添头 |
| boss | boss | `§4【终厅】使徒！分摊砸击，别叠脸` | 终厅垫 |

现有 kill Display 保持：`团本·通道卫兵/射手/精英` · `团本·终厅使徒`。

**可选增强（有余力）：** 波 2 未清完射手时精英不刷（已有链式 end，够用）。

超时：维持 `task/timeout.yml` 2400s，失败不发通关箱。

## 3. 奖励（对齐掉落表 · 降通胀）

### 3.1 通关箱（每次 COMPLETE · 全队）

| NI | 数量 | 备注 |
|----|------|------|
| `mat_ember_core_fragment` | 3～4 | 可固定 4 |
| `crystal_ember_enchant` | 2 | |
| `mat_ember_shard` | 10 | |
| `mat_ember_bone_dust` | 6 | |
| 随机孔石 | 1 | sharp/steady 二选一即可 |
| `mat_calamity_ember` | 0～1 | 可选 50% 或去掉（灾厄主产） |
| `gear_ember_t2_blade` 或 `_charm` | 15% / 12% | 无 T2 NI 则跳过 |
| `gear_ember_t3_blade` / `_charm` | **8% / 6%** | **取消必给 T3** |

### 3.2 团戒（周首通）

| 规则 | 值 |
|------|-----|
| NI | `acc_ember_raid_ring` |
| 保底 | **每角色每自然周首次通关**必给 1 |
| 同周再通 | 不发戒；可 tell `§8本周团戒已领取` |
| 存储 | CoreRpg：`raidRingWeek=yyyy-Www`（上海）或 weekId |

### 3.3 战斗中

通道怪材料向；精英低概率 T1/T2（无装则只材料）。**不**在小怪掉 T3。

## 4. 2 件套（最小实现）

| 件 | 条件 |
|----|------|
| A | 主手/装备栏有任意 `gear_ember_blade` / `gear_ember_t1_blade` / `t2` / `t3` 刃 |
| B | 背包或饰品位有 `acc_ember_raid_ring`（本期：**lore 佩戴** 或「在背包即生效」二选一；推荐 **在线背包持有即生效**，省槽位系统） |

**效果（YAML 旋钮，展示用也行）：**

- 名称：`余烬同袍`  
- 效果：击杀回 1 点饱食 **或** 微量生命（≤总战力 2%）；**禁止**大额攻击乘区  
- 触发：CoreRpg 监听击杀 / 周期检查套装标记写 lore 一行 `§6套装：余烬同袍 ✓`

无效果代码时：本期可先 **通关 tell + 戒指 lore 写「与余烬之刃组成套装（生效待开）」**——但优先做「背包持有即小回血」，玩家才能感知。

## 6. 验收（PASS）

1. 3 人持票可进；2 人拒进。  
2. 四波播报能区分左道/右道/汇合/终厅。  
3. 通关发材料箱；**不**每人必掉 T3 刃。  
4. 角色本周首次通关获得 `acc_ember_raid_ring`；同周第二次通关不再发戒。  
5. 持戒+刃时套装有可见反馈（lore 或回血/提示）。  
6. 不影响深渊撤离、灾厄刷怪点。
