## 3. 动线（共用骨架）

与父稿一致，仅换地图与怪：

```
枢纽选本 → 体力≥30 则扣 30 → DP 实例落点（安全门廊/井口）
  → 房1 清怪 → 开门 → 房2 清怪 → 开门 → Boss → 通关箱 + daily_clear → 回枢纽
```

| 步骤 | 线 B 玩家所见 | 线 C 玩家所见 | 失败 / 撤离 |
|------|---------------|---------------|-------------|
| 落点 | 焦黑拱门内侧，前方铁栅锁死 | 地窖井口平台，前方下阶铁门锁死 | 菜单回枢纽；未通关无箱；体力不退 |
| 房 1 | 第一段甬道 | 上层厅（下阶前） | 同左 |
| 过渡 | 真门开；**假岔路**尽头是封死焦骨墙（可放 1～2 垃圾怪或空） | 下一段楼梯；中间可有铁栅门 | — |
| 房 2 | 弯折/收窄段 · 混编 | 中层厅 · 混编 | — |
| Boss | 尽端鼓室 | 底层圆厅 | 击杀结算 |

**时长目标：** 熟手 **≈5 分钟**，摸索 **≈8 分钟**（允许 ±1 记债务，不记视觉 PASS）。

## 4. 线 B · 余烬窟·焦骨甬道

### 4.1 一句话

被烧塌的补给甬道：烟与焦骨夹着一条窄路，假岔路骗人，尽头鼓室里还有没熄的核。

### 4.2 地图规格（施工意图）

| 元素 | 规格 |
|------|------|
| 外轮廓 | 总长感 **约 48～64** 格甬道轴；宽 **3～5**（收窄处 3）；局部扩成鼓室 **≈10×10** |
| 垂直 | 以同层为主；允许 1～2 处 **±1～2** 小落差，禁止整盘空板 |
| 门 | ≥2 道「清完才开」的真门；**1 条假岔**（明显死路或假门装饰） |
| 主材 | `netherrack` / `red_sandstone` / `soul_sand` 点缀 / 栅栏·骨块；少量子 `lava` 装饰（不可伤到刷怪格） |
| 禁 | 复制庭院回廊布局；开阔院子感；平板虚空岛 |

**建议本地坐标意图（可平移，施工后写入 DP）：**

| 点 | 意图 |
|----|------|
| 出生 | 拱门内 `0,65,0` 朝 +Z |
| 房1 刷点 | z 6～14 段两侧壁龛开放格 |
| 假岔 | 约 x+ 侧支路，尽头封墙 |
| 房2 | z 22～34 收窄弯道 |
| Boss | z≈42 鼓室中心，地面略凹或略抬均可，须可绕 |

### 4.3 建议波次（怪物岗落地 · 数值一次平衡）

| 阶段 | 建议 MM（新建，勿复用庭院同名冒充差异） | 数量感 |
|------|------------------------------------------|--------|
| 房 1 | `EmberAshZombie`（焦骨尸） | 5～6 |
| 房 2 | 焦骨尸 + `EmberAshSkeleton`（燃矢骷，射速/威胁略高于庭院骷） | 3+3 或 4+2 |
| Boss | `EmberAshBrute`（焦核蛮兵）：窄场冲锋感；可复用 SoftHit 系技能骨架但 **Display/装备/技能名独立** | 1 |

### 4.4 节奏备注

窄道 → 玩家更吃走位；假岔只做 **10～20 秒** 分心，不要迷宫。Boss 鼓室必须比甬道宽，否则风筝 FAIL。

## 5. 线 C · 余烬窟·残誓地窖

### 5.1 一句话

旧誓守军的地窖：一层比一层暗，台阶把战线切开，底层圆厅里还跪着最后一个守墓者。

### 5.2 地图规格

| 元素 | 规格 |
|------|------|
| 垂直 | **至少 2 段下阶**（总落差建议 **8～12**）；三层语义：井口/上层 → 中层厅 → 底层 Boss |
| 水平 | 上层厅 ≈16×16；中层 ≈14×14；底层圆厅直径 ≈12～14 + 一圈可走廊宽 2 |
| 门 | 上层清完 → 开下阶门；中层清完 → 开底层门（≥2 道真门） |
| 主材 | `stonebrick` / `mossy_cobble` / `iron_bars` / 稀疏火把；忌整厅通亮 |
| 禁 | 单层平板；与焦骨甬道同「一条直筒」；复制庭院 |

**建议本地坐标意图：**

| 点 | 意图 |
|----|------|
| 出生 | 井口平台 `0,72,0` 朝下阶 |
| 上层厅 | y≈72，刷点靠墙柱 |
| 中层 | y≈66，混编 |
| Boss | y≈60 圆厅中心；廊道 y 同层可风筝 |

### 5.3 建议波次

| 阶段 | 建议 MM | 数量感 |
|------|---------|--------|
| 上层 | `EmberCryptZombie`（窖卫尸；**若与挂机/深渊重名则改 `EmberDailyCryptZombie`**） | 4～5 |
| 中层 | 窖卫 + `EmberCryptSkeleton`（誓印骷，偏高台/栏后射击） | 3+3 |
| Boss | `EmberCryptWarden`（残誓守墓）：圆厅慢压 + 偶发点名；与庭院蛮兵 / 焦核蛮兵 **观感三别** | 1 |

> 命名以「DailyCrypt / Ash」前缀优先，避免和深渊 `EmberAbyss*`、挂机 `EmberAfk*` 撞逻辑掉落。

### 5.4 节奏备注

高差 → 远程阶段更爽；楼梯口可当卡点但 **禁止** 卡怪无法过门。Boss 必须留一圈廊，避免「钉子地板对砍」。

| 硬条 | PASS / FAIL | 说明 |

## 9. 验收硬条（S2）

1. 选本菜单 B/C **可进**（非筹备中）；各扣 **30** 体力。  
2. 两线均为：安全落点 → ≥2 次清房开门 → 独立 Boss 厅。  
3. 通关落在 **5～8 分钟**（抽检）。  
4. 与 S1 庭院 **俯视或进本 5 秒可区分**；焦骨≠地窖≠庭院。  
5. 玩家可见路径 **无** `/dp` `/corerpg` `/hub` `/mvtp`。  
6. 仍为 **本服** MV + DP 实例。  
7. 挑刺抽检：假岔不是迷宫；地窖楼梯不卡怪；Boss 有风筝空间。
