## 1. 问题一句话

**现网战斗主动只有「誓约绑定的 1 招」（烬斩/灰印/守墓壁垒），无第二轻技可装配；玩家想「稍微灵活」——在不动誓约主动与体力门的前提下，加 1 个可菜单装配的轻技槽试点（位移或保命择一）。**

## 3. 目标体验

- 玩家感知：誓约主动仍在；**另有 1 格「轻技」可点选装配**，日常走位/逃生「稍微灵活」一眼能感到。  
- 操作：**TrMenu 点击**装配与释放（hub 技能旁或子页）；**少打指令**（底层可保留 `corerpg flex …` 给插件，玩家 lore 不教手打）。  
- 数值：试点技 **极简**；CD 略长于誓约技；**不**绑体力日周门；**不**做 DPS 轴。

## 4. 方案

### 方案 A（荐）· **位移** 试点 · 1 槽装配

| 块 | 做法 |
|----|------|
| **为何位移（非保命）** | ① **更薄可测**：释放后身位变化即可目视，验收不靠扣血/吃伤表。② **与现誓约主动不撞**：烬斩/灰印偏输出控制，守墓壁垒已是 **抗性+嘲讽保命向**；再加保命轻技易稀释守墓辨识。③ 灰行仅有 **被动移速 2%**（`stats.apply_covenant_stats`），**无**主动位移；短冲刺补的是「操作灵活」而非叠保命。④ 对准用户「稍微灵活」字面。 |
| **槽位** | 每玩家 **1** 装备槽：`flex_skill_id`（空=`none`）。与誓约主动 **并行**：誓约技仍由契约决定；轻技仅当槽非空才可放。 |
| **试点技** | 见下表（id/名可批后微调，效果冻结）。 |
| **UX** | hub「技能」改薄双入口，或新开 `ember_flex_skill` 一页：`装配余烬踏步` / `卸下` / `释放轻技`；短 lore。不教 `/corerpg`。 |
| **消耗** | **零体力**；仅 CD。 |

#### 试点技（荐 A · 仅此一条上线）

| 字段 | 值 |
|------|----|
| id（建议） | `flex_ember_step` |
| 显示名 | §a余烬踏步 |
| 效果（极简） | 朝看向水平方向短位移约 **5 格**（落地安全：不穿墙；失败则原地+短提示）；**无伤害**；无无敌帧或极短 ≤5 tick（防卡墙即可，非保命窗） |
| CD | **14s**（略长于守墓 12s，避免替代誓约节奏） |
| 消耗 | 无（不碰体力） |
| 解锁 | 试点期：**全员可装配**（或 Lv≥10 软门 · 批后插件定一；**禁**绑日周票/体力） |

**利：** 可测、不撞守墓、满足「稍微灵活」、与 B-flex-1 副手正交。  
**弊：** 需插件新分支（YAML 类型 `dash`/`step` + 1 槽持久化）；位移需防穿墙（薄实现即可）。

### 方案 B（极薄旁附 · **勿与 A 同窗双上**）

| B 选项 | 内容 | 何时 |
|--------|------|------|
| B1 · **换类** | 同 1 槽改试点为 **保命**：`flex_ember_guard`「余烬护息」· 自身抗性 I **2s** · CD 16s · 无伤害；**卸下/不装位移** | 总控否决位移或测后位移难落地时 **整窗换皮** |
| B2 · **同槽换皮** | 仍位移：改显示名/粒子（如「余烬跃」）或距离 4↔6、CD ±2s | A 已通、仅 UX/手感微调 |

**本轮默认：只批 A（位移）；B 仅总控点名替换，禁止「位移+保命」两套同时挂槽。**

- 体力日周门、进本 cost、技能耗体力  
- 四件甲、锻炉大改、T0–T3 刃护符
