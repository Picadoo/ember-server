## 1. 目标意象（独立视觉）

**一句话：** 露天/半露天灰烬庭院——四面回廊清潮，中央抬高 Boss 垫，南北（或东西）有出入拱门；进本 5 秒内能感到「这是院子，不是石盒」。

| 元素 | 规格（施工目标） |
|------|------------------|
| 外轮廓 | 约 **32×32**，墙高 4～5；可局部开天（露天感） |
| 回廊 | 内侧宽约 3；四边可走；角落/节点放小怪刷点 |
| 中央 Boss 垫 | 约 **8×8**，相对回廊地面 **抬高 1**；蛮兵只在此区打 |
| 出入拱门 | 至少 **1 主入口拱**（玩家落地面向庭院内）+ **1 撤离语义拱/牌**（通关前可作视觉出口；真回城仍走结算） |
| 主材 | `stonebrick` / `cobblestone` / `gravel`；少量 `netherrack`+火盆；地面 `stone` 混砂砾 |
| 禁 | 整盘同 y 平板；与 `ember_weekly`/`ember_abyss` 同材质同布局的「复制粘贴房」 |

与现网占位对比：现可玩区约 x -42..-38 × z 268..272（约 5×5）→ **必须扩到庭院尺度**，禁止只改告示牌交差。

## 2. 动线（入 / 战 / 撤）

```
[拱门入口落点] → 回廊清波1/波2 → 踏上中央垫打 Boss → 通关结算回枢纽
                      ↑
                 撤离牌/菜单语义（见 §3）
```

| 阶段 | 玩家应看见 | 设计意图 |
|------|------------|----------|
| **入** | 拱门外侧或内侧落地；前方是院子中轴与中央垫轮廓 | 3 秒知「往哪走」 |
| **战·回廊** | 波1 僵尸在回廊节点；波2 混编偏远端 | 文案已有「别急着冲中央」——地形要真有「中央可晚进」 |
| **战·Boss** | 垫上台阶 1 格；垫外可风筝 | 与播报「庭院·中央垫」一致 |
| **撤** | 入口侧或侧翼「回枢纽」牌：打开菜单返回；通关后脚本 `mvtp ember_hub` | 不教打 `/hub` `/dp leave` |

本地坐标建议（施工后写进 option/monster；可相对平移）：

| 点 | 建议本地坐标 | 现网占位（对照） |
|----|--------------|------------------|
| 玩家出生 | `0,65,0`（拱门内） | `-40,65,270` |
| Boss 垫中心 | `0,66,12`（垫面 y=66 若抬高 1） | 蛮兵曾在小房角 |
| 回廊刷点示例 | 四边中点内侧，如 `(±10,65,6)` `(0,65,±8)` 等开放格 | `-41,65,268` 等 |

插件落地：**一次对齐** `$setspawn` / `$teleport` / `monster.yml` location；先备份 `map/ember_daily`。

| 进本 | `/ember` → 日常（或日菜单一点进） | `dp start EmberDaily` |

## 6. 验收 checklist

### 6.1 视觉 / 动线（一票否决）

- [ ] 进本 5 秒内能辨认为 **庭院**（露天感或半露天 + 回廊），不是石盒小房  
- [ ] 存在 **出入拱门** + **中央抬高 Boss 垫** + **可走回廊**  
- [ ] 与周本/深渊图 **俯视或进本观感可区分**（材质或布局至少一项明显不同）  
- [ ] 无整盘空岛/同 y 屏障平板感  

### 6.2 玩法安全（不改数值前提下）

- [ ] 出生不掉虚空、不卡墙  
- [ ] 三波刷点均在开放格，无窒息  
- [ ] 通关仍回枢纽；奖励与改前一致  

### 6.3 UX

- [ ] 玩家路径不依赖手打 `/dp` `/hub`  
- [ ] 日菜单无「请打进本命令」教学句  
- [ ] 本内有回枢纽语义牌（或等价菜单提示）  

**任一条 6.1 FAIL → 不得标 P4 地图完成。**
