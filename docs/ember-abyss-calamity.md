## 0. 定位对比

| | 深渊 EmberAbyss | 灾厄 EmberCalamity |
|--|-----------------|-------------------|
| 形态 | 单人/小队无尽波次副本（DungeonPlus） | 限时世界 Boss 战（独立实例或园区） |
| 次数 | **日 1 票**（`ticket_ember_abyss`） | **日 2～3 窗口**，窗内不限人次进场，**每人每日领奖 1 次** |
| 时长 | 15～30 分（或主动撤离） | 单窗约 10 分 |
| 主产出 | 孔石、强化材料、**层数榜** | 全服同分变异材料、外观碎片、少量核心 |
| 肝度 | 冲层给肝帝；低层保底材料 | 闹钟型；错过等下一窗 |

## 1. 深渊 EmberAbyss

### 1.1 次数与入场

| 项 | 值 |
|----|-----|
| 门票 NI | `ticket_ember_abyss`（显示名 **余烬深渊票**） |
| 日免费 | 1 张（0:00 Asia/Shanghai 发） |
| 氪金补票 | 可接经济文档旋钮；**硬顶建议 ≤2/日**（免费+购） |
| 扣次 | 进本即扣（与日/周票一致） |
| 人数 | 1～2 |
| 撤离 | `/dp leave`；已扣票不返还；**按最高达成层结算层奖**（见 1.4） |

### 1.2 结构（无尽波次 · 层）

- **1 层 = 1 小波小怪 + 层末精英**；每 **5 层** 一次「深渊看守」Boss 波。  
- 难度随层：血量/伤害系数建议 `1 + 0.08 × (层-1)`（YAML 旋钮，插件落地）。  
- 复用 MM：僵尸 / 骷髅 / 蛮兵；精英可用同 ID 或日后 `AbyssElite*`（怪物岗）。  
- 击杀名仍用 Display：`余烬地窟僵尸` / `余烬地窟骷髅` / `余烬地窟蛮兵`（若拆 Abyss 皮，改 Display 后同步 kill 条件）。

## 2. 灾厄 EmberCalamity

### 2.1 窗口与入场

| 项 | 值 |
|----|-----|
| 窗口 | 建议 **12:00 / 20:00 / 22:00**（Asia/Shanghai），每窗开放 **10 分钟** |
| 预告 | 开窗前 5/1 分钟全服 title + 菜单灾厄 lore 刷新「进行中」 |
| 进入 | 窗内：`/dp start EmberCalamity` 或 TrMenu「奔赴灾厄」 |
| 窗外点击 | `§c灾厄未苏醒。下一窗：§f%next_window%` |
| 人数 | 实例内建议 1～5（或公共园区，插件任选） |
| 个人领奖 | **每窗可参战；每日宝箱只领 1 次**（防三窗刷爆） |

### 2.2 Boss 与波次文案

**Boss 占位 MM：** 可先复用 `EmberCryptBrute` 高血皮，Display 改为 `§4余烬灾厄·灰烬巨像`；正式由怪物岗做 `EmberCalamityColossus`。

| 阶段 | 条件 | 播报文案 | 怪意图 |
|------|------|----------|--------|
| 开场 | 进本 / 开窗 | `§4灾厄降临时刻。§7灰烬巨像自地脉升起——打掉它的外壳！` | Boss 入场 |
| 阶段 1 | Boss HP > 70% | `§7外壳坚固。先削甲！` | Boss 单体 |
| 添头 A | HP ≤ 70% | `§c地脉裂口涌出亡灵！` | 僵尸×4 + 骷髅×2 |
| 阶段 2 | HP ≤ 40% | `§4巨像狂暴——注意砸击！` | Boss 技能更频（怪物岗） |
| 添头 B | HP ≤ 40% 时一次 | `§c第二波裂口！` | 蛮兵×1 + 僵尸×3 |
| 斩杀 | HP ≤ 5% | `§e巨像将溃。§7全力输出！` | — |
| 击杀 | Boss 死亡 | `§a灾厄暂息。§7全服共享了这一剑。` | 结算 |
| 失败 / 超时 | 10 分到或团灭 | `§c灰烬再度合拢…下次窗口再见。` | 无通关箱 |

## 5. 验收（策划标准）

1. 菜单深渊 / 灾厄 **无**「即将点燃」，可进子菜单并触发 `dp start …`。  
2. 无深渊票无法进 EmberAbyss；有票进本扣 1。  
3. 深渊撤离后按最高层发结算箱（表 1.4-B）。  
4. 灾厄非窗口提示下一窗；窗口内可进；Boss 死后发参战掉落；日箱每日仅 1。  
5. 不破坏日 / 周本既有数值与冒烟路径。
