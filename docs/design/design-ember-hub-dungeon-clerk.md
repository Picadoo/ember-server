## 1. 站岗表（功能锚）

| 功能锚 | NPC id | 显示名 | 位置（世界 + 精确站位） | 右键主交互 | 副交互 | 备注 |
|--------|--------|--------|-------------------------|------------|--------|------|
| 日常选本场景锚 | `ember_dungeon_clerk` | `§e门吏 · 灰钥` | `ember_hub` **(-14.5, 58.0, 110.5)** yaw **90** | tell 2～3 句 → 打开 TrMenu **`ember_daily`** | 旁立体力提示牌（可选，见 §4） | **唯一**主交互=选本；无对话树分支 |

**显示名定稿：** `门吏 · 灰钥`（色码 `§e`）。  
理由：与灰烛 / 灰粮同「灰」族好认；「钥」点选本开门，比旧占位「烬扉」更贴体力选本。旧稿「余烬门吏 · 烬扉」作废，统一本 id。

**站位理由（勿挡现岗）：**

| 已有锚 | 坐标 | 与灰钥关系 |
|--------|------|------------|
| 出生 / MV spawn | (-18.5, 58.0, 110.5) yaw 180 | 灰钥在其 **正东约 4 格**，转身即见 |
| 灰烛 `ember_guide` | (-16.5, 58.0, 106.5) | 北侧；不重叠 |
| 烬砧 `ember_smith` | (-11.5, 58.0, 105.5) | 东北工棚；灰钥不挡棚门 (-9,58,105) |
| 余晶 `ember_enchanter` | (-21.5, 58.0, 104.5) | 西侧；无干涉 |
| 灰粮 `ember_quartermaster` | (-18.5, 58.0, 114.5) | 南侧；无干涉 |

落地允许 ±1 格避碰撞；**菜单绑定与 id 不变**。yaw **90** = 面向西，正对出生点一带玩家。

## 2. 右键交互（唯一主路径）

对齐工坊：`tell` → `trmenu open <menu>`；**禁止**教 `/corerpg` `/dp` `/hub` `/ember`（`/ember` 可继续作管理/菜单底层，但不进话术）。

### 2.1 短对话（2～3 句，定稿）

```
§e灰钥：§f日常窟靠体力进。顶栏能看见还剩多少，一条扣 30，0 点回满。
§7庭院、焦骨、地窖、潮蚀、断塔、霜晶、锈轨——点菜单选一条。
§e灰钥：§f点开选本。不够体力就改天或用药。
```

实现可合并为 2 条 tell（把第 3 句并入第 1 或第 2），**不得少于**：① 体力语义；② 七线一句提。

### 2.2 菜单

| 项 | 值 |
|----|-----|
| TrMenu id | **`ember_daily`**（现网体力选本页；与枢纽图标 H 跳转同页） |
| 打开时机 | tell 之后立刻 `open` |
| 副交互 | **无**（不做强化/生活/主线分流；不做「仅 tell 不开菜单」） |

### 2.3 `hub_npcs.yml` 草案字段（给插件，未批准不落盘）

```yaml
  ember_dungeon_clerk:
    enabled: true
    id: ember_dungeon_clerk
    name: '§e门吏 · 灰钥'
    world: ember_hub
    x: -14.5
    y: 58.0
    z: 110.5
    yaw: 90.0
    action: daily          # 或复用通用 open_menu
    tell: |-
      §e灰钥：§f日常窟靠体力进。顶栏能看见还剩多少，一条扣 30，0 点回满。
      §7庭院、焦骨、地窖、潮蚀、断塔、霜晶、锈轨——点菜单选一条。
      §e灰钥：§f点开选本。不够体力就改天或用药。
    menu: ember_daily
    open_menu: true
```

灰烛仍由 QuestService 管理，**本条不改灰烛**。

## 7. 验收硬条

1. `ember_hub` 可见 Ady NPC id=`ember_dungeon_clerk`，显示名含「门吏 · 灰钥」。  
2. 站位在 **(-14.5±1, 58, 110.5±1)** 一带，**不重叠**烬砧/余晶/灰粮/灰烛碰撞箱。  
3. 右键 → 出现体力选本文案（含体力 + 七线提法）→ **打开 `ember_daily`**。  
4. 无 Citizens；无教玩家打指令。  
5. 不改体力上限/日切/单次 30。  
6. 灰烛主线 talk、工坊三岗右键 **回归仍正常**。  
7. 萌新路径抽检：出生点 → 东侧见灰钥 → 右键进选本，**不依赖**先翻枢纽菜单大海。
