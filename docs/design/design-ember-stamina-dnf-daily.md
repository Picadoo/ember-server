## 2. 动线

### 2.1 路径表（日常 MVP）

| 步骤 | 世界 / 区域 / 落点 | 玩家看到或点击什么 | 发生什么 / 下一步 | 失败、撤离与回枢纽 |
|---|---|---|---|---|
| 1. 入口 | `ember_hub` | `/ember` 或右键门吏 →「日常地下城」 | 打开选本菜单，顶栏显示体力 `当前/上限` | 体力不足：按钮灰显 + 短提示「体力不足，明日 0 点恢复」 |
| 2. 选本 | 菜单 `ember_dungeon_daily` | 点击「余烬窟·庭院」（MVP）；另两条灰显「筹备中」 | **先校验体力 ≥ 消耗 → 扣体力 →** `dp start EmberDaily`（底层，勿写入 lore） | 扣费失败 / 进本失败：退还本次体力（插件硬条） |
| 3. 落点 | DP 实例 · `ember_daily` 门廊 | 有顶/半露天门廊，前方第一道门关闭 | 安全区；前方提示「清尽前厅再开门」 | 打开枢纽菜单可撤；未通关无通关箱 |
| 4. 房 1 | 前厅 / 回廊段 A | 清波；门上锁→清完开门（脚本阶段） | 推进到房 2 | 同撤离 |
| 5. 房 2 | 回廊段 B / 侧厅 | 混编怪；第二道门 | 推到 Boss 厅门 | 同撤离 |
| 6. Boss | 中央抬高垫 / 终厅 | Boss 蛮兵；可风筝 | 击杀 → 通关箱 + `daily_clear` | 超时/团灭：按现 DP 失败语义；体力 **不退**（已消耗的冒险） |
| 7. 回枢纽 | 自动 `ember_hub` | 结算消息 | 菜单可再选本（体力够则继续） | — |

### 2.2 地图与观感说明

- **独立 map 名：** MVP = `ember_daily`（在 P4 庭院意象上 **拉长为门廊→分房→Boss**，禁止再缩回 5×5 石盒）。
- **入口落点：** 门廊内侧，面朝第一道门；3 秒内知道「往门里走」。
- **战斗区：** 掩体柱 / 回廊转角 / Boss 垫抬高 1；**禁止**整盘同 y 空平面。
- **撤离：** 牌 + 枢纽菜单；通关自动回城。
- **边界：** 脚本阶段可先在旧坐标测「开门」逻辑；**宣称 S1 视觉完成**必须分房门廊可辨，且与周本/深渊俯视可区分（承接 P4 否决条）。

# A. 体力（Stamina）

显示名玩家侧：**余烬体力**（短称「体力」）。底层账户字段建议：`stamina` / `staminaMax`（CoreRpg PlayerData）；**进本扣费走 CoreRpg API**，TrMenu / DP 条件读 PAPI，**禁止**教玩家打指令。

## A.1 日回复与上限（建议值 · 平衡一次算）

| 项 | 建议 | 说明 |
|----|------|------|
| 时区 | **Asia/Shanghai** | 与现 `cash.yml` `timezone` 一致 |
| 日切 | **每天 0:00** | 将体力 **回复至上限**（未超出上限的溢出不保留；见药剂规则） |
| 基础上限 | **90** | 对齐旧「日免费约 3 次日常」体感 |
| 月卡上限加成 | **+30**（上限 120） | 便利，不直加伤害 |
| 自然回复（可选二期） | 不做 / 或每 10 分钟 +1 | **MVP 不做在线滴答**，只做 0:00 回满，降低复杂度 |

> 最终数字由平衡一次计算验收；本稿锁定 **比例关系**：日常最便宜，团本最贵，日免费日常次数感 ≈ 3。

## A.2 各玩法消耗（建议）

同一体力池；进本（或确认进场）时扣除；**失败不退**（灾厄见例外）。

| 玩法 | 建议消耗 | 旧票对照 | 日/周体感（上限 90） |
|------|----------|----------|----------------------|
| 日常地下城（任一线） | **30** | `ticket_ember_daily` ×1 | ≈ 3 次/日 |
| 周常本 | **45** | `ticket_ember_weekly` ×1 | 与周 1 次对齐时可另加「每周免费抵扣 1 次」或纯体力 |
| 精英试炼 | **40** | `ticket_ember_elite` ×1 | 周频 |
| 深渊 | **30** | `ticket_ember_abyss` ×1 | 日 1 次感 |
| 灾厄 · 奔赴 | **0** | 无票（窗期） | 社交窗；领奖仍日限 1 |
| 团本 | **50** | `ticket_ember_raid` ×1 | 周频 · 最贵 |

**周本/精英/团「每周免费 1 次」兼容方案（推荐）：**  
日切只回体力；另设 `weekly_grant_credit`（周一本类抵扣券，**账户计数非 NI 票**）：周本/精英/团各 1 次「本周首次免费」（不扣体力），第二次起扣表内消耗。这样月卡党与零氪周节奏与旧「周发 1 票」接近，又去掉票券背包观感。

| 位置 | 内容 |
|------|------|
| 枢纽 / 选本菜单顶栏 | `§e体力 §f%corerpg_stamina%§7/§f%corerpg_stamina_max%` |

## A.4 与现 `ticket_ember_*` 迁移（推荐方案）

**推荐：停发 + 限时兑换为体力 + 逾期自动折算（补偿体力）。不作默默作废。**

| 阶段 | 动作 |
|------|------|
| T0 上线体力 | 停止一切 **新发放** 票（登录免费、月卡、战令、商城、主线奖励里的 `ticket_ember_*` 改为体力或体力药） |
| T0～T0+7 日 | 背包/仓库/邮件中的旧票：生活菜单「旧票兑换」→ 按下表折算体力（可超额暂存到 `staminaBank`，日切时先填满上限再留银行，或兑换时允许溢出持有至 `staminaMax + bank`） |
| T0+7 后 | 登录时 **自动** 按同表折算并清除剩余票；聊天一条：`旧日票已折算为体力`（不提命令） |

**折算表（建议）：**

| NI id | 显示名（旧） | → 体力 |
|-------|--------------|--------|
| `ticket_ember_daily` | 余烬日票 | **+30** |
| `ticket_ember_weekly` | 余烬周票 | **+45** |
| `ticket_ember_abyss` | 余烬深渊票 | **+30** |
| `ticket_ember_raid` | 余烬团本票 | **+50** |
| `ticket_ember_elite` | 余烬精英票 | **+40** |

**进本逻辑：** DP / 菜单条件改为 `stamina >= cost` + CoreRpg `consumeStamina`；**不再** `<item:余烬日票>`。顺带关掉 B0.1「显示名扣票」债务。

**主线 / 战令 / progress.yml：** 凡 `ticket_ember_daily: N` 改为 `stamina` 直加或 NI `consumable_ember_stamina_30: N`（体力药）。

## A.5 商城 / 月卡 / 战令（原「买票」）

红线不变：**不直售战力**；便利有硬顶，**禁直售过肝**（无限体力）。

| 旧 SKU | 新 SKU | 规则 |
|--------|--------|------|
| 日票 ×1（60 晶钻） | **余烬体力药 · 小** `consumable_ember_stamina_30`（+30） | 日限购 **3**；且当日「药剂回复总量」≤ **90**（≈旧 hard_cap 6 次日常的一半偏紧，或订 **≤90** 与免费叠加后日常最多约 6 次：90+90） |
| 周票 ×1（180） | **余烬体力药 · 周**（+45）或「周本免费抵扣 +1」 | 周限 1；不与日常药剂池混算也可 |
| 月卡每日日票 | 每日登录：**币 200 + 体力 +30**（计入药剂/日回规则：建议 **直接加当前体力，受上限裁剪，溢出进 bank 上限 30**） | 立即票 → 立即 +30 体力 |
| 战令付费轨日票×5 | 分散发 **体力药·小 ×5** | 同日限 |
| 首充日票 | 改体力药或一次性 +60 体力 | — |

**推荐硬顶表述（玩家可见）：**  
`今日体力（含药剂）最多支撑约 6 次日常`——实现上用「日药剂回体 ≤ 90」+「基础上限 90」表达，避免再发「票」。

# B. 日常 DNF 式

## B.1 对标与同服约束

| 对标点 | 落在余烬 |
|--------|----------|
| 选图进本 | TrMenu 选线 → 扣体力 → DP 实例 |
| 疲劳 | 统一 **余烬体力** |
| 房间门推进 | 脚本阶段：清房 → 开门 → 下一房 → Boss |
| 短本爽感 | **目标通关 5～8 分钟**（熟手偏 5，摸索偏 8） |
| 同服多世界 | Multiverse 常驻 + DP 实例；**禁止一图一服 / 拆 Paper** |

## B.2 线路规划

见 §2.2 表。MVP 只做 **余烬窟·庭院**；B/C 菜单可显示但灰显「筹备中」。

## B.3 MVP 本内结构（建议波次 · 平衡可改）

| 阶段 | 空间 | 建议内容 | 时长感 |
|------|------|----------|--------|
| 门廊 | 安全 | 无伤；看第一道门 | 15～30s |
| 房 1 | 前厅 | 僵尸为主 ×4～6；清完开门 | ~1.5–2 min |
| 房 2 | 回廊/侧厅 | 僵尸+骷髅混编 ×5～7；清完开 Boss 门 | ~2–2.5 min |
| Boss | 中央垫 | 蛮兵 ×1；可略加小添头 ×0～2（可选） | ~1.5–2 min |
| 结算 | — | 通关箱 + `daily_clear` + 回枢纽 | — |

**开门叙事：** 门用障碍方块/门扉；阶段完成 `$setblock` 开门或撤屏障；播报短句「前厅已清 · 门开了」（勿命令）。

承接 P4：回廊 + 中央垫意象保留，但 **必须拉出独立前厅与第二房**，不能「同一院子三波刷怪」冒充分房。

## B.4 进本动线（汇总）

`枢纽菜单选本 → 校验并扣体力 → DP 实例落门廊 → 分房开门 → Boss → 结算回枢纽`

## B.5 验收硬条（好玩 + 非换皮 + 菜单无指令）

1. **菜单无指令：** 选本 / 进本 / 撤离玩家可见文案无 `/dp` `/corerpg` `/hub` `/mvtp`。  
2. **体力：** 不足无法进；成功进本准确扣 30；进本失败退还。  
3. **分房：** 存在 ≥2 道「先清后开」的门（或等价屏障），Boss 在独立终厅。  
4. **时长：** 内部测试通关落在 **5～8 分钟**（允许 ±1 分钟记债务，不记 PASS）。  
5. **非换皮：** 与周本/深渊俯视或进本 5 秒观感可区分；禁止复制他图改名。  
6. **同服：** 仍为本服 MV + DP；无单独日常服。  
7. **好玩（挑刺标准）：** 门廊方向清晰；房 2 有站位变化（混编/掩体）；Boss 有垫上可风筝空间——`余烬-挑刺玩家` 抽检不出现「三波同房换皮」。
