## 0. 一段话

烬砧把“印记保底”和“词条养成”收进一个台子，分 5 个按钮：
**兑换**（不变的地板：8 枚印记换刃 / 护符的标准件，护甲 4 枚）、
**随机锻造**（同样的印记 + 4 胚料 + 500 币，选族选部位，成色 / 精工随机，但**出不了极品**）、
**烙纹定向**（用新材料「余烬烙纹」直接写入**指定的词条类型**，档位照 D143 随机，第 6 次保底不变）、
**锻造次数**（每件 13 次，洗练和定向都扣 1 次）、
**每周转化**（每周 1 次，把同阶同部位的异族件改成目标族，成色最高保留到卓越）。
不加新槽位、不加乘区、不加宝石孔，不加攻速 / 暴伤 / 冷却词条；成色表、精工表、词条表都不变，所以**数值天花板不变**。模拟里双极品时间线（W30）在两条后期路线上都 **±0.00 周**。

## 1. 白话版（给服主 / 玩家）

- **兑换照旧**：攒够 8 枚同阶印记，换一件你指定族、指定部位的标准件（刃或护符）。6 槽上线后护甲也能换，只要 4 枚。
- **想赌一把就用随机锻造**：同样花印记，再加 4 个胚料和 500 币，出来的件成色 / 精工是随机的（大多数是标准，偶尔精良 / 卓越），最差也等于兑换。它**不会出极品**——极品还是只能打出来。平均下来它省下的养成材料和多花的胚料 / 币差不多，所以它是“同价的赌”，不是捷径。
- **烙纹：词条类型自己选**。护符想要「抗缀纹」就直接写「抗缀纹」，不用在 3 个里碰运气；档位还是随机（被成色截住），连续 5 次没到上限，第 6 次必到。烙纹用 40 碎片在烬砧换 1 个，一次定向（T3）用 6 个烙纹 + 1000 币，正好等于一次“锁定洗练”的价。
- **每件装备有 13 次锻造次数**。洗练（锁不锁都算）和烙纹定向每次扣 1。只要你不中途换词条类型，13 次永远够用；想反复换类型就会用完，用完只能换底子。小提示：**先把成色养上去，再定向**，次数最省（平均 4 次，最多 6 次）。
- **每周一次转化**：拿一件同阶同部位的“错族”件，改成你要的族。强化归零（可以先用「互换」（§6.3 强化轨迹互换）把强化挪到别的件上），成色最高保留到卓越（极品转过去会变卓越，所以没人会拿极品去转）。

## 3. 规则与准确数值

### 3.1 兑换（地板，已上线规则 + 扩部位）

| 项 | 值 |
|---|---|
| 价格 | 刃 / 护符：**8 枚**同阶印记（`MARKS_PER_EXCHANGE = 8`，不变）；护甲：**4 枚**（Stage 1 后） |
| 产物 | 指定族、指定部位、该阶，**标准、精工 0、+0、词条槽空**；`src = drop`（可分解、可当洗练重复件，和现在一样） |
| 门槛 | 不变：T2 需 Q04 首通、T3 需 Q07 首通（`directedForgeFlag`） |
| 其它材料 | 无 |

### 3.2 随机锻造（新）

| 项 | 值 |
|---|---|
| 价格 | 兑换的印记数（刃 / 护符 8、护甲 4）+ **4 胚料 + 500 币**（T1–T3 同价；§5.3 养成本来就不分阶） |
| 护甲价 | 印记 4 + 胚料 / 币按 Stage 1 定下的“护甲养成折扣”同比打折（若护甲养成为半价 → **2 胚料 + 250 币**） |
| 族 / 部位 / 阶 | 玩家选族、选部位；阶 = 印记的阶 |
| 成色 | `[70, 23, 7, 0]` = §5.1 掉落表把极品的 1 并进卓越。**永远不出极品**（与 §5.3「极品只从正常随机掉落获得」一致） |
| 精工 | `[70, 20, 9, 1]`（§5.2 原表，精工可用 §5.3 买满，不影响天花板） |
| 强化 / 词条 | +0；词条槽空（可以在同一次确认里捆一次烙纹定向，见 3.3） |
| 保底 | **没有**成色保底（卓越本来就能用 §5.3 固定价买到，保底只会让锻造比养成更便宜） |
| 来源标记 | 物品 `src = drop`（和兑换件一致：可分解、可当重复件；回滚 / 撤销逻辑不用分叉）；出处记在 `cr_p1_txn.kind = forge_roll` |
| 门槛 | 同兑换 |

**为什么这个价**：随机锻造一次“省下的 §5.3 养成”期望 = 5.14 胚料 + 6.22 骨粉 + 514 币（`forgesim odds`）。多收 4 胚料 + 500 币 → 期望大约持平，差额是骨粉。玩家想稳就“兑换 + 养成”，想赌就锻造，两条路都不比现在快出极品。

**分解检查**：T3 随机锻造 = 8 印记 + 4 胚料 + 500 币，分解得 3 胚料 → 净亏，不能刷胚料。

### 3.3 余烬烙纹与定向（新）

| 项 | 值 |
|---|---|
| 材料 | 「余烬烙纹」`mat_ember_brand`（NI 材料，可堆叠、可进仓库） |
| 获取 | 烬砧合成：**40 余烬碎片 → 1 烙纹**（确定、不可逆）。以后可以把它加进挑战 / 周常奖励（调研 §3.5），本 D 不加 |
| 定向价 | T1 / T2 / T3：**2 / 4 / 6 烙纹 + 300 / 600 / 1000 币**（= `reroll.shard + reroll.lock_shard` 的碎片价 + `reroll.coin`，即一次锁定洗练的价）；T0 不开 |
| 效果 | 选该部位池里一个**可洗**词条类型（现行：刃 猎缀纹 `b_affix` / 余烬纹 `b_set`；护符 定身纹 `c_tele` / 分核纹 `c_share` / 抗缀纹 `c_affix`；`rollable: false` 的不能选——现在是裂身纹 `b_split`，以后 sidegrades 包若让余烬纹 / 定身纹退池也自动跟随；Stage 3 护甲词条池同理），档位 = `EmberAffix.roll(rules, slot, quality, pity, rng, lockId = 选的类型)` → 截在成色上限、用 `[50, 30, 15, 5]` 归一，共用 `p4_afp_<uid>` 保底：连续 5 次没到上限，第 6 次直接给上限 |
| 已有词条时 | 和洗练一样给 [保留新] / [保留旧]，不选 = 保留旧，花费不退 |
| 次数 | 扣 1 次锻造次数（3.4） |
| 之后 | 用现有“锁定洗练”追档位（D148，每次 shard + lock_shard + coin） |

模拟（T3，`forgesim affix`）：极品护符追到 4 档，D143 不锁→锁 平均 6.25 次 / 1137 碎片 / 6253 币；烙纹定向→锁 平均 5.29 次 / 1270 碎片 / 5293 币，**最坏 6 次**。标准护符：1 次 240 碎片（原来平均 3.02 次 / 362 碎片）。定向不改变能到的档位，只把“碰类型”的运气换成固定价，所以对天花板 0 影响；碎片总价大致持平，省的是币和方差。

### 3.4 锻造次数（新）

| 项 | 值 |
|---|---|
| 上限 | 每件 **13** 次（刃、护符、4 件护甲一样；yml 可改成只对护甲） |
| 扣次数 | 每次洗练（碎片 / 重复件、锁不锁）和每次烙纹定向扣 1；在付款成功时扣，保留旧不退 |
| 不扣 | 强化、精工、成色养成、升阶、互换、转化 |
| 用完 | 洗练和定向按钮灰掉：「锻造次数已用完，只能换底子」；其它养成照常 |
| 存法 | PlayerData `p4_afc_<uid>`（period `all`，存“已用次数”，所以**上线时所有旧件自动满 13 次**，过去洗过的不算） |
| 为什么 13 | 能被逼出来的最长“单一词条”路线 = 标准件定向 1 + 养到精良后 ≤6 + 养到卓越后 ≤6（保底计入）。不改主意的玩家**永远不会**被卡住；护符想换类型大约只够换一次 |

模拟：先定向再养成（标准→精良→卓越）平均 7.59 次、P90 11、最坏 13；超过 10 次 12.5%、超过 12 次 4.1%、超过 13 次 0%。先养成到卓越再定向：平均 4.09、最坏 6。→ 10 次会误伤 1/8 的正常玩家，所以取 13，并在定向预览里提示“先养成色再定向更省次数”。

### 3.5 每周转化（新，Stage 2）

| 项 | 值 |
|---|---|
| 次数 | 每角色每周 **1** 次（周键 `p4_conv_w<周号>`，用与团本周上限同一个周函数） |
| 输入 | 手持一件 T1–T3 装备（族 A、部位 S），选目标族 B ≠ A |
| 结果 | **同一 uid** 原地改成族 B、部位 S、同阶；精工、词条、词条保底、锻造次数都保留；**成色 = min(原成色, 卓越)**；**强化归零**（预览里提示可以先用「互换」挪走强化）；结果绑定 |
| 价格 | T1 / T2 / T3：**2 / 4 / 6 胚料 + 300 / 600 / 1000 币**（护甲按 Stage 1 折扣） |
| 门槛 | 同兑换（T2 需 Q04、T3 需 Q07） |
| 为什么截在卓越 | 保留极品的版本让双极品 W30 提前 **2.10 周**（轮换 + 团本）/ **1.53 周**（深渊），远超容差；截在卓越则 **±0.00**（卓越本来就能用 §5.3 买到） |

转化真正的用处在 Stage 2：4 件效果要 2 件同族护甲（≥T2），转化让“好成色的错族甲”能补进来；对核心件只是省一段 §5.3 养成。模拟里核心件每周只用到 0.06 次（追极品时很少恰好有一件更好的错族卓越件）。

## 4. 模拟证据（`tools/p1sim/forgesim.py`，`out-forgesim-d167.md`）

### 4.4 w30：Q07 之后两件极品（刃 + 护符，目标族，T3）

结论：
- **提案对双极品时间线 0 影响**（W30 / P50 两条路线都 ±0.00）：锻造和转化都拿不到极品，极品仍只从掉落来。
- “锻造也能出 1% 极品”在轮换 + 团本路线上即使涨到 16 印记一次仍提前 0.58 周（超调研 ±0.5），8 印记提前 1.03 周（超 0.7）→ 否决。原因：这条路线印记多（21.5 / 人·周）、币不缺，印记几乎全变成额外的极品抽奖。
- 转化保留极品提前 1.5–2.1 周 → 否决。
- 资源：轮换路线全用印记锻造约 2 次 / 人·周 = 983 币 + 7.9 胚料；深渊路线 0.74 次 = 370 币 + 3.0 胚料（模型的深渊印记 10.8 / 周低于 D144 的 18.5，因为失败局不给印记；深渊玩家还要拿多余 T3 印记抵层费 200 币 / 枚，锻造与抵费二选一）。

模型局限：只模拟核心两件的追逐，不模拟战斗、不模拟 6 槽护甲（Stage 0 sim 负责）；基线曲线后段比 D144 稍快（第 12 周 54% vs 46%），所以只看各方案之间的差值。

## 5. 漏洞审查

| # | 风险 | 现状 / 结论 | 设计里的处理 |
|---|---|---|---|
| X1 | 断线 / 崩服重复扣费或白拿（双花） | 兑换现在是“PlayerData 扣印记计数”和“写 ledger 待发货行”两次写入，中间崩服可能丢件或重复（不在 A01–A04 耐久模式内） | 兑换、随机锻造、定向、转化、烙纹合成全部走 `payDurable`：先插 hold（`cr_p1_delivery status=hold`，`refund:<rid>`）→ 扣材料 / 币 / **印记** + `p1paid_<hash>` 标记，同步存档 → 一个 COMMIT 里写物品 + txn + 作废 hold。失败 → `releaseHolds` 只退一次；崩服 → 进服 `reconcileHolds`。**兑换部分 1.65.5（D172）已做**：`EmberPay` 扣印记 → `commitCreate` 一个事务写物品行 + txn + 待发货行 + 作废 hold |
| X2 | 不满意就断线 / 取消来“重抽” | 随机结果若在扣费前或提交前可见就能 SL | RNG **只在付款落盘后**抽，种子 = 服务器盐 + 玩家 + rid；结果在 COMMIT 后才显示；同一 rid 重放直接返回原结果（`cr_p1_txn` request_id 已有 replay 检查） |
| X3 | 保底计数操纵 | 定向用同一个 `p4_afp_<uid>`；6 次保底只保档位不保类型 | 不新增计数；定向和洗练共用保底，不能“先定向刷保底再换类型”占便宜（换类型本身要花次数） |
| X4 | 印记复制 | 印记是 PlayerData 计数 `p1_mark_t<阶>`，退款要能退回计数 | `EmberDelivery` 加 `mark` 欠款类型（写 PlayerData 计数，与 `p1dlv_<id>` 标记同一次保存）；印记扣减移进 `pay()`。**1.65.5（D172）已做**（`EmberDelivery` `mark` 类型；兑换退款走它） |
| X5 | **分解 / 撤销竞态（现存漏洞，锻造会放大）** | `EmberGearLib.undo` / `undoBatch` 在主线程检查胚料够不够，异步提交，**之后**才用负数送货行扣胚料。中间把胚料花掉（例如锻造），扣款只记 warning（`EmberDelivery` “debit short”），玩家同时留下撤销回来的件和花掉的胚料 | ① 撤销改成先 hold → pay（预先扣胚料）→ commit；② 在修好之前，锻造的 `lacking()` 把“待处理的负数材料送货行”当作不可用；③ 修复列为烬砧实现的**前置**（§6.6）。**1.65.5（D172）已修 ①**：撤销 / 批量撤销 = hold → 先扣胚料 → commit，扣不到就什么都不做；不再写负数送货行，② 不再需要 |
| X6 | 装备库 / 自动存放 | 物品在装备库时 `doTxn` 的 owner / rev / state 检查能挡住双用 | 转化、定向要求手持（同现行洗练 / 强化），装备库里的件不能直接操作 |
| X7 | 锻造件当洗练重复件 | 兑换件本来就能当重复件（`duplicateOk`：同部位同阶、src drop、无投入） | 随机锻造件同样；它比兑换件贵（多 4 胚料 + 500 币），当重复件只省 120 碎片，不构成套利 |
| X8 | 锻造 → 分解刷胚料 | 分解给 `tier` 胚料 | 锻造多收 4 胚料 > T3 分解 3 → 净亏 |
| X9 | 转化循环 | 原地改族；极品会被截成卓越 | 每周 1 次；成色只降不升；强化归零；绑定。A→B→A 不产生任何东西，只花材料 |
| X10 | 转化洗掉“已投入”判定 | `duplicateOk` 要求无投入 | 转化后的件绑定且保留词条，算“有投入”，不能当重复件 |
| X11 | 锻造次数绕过 | 次数按 uid 存；转化保留 uid | 转化、升阶、互换都不重置次数；物品被分解 / 删除后计数作废（新 uid 新计数，但新底子本来就是“换底子”） |
| X12 | 回滚安全 | 物品 `src = drop`，和兑换件一样，没有新的来源分支 | 出处只在 `cr_p1_txn.kind`（`forge_roll` / `forge_pin` / `forge_convert` / `forge_redeem` / `brand_craft`），回滚工具按 txn 识别 |
| X13 | 管理员 invsnap 回档 | `EmberAssetGuard.hold()` 在回档 / 写失败时冻结 | 烬砧所有操作先查 `EmberAssetGuard`；InvSnap 账本要记录烙纹、印记的支出（vault log），否则回档会把花掉的材料还回来 |
| X14 | 并发连点 | 洗练有 `rerollBusy`，锻造有 per-uid busy | 烬砧用**按玩家**的 busy 键 + `ConfirmTokens` 一次性确认 + 每玩家递增 rid（`p4_fseq`） |
| X15 | 现行洗练本身不耐久 | `EmberGrowthService.reroll` 先 `takeCoin` + `ni.consume` 再 `ThreadLocalRandom` 抽、改 PlayerData，币 / 碎片 / 计数分开保存 | 加锻造次数时顺手把洗练和定向一起迁到 `payDurable`（同 X1），否则“扣了次数没扣碎片”之类的组合会变多。**1.65.5（D172）已修：** hold → 扣币 / 碎片 + “欠一次结果”计数同一次存档 → ledger 行（或重复件退役）提交 → 才用 `seed(盐, 玩家, rid)` 抽，写结果的那次存档清欠款；断线 / 崩服 = 退一次，或下次进服补同一次结果 |

## 7. 不做什么

- 不加新槽位以外的东西：没有宝石 / 插槽，没有攻速、暴伤、冷却词条（P1 书 §7.2），没有新乘区。
- 成色表、精工表、词条档位表、洗练价不变；极品仍只从掉落来。
- 不给随机锻造成色保底，不让锻造件 / 转化件出极品。
- 烙纹不按词条类型分成多种材料（5+ 种 NI 物品、背包噪声大），也不能拆回碎片。
