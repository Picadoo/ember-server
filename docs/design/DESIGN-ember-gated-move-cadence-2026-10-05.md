# D194 · 半血招冷却重锚（CoreRpg 1.65.32，2026-10-05）

> 状态：**已上线 CoreRpg 1.65.32 / D194 / balance_version 55**（`COORD-routine-1016`）。来源：09:44 合批冒烟（`docs/tests/smoke-2026-10-05-batch-1.65.29-31.md`）发现 Q07 第 2 次「炉心聚爆」在第 1 次之后约 7 秒就来了。

## 问题

首领招表里带 `below`（半血门槛）的顶层招，冷却和其它招一样从首领出生起按网格排（§10.I：25 / 50 / 75 …）。门槛没开时它的格子过去了就一直挂着「已到点」，所以一过半血立刻放第一次（这是想要的：半血转阶段马上有反馈）。但放完之后旧代码 `nextDue` 只是沿原网格往后找下一个格子：若半血发生在 68 秒，第一次在 68 秒放，第二次却在 75 秒，只隔 7 秒，而不是一整个 `every`。

受影响的顶层半血招：Q02 门廊突刺（every 40）、Q03 焦冲（18）、Q06 霜潮汲取（25）、Q07 炉心聚爆（25）、R02 砸地（12）。follow 招不走网格，不受影响。

## 改法

- `EmberRunDirector`：每个首领招多一个 `gateOpened` 标记。带门槛（below ≤ 1.0）的招**第一次**放完，下次到点 = 现在 + every；之后照旧走它自己的网格（`gatedNext`）。
- 不带门槛的招完全不变（§10.I 网格、同帧先列先放、长停顿跳过错过的格子）。
- 余烬连战照旧：破招两招在连战里永不到点。
- 数值、奖励、掉落、词缀、事件、团本人数规则：**不动**。只是把半血招的节奏改成「一过半血放一次，之后每 every 秒一次」。

## 参照

- WoW / FF14 首领阶段转换：新阶段的技能计时器从转阶段那一刻起算，不沿用开战时的计时。
- 本服 p1sim：`p1sim.py` 对 break 招本来就是「门槛开时放，下次 = t + every」（D193 门禁就是按这个节奏算的）；其它半血招在模拟里只在网格点放、门槛前的格子丢弃。线上改完后，半血阶段每 every 秒最多一次，与模拟的平均频率一致，旧代码多出来的那一下「紧跟着又来」消失。

## 模拟门禁

模拟器本身不需要改：D193 `breakmove.py` 门禁（MAX_ABS_DPP 1.6，cap 3.0）用的已经是新节奏；其它半血招线上次数只会 ≤ 旧代码、与模拟频率对齐 → 难度只会略降或不变，**within range**。不另跑 W30。

## 漏洞审查

不碰奖励 / 次数 / 每周上限 / 资产路径。可能的利用：故意卡在半血线附近拖招？门槛只开一次（`gateOpened` 不会重置），首领回血也不会让它重新「第一次」→ 无法反复刷出「第一次之后的长冷却」。重试、断线、重进：每次首领出生都重新建表，与旧行为相同。
