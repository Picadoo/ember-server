## 0. 给服主的话（一页看懂）

**结论：后撤步不绑任何套装，也不当成第 4 个「身法变体」；改成身法的一个「方向」开关——技能页手动选「前冲 / 后撤」，一开始就有，三套都能用。**

- **后撤**：向后 4 格（前冲是 5 格），脸始终朝着原来的方向；无伤害、无无敌；和踏步共用同一个 14 秒身法冷却（切方向不会多出一次闪避）；挂机照旧不放。
- **焚烬的火痕步也能后撤**：切到后撤时，点燃改在**起跳点**（你离开的那块地方）3 格内最近的 1 个敌人，系数不变、仍只点 1 个。这个做法有现成的参考：PoE2 的「黑火药闪击」是替换闪避翻滚的跳跃，**点燃你逃离的那片区域**的敌人；WoW 恶魔猎手的「复仇回避」是后空翻离开，同时伤到身边的敌人。

**为什么这样定（§1 的调研）：**

1. **成熟游戏里，"往后闪"几乎从来不是一个单独解锁的招，而是闪避的一个方向。** 艾尔登法环：闪避键不推方向就是后撤步，推方向就是翻滚；暗黑 4、命运方舟、PoE2：朝你指的方向闪。闪避本身是人人一开始就有的基础动作。
2. **真有专门后撤技能的游戏，它是职业 / 武器身份的一部分，而且通常是"更差的闪避换朝向"。** 怪猎长枪只能小跳闪避，距离和无敌帧都不如翻滚，换来的是贴着怪不丢输出；艾尔登法环的后撤步距离更短、保护更少，但收招快、能接突刺。WoW 1.12 原版里猎人的"逃脱"甚至不位移，只是降仇恨（往后跳是后来的版本才改的）。
3. **在 Minecraft 里转身是一瞬间的事**：「后撤 4 格」和「转身 + 踏步 + 转回来」在数值上完全一样（D210 模型里也一样）。它真正多给的只是"边退边盯着首领、退完马上砍"的手感。这点手感**不值得占一个套装的 Q05 里程碑**：
   - 给 **炽愈**：等于给它一个比踏步还短的踏步，而焚烬同一时间拿到的是点燃——炽愈吃亏，而且炽愈回血靠"每 5 下命中"，往后退只会少打几下。
   - 给 **烬爆**：后撤唯一顺手的附加效果是"边退边把怪拉成一团好炸"，这就是 D210 已经否决的「聚火」（杂兵房快 4%～17%）换了个名字。
   - 给 **焚烬**：它已经有火痕步，一个位子只能放一个（暗黑 3 一招一个符文、PoE2 / WoW 的替换都是"替换"不是"叠加"）。
4. 所以最干净的做法是：**后撤是方向，不是变体。** 它不加强度（不需要新的模拟），不硬编套装亲和（满足 §4b），所有人都多一个手感。**烬爆 / 炽愈 在 Q05 的身法变体仍然是空的**——以后另开调研，不拿后撤步凑数。

**唯一新增的风险：往后闪看不见身后。** 所以后撤只落在**脚下有方块**的位置（不掉崖、不落岩浆 / 虚空），找不到就停在最后一个安全点；其余碰撞、门控和踏步完全同一套。

**下一步：** 等 CoreRpg 部署锁释放后一个小版本（§5 S1）就能做：改 4 处代码 + 单测，数值版本不动（bv57），冒烟进下一批合批。

### 1.2 从这些游戏里抽出来的规律

- **B-R1 · 基础闪避人人都有、一开始就有。** 暗黑 4 一级就有闪避，PoE2 / 方舟 / 魂系 / 怪猎都是基础动作。Ember 的踏步（Q01 就有）已经对上。
- **B-R2 · "往哪闪"是玩家的输入，不是解锁物。** 艾尔登法环的后撤步就是"不推方向的闪避"；暗黑 3 / 4、方舟、PoE2 都是朝玩家指的方向。**专门的后撤技能**只出现在位移跟着角色朝向走的游戏里（WoW 复仇回避"背对朝向后空翻"）——Ember 正是这种：踏步沿视线水平方向走（`EmberDash.tryDash`）。
- **B-R3 · 后撤比前冲"更差"，换来的是朝向和收招。** 艾尔登法环：后撤距离短、保护少、收招快、可接攻击；怪猎长枪：跳步距离和无敌都不如翻滚。后撤的价值是"人退开了，脸还对着敌人，马上能还手"。
- **B-R4 · 后撤如果带东西，带在起跳点。** 复仇回避伤到"身边"（起跳处）的敌人；黑火药闪击点燃"你逃离的区域"；暗黑 3 火痕伤"追你的敌人"。没有一个是"后撤到哪儿炸到哪儿"。
- **B-R5 · 一个位子一个，变体是替换，冷却不叠加。** PoE2「替换你的闪避翻滚」、WoW 真气突「替换翻滚」、暗黑 3 一招一个符文、哈迪斯一位一个祝福。没有任何一款让玩家同时拥有两个独立冷却的闪避。
- **B-R6 · 现代动作 ARPG 的闪避越来越少给无敌。** PoE2 翻滚不给无敌；暗黑 4 闪避过不了障碍；艾尔登法环后撤保护比翻滚少。这与 D212 的结论一致：在临界格里"活过最重一下"的价值极高，**不能给无敌帧**。
- **B-R7 · 位移带伤害要付代价，否则会被砍。** 暗黑 4 变身威能加伤害就加冷却；暗黑 3 火痕"靠高消耗限制成辅助"，1.04 一度过强；WoW 真气突 7.0.3 干脆去掉伤害。Ember 火痕步只点 1 个、套装同系数，已经是这一档的保守做法。
- **B-R8 · 变体从哪来，三种都有：** ① 职业 / 武器绑定（WoW、怪猎、方舟冷却）；② 装备决定（魂系负重、暗黑 4 威能、PoE2 / 怪猎的距离词条、暗黑 3 套装武器附带符文效果）；③ 玩家自选（暗黑 3 符文、PoE2 替换宝石、WoW 天赋二选一）。**但"往后"这个方向本身，在所有游戏里都不属于任何一种——它是输入。**

### 2.1 现有规则（不动）

### 2.3 后撤在 Minecraft 里到底多了什么

- 数值上：**什么也没多。** 同一个 14 秒冷却、无伤害、无无敌、距离还短 1 格。D210 模型里后撤步与踏步逐位相同（躲招已经在 `dodge` 里）。
- 操作上：玩家本来就能"甩鼠标转身 → 潜行 Q → 甩回来"。后撤让这一下变成**一个按键、视线不离开首领**——正好是艾尔登法环后撤步的定位（B-R3）。这对低操作玩家是便利，对会甩鼠标的人几乎没差。
- 所以它的本质是**输入便利**，按 B-R2 应该当方向，不该当一个要靠套装 / 里程碑去换的"新招"。

## 3. 推荐

### 3.1 定稿建议

**R-BS1 · 后撤是身法的方向开关，不是变体，不绑套装。**

| 项 | 建议 | 依据 |
|---|---|---|
| 形式 | 技能页「身法方向」：**前冲**（默认）/ **后撤**，二选一 | B-R2（方向是输入）；1.12 原版客户端服务端拿不到"按着 S"，只能用开关代替（§3.3） |

| 方案 | 为什么不 |
|---|---|
| 炽愈绑定，Q05 自动替换踏步 | 参考里防御身份配的是"更差的闪避"（怪猎长枪、魂系重负重），当 Q05 奖励发给炽愈等于发降级；要补效果就是生存强度 → D212 的老矛盾（§2.2） |
| 烬爆绑定 + 聚怪 / 减速 | 就是 D210 否决的聚火；复仇回避的减速在 WoW 是天赋、也是 25 秒冷却 + 少量伤害的整套设计，不能单拿来 |
| 技能页三选一变体（踏步 / 火痕步 / 后撤步） | 会把火痕步从"焚烬自动"改成"人人可选"，推翻 D214 的套装绑定；而后撤步本身在数值上等于踏步，选它就是"选一个更短的踏步"，择优 0（D210 "择优 0 = 设计失败"） |
| 后撤给无敌帧 / 短无敌 | B-R6；D212：活过最重一下价值极高，低操作格会被推高 |
| 后撤带伤害（落点爆炸等） | B-R7；会进主动伤害预算（≈10%），需要新 S0；而且参考里后撤的效果都在起跳点 |
| 直接搁置 | 可以，但"边退边盯首领"是零强度、全员受益的手感，做起来很小；搁置会让 D210 表上那一格永远挂着 |

### 3.3 输入方式：为什么用开关，而不是"按着后退键就后撤"

艾尔登法环 / 暗黑 / PoE2 的方向来自摇杆或鼠标。1.12 原版客户端按键不发给服务端，服务端只能从位置变化反推玩家在往哪走：潜行时移速只有约 0.3 倍、被击退时位移方向和按键无关，反推容易误判（想后撤却前冲，正好冲进首领的招里）。**开关是确定的**，所以 S1 用开关；"跟随移动方向"留作 S2 候选，要先看真人反馈。

## 4. 设计与漏洞审查

| # | 风险 | 处理 |
|---|---|---|
| B1 | **盲落**：身后是悬崖、虚空、岩浆，玩家看不见 | 后撤用严格落点：只接受 `snapGround` 找到实心方块 / 水的位置；现行 `tryDash` 在找不到地面时会接受"脚和头都能过"的半空点（前冲你看得见，后撤看不见），后撤**不接受**；脚下 / 落点方块是岩浆、火、仙人掌、蜘蛛网也不接受。找不到 → 退回最后一个安全采样点；不足 0.6 格 → 失败、不进冷却 |
| B2 | 穿墙 / 斜角缝 | 与踏步、烬突同一段 `tryDash`：路径上每 0.25 格查一次，遇实心方块就停，所以穿不过墙。**已有的小坑（三招共用）：** 只查中心点所在方块，斜着穿过两个只有角相接的方块时，可能从 0.6 宽的身体都不该过的缝里挤过去。S1 冒烟专门测一次；要修就三招一起修（另开小单，本稿不改） |
| B3 | 门控 / 跳房间 | 关着的铁栏门是实心 → 钳在门内。后撤是往来的方向退，后面是已清过的房间，没有"跳过未清房间"的问题；首领房门关着时也退不出去 |
| B4 | 首领撞墙破绽（D188 / 团本 D195） | 不新增交互。"背靠墙等首领冲过来再闪开"是设计里的正常打法（踏步也能做）；后撤不会把人放进墙里（遇墙就停），靠墙太近时后撤失败、不进冷却，不会白丢闪避 |
| B5 | 落空破绽（D192 / 团本 D195） | 后撤让"人在圈里 → 退出圈 → 首领踉跄 → 马上砍"更顺手（B-R3），这就是它的全部价值。数值上：冷却、距离、无无敌都不变，和"甩鼠标 + 踏步"等价；p1sim 把躲招当玩家水平（`dodge`），不按用哪种身法区分。天赋「回身斩」「踏步回气」和签名 L02 的回血按"躲开预警招"触发，不按放身法触发 → 不会一份闪避吃两份。接受；S1 冒烟看一眼 |
| B6 | 破招（D193）| 和破招计量无关（后撤无伤害）。Q06 / Q07 破招半径 5 / 5.5 格，贴身后撤 4 格不一定能完全退出——技能说明**不写**"能躲开破招" |
| B7 | 挂机 | 挂机不放身法（X7 不变），方向开关在挂机庭里没有任何作用 |
| B8 | 重试 / 刷冷却 | 失败（受阻）不进冷却是现行规则——失败时什么都没发生，没有可刷的东西；换方向只在副本外、换了冷却转满；后撤无伤害，没有可刷的触发；火痕·后撤每次仍只点 1 个 |
| B9 | 点燃快照毒化（C4） | 火痕·后撤用 `skillIgnite` ×1.0，只点 1 个；只是把搜索中心从落点换成起跳点 |
| B10 | PvP | P1 模式下竞技场被 S0-3 路由闸关着（D199；D201 另修了竞技场刷币），P1 副本里没有玩家对战玩法 → 本稿不涉及。若以后重开竞技场，后撤要单独过一遍（魂系 PvP 后撤的无敌帧本来就比 PvE 少 [B1]，说明 PvP 要另调） |
| B11 | 多人 / 团本 | 传送不和队友碰撞、不推人；不影响分摊 / 全员躲招判定（那些按站位算） |
| B12 | 半空释放 / 跑酷捷径 | 只水平移动、最多下落 1 格（同踏步）；后撤用严格落点后比前冲**更难**做空中位移，不会产生新捷径 |
| B13 | 朝向 | `tryDash` 把起点的 yaw / pitch 写进每个候选点，落地朝向不变；S1 冒烟确认客户端不会被"甩头" |

| B15 | 计数器注册 | 方向存 `p1_step_dir@all`（类别 SETTING，同 `p1_slash_shape@all`）；**必须**登记进 `EmberCounters`，否则 `EmberCountersTest` 扫描会失败 |

## 5. 分阶段计划

### 5.1 p1sim 能算什么、不能算什么

| 问题 | p1sim 能不能 | 说明 |
|---|---|---|
| 后撤（踏步）的通关率 / 用时 | 能，但**不需要新模型** | 无伤害、同冷却，模型里与踏步逐位相同（D210 §3 已写） |
| 火痕·后撤 | 能，**沿用 F14c0n1** | 模型里火痕步只是"每次放点 1 个"，不管在落点还是起跳点；起跳点在近战距离内更容易点到，但 F14c0n1 本来就按"冷却好就用、能点就点"的上界算（✅ 27/27，平均 0.17） |
| 朝向便利让低操作玩家多躲几次 | **不能** | 模型里躲招率是玩家水平参数，不分用的是哪种身法；只能做灵敏度（见 S0） |
| 盲落、斜角缝、门控、墙 | 不能 | 地形问题，只能靠单测 + 冒烟 |
| 首领 AI 对"边退边打"的反应 | 不能 | 冒烟看手感 |

### 5.2 阶段

| 阶段 | 内容 | 碰代码吗 | 验收 |

### 5.3 给下一个开发窗的清单

- 改动点只有 `EmberDash` / `FlexSkillService` / `EmberSkillKit` / `EmberCounters` + TrMenu `ember_skill_kit` + PAPI；**不碰**套装、签名、挂机、`ember-v1*.yml` 数值。
- D214 火痕步的"焚烬 + Q05 自动替换"不改；方向开关和它正交。
- 若严格落点让很多地图的后撤"总是失败"（比如地图边缘全是半砖 / 台阶），先在冒烟里记下来，再决定是否把台阶 / 半砖算作落脚（`Material.isSolid()` 对它们本来就为真，预计不是问题）。
