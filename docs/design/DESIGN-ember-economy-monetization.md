# 余烬服 · 好玩 & 可控 & 肝度 & 氪金 — 总设计

**日期：** 2026-09-12（Asia/Shanghai）  
**状态：** 设计锁定稿（先设计、后落地）  
**承接：** `docs/design/DESIGN-dungeon-daily-weekly.md`、`docs/design/DESIGN-ember-enchant-anvil.md`  
**落地规格（晶钻/日票/月卡）：** `docs/design/DESIGN-ember-cash-monthly.md` · 旋钮 stub `plugins/CoreRpg/cash.yml`  
**约束：** 不改方块；奖励只走 NI / MM / 副本结算；不装 Citizens；经济走 Vault 实现。玩家硬通货键 **`ember_crystal_cash`**。

---

## 0. 设计目标（一句话）

免费玩家 **每天 40～70 分钟** 能感到变强；挂机能补材料但不能跳过日/周本尖峰；氪金主要买 **时间与外观与便利**，不直接卖毕业战力。

---

## 1. 好玩：三层循环

```
短循环（2～5 分钟）  挂机击杀 → 碎片/骨尘 → 合成晶 → 附魔一档
中循环（每日）        日本 ×3 → 核心/晶保底 → 修装/冲下一档附魔
长循环（每周）        周本 ×1 → 稀有装备/高阶材料 → 下周目标感
```

### 1.1 爽点清单（必须有）

| 爽点 | 怎么给 |
|------|--------|
| 击杀反馈 | 掉落飘字/音效（NI 给物）；挂机 3～6 秒一怪 |
| 合成反馈 | 晶合成成功提示；工作台有明确配方书/菜单指引 |
| 变强反馈 | 附魔台出词清晰（锋利/耐久等）；分数板显示今日核心/晶 |
| 副本反馈 | 波次清完有阶段提示；Boss 必掉核心；通关箱动画/标题 |
| 目标反馈 | `/ember` 菜单显示「今日材料目标 / 剩余次数」 |

### 1.2 故意不做好玩的坑

- 不把主成长绑在 RNG 装备刷（刃/护符低概率即可，核心与晶保底）。
- 不让失败本「白打」：进本扣票，但波次中掉落保留（已有材料不回收）。
- 不做无提示的黑箱配方；养成路径写进菜单。

## 2. 货币与道具分层（数值可控的前提）

| 层 | ID / 名 | 获取 | 消耗 | 可否用钱买 |
|----|---------|------|------|------------|
| **A 材料** | `mat_ember_shard` / `bone_dust` / `core_fragment` | 挂机、日/周本 | 合成晶、修理 | **否**（防战力直售） |
| **B 养成** | `crystal_ember_enchant` | 合成 + 日通关箱 | 附魔台 | **否**（可卖「合成加速券」间接） |
| **C 门票** | `ticket_ember_daily` / `ticket_ember_weekly` | 每日/周免费发 + 氪金补 | 进本 | **是（限购）** |
| **D 软通货** | `ember_coin`（余烬币）Vault 余额或 NI | 挂机微量、任务、卖多余材料 | 外观、便利、补票折扣 | **是（充值点→币）** |
| **E 硬通货** | `ember_crystal_cash`（余烬晶钻） | **仅充值/礼包** | 买礼包、战令、外观、限购票 | **是** |
| **F 外观** | 称号/粒子/武器皮肤（NI 显示名/Lore） | 商城、战令 | 无战力 | **是（主推）** |

原则：**A/B 永不直售**；氪金只动 C/D/E/F。战力差距来自「多打几次本 / 少肝材料」，不来自「钱包直接 +伤害」。

## 3. 肝度：日活跃时间预算

| 活动 | 目标时长 | 产出定位 |
|------|----------|----------|
| 挂机 | 20～40 分钟（可挂机） | 碎片/骨尘稳态 |
| 日本 ×3 | 约 8～12 分钟 ×3 ≈ 30 分钟 | 核心 + 晶保底 |
| 周本 ×1 | 20～25 分钟 | 周峰值装备/核心 |
| 养成（合成/附魔/修） | 5～10 分钟 | 花材料 |
| **日合计（认真玩）** | **约 50～70 分钟** | 感到「今天有进度」 |
| 纯挂机党 | 可只挂机 | 能附魔低档，**赶不上**日/周本核心节奏 |

### 3.1 日产出目标（单人、默认旋钮）

| 资源 | 纯挂机 40 分钟 | 挂机+日本满次 | 再加周本（摊到日） |
|------|----------------|----------------|---------------------|
| 碎片 | ~60 | ~80 | ~90 |
| 骨尘 | ~20 | ~28 | ~30 |
| 晶（折合） | ~15（需合成） | ~15 合成 + 3 箱 ≈ 18 | +周箱 |
| 核心碎片 | ~0 | ~6（3 本 × Boss1+箱1） | +周本大额 |

对齐附魔：刃锋利 II ≈ 2 晶 → **日本满次当天即可小升级**；高档附魔吃周本核心转化。

### 3.2 肝度「合适」判定

- 连续 7 天免费满勤：刃达中档附魔、有修理余粮、周本有机会出第二把稀有。  
- 连续 7 天只挂机不打本：材料够低档附魔，核心严重短缺 → **想打本**。  
- 连续氪金满补票：进度快约 **30%～50%**（时间），不是 200%。

## 5. 氪金手段（要有，但不毁服）

### 5.1 定位

| 类型 | 例子 | 是否推荐 | 说明 |
|------|------|----------|------|
| 便利 | 额外日/周门票（限购） | **主推** | 买时间，不买伤害 |
| 战令 | 免费轨 + 付费轨（外观/币/少量票） | **主推** | 30 天季节，肝也能拿免费轨 |
| 月卡 | 每日领币 + 1 张日票补 | **主推** | 稳定小额 |
| 外观 | 刃皮肤 Lore、称号、进服特效 | **主推** | 零战力 |
| 礼包 | 首充、周礼包（币+票+外观） | 可做 | 绑限购 |
| 直接卖核心/晶/成品刃 | — | **禁止** | 破坏养成 |
| 伤害宝石 / 付费属性 | — | **本期禁止** | AP 以后再说，且需单独评审 |
| 抽奖箱出战力 | — | **禁止** | 可用外观扭蛋 |

### 5.2 商品草案（TrMenu「余烬商城」）

**硬通货 `ember_crystal_cash`（晶钻）充值档（示意）：**  
6 / 30 / 98 / 198（赠币比例随档微增，不做过大）。

| 商品 | 价 | 限购 | 内容 |
|------|----|------|------|
| 日票 ×1 | 60 晶钻 | 3/日 SKU | `ticket_ember_daily`；命令 `/corerpg shop buy daily_ticket` |
| 周票 ×1 | 180 晶钻 | 1/周 | `ticket_ember_weekly`（本期不做） |
| 月卡 30 天 | 68 晶钻 | 1 | 立即日票×1；之后每天登录：余烬币 200 + 日票×1（计入硬顶 6）；命令 `/corerpg monthly` |
| 战令解锁 | 48 晶钻 | 季 | 付费轨外观 + 币 + 累计日票×5（赛季内发） |
| 外观·刃焰红 | 28 晶钻 | — | 仅显示名/Lore/粒子，属性同 `gear_ember_blade` |
| 便利·仓库扩容 | 18 晶钻 | 账户 | 若后期有背包插件；暂可占位 |
| 合成加速券 | 12 晶钻 | 5/日 | 一次合成少 1 碎片（**不省核心**） |

**日票上限（防崩）：**  
免费 3 + 晶钻购票 + 月卡赠票 ≤ **6 次/日（总进本硬顶）**；晶钻购买另有 SKU **3/日**。周票免费 1 + 氪 ≤ **2 次/周**。  
超过上限拒售 / 月卡只发币不发票。旋钮：`daily.hard_cap` / `shop.daily_ticket.sku_limit`（`cash.yml`）。  
玩家晶钻字段：`ember_crystal_cash`。规格：`docs/design/DESIGN-ember-cash-monthly.md`。

### 5.3 战令（季）骨架

- 免费轨：币、少量碎片、称号（普通）。  
- 付费轨：外观、日票×5（分散等级发）、稀有称号。  
- **付费轨不出核心、不出成品高伤装备。**  
- 经验来源：每日挂机击杀计数、通关日本、通关周本（有日上限，防 24h 挂机刷满）。

### 5.4 首充 / 小额钩子

- 首充 6 元档：外观称号 + 日票×2 + 币 500（一次）。  
- 目的：转化，不给战力碾压。

## 6. 经济闭环（材料怎么花光）

```
挂机材料 ──┬─→ 合成晶 ─→ 附魔台（刃/护符）
           ├─→ 铁砧修理（碎片/核心）
           └─→ （可选）商店回收成余烬币（低价）
日/周核心 ──→ 合成晶（更赚）或大修
多余材料   ──→ 低价收币 ──→ 外观/便利（软通货池）
晶钻       ──→ 票/战令/外观（不进材料直购）
```

回收价建议极低（如 1 碎片 = 1 币），避免「挂机印钞」冲击商城；商城软货以外观为主。

---

## 7. 公平与防刷

1. **材料/晶/核心不可晶钻直购。**  
2. 门票硬顶（上节）。  
3. 进本扣票；掉落只 NI；禁止菜单 `/ni give` 当奖励。  
4. 挂机区不掉核心；装备掉率默认 0。  
5. 同账号日票/周票限购用 UUID（离线 UUID 规则与现 ops 一致）。  
6. 验收：同配置装等，满氪 vs 零氪，日本通关时间差与输出差 **≤ 约 40%**（来自多打本养成进度，非付费属性）。

---

## 8. 落地顺序（设计确认后执行）

1. Vault / CoreRpg 软通货（已有 `coin`）+ 硬通货 **`ember_crystal_cash`**（规格见 `docs/design/DESIGN-ember-cash-monthly.md`）。  
2. 每日免费日票 3 + 晶钻补票（价 60，总硬顶 6）；NI `ticket_ember_daily`。  
3. TrMenu：`/ember` 商城已有；日票图标走 `/corerpg shop buy daily_ticket`（tell 回退）。  
4. 商品：**日票限购 + 月卡登录礼** 优先（`cash.yml`）；外观 / 战令第二周。  
5. 旋钮：本期 `cash.yml`；其余仍预留 `economy.yml`。测试：零氪日环 / 补票至硬顶 6。  
6. 策划补文案；物品岗补外观 NI；插件岗接线命令；**不动 Paper，不覆盖无关 CoreRpg.jar。**

## 9. 明确不做（本期）

- Citizens；付费属性宝石；箱庭抽战力；卖成品刃/核心。  
- 改方块、加 Paper NMS 钩子。  
- 无上限补票、无上限抽奖。

## 10. 验收清单（好玩 & 肝度 & 氪）

- [ ] 新号 60 分钟内：挂机有掉落、合成出晶、附魔成功一次、日本通关一次。  
- [ ] 零氪满日次：核心 ≥6/日，能修能小升。  
- [ ] 只挂机不打本：核心近 0，菜单提示去打本。  
- [ ] 氪金补日票至硬顶：当日核心明显更多，但刃基础伤害数值未因付费改变。  
- [ ] 商城可见：票、月卡、外观；无「买核心」条目。
