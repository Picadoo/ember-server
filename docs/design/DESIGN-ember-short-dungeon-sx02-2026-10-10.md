### 2.2 与 sx01 的硬差异（禁换皮空转）

| 维 | sx01 烬门哨岗 | sx02 锈灯栈道（本债） |
|----|---------------|----------------------|
| 情绪 | 半露天石砖哨墙 · 灰火盆 | **锈铁栈道 · 灯笼/栏杆 · 潮气木板+氧化铜点缀** |
| 平面流 | 院角 → 甬道 → Boss 垫（**线性地面**） | **抬升栈台 → 分叉灯桥汇合 → 灯塔垫**（**有高差+分叉**） |
| 终厅 Cast | 环伤「拉开」（哨长蓄力） | **灯塔扫线/延时砸地**（message→粒子线或落点圈→delay≈25→伤害）；仍须可读可躲 |
| 怪气质 | 哨尸 / 哨弓 / 哨长 | **锈灯巡卫 / 栈道弩手 / 灯塔守吏**（新 MM id，可复用技能范式） |
| 经济号 | S40 | **S41**（独立登记；薄表见 §2.5） |
| 日帽计数 | `p1_sx01_day` | **`p1_sx02_day`**（独立；**不**与 sx01 共用次数） |

| 步 | 路径 | 说明 |

### 2.4 结构（多房 · 5～8 分钟 · Cast）

| 房 | 内容 | 时长感 |
|----|------|--------|
| R1 | 抬升栈台清场（1～2 波）· 栏杆边缘可读 | ~1.5–2.5 min |
| R2 | **分叉灯桥**：左/右各轻压力或一侧精英，**汇合**后再开门（首航可「双侧都刷、先清汇合点」简化，但地图须真有分叉形体，禁假画两条线） | ~1.5–2.5 min |
| R3 | 灯塔终厅 · **可读 Cast**（扫线或落点圈 + 拉开/侧移） | ~2–3 min |

| 项 | 钉 | 禁 |
|----|----|----|
| 目标通关 | **5～8 分钟**手感 | 15+ 长本；假「一键秒清」 |
| Boss 可读 | 必挂 1 个 `EmberSx02…Cast` | 无预警静默环当唯一机制 |
| 人数 | 单人（首航 **1**） | 强绑团本体量 |
| 复用 | Cast/门宽范式可参考 sx01/日更 | 直接 `enter sx01` 换皮；复制 S40 数字不登记 S41 |

### 2.6 经济回盘（薄表 · S41）

**目标：** 通关收获 → 币/材料进现网账户 → 工坊花；**显式不**动 `afk.daily_kills` / `afk.tiers`。

| 账户 | 方向 | 说明 |
|------|------|------|
| 余烬币 | 发 | 短征结算包 |
| `mat_ember_shard` / `mat_ember_bone_dust` | 发 | 喂强化/精工/成色 |
| 核心 / 胚料 | **薄或首通才给** | 避免压过主线首通 |
| 装备 / 印记 / 徽记 / 签名 | **默认不发**（首航） | 同 sx01 |
| 挂机日表 | **不动** | 硬禁 |

**薄表草案（设计钉 · 金样可另号数值模拟后写入 `ember-v1-economy.yml`）：**

| 触发 | 草案数量（待 sim 闩） | 相对 S40 差异意图 |
|------|----------------------|-------------------|
| 有奖通关（≤3/日） | 币 **75** + 碎片 **3** + 骨尘 **5** | 略少币/碎片、**略多骨尘**——工坊精工向；总期望与 S40 同量级（±15% 内） |
| 生涯首通（一次） | 另加 币 **180** + 碎片 **6** + 胚料 **1** | 略薄于 sx01 首通，避免双本首通洪水 |
| 无奖通关（日帽后） | 币 **0** 材料 **0**（行为与 sx01 一致） | — |

| 登记 | 要求 |
|------|------|
| 新来源 | **S41 短征通关（sx02）** · REG + `EmberEconomy` + source-map；标签进 p1sim **或** STATUS 写明「另号补模型」 |
| 消耗侧 | **不新开商店**；回盘 = 现有工坊/仓 |
| 门禁 | 批 A 后施工可落；金样偏离草案 >20% 须再批或记 STATUS；**禁止**借短征抬挂机产量 |
