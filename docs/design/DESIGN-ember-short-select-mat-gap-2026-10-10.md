## 3. 可落地（方案 M）§2

### 2.1 键复用（钉死 · 只读 · **禁止本窗新造 gap 算法**）

| 键（已 live · D404） | 选页用途 |
|---------------------|----------|
| `%corerpg_p1_vault_shard%` / `bone` / `core` / `blank` | 紧凑「仓内」一行 |
| `%corerpg_p1_recipe_gap_enhance1%` | 强化+1 碎片还差 |
| `%corerpg_p1_recipe_gap_upgrade_t2%` | 升阶 T1→T2 拼接还差 |
| `%corerpg_p1_recipe_gap_refine1%`（可选同批） | 精工 0→1 拼接还差 |

**纪律：** 只读挂键；禁改 `EmberVault` / UpgradeRules / 产量 / 日帽；禁假写固定余额；禁暗示「打满今日有奖必够升阶」。

### 2.2 文案钉死示例（施工可微调色码/换行，语义不得漂）

```
§e仓内：§f碎%vault_shard% §7· §f骨%vault_bone% §7· §f核%vault_core% §7· §f胚%vault_blank%
§c还差：§e强化+1 §7碎差 §f%recipe_gap_enhance1% §7· §e升阶T2 §7%recipe_gap_upgrade_t2%
（可选）§6精工0→1 §7%recipe_gap_refine1%
§8材料进仓 · 点「去哪花」开工坊 · 不加快产量
```

过长时：**优先保留「还差」行**；仓内四材可缩为「仓内四材见工坊速览」半句，但**至少一条数字锚**（还差或仓内）必须在选页说明可见。

**满态分支：** `sx_day_left_sum==0` 时 **保留** D409 满态「去工坊花」主 CTA；仓差行可同屏保留（不盖工坊主 CTA）或缩为一行「还差见上 / 去工坊花」。
