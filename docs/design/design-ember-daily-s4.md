## 4. 线 F · 余烬窟·霜晶裂隙

### 4.1 一句话

补给渠冻裂成缝：冰台上跳着清怪，尽头霜厅里还杵着不肯化的霜核蛮兵。

### 4.2 地图硬条

| 元素 | 规格 |
|------|------|
| 轮廓 | 轴长感 **48～64**；战斗台宽 **4～6**；Boss 霜厅 **≈12×12** |
| 裂隙 | 中央或侧缝可见深落差；缝底须有 **雪/冰落点或浅水**，禁虚空秒杀 |
| 门 | ≥2 道真冰闸/铁门（清完才开） |
| 主材 | `packed_ice` / `ice` / `snow` / `quartz_block` 点缀 / 白染色粘土；少量子 `soul_sand` **禁止**（避免焦骨串味） |
| 禁 | 大片流水当「潮蚀翻版」；直筒焦骨布局；整盘向下地窖 |

### 4.3 坐标 / 门 / 刷点表（本地意图，可平移；施工后写入 DP）

原点约定：出生朝 **+Z**，y 以出生地面为准。

| 锚点 | 坐标意图 (x,y,z) | 用途 |
|------|------------------|------|
| `spawn` | `0, 70, 0` | 玩家落点；面朝 +Z |
| `door1` | `0, 70, 16` | 房1 清完打开的真门（冰闸） |
| `room1_spawns` | `(±3,70,6)~(±3,70,14)` 两侧壁龛 | 房1 刷点 5～6 |
| `door2` | `0, 70, 34` | 房2 清完打开 |
| `room2_spawns` | `(±4,70,22)~(±4,70,32)` + 折台 `4,71,28` | 混编刷点 |
| `boss_door` | 同 door2 或 `0,70,36` | 进 Boss |
| `boss_center` | `0, 70, 48` | Boss 出生 |
| `boss_arena` | 霜厅约 `[-6..6] × [70] × [42..54]` | 可绕；边缘裂隙有落点 |
| `leave_sign` | `-2, 71, 1` | 撤离牌 |

### 4.4 波次 + Display 去色预留名（给 MM / `$kill`）

| 阶段 | MM id | Display 去色名 | 数量感 |
|------|-------|----------------|--------|
| 房1 | `EmberDailyFrostZombie` | `霜晶尸` | 5～6 |
| 房2 | `EmberDailyFrostZombie` + `EmberDailyFrostSkeleton` | `霜晶尸` / `霜矢骷` | 3+3 或 4+2 |
| Boss | `EmberDailyFrostBrute` | `霜核蛮兵` | 1 |

YAML 内可写 `Display: '&b霜晶尸'` 等，**逻辑/计分板 `$kill` 用去色名上表**。勿复用 Tide/Ash/Crypt/Spire/庭院 id。

### 4.5 Boss 定位

霜厅中央慢压 + 偶发「冻步」感（实现可用减速区，非必新系统）；须与潮闸蛮兵（水边冲锋）、焦核（窄冲）观感可辨。

## 5. 线 G · 余烬窟·锈轨矿道

### 5.1 一句话

废弃补给矿巷：铁轨还在，支柱东倒西歪，尽头机房里锈住的矿监还不让路。

### 5.2 地图硬条

| 元素 | 规格 |
|------|------|
| 轮廓 | 主巷轴长 **48～64**；巷宽 **5～7**（明显宽于焦骨 3～5）；Boss 机房 **≈12×12** |
| 轨 | 地面可见 `rail` 装饰线；**不要求**可乘矿车（免新系统） |
| 支洞 | **恰好 1** 条短支（深 ≤8），尽头封死或 1～2 垃圾怪；禁迷宫 |
| 门 | ≥2 道真木/铁闸 |
| 主材 | `cobble` / `oak_fence`·支柱 / `rail` / `torch`·矿灯感 / 少量矿石装饰块 |
| 垂直 | 同层为主；允许 ±1 轨枕落差；**禁**做成断塔上攀或地窖下潜 |
| 禁 | 复制焦骨直筒缩宽；复制庭院环廊；空板 |

### 5.3 坐标 / 门 / 刷点表

| 锚点 | 坐标意图 (x,y,z) | 用途 |
|------|------------------|------|
| `spawn` | `0, 64, 0` | 落点朝 +Z |
| `door1` | `0, 64, 15` | 房1 真门 |
| `room1_spawns` | `(±4,64,5)~(±4,64,13)` 柱间 | 4～5 |
| `spur_entry` | `6, 64, 20` | 短支洞入口（装饰/可选垃圾怪） |
| `spur_end` | `12, 64, 20` | 支洞尽头封墙 |
| `door2` | `0, 64, 33` | 房2 真门 |
| `room2_spawns` | `(±5,64,18)~(±5,64,31)` + 支洞口侧 | 混编 |
| `boss_center` | `0, 64, 46` | Boss |
| `boss_arena` | 机房 `[-6..6]×[64]×[40..52]`，可有报废矿车掩体 1～2 | 可绕 |
| `leave_sign` | `-2, 65, 1` | 撤离牌 |

### 5.4 波次 + Display 去色预留名

| 阶段 | MM id | Display 去色名 | 数量感 |
|------|-------|----------------|--------|
| 房1 | `EmberDailyRailZombie` | `锈轨尸` | 4～5 |
| 房2 | `EmberDailyRailZombie` + `EmberDailyRailSkeleton` | `锈轨尸` / `矿矢骷` | 3+3 |
| Boss | `EmberDailyRailWarden` | `锈轨矿监` | 1 |

### 5.5 Boss 定位

机房内柱间压迫 + 短距离冲锋；与霜核（冻厅）、断塔守望（顶台推离）、残誓守墓（圆厅慢压）须 **七线可辨**。

## 9. 验收硬条（S4）

1. 菜单 F/G 可进；各扣 **30**。  
2. 安全落点 → ≥2 真门清房 → 独立 Boss 厅。  
3. 通关 **5～8 分钟**。  
4. 与庭院/焦骨/地窖/潮蚀/断塔 **5 秒可辨**；霜晶≠潮蚀；锈轨≠焦骨窄筒；非垂直翻版。  
5. 可见路径无命令。  
6. 本服 MV + DP。  
7. 挑刺：裂隙/轨旁无秒杀虚空；支洞非迷宫；Boss 可绕；MM 去色名与 `$kill` 一致。  
8. **未批准前未施工** 记入过程证据。
