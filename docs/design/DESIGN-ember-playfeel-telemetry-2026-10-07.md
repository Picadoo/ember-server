## 1. 感知目标

### 1.1 对玩家：**无感知**

- 不新增菜单 / HUD / 成就 / 排行榜 / lore 遥测行。  
- 不改 TrMenu 玩家面、不改 NI 获取口。  
- 结算 `playfeelSummary` 文案**默认保持**（本稿不重写玩家可见句）。

### 1.2 对 OP（三条内能答）

1. **破绽：** 本周合格重打里，撞墙 / 落空 / 破招的**局均成功次数**各多少？  
2. **事件：** 本周出事件房占比、事件成功占比各多少？  
3. **签名调律：** 本周佩戴签名局占比、其中至少一件调律生效占比各多少？

（可选第四问若批 8 指标含花样：花样委托达成率——不占上三条硬答。）

## 3. 最小指标集（≤8）

> 口径：**合格重打** = 日刷/挑战 q01–q07、已扣体力开跑并进入结算（通关或失败均计）；深渊/团本本窗默认排除。  
> 聚合：**P 周**（与签名确认 / 轮换周同源 `weekKey`，施工钉死同一函数）。  
> 分母：`pf_runs`（本周合格重打局数）——**内部键**，可在 OP 摘要展示，**不计入「对外指标 ≤8」条数以外的玩法 KPI**。

| # | 键（建议） | 含义 | 来源瞬态 / 快照 |
|---|------------|------|-----------------|
| 1 | `p1_pf_wall` | 撞墙破绽成功次数（周累加） | `wallHits` |
| 2 | `p1_pf_whiff` | 落空破绽成功次数 | `whiffHits` |
| 3 | `p1_pf_break` | 破招成功次数 | `breakHits` |
| 4 | `p1_pf_evt_roll` | 出事件房局数（`eventRoom` 非空） | session 结算 |
| 5 | `p1_pf_evt_ok` | 事件成功局数（`eventDone`） | session 结算 |
| 6 | `p1_pf_sig_wear` | 开跑时至少一件签名佩戴局数 | 进本/结算快照 |
| 7 | `p1_pf_sig_alt` | 开跑时至少一件调律生效（`sigalt=1`）局数 | 同快照 |
| 8 | `p1_pf_vb_hit` | 花样委托本局有进度/达成（对齐 D292 口径，施工钉「+1 或完成」其一） | `C_VBOUNTY` / settle 既有 |

**OP 派生（不算第 9 指标，现场除法）：**

- 破绽局均 = `p1_pf_*` / `pf_runs`  
- 事件出房率 = `evt_roll` / `pf_runs`；成功率 = `evt_ok` / `max(evt_roll,1)`  
- 签名佩戴率 / 调律率 = `sig_wear` / `pf_runs`；`sig_alt` / `max(sig_wear,1)`（或 / `pf_runs`，摘要两种都印一行）

**注册表：** 新键必须进 `EmberCounters`；类别建议 **STAT**；周期 **PWEEK**；**非** CLAIM（不受 clockGuarded 领取饱和逻辑干扰）。

## 5. 门禁

| 项 | 要求 |
|----|------|
| **p1sim / 通关率** | **无**（纯观测；不跑 42 格门） |
| **retention** | 默认 **周滚**（当前 P 周）；OP 摘要可带「上周」只读对比；**不做月滚**本窗（防键膨胀；月滚另开） |

| **隐私** | 日志 JSON（若批 R 或 M+R）uuid 可用短哈希；禁止把遥测挂到玩家可见排行 |
| **冒烟** | 开一局日刷 → 结算后 `periodCount` +1；`/corerpg p1 telemetry <player>` 数字对齐；非 admin 无入口；排除表生效 |
