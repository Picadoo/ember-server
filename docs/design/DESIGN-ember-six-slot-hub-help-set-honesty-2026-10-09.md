## §2 文案补丁规格（方案 M）

### 2.1 `ember_hub.yml` · 装备格 `o`

**保留：** 主手/护符/突破/副手说明；`%corerpg_p1_awaken%` 行。

**追加（示例，文案岗可改字）：**
```
- '§8护甲四件套：§f%corerpg_p1_armor_set%'
- '§8已激活时受伤 −3%（见装备/护甲页）'   ← 或仅依赖 PAPI 行已含 −3% 则删静态行，避免双写
```

**实现注意：** 若 `%armor_set%` 已含「受伤 −3%」字样，**只加一行 PAPI**，勿再静态谎称未激活也 −3%（对齐 D329 三态纪律）。

### 2.2 `ember_hub.yml` · 工坊格 `p`（可选同号）

**现有：** 「手持刃或护符：强化 / … / 分解」

**改为例：**
```
- '§7手持刃或护符：强化 / 升阶 / 精工 / 成色 / 互换 / 分解'
- '§8手持护甲：仅可分解（白板零头）；养成随护符'
```

### 2.3 `ember_help.yml` · 怎么玩 `L`

**现有 §74：** `刃 + 护符同族 = 套装被动`

**改为（示例）：**
```
- '§74. §f刃+护符同族 = 族觉醒；再穿同族 T2+ 甲≥2 = 四件套（受伤 −3%）'
```
或拆成 4 + 4b 两行，保持「一分钟」可读。

### 2.4 `ember_help.yml` · 三套装 `S`

**保留：** 焚烬/烬爆/炽愈族被动与觉醒档。

**收束追加一行（示例）：**
```
- '§7另：护甲四件套（两件套已激活 + 同族掉落阶 T2+ 甲≥2）→ 受伤 −3%，不进面板 B/H'
```
