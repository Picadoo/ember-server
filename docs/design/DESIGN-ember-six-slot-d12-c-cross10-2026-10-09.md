## §2 补测清单（方案 M 正文）

### 2.1 前置

| # | 项 | 合格 |
|---|----|------|
| P1 | 环境 | 测服优先；或线上**测号/管理号**（不碰真人档） |
| P2 | 开关 | `enabled=true`；记录 bv / jar tip（本窗不改） |
| P3 | 样件 | **仅** `source=drop` 甲；**禁** `p1 give`/admin/migrate/quest 冒充 drop |
| P4 | 十分位预算 | 选一：**(a)** ≥10 件 T1 drop 甲；**(b)** ≥5 件 T2；**(c)** 混合使 `Σ tier ≥ 10` 且至少一次跨整十边界 |
| P5 | 基线读数 | 分解前记录：整胚库存、胚零头（十分位）、将拆 uid 列表 |
| P6 | 注记 | 报告首行：**白板经济模型未覆盖** |

**样件获取建议：** Q01（或等价）结算续刷；避开与热换 jar 同窗抢号（D332 教训）。若测服可稳定刷本，优先测服。

### 2.2 用例（仅 C 族）

| ID | 步骤 | 预期 | 中止（失败） |
|----|------|------|--------------|
| **C0** 基线 | 读整胚 `B0`、零头十分位 `T0`（0–9） | 可复述；证据入目录 | 读不到账无法验收 |
| **C1** 跨界规划 | 计算还需十分位 `need = 10 - (T0 % 10)`（若 T0%10=0 则 need=10）；选 drop 甲使累加 ≥ need | 计划写入 STATUS | 用非 drop 凑数 |
| **C2** 连续分解 | 按计划拆至累计十分位跨过下一个整十 | 每件：预览仍为 0.`tier`；确认后件 dismantled / 非 active | ×1.0 整胚暴涨；资产双失；误拆 migrate |
| **C3** 跨 10 记账 | 跨界当次后读 `B1`、`T1` | **`B1 = B0 + floor((T0 + Σtenths) / 10) - floor(T0/10)`**（通常恰好多 1）；**`T1 = (T0 + Σtenths) % 10`**；与 `addTenths` 一致 | 整胚 +0 或 +≥2（无对应十分位）；零头漂移/浮点 |
| **C4** 审计短抽 | `p1 audit`（或既有 OPS 口径） | 无非预期 ACTIVE_NOT_HELD 大面积 | 大面积差异 |
| **C5**（可选）再跨一次 | 若样件充足再跨一个整十 | 再次恰好多 1 整胚 | 同 C3 失败态 |
