## §2 文案补丁规格（示例 · 文案岗可改字）

**位置：** `ember_p1_gear` → 护甲入口 `display.lore`（`armor_on==1` 分支）。

**现有保留：** 四部位 `%corerpg_p1_armor_* %`、待领行、F/成色精工说明、➥ 打开护甲页。

**追加（示例）：**

```
- '%corerpg_p1_armor_set%'
- '§a受伤 −3%（四件套已激活时）'   ← 仅当 active==1 用 icons 条件分支显示；进行中/未激活不写 −3%
```

**推荐实现（施工另号）：**
- 用与护甲页相同的 **icons 条件分支**（`armor_set_active` / `armor_set_busy` / 默认）：  
  - 已激活：`%corerpg_p1_armor_set%` + `§a受伤 −3%` + 短句「另 2 甲位可穿异族追成色」（可选）  
  - 进行中：`%corerpg_p1_armor_set%` + `§7还缺同族掉落阶 T2+ 护甲`  
  - 未激活：`%corerpg_p1_armor_set%` + `§8先让刃与护符同族`  
- **禁止**再写「后续开放」。  
- **不**改 `ember_p1_armor` 已过线三态（除非发现与入口用词不一致的笔误，另记）。  
- 候选对比：护甲页 `armor_*_fam` **保持**；本窗不强制改装备页（装备页无候选格）。

**真源：** 文案只镜像 PAPI / 现网规则；费用与减伤数字仍以代码为准（×0.97 钉死）。
