**一句话问题：** 套装说明承诺「灰粮可购」守腕/生坠，生活 Layout 却仍收起购键——旁轨断在「买不到」。

**为何选本债、排除其它：**  
- **E/F 重铸/稳固回盘：** P1 拒旧 enhance/reforge → 兑得到用不上；D377 已排除；NI 遗物/宝珠假兑可**另号**只改 lore。  
- **再跳转格：** 互指波 D373–D381 已齐；派单禁空跳转。  
- **复述 D383–D385：** 挂机层钩 / 使魔 PAPI 刚落。  
- **新短本房 / 新挂机产量层：** 须可达+经济或抬表；非本薄窗。  
- **本债：** D376 官方另债 + set 页假平面硬证据；TrMenu-only；P1 下真实可用。
