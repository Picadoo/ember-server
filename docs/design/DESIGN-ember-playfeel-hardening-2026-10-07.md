## 0. 给服主一页结论

### 问题排序（重 → 轻）

| 序 | 欠债 | 一句话 | 为何排这里 |
|---:|------|--------|------------|
| 1 | **主循环「可感差异」仍偏薄** | 七线房间结构同构；差异化已堆在词缀 / 事件 / Boss 破绽 / 签名上，但**多数重打局玩家仍像在刷同一条走廊** | 服主要「别太烂 / 更好玩」；扩包再堆词缀边际递减（ARCH POLICY 12:19 曾暂停扩包） |
| 2 | **成长横向「有手感」不足** | 三套装是唯一全程可感选择（`DESIGN-ember-build-diversity`）；天赋一排几乎无感；二排只绑词缀精英；技能组 S1/S2 已落地但仍缺**局内决策密度** | 六槽不做；不能开新永久乘区 |
| 3 | **再刷动机偏「印记 / 成色」一条线** | 签名 + 徽记已给每图身份，但基础件仍是 T1/T2/T3 池（G1）；毕业后真目标是极品成色 + 精工，反馈周期长 | 掉落值得再刷 ≠ 再加一层数值 |
| 4 | **付费边口径分裂** | D282 月卡登录礼照常发；VIP / 战令仍挡（D281）——入口文案与玩家预期要对齐，**不能暗开卖战力** | 已有代码闸；差的是产品口径 + 菜单诚实 |
| 5 | **维护性：薄修天花板** | `EmberRunDirector` / `EmberRunService` 上帝类仍在；内容包 = Java + yml + p1sim + 冒烟；继续「再来一个 Pack」会越修越碎 | ARCH S3 原语已拆完，该用它做**体验窗**而不是再堆手写分支 |

### 本阶段要什么

- **让同一套体力日刷「打起来不一样」**：把已落地的 Boss 破绽 / 房间事件 / 词缀 / 签名，变成玩家**看得见、记得住、愿意为了练而重打**的反馈。
- **在 2 槽 + 体力门下给横向选择**：技能形状 / 身法方向 / 签名调律 /（可选）副手替换预算——**侧移，不抬通关率预算**。
- **付费边写死口径**：月卡维持；VIP / 战令维持挡或迁到外观 / 余烬徽便利——**零战斗乘区**。
- **维护性一次设计再做**：先做「体验可观测 + 差异化盘点表」，再动大改。

### 本阶段不要什么

- 六槽护甲 Stage 1、NMS、新永久乘区、第 4 套装、重开卖战力的 VIP / 战令币轨。
- 「全面重做七张图」、再开一打词缀 Pack（除非有真人反馈证明现包不可感）。
- 文案薄窗冒充玩法加固（旁注 / lore-only 另轨，不占本阶段主窗）。

## 1. 现状体检（主循环 / 枢纽 / 挂机）

### 1.1 主循环长什么样（现网）

默认模式 **P1**（D61+）。核心循环（书 `design-ember-v1.0-P1.md` §03 + handoff）：

| 块 | 现网入口 / 键 | 消耗 | 玩家在干什么 |
|----|---------------|------|--------------|
| 七线主线 Q01–Q07 普/挑 | TrMenu `ember_hub` → `ember_p1_adventure` / `_challenge`；`/corerpg p1 enter <qNN>` | 每局 **30 体力**（`ember-v1-runs.yml` `cost: 30`） | 分房清怪 → Boss；首通链解锁下一图 |
| 深渊 10 层 | `ember_p1_abyss` | 30 体力 + 层费币 / 多余 T3 印记 | 段式下潜、成色右移 |
| 团本 R01–R03 | hub「团本」→ 冒险页选图 | **50 体力** / 本；周合计 cap | 3–5 人机制战 |
| 每日委托 / 花样 | `ember-v1.yml` `bounty` | 计入主线局 | 日 1/3 局币碎；花样计数 |
| 周规则 / 精选 | `rotation` + 14 条 `modifiers` | 挑战（及条件下普通） | 只改怪种映射 / 压力，不改掉落表结构 |
| 挂机庭 | `ember_p1_afk` · 世界 `ember_afk` | 0 体力；日 **2400 击杀**封顶 | 自动普攻 + 自动烬斩；装备决定层与速度（D177 rev2） |
| 签到 / 在线 | `ember_p1_sign` | — | 币 / 经验 / 徽记兜底（D180） |
| 赛季 / 周目标 | `ember_p1_season` | — | 余烬徽 → 外观（D116–D117） |

技能组现状（`DESIGN-ember-skill-kit-2026-10-06.md`）：**烬斩 F** · **烬突 潜行+F（Q02）** · **烬斩三形状（Q04）** · **火痕步 / 后撤步（Q05，D214/D219）**；**守招搁置（D212）**。

装备权威（`DESIGN-ember-gear-structure-2026-10-06.md`）：**2 槽刃 + 护符**；六槽 Stage1 **HOLD / 本窗不做**。副手守腕 / 生坠薄获取已在灰粮试点 PASS（B-flex-3 / `STATUS-ember-flex-offhand-thin-acquire-test.md`）——属**旧 StatService 白名单饰品轴**，与 P1 `EmberLoadout` 2 槽并行；P1 书口径下副手若再扩必须走「**替换预算，不新增轴**」。

### 1.2 具体痛点（有证据）

**A. 房间同构 → 「空」与「单调」**

- 七张图任务书共用「R1–R3 + Boss、候选点 P1–P6」骨架（书 §11–§17）。主题（灰烬 / 焦骨 / 残誓 / 潮蚀 / 断塔 / 霜封 / 锈轨）在方块与 MM 怪模型上有差，但**操作循环仍是：进门 → 清波 → 下门 → Boss**。
- 旧五本差异文（`docs/ember-dungeon-gameplay-diff.md`）讲的是 **Daily / Weekly / Abyss / Calamity / Raid** 五类模式差；**不能**套到现行七线日刷上——七线是同模式递进，不是五类玩法。
- **已落地、应可感（盘点，勿当从零）：**

| 层 | 已落地 | 真源 | 可感？ |
|----|--------|------|--------|
| Boss 招式 + 破绽 | Pack2–5：半血压、撞墙破绽 `wall_stun`、落空破绽 `whiff_stun`、破招 `break_hp`；门控冷却 D194；团本继承 D195 | `ember-v1-runs.yml` `maps.*.boss.skills`；`EmberRunDirector` | **高**——但依赖玩家是否学会「躲完反打 / 引撞墙 / 破招」；新手提示不足则等于没有 |
| 房间事件 | 池 9：`timed/crystal/escort/hold/beacon/relay/breach/chain/unscathed` | `variety.events` | **中**——约一半局出事件；成功差在「那一下」，整局时长感弱 |
| 词缀精英 | 池 12：`blazing…firechain` | `variety.affixes` | **中**——每局约 1 只；摊到 60s 局 ≈ 1–2% 时长（build-diversity） |
| 周规则 | 14 条 remap / 压力 | `rotation.modifiers` + Pack2–4 | **中高**——挑战周可感；普通重打仅部分规则（D94） |
| 签名传奇 | L01–L15 + 调律 6 | `EmberSignature` / D174–D184 | **高（装上后）**——刷出率与烙印成本把「可感」推到中后期 |
| 奖励精英变招 | 每图 2 招 light | `elite_twists` | **低～中**——轻招，易被当成噪音 |

**缺口：** 机制已在，**教学 / 结算反馈 / 「本局教了你什么」** 弱。玩家死在 Boss 往往只看到失败行，不知道是该撞墙、该破招、还是该换形状。

**B. 枢纽反馈散**

- `ember_hub.yml` 主路清楚（冒险 / 装备 / 工坊 / 挂机 / 签到），但 Q07 前「挑战 / 深渊 / 团本」合成灰锁一格（D99）——好；Q07 后入口变多，**「今天该打哪」**仍靠 `%corerpg_p1_next%` 一行，缺少「本周精选 · 花样 · 体力剩余 · 挂机是否该降层」的一屏决策。
- 技能组说明在 hub lore（烬斩 / 烬突 / 踏步），**形状与身法方向**在技能页——容易漏。

**C. 挂机软顶体验**

- 设计闭环正确：满额 ≈ 主动日的 6–11% 币（`DESIGN-ember-afk-p1`）；装备差 → 扛不住高层 → 回主线。
- 痛点：T4「刚首通 Q07 扛不住」是故意的，但**软顶到达瞬间**反馈主要是 ActionBar「今日 N/2400」——到顶后继续站着「零收益」的失落感偏强；菜单已有战况格，可再强化「今日已满 · 去打主线」按钮跳转（体验，不改数值）。

**D. 体力节奏**

- 基线体力日 ≈ 3 次合格主线结算（书 §9.5 情景）；月卡 +30 上限（`StaminaService` / cash）按 D282 仍服务登录礼。
- 痛点不在「次数太少」，而在**三次是否三次同质**——同质则腻，异质则耐玩。

## 2. 体验加固提案（按优先级分窗）

> 每条：**玩家感知 · 改哪些系统 · 不动什么 · 风险**。全部遵守：不抬通关率预算（p1sim 42 格 ±2pp / 侧移择优规则沿用 skill-kit）；不改基础掉落张数；六槽不做。

### P0 · 「本局教了你什么」——Boss 破绽 / 事件反馈窗（体验主窗）

| | |
|--|--|
| **玩家感知** | 预警出现时有一句可读提示；破绽打出时有短反馈（ActionBar / 标题）；结算多一行「本局：撞墙破绽 ×1 · 破招成功 · 限时清房 ✔」 |
| **改哪些** | `EmberRunDirector` 破绽触发点（已有 `wall_stun` / `whiff_stun` / `break_hp`）；结算串 `EmberSettleService` / `EmberRunService` 结算段；TrMenu 挑战 / 冒险 lore 补「本图招牌破绽」；可选 `ember-v1-runs.yml` 每图 `hint:` 文案键（只文案） |
| **不动** | 招式伤害、冷却、掉落、体力、周 cap |
| **风险** | 提示刷屏 → 限「每招种首次 / 每局摘要」；文案过长 → 只写动词 |

**验收：** 静态 rg 提示键；合批冒烟每图触发一次破绽见摘要行；p1sim 不变（纯反馈）。

### P1 · 技能「局内决策」加固（不扩守招）

| | |
|--|--|
| **玩家感知** | 每 8 秒烬斩 / 烬突二选一更醒目；安全区换形状有预览；身法前冲 / 后撤在 HUD 或技能页一眼可见 |

### P2 · 重打「短目标」——花样 / 誓约 / 残响可见化

| | |
|--|--|

3. 团本 R01「建议炽愈」类提示扩到每本一条（已有先例 D166）。

## 4. 副本差异化与再刷动机

### 4.1 七线是否换皮？

**结论：结构同构，机制层已有差异；玩家感知仍偏换皮。**  
差在「教学与反馈」，不在「再做 Pack 6」。

每图应有一张**玩家能背下来的名片**（建议写进冒险页 lore，批准后施工）：

| 图 | 名片（草案，待批） | 已有机制锚点 |
|----|-------------------|--------------|
| Q01 灰烬庭院 | 学预警 · 重斩落空破绽 | `whiff_stun` Pack4 |
| Q02 焦骨甬道 | 冲撞引墙 | `wall_stun` Pack3 |
| Q03 残誓地窖 | 召唤压力 + 双签名门槛 | 签名 / 双签名解锁 |
| Q04 潮蚀水道 | 落差 / 冲击圈走位 | 地图机制 + whiff |
| Q05 断塔回廊 | 斧刃横扫 · 团本同源 | R03 地图 |
| Q06 霜封哨所 | 半血破招（霜潮汲取） | `break_hp` Pack5 |
| Q07 锈轨矿道 | 冲撞撞墙 + 炉心破招 | wall + break |

### 4.2 Boss / 房压是否可感？

- **可感条件：** 玩家知道窗口存在。P0 反馈窗就是为这个。
- **房压：** 事件池 9 + 词缀 12 已够用；再扩需 POLICY 级重启扩包理由（真人「不可感」证据）。

### 4.3 掉落是否值得再刷？

现行值得刷的理由（已有）：

- 成色 / 精工（极品仅掉落）
- 目标族偏向 + 印记 8 兑
- 图签名烙印 12% + 徽记（烬炉 / 调律）
- 精选周印记、挑战成色权重、深渊高层成色表
- 花样碎片 / 事件核心（小）

**缺口（G1）：** 基础件无 `source_map` 玩家叙事（D245 origin 已是 OP 向、行为中性）。本阶段**不**开「图专属基础件」大改（属 S4 装备结构）；体验侧用**签名名片 + 徽记进度条（菜单）**先让「这图有自己的东西」可见。

**不要：** 为「再刷」加第 N 种材料或抬单局币。

## 6. 维护性：该一次性设计再做的坑（5 个）

1. **差异化「可感性」无仪表盘** — 继续 Pack 而不测量「破绽触发率 / 事件成功率 / 签名佩戴率」→ 堆机制玩家仍喊换皮。→ **先做 P0 反馈 + 轻量遥测计数（仅 OP / 日志）规格**。
2. **上帝类再堆分支** — `EmberRunDirector` 内容包成本（ARCH R2）。S3 原语已落地——**新体验必须组合原语，禁止新手写招式大分支**（除非批为 S3 扩展）。
3. **天赋 / 词条「假选择」** — build-diversity 已证一排无感、拆分已改破甲；若薄修文案不改数值认知，玩家仍觉得成长假。→ **要么 sidegrade 返工（模拟门禁），要么标成经济便利，禁止中间态**。
4. **付费三轨文案漂移** — 月卡开、VIP/pass 关，若菜单仍像旧 RPG 壳，每一次客服都是设计债。→ **一次付费口径页 + 菜单对齐（§5）**。
5. **副手 / 六槽 / P1 公式双轨** — 灰粮副手走 StatService，P1 走 EmberFormula；长期双计风险。→ **要么声明副手永不进 P1 B/H，要么替换预算并轨；禁止默默叠**。
