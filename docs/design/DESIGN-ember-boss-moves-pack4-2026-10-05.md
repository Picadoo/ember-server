# Ember Boss Moves Pack 4：落空破绽（D192，2026-10-05）

> 状态：**已上线 CoreRpg 1.65.30 / balance_version 53**（routine-0815）。发布凭证 `docs/status/RELEASE-ember-1.65.30.md`；门禁 `tools/p1sim/out-whiffstun-d192.md`（MAX_ABS_DPP 2.9，cap 3.0）。
> 前置：D140（每首领 +1 预警招）、D173（半血转阶段）、D188（撞墙破绽：冲撞撞实心墙眩晕 1.5 秒）。本包把 D188 的「读招 → 破绽 → 输出」从冲撞推广到 Q01–Q05 首领的**主重招**。
> 参考：Monster Hunter / 魂系「招式落空后的硬直」（whiff punish）、WoW 首领大招打空后的「力竭」短窗口、Diablo 3 首领大招的收招时间。共同点：**惩罚窗口只奖励真的躲开了的人**，而不是站远不打的人。

## 0. 一段话裁决

Q01–Q05 每个主线首领指定**一条主重招**（重斩 / 砸地 / 誓斩 / 冲击圈 / 斧刃横扫）。预警开始时**有人站在预警范围里**，落下时**范围里一个人都没有**（全员躲开）→ 首领**踉跄 0.5 秒**：不放招、普攻取消、定身，已排队的后续招顺延。聊天一行「落空！… 踉跄 0.5 秒 · 破绽，趁现在输出」。Q04 冲击圈普通伤害 22 → 25 抵消（挑战 / 深渊走 heavy 覆盖不变）。Q06 / Q07 不加：Q07 已有冲撞撞墙 1.5 秒 + 重砸固定收招 1.5 秒；Q06 两段刀气第二段右移 4 格，躲开第一段的人一般不在第二段里，挂在第二段上几乎不会触发，挂第一段又会把二段推迟、让组合变简单。团本 r01–r03 不动。

## 1. 白话版（给服主 / 玩家）

- 前五张图的首领，最痛的那一招如果大家都躲开了，它会踉跄一下（半秒），这时多砍一刀。
- 必须是「本来会被打中、然后闪开」才算：一开始就站得远远的不算躲，不会踉跄。
- 有一个人被打中就不踉跄（组队时要大家一起躲）。
- 图鉴每个首领页多一行「破绽」说明，该招一行写着「全员躲开会踉跄 0.5 秒」。

## 2. 规则

| 项 | 值 |
|---|---|
| 字段 | runs yml 技能 `whiff_stun`（秒）；只认非 `charge`、非 `share` 的招；钳位 ≤ 2.0 |
| 装备（armed）| 预警开始那一刻（`startWarn` 锁定原点 / 方向后）用同一个 `inShape` 判断，本局在场、活着、非旁观的玩家至少 1 人在形状内 |
| 落空 | 落下时 `execute` 命中 0 人 |
| 效果 | 与 D188 同一套 `stunUntil`：不放招（`recoverUntil` 顺延）、普攻取消（`EmberCombatListener` 已有的 `bossStunned`）、SLOW 10 定身、已排队 follow 顺延到踉跄结束 |

| 互斥 | 冲撞只有撞墙破绽；同一次出招不会两个都触发 |
| 继承 | 挑战 / 深渊 / 连战 / 前哨 / 残响沿用（`withDmg` 复制保留字段）；团本 r01–r03 无字段 |

## 4. 设计 / 漏洞审查

| 风险 | 结论 |
|---|---|
| 奖励重复领取 / 刷物品 | 无奖励、无掉落、无物品；只改首领出招时间 |
| 周上限绕过 | 不涉及任何计数 |
| 重试刷 | 不涉及 |
| 站远不打骗踉跄 | 装备条件要求预警开始时有人在形状内；站在范围外的预警不装备 |
| 连锁定身 | 每次出招最多一次；该招 every ≥ 10.5 秒，踉跄 0.5 秒，上限约 5% 时间；与撞墙破绽互斥（冲撞不带 whiff） |
| 组队一人诱招 | 允许，这就是想要的配合（一人站扇里诱招闪开，其他人输出）；有人被打中就不踉跄 |
| 挂机庭 | 挂机庭是个人 MM 怪包，不走首领导演，不受影响 |
| 新永久战力 / 乘区 | 无；不改装备、天赋、套装 |
| 化妆品 | 无（只用现有 CRIT 粒子 + 原版音效，与 D188 同） |

## 5. 实现

- `EmberRunMaps.Skill.whiffStun`（解析 + 复制构造保留）。
- `EmberRunDirector`：`pendingArmed`（`startWarn` 末尾 `anyoneInside`；`startShifted` 清零）、`execute` 返回命中人数、`whiffs(armed, landed, done)`（静态，可单测）、`whiffStun(...)`（同 D188 的 `stunUntil` / `recoverUntil` / follow 顺延，日志 `[P1 run] <run> whiff stun <招> 0.5s`）；预警提示装备时加「全员躲开它会踉跄 0.5 秒」。
- 单测 +3：`whiffStunParsesOffChargeAndShareAndIsCapped_D192`、`whiffOnlyWhenArmedAndNobodyHit_D192`、`earlyBossesStaggerOnAWhiffedHeavyMove_D192`（294 / 0）。
- p1sim：`Fight.hurt` 躲开时返回 True；`WHIFF_STUN` / `WHIFF_ARM` 开关；门禁 `tools/p1sim/whiffstun.py`。
- 图鉴 `ember_p1_codex.yml`：Q01–Q05 该招一行 + 「破绽」一行；Q04 冲击圈伤害 25；连战页斧刃横扫注「躲空踉跄 0.5 秒」。
