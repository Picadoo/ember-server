## 3. 可落地（方案 M）

### 3.1 轮换钉死（只读 · 零经济）

| 项 | 口径 | 纪律 |
|----|------|------|
| 时区 | Asia/Shanghai（与日帽同） | 禁 UTC 漂移 |
| 映射 | `idx = floorMod(LocalDate.toEpochDay(), 19)` → `sx01`…`sx19`（idx0=sx01） | **稳定日更**；禁随机每进菜单变 |
| 键 | `%corerpg_p1_sx_today%` / `_name` / `_day_line`（可选 `_fc`） | 名称取 runs 短征 name；day_line **复用**既有逻辑 |
| 进本 | `corerpg p1 enter <sx_today>` 或别名 `enter short-today` | **同**现网解锁/体力30/日帽；禁第二奖励轨 |
| 奖励 | **不变** | 禁抬有奖次数/包/首通 |

### 3.2 窗拆分

| 窗 | 做什么 | 不动 |
|----|--------|------|
| **W1a · 轮换 PAPI（必做 · 插件）** | `EmberRunPapi`（或并列）增 `sx_today` / `sx_today_name` / `sx_today_day_line`；单测覆盖 mod 边界 | 不改 featured 周规则；不改日帽计数 |
| **W1b · 今日推格（必做 · TrMenu）** | `ember_p1_short` 末行空位落 **D**：`'#PRSJ   #'`→`'#PRSJD  #'`；名 `§e今日推 · %corerpg_p1_sx_today_name%`；lore：day_line +「0 点换下一本」+「与下方各本同规则」；actions：`enter %corerpg_p1_sx_today%`（或 short-today）；未解锁/体力不足灰态对齐该本格 | 不改 A…J 十九本格；不改 Z 返回；不改 B 去哪花 |
| **W1c · Open / 冒险半行（必做同批）** | 短征 Open +半行「今日推：%sx_today_name%」；冒险页短征入口 lore +半行同指针 | 不盖 D409 满态去工坊；不重写十九本墙 |
| **W1d · 事件窗（本窗不做）** | — | 后置 |
| **W1e · 经济/地图（默认不做）** | — | 禁动 S40–S58 / 地图 / MM |

### 3.3 玩家路径

| 步 | 路径 | 说明 |
|----|------|------|
| 看 | 开短征选本 / 冒险半行 | 见今日推名 |
| 进 | 点「今日推」 | 真 enter；门禁同该本 |
| 满 | 该本日帽满 | 仍可练习进；有奖规则不变 |
| 换 | 次日 0 点 | 自动下一本；无需玩家操作 |
| 自选 | 仍可点下方十九本 | 今日推=导航，不锁其它本 |
