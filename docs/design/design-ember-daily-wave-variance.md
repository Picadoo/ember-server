
| 线 | DP | 改哪一房 | 新节奏一句话 | 玩家应感到 |

- `delay` 单位秒（实现按 DP 语法改）；`需清`=计入开门 `$kill`。  
- 刷点写 **相对现网门/房间语义**（施工用现坐标表微调，勿为波次重挖地形）。

## 4. 不动清单（防范围蔓延）

| 项 | 说明 |
|----|------|
| 体力 | 仍 30 / 同池；不改上限日切 |

## 6. 验收硬条

1. 七线仍：选本 → 分房真门 → Boss；体力 30；箱数量不变。  
2. **每线至少一房** 与旧「5→3→3」节拍可口述区分（用 §2 一句话抽检）。  
3. 焦骨假岔、锈轨支洞怪 **计入** 对应门击杀。  
4. 无「全员 +30% 血」式难度；时长仍约 5～8 分。  
5. Display 去色名与现 `$kill` 一致。  
6. 玩家路径零指令。  
7. **未批准前未改 YAML**。
