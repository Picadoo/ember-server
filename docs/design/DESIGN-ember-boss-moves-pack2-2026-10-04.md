# Ember Boss Moves Pack 2：半血转阶段（D173，设计-only，2026-10-04）

> 状态：**已上线 CoreRpg 1.65.23 / balance_version 46**（routine-0214）。实现见 `docs/status/RELEASE-ember-1.65.23.md`；门禁 `tools/p1sim/out-bossmoves-d173.md`（MAX_ABS_DPP 2.2）。
> 前置：D140（七首领各 +1 预警轻招，主招放慢抵消，6 格最大 Δ1.7pp）；技能形状只允许现有 `circle` / `cone` / `line` / `charge` + `follow` / `below` / `light` / `target: player` / `kb≤1`。
> 实现对齐：等 `COORD-asset-fix-1655` DONE **且** `COORD-gear-stage0` 释放 `tools/p1sim` 后，用 `tools/p1sim/bossmoves.py` 过 §7 门禁再动 runs yml。
> 参考：Diablo 首领半血转阶段、WoW 可躲开的预警圈 / 扇 / 条带、本服 R02「半血砸地接横扫」与 R03「烬核分摊」已验证的 `below` / `follow` / `share` 模式。**本包不做单人主线分摊（share）**——R03 是团本专属。

## 0. 一段话裁决

在 **Q01–Q07 主线首领**（普通 / 挑战 / 深渊复用挑战首领）上，加一套 **半血（HP < 50%）才出现的转阶段压力**：早期图（招式条目 ≤2）各加 1 条 `below: 0.5` 的轻招；后期图（已有 3 条计时招）**不新增第 4 条独立计时**，而是给既有轻招挂一条 `follow`（半血后才打出），避免预警叠在一起。全部 `light: true`、预警 ≥1.2s；主招或相关轻招再放慢一点抵消。**团本 / 连战首领配置本包不动**（仍用各自 yml）。不加永久乘区、不加新货币。已实现并上线。

## 1. 白话版（给服主 / 玩家）

- 每个主线首领打到半血后，招式会变一下：多一段要躲开的预警，或者原来那招后面多接一下。
- 前半场和现在一样；后半场要多看脚下 / 扇形 / 条带。
- 挑战版和深渊里这些新压力也有（走挑战轻值）；团本三个首领、余烬连战：**这包不加**（怕和现有团本机制抢注意力）。
- 图录七个主线首领格子会同步新招名字、范围、预警、躲法。

## 2. 为什么是 Pack 2（与 D140 的差别）

| | D140 | Pack 2（D173） |
|---|---|---|
| 主题 | 「每个首领多一招日常轮换」 | 「半血后打法变一下」 |
| 时机 | 多数独立 `every`；Q01 例外用 follow | **全部**挂在 `below: 0.5`（顶层或 follow） |
| 后期图 | Q04–Q07 直接 +1 独立计时（现已 3 招） | Q04–Q07 **禁止**第 4 条 `every`；只给现有轻招加 follow |
| 补偿 | 主招 `every` 放慢 | 主招或被加 follow 的那条再放慢 1～2s |
| 门禁 | 6 格 Δ≤约 3pp（实绩 1.7） | 同工具同格；目标 Δ≤2pp，硬顶 3pp |

## 5. 明确否决

| 想法 | 原因 |
|---|---|
| 单人主线 `share: true` 分摊圈 | 一个人吃满额；团本 R03 才合适 |
| 第 4 条独立 `every`（Q04–Q07） | 短战斗里预警叠爆；D140 后已经 3 条 |
| 无预警真实伤害 / 击飞出图 | 违反 §10.I；Q04 落差图尤其危险（`kb` 仍 ≤1 且不穿墙） |
| 改团本 / 连战首领 | 团本已有阶段性机制；连战三连压力已够；另开窗 |
| 新技能类型 / 粒子化妆品 | 用户 10-04：化妆品后置；形状库不扩 |
| 靠加伤「教操作」 | 门禁超了只许放慢 / 降 dmg / 加 warn，不许加薪 |

## 6. 漏洞 / 实现注意

| 风险 | 处理 |
|---|---|
| Q01 战太短，半血招放不出 | 同 D140：门廊突刺 every 偏长；若 sim 显示半血招触发率过低，改为接在重斩后的第二条 follow（互斥：不可与踏地同 delay 叠） |
| charge 贴墙 0 格假预警 | 已有 B2.165：短于阈值则跳过施放、CD 照走；焦冲沿用 |
| follow + 顶层同时亮 | 导演已有 recover；补偿放慢后用 bossmoves 查「同时预警」次数，必要时再拉长 every |
| 深渊自动带上 | 深渊用挑战首领 → 新招会出现；门禁必须含挑战 0.3/0.5/0.7 |
| 图录不同步 | 实现窗改 TrMenu `ember_p1_codex` + selfcheck 数字一致 |
| 重连 | 招式状态机跟 run 实例；不另存阶段标记 |

## 7. 平衡门禁（实现窗，非本窗）

工具：`tools/p1sim/bossmoves.py`（与 D140 相同格）。

| 检查 | 通过线 |
|---|---|
| Q01–Q07 × 普通/挑战 × dodge 0.3/0.5/0.7（6 格） | 每格通关率 vs 现网 Δ **≤2pp** 优先；硬顶 **3pp** |
| 种子 | ≥5 种子 × 4000 局取平均（Q01 短战斗噪声大） |
| 超标 | 只许：再放慢 every、降新招 dmg、加 warn、或把顶层半血招改成 follow；**禁止**加奖励 / 加永久乘区 |
| 经济 | 不改掉落 → 不要求 p2econ；若误动奖励表才开 p2econ |
