## §1 四件套触发与数值

### 1.1 触发条件（钉死）

| 项 | 规则 |
|----|------|
| **两件套** | **一字不改**（刃 + 护符同族 → 焚烬 / 烬爆 / 炽愈被动与觉醒 I/II/III） |
| **四件套激活** | 同时满足：① 两件套已激活（刃 + 护符同族 X）；② 穿着的 4 甲位里，**族 = X** 且 **自身掉落阶 ≥ T2** 的甲 **≥ 2 件** |
| **「阶」用哪一个** | **只用甲件自身掉落阶**（物品字段 `tier` / lore「掉落阶」）。**不用** F 跟随后的生效阶 / 强化。对齐 T1 §2 / §3.2 |
| **成色 / 精工** | **不计入**触发（只影响生命差与换甲动机，见 §2 / §3） |
| **空甲位 / T0 / 无族** | 不计件 |
| **散件取舍** | 另 2 个甲位可穿异族高成色 / 高精工（D169 保留）；菜单要让玩家看见「成套 vs 生命」的取舍 |
| **迁移甲** | 迁移发放的掉落阶 = 当时护符阶（T1 §3.2）；护符已 T2+ 的老号迁完即可具备「2 件 T2 甲」地板，**不额外送礼** |

**一句话（菜单用）：** `同族刃+护符，再穿至少 2 件同族且掉落阶 T2+ 的护甲，激活四件套。`

### 1.2 效果轴原则

1. **别抢戏：** 刃 = 攻击主轴；护符 + 两件套 = 族被动主轴。四件套只做**侧向**（减伤 / 短窗韧性 / 轻量回复辅助），**禁止**新增攻击系数、暴击、技能倍率、永久 `B` / 伤害乘区。  
2. **禁止永久大倍率：** 不作 `H ×1.1` 一类；炽愈 `sustain_hp_mult` **保持 1.00**，不借四件套加回。  
3. **行为型优先于面板：** 若做「改变手感」的效果，也须服从 1–2（例如短 CD 受伤减免，而不是抬 B）。  
4. **各族可感差异**（同触发、不同侧向文案），但 **C 档可先做「三族同一减伤」**，降低首发风险；S 档再分族。

### 1.3 两档可勾选

| 档 | 效果（纸面） | 进 P1 B/H？ | 相对 Stage1 基线 | 菜单一句话 |
|----|--------------|-------------|------------------|------------|
| **C · 保守（荐）** | 四件套激活时：**受到的 P1 伤害 ×0.97**（减伤 3%）。三族相同。无额外攻击。可加一条非战斗提示粒子 / 动作条小字（物品岗可选，非必须） | **不进** `EmberFormula` 的 B/H0/H/D；运行时受伤口径乘一次（类似签名 / 套装事件侧的「结算外」修正，须插件岗落在**单一**受伤钩子，防双计） | 等价 EHP ≈ **+3.1%**（1/0.97−1）。生命面板数字不变。对通关率：纸面远小于 ±2pp 敏感带（Stage1 甲精工差对应 H 中位仅 −0.46%）；**不预期**推动 W30 / 团本点估越线 | `§a四件套：受伤略减（−3%）` |
| **S · 标准（可勾，另号 T0）** | 在 C 的减伤之上**或改为**分族行为侧向：① **焚烬** = 连锁燃烧 P1b（剩燃最多 3s 传最近未燃目标，燃跳 ×0.9）——RESEARCH / 构筑报告曾 42/42；② **烬爆** = **禁止**聚爆类（曾越界），改「爆发后 2s 内自身受伤 ×0.95」一类短窗减伤；③ **炽愈** = 触发回复时额外清除 1 个短控 / 或低血（<40%）时减伤再 +2pp（须单测），**不**抬 `sustain_hp_mult` | 仍**不进 B**；行为影响通关率 → **必须**另号离线 T0（下表） | 焚烬 P1b 历史最大格约 +1.1 / −0.7pp；团本须重跑（多焚烬放大风险，RESEARCH §风险） | 各族一句，例：`§a焚烬四件套：燃烧会传到旁边的敌人（每跳略弱）` |

**推荐勾选：档 C。**  
理由：① Stage1 刚进观察期，先上可感、低耦合的侧向减伤，不跟两件套抢攻击戏；② 不进 B/H，公式 / 迁移不变量 / G6 逐位不受影响；③ 相对 K0 精工差（约 0.5% H），**−3% 受伤**是更清楚的「凑套理由」，又不足以逼所有人弃散件（另 2 甲位仍可追成色）；④ S 档焚烬连锁需重跑 42 格 + 团本，适合观察期后再开。

**纸面估算（C，参考 T3 护符 h=165、六槽 H≈320 量级）：** 面板 H 不变；有效承受 ≈ H/0.97。与「甲精工再追 1 档（≈+0.17 生命 / 件）」相比，C 的换甲动机主要来自**族进度**，成色 / 精工仍管面板生命（§3）。

### 1.4 是否进 P1 B/H · 对 p1sim 的含义

| | 档 C | 档 S |
|--|------|------|
| B | 不进 | 不进 |
| H0 / H / D / M | 不进（面板不变） | 不进 |
| 通关率 / 团本 | 预期噪声内；**可不跑完整动态 T0**，改做 §4.1 静态敏感度 + 测服冒烟 | **要** T0：静态 42 + 动态 21 + 团本 R01–R03（至少）+ 与 Stage1 基线 CRN 对照 |

## §2 族 / 成色 / 精工与换甲动机（TrMenu）

### 2.1 动机分工（K0 并存）

| 动机 | Stage1 | Stage2（本稿） |
|------|--------|----------------|
| 成色 / 精工 | **主因**（生命差） | **仍是主因之一**（K0：只靠掉落；菜单继续显示 Δ生命） |
| 族 | 只显示「后续开放」进度 | **套装进度主因**（凑 2 件同族 T2+ 甲） |
| 样子 | 材质随掉落阶 | 不变；成套时可加一句「四件套已激活」染色（可选） |

**结论：** K0 下仅靠精工差换甲偏「小数」；C 档减伤 + 真实套装进度足够支撑「为什么要同族」；**不必**为了动机默认上 K3（§3）。

### 2.2 护甲页改动（沿用 `ember_p1_armor`，施工阶段）

入口仍：`/ember` → 装备 → 护甲。S 格从「后续开放」改为真实状态机（**示例文案，文案岗定稿**）：

| 状态 | 名称（示例） | lore（示例） |
|------|--------------|--------------|
| 未成两件套 | `§7四件套 · 未激活` | `§8先让刃与护符同族` / `%corerpg_p1_awaken%` |
| 两件套有、同族甲 0–1 或阶不够 | `§e四件套 · 进行中` | `§f%族% 护甲 §e%n%/2`（只计同族且掉落阶≥T2） / `§7还缺：%部位列表或「任意同族 T2+」%` / `§8掉落阶不够的同族件：%列表%（F 跟随不计入）` |
| 已激活 | `§a四件套 · 已激活` | `§a受伤 −3%`（C）或各族句（S） / `§7另 2 甲位可穿异族追成色` |

比较行（候选格）**并排** Δ生命与套装进度（示例）：

```
§f背包里：胸 · 焚烬族
§7成色 优 → 精 · 精工 二 → 三
§a生命 +0.5
§e四件套 护甲 1/2 → 2/2（可激活）   ← 仅当进度变化时显示
§e点击换上
```

- 族不变且进度不变：不刷套装行（减噪）。  
- 换上会**丢掉**激活：`§c四件套将中断（护甲 2/2 → 1/2）`。  
- 全程菜单点击、NI 物品、**无命令教学**（与 Stage1 同）。
