**一句话问题：** 成色/精工权重与工坊价早已定死，印记「n/8」也看得见；毕业后再刷仍像「赌极品」——因为**装备页 / 工坊 / 结算都不回答「你离下一档成色·精工还差什么、这局掉的件比身上好在哪」**。

## 1. 玩家感知目标（≤3）

1. **打完一眼：** 结算或掉落对照里，能看出「这件成色/精工相对穿着件：更好 / 同档 / 可养」——不靠猜掉率表。  
2. **城里一眼：** 装备页或工坊预览旁，穿着刃/护符显示当前成色·精工 + **下一档费用或「极品仅掉落」**（短文案）。  
3. **不抬经济：** 不改权重表、不改工坊价（除非另批 R）、不加新材料、不抬单局币；印记 8 兑与徽记价保持。

## 2. 方案表

### 2.1 方案 M（**荐** · 菜单 / 结算可见进度 + 近档提示 · **零经济改**）

| 窗 | 改什么 | 不动什么 | 热更 |
|----|--------|----------|------|
| **W1a · 装备页进度** | `ember_p1_gear`（或工坊入口旁）：穿着刃/护符各 1～2 行：`成色 精良 → 下一档卓越（胚16 骨16 币1600）` / `成色 卓越 → 极品仅掉落`；精工同理至满档「已满」 | 不改 `qualityCost` / `refineCost` 数值 | TrMenu + 只读 PAPI（如 `p1_gear_next_q` / `p1_gear_next_c`） |
| **W1b · 工坊近档** | `ember_p1_forge` 精工/成色预览格：在规则句下加「手持件：当前 → 下一档 + 费用摘要」（可复用预览命令已有 Plan 文案思路，菜单侧只读展示） | 确认仍走现有 preview→confirm；费用仍以聊天为准作权威 | TrMenu ± 薄 PAPI |
| **W1c · 结算对照（轻）** | 通关发 ITEM 时：若存在同部位穿着件，追加**一行**短对照：`相对穿着：成色↑/精工↑/同档/低于`（极简；可与 D295 摘要并列，**不**改破绽摘要语义） | 不改掉落权重、不改 grant 数量 | jar 结算文案 + 可选 |

**期望：** 把「再刷为什么」从隐式赌表拉到**菜单 + 结算决策面**；通关率 / 币沉 / 掉率预算 **零移动**。

**荐批：** **批 M（W1a+W1b 必做；W1c 同批或续窗观察摩擦）**。

### 2.2 方案 R（工坊费用或节奏轻调 + p1sim 门禁）

| 项 | 内容 |
|----|------|
| **做什么** | 仅当批 M 后真人仍喊「看得见但养不起 / 2→3 精工劝退」时：轻调 **单档** `refineCost` 或 `qualityCost`（例：仅 1→2 成色胚骨−25% **或** 仅 2→3 精工币−20%——**一次只动一档一行**）；**禁止**同时动掉率表 |
| **门禁** | `tools/p1sim` 相关经济/升档路径（既有 C05/C06 成本断言扩展）+ 主线通关率 **不动**（本稿不改战斗键）；币沉周口径对照：升档消耗下降幅度须有上限说明 |
| **相对 M** | 真改节奏；有经济副作用。**默认后置**；证据未显示「价劝退」为主因前不荐首批 R |
| **本稿建议** | 总控可勾 **批 M**；若坚信价是主因再勾 **批 M+R**（R 仍须单档 + 门禁） |

### 2.3 方案 W（**否决默认** · 抬掉率或新材料轨）

| 项 | 内容 |
|----|------|
| **提议（不采纳）** | 抬 `QUALITY_WEIGHTS` / 挑战表 / 深渊极品%、或新增「成色材料 / 精工石」第 N 轨、或抬单局币激励再刷 |
| **否决理由** | ① 加固债 #3 / tip 明文禁止「为再刷加第 N 种材料或抬单局币」；② 抬极品权重直接扭曲 42 格与挑战标定外的掉落预期；③ 新材料轨增加分解/商店/背包复杂度，反馈周期未必更短（多一层养成）；④ 图专属基础件属 S4，本阶段不做 |
| **结论** | **默认否决**；批注不提供「批 W」勾选 |
