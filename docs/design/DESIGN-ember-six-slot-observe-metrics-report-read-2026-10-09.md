## §2 报告读法口径（方案 M）

### 2.1 定位（与已有清单分工）

| 项 | D326 §2 必抽 | D342 / D364 | D363 | **本口径（报告读法）** |
|----|--------------|-------------|------|-------------------------|
| 问题 | 测什么才算 PASS | 班次/签字复跑查现态 | 关窗短语勿误读 | **写/读报告时指标各字段表示什么、禁止推出什么** |
| 时机 | 观察抽测号 | 班次 / 满窗前预检 | 任何「像关窗」措辞 | **每次写观察相关 STATUS / 读证据包** |
| 动作 | 跑 M1–M9 | 只读勾选 | 短语对照 | **按 §2.2–2.3 读字段；禁 §2.4 推断** |
| 出口 | PASS/FAIL | 红报或不拧 | ≠关观察 | 报告语义正确；**≠**改 live |

**批 A = 采纳本口径。批 A ≠ 关观察 ≠ 开闸 ≠ 改 ×0.97 ≠ 开 R ≠ 勾选 §2.4。**

### 2.2 读什么（字段 → 合法含义）

| 报告常见写法 | **合法读成** | 真源指针 |
|--------------|--------------|----------|
| **档 C** / Stage2 set bonus | 激活受伤侧减伤方案（不进 B/H）；现网已 live 观察 | D325 · D326 |
| **`set_bonus=true`** | 线上开关开着；四件套减伤钩子可触发（仍须满足激活条件） | ember-v1 · D344 保护键 |
| **`set_bonus=false`（短暂对照）** | 仅抽测对照（如 M5）；测完须恢复 true 并记 STATUS | D326 M5 · D327 |
| **×0.97** / −3% | 激活且条件满足时，该次受伤相对未套装基线的**乘区**；钉死值 | D325 · D326 M2 |
| **D325 日志行**（例：`D325 四件套受伤 ×0.97: 1.00 → 0.78`） | 该次受伤事件套装乘区已应用；应与同事件 `[P1伤害]` **至多一条** | D326 M8 · D327 |
| **`final 0.78`（相对基线 0.80）** | 采样世界（常 ember_afk）下相对毒伤基线的结果样例；**仅证据** | D327 spot |
| **bv=62** | 构建/配置钉点；与 Stage2 live 对齐 | D325 · D343 |
| **M1–M9 整轮 PASS** | 必抽测项已过 ≥1 轮；**是**绿出口门槛之一，**不是**已关观察 | D326 §4 · D338 G2 |
| **三开关全 true** | enabled/migrate/set_bonus 现态合格（观察维持） | D342 R1 · D364 D1 |

### 2.3 不读成什么（禁推断）

| 见到… | **不等于** | 为何 |
|-------|------------|------|
| 报告里出现 ×0.97 / −3% | ≠「该改成别的倍率」≠授权拧数字 | ×0.97 **钉死**；改倍率=新平衡窗 |
| M2 PASS / 见 D325 行 | ≠关观察 ≠勾选 D338 §2.4 | 关窗须满日历 + 另号签字 |
| `set_bonus=true` | ≠开 K3 ≠开 `k3_refine` ≠开样本 R | 开闸走 D341；R 全表禁 |
| `final 0.78` / 毒伤样例 | ≠玩家面 KPI ≠战力分 ≠公开排行素材 | 禁玩家面 KPI；仅运维证据 |
| 「减伤生效 / 套装激活」 | ≠可提前关窗「观察够了」 | 日历 ≥**2026-10-10 17:40 CST** 不动 |
| 本页（本口径）**批 A** | ≠关观察 ≠改系数 ≠开闸 | 仅采纳读法表 |
| 值班 D3 / 复跑 R3「倍率未改」PASS | ≠授权改倍率「验证一下」 | 只读；异常只报不拧 |
| 附录已写 / 菜单诚实结案 | ≠关观察（见 D363；此处不复述正文） | 关窗另号 |

### 2.4 写报告时最小纪律

1. **写减伤/套装类观察报告：** 若引用 ×0.97 或 D325 行，同段或表注可指针本口径 §2.2–2.3（半行即可）。  
2. **禁止**在观察报告末写「建议改 ×0.9x」「建议关观察」「建议开 R/K3」（无总控另号授权时）。  
3. **短暂 `set_bonus=false` 对照：** 必须写「已恢复 true」+ 时间/证据；否则读者易当成事故回滚。  
4. **与白板注记：** 分解/经济类仍走 D361 标准句；本口径**不**替代白板注记（不复述 D361 正文）。  
5. **与关窗/开闸禁误读：** 关窗短语 → D363；K3 短语 → D362；本口径只管**指标字段**。
