## 0. 问题与目标

**现状：** 全服可交互「人」只有 **灰烛**；锻炉 / 附魔 / 强化 / 补给全靠 TrMenu + 告示，工坊像空壳。  
**目标：** 工坊旁能看见职能 NPC，右键直接进对应菜单或短引导；菜单 `/ember` 仍保留，NPC 是场景入口，不是第二套数值。

## 2. 交互规格（玩家视角）

### 2.1 灰烛 `ember_guide`（已有）

- **不动：** id / 坐标 / 主线 talk / `talk_radius` / CoreRpg 创建逻辑。  
- 落地本批 **不要** 改其右键去开菜单，避免冲掉 quest talk。

### 2.2 锻炉师 · 烬砧 `ember_smith`

**主路径（一次右键）：**

1. tell（可选 1 行）：`§6烬砧：§f刃与护符，放到菜单里锻。材料不够就去挂机庭。`  
2. 立即 `menu: ember_forge`（或底层等价打开该菜单）。

**副交互（强化 / 镶嵌）— 锁定方案 A（禁止方案 B）：**

在 `ember_forge` 布局内加图标（少套娃，一点进 forge 同页可去）：

| 图标 | 名 | 动作 |
|------|----|------|
| 铁砧/红石 | §c去强化 | `menu: ember_enhance` |
| 绿宝石 | §e去镶嵌 | `menu: ember_socket` |

不采用「潜行右键 / 对话三选一」分流。

**禁止：** lore / tell 要求玩家手打 `/corerpg forge` `/corerpg enhance`。菜单底层可继续挂这些 command。

### 2.3 咒火师 · 余晶 `ember_enchanter`

附魔主流程是 **手持余烬附魔晶 + 原版经验 → 右键附魔台**（CoreEnchant），不是聊天指令。

**右键一次（强制）：**

1. tell 1～2 行：  
   - `§d余晶：§f把附魔晶放在热键栏，对着旁边的附魔台用。`  
   - `§7刃与护符分表；晶不够去日常或补给看看。`  
2. **立刻打开引导薄菜单**（新建 `ember_enchant_guide`，或复用 hub 附魔说明页），至少含：  
   - 说明「用手持晶点附魔台」（主路径）  
   - 按钮「打开强化」→ `ember_enhance`  
   - 按钮「打开锻炉」→ `ember_forge`  
   - **禁止**「请输入 /enchant」或任何附魔指令教学  

**仅 tell、不开菜单 → 验收 FAIL。**

**禁止：** 要求玩家打 `/enchant` 或任何附魔命令。

### 2.4 补给官 · 灰粮 `ember_quartermaster`

- 右键：tell 一句 `§a灰粮：§f面包、竿子、代烤，点菜单就行。` → `menu: ember_life`  
- 无副交互。  
- 站位在广场，方便出生点回头就能看见「人」卖粮，减少只认告示。
