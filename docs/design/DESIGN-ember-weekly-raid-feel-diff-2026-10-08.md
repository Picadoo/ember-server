**一句话问题：** 日刷与深渊已有节奏名片；团本三本机制虽厚，入口与本间仍像同骨架换 Boss——要在**不抬体力/掉率、不新开地图包**前提下，让 **入口一眼可分 + 本内段/波线索可感**（同 Multiverse 轻差异）。

---

## 1. 玩家感知目标（≤3）

1. **开团本页一眼分清三本节奏身份：** 每本有可背短签（名片 + 本间线索），不靠读完三段长 lore 才分清「冲撞 / 半血砸地 / 烬核」。  
2. **进本后段/波线索与真实编排一致：** R1→R2（事件）→R3→Boss（及半血/烬核）有短反馈，与 YAML 真实阶段一致；不靠抬掉率/新材料/新地图包堆辨识。  
3. **周规则与团本身份不糊成一锅：** 玩家能感到「本周精选规则」是日刷挑战 remix，「团本三本」是组队机制本——入口短签各说各的，不互相偷换。

## 2. 方案表

### 2.1 方案 M（**荐** · 菜单/本间节奏短签 + 软段线索 · 零经济 · 零新 Pack）

> **原则：** 先把「本名片 + 本内段线索」做进可感层；**禁止**纯 lore（文案宣称段差、局内零揭示且无真实机制锚点）。复用 D195 已有破绽/烬核与房间标签，不重造三本地图。抽 D302「软段签 + 进层/进本揭示」形。

| 窗 | 做什么 | 不动 |
|----|--------|------|
| **W1a · 入口节奏短签（三本）** | `ember_p1_adventure` 团本三格在长 lore 之上加两行短签（展示意向）：`§d名片：…` + `§b本间：…`。例——**R01** `名片：冲撞撞墙破绽` · `本间：三房推进 · 半血增援`；**R02** `名片：半血砸地破绽` · `本间：三房推进 · 半血转阶段`；**R03** `名片：烬核分摊` · `本间：三房推进 · 全队靠拢`。状态/体力/周 cap/结算段可收束或下移，**不改**数值 | `cost:50` · `weekly_cap:3` · `cap_group` · 掉落表 · HP/伤 |
| **W1b · 进本/本内软段线索** | 进本瞬间聊天短行或 actionbar：`本局：锈轨矿道·团 · 名片：冲撞撞墙`；房清/进 Boss/半血/烬核触发时各 **≤1** 行短提示（对齐现行房间 `label` 与 Boss 阶段键，文案钉死真实机制）。施工可择 TrMenu 进本 tell / jar 揭示（对齐 D302 W1b） | 不改 a/b 房压、不改 skills 数值（除非另批 R） |
| **W1c · 周规则入口对照（可选同批）** | 冒险页「本周短目标」或挑战页已有 `%corerpg_p1_modifier%` 旁加半行身份钉：`§8周规则＝精选挑战 remix · 团本不受影响`（与 modes 页口径一致）；**不**新开周本图、**不**改 modifier 池 | `rotation.modifiers` 池与权重 |
| **W1d · 材料/色阶轻收束（可选）** | 三本格材料已铁/钻/金胸甲——可与短签色阶对齐（例 R01 铁·冲撞 / R02 钻·霜砸 / R03 金·烬核）；返回键不动 | 不改进本指令 / 解锁逻辑 |

**期望：** 点本前看见名片+本间；进本后段线索挂在真实 R1–R3/阶段上——可感差来自**短签 + 真实机制揭示**，不是假编三句不同 lore。

**荐批：** **批 M**（W1a+W1b 必做；W1c/W1d 同批或可砍）。

### 2.2 方案 R（轻量 Director / 波次喘息 / 门延迟按本或按段 · **禁新地图包**）

| 项 | 内容 |
|----|------|
| **做什么** | 在 `raids.r0X` 下增**可选**编排键（缺省 = 现行，保证回滚），例：按本 `door_delay`（叠在 R1/R2/R3 门上，0～1.2s）· 或 `event.after` 分本（现皆 r2 → 邻本不撞同一挂点叙事）· 或 Boss 前短喘息 / 半血前提示窗（演出级，不改伤） |
| **玩家感知** | 「锈轨门开得快；霜封清完喘半拍；断塔事件偏早」——与菜单本间短签一致 |
| **回滚** | 键缺省/空 = 现行；单键可热关 |
| **相对 M** | 表达力更强（本本身有编排差）；jar/YAML 面更大；须与 D300 七图旋钮语义对齐，避免团本与日刷短签口径分裂 |
| **本稿建议** | **不荐纯 R 首批**；若总控要本内编排差，勾 **批 M+R**（先 M 短签+揭示，R 作续窗或同批轻旋钮）。R **仍禁**新地图包 / Pack6 / 抬房压全局伤 / 抬体力掉率 |

### 2.3 方案 W（**否决默认** · 新团本/周本地图包 / Pack6 / 重铺三本）

| 项 | 内容 |
|----|------|
| **提议（不采纳）** | 新开团本/周本地图包、Pack6、或重铺 R01–R03 地形/刷点拓扑，用「新内容」制造本间差 |
| **否决理由** | ① tip / ARCH：**禁 Pack6、禁新团本·周本地图包**；② 与「同 Multiverse 轻差异」目标相反，工期大、边际递减；③ D300/D302 已证明痛点在**入口短签 + 真实编排/机制可感**不在再堆图；④ R01–R03 机制名片已厚（tip：团本已厚，不改派挂机庭/Boss 预警大修）；⑤ 抬体力/掉率不在本题且硬禁 |
| **结论** | **默认否决**；批注**不**提供「批 W」勾选 |
