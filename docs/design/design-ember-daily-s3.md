## 3. 动线（共用骨架）

与父稿 / S2 一致，仅换地图与怪：

```
枢纽选本 → 体力≥30 则扣 30 → DP 实例安全落点
  → 房1 清怪 → 开门 → 房2 清怪 → 开门 → Boss → 通关箱 + daily_clear → 回枢纽
```

| 步骤 | 线 D 玩家所见 | 线 E 玩家所见 | 失败 / 撤离 |
|------|---------------|---------------|-------------|
| 落点 | 干岸闸门内侧，前方桥锁 | 塔底大厅，前方上阶门锁 | 菜单回枢纽；未通关无箱；体力不退 |
| 房 1 | 第一段沿岸平台 / 短桥 | 底层厅（上阶前） | 同左 |
| 过渡 | 开闸/开桥；水面可走浅滩（可选） | 上一段楼梯或断桥补板 | — |
| 房 2 | 对岸厅 / 折桥混编 | 中层环廊混编 | — |
| Boss | 闸门厅 / 池边平台 | 塔顶露天台 | 击杀结算 |

**时长目标：** 熟手 **≈5 分钟**，摸索 **≈8 分钟**（±1 记债务，不记视觉 PASS）。

## 4. 线 D · 余烬窟·潮蚀水道

### 4.1 一句话

被潮水啃穿的补给渠：桥一段断一段，沿岸清怪开闸，尽头闸厅里还泡着不肯退的潮蚀蛮兵。

### 4.2 地图规格（施工意图）

| 元素 | 规格 |
|------|------|
| 外轮廓 | 总长感 **约 48～64** 格沿运河轴；战斗面宽 **4～6**；Boss 厅 **≈12×12** 平台 |
| 水面 | 中央或侧缘常驻水层；浅滩可走；**禁**无底虚空落水秒杀；落水最多减速/小伤 |
| 门 | ≥2 道「清完才开」的真闸/桥门 |
| 主材 | `prismarine` / `prismarine_bricks` / `sea_lantern` 点缀 / 湿 `stonebrick` / 铁栏桥；少量子水源装饰 |
| 垂直 | 同层为主；允许 ±1 踏步上桥；**禁止**整盘下潜成地窖翻版 |
| 禁 | 复制焦骨直筒；复制庭院环廊；空板岛；迷宫叉路超过 1 条短支 |

**建议本地坐标意图（可平移，施工后写入 DP）：**

| 点 | 意图 |
|----|------|
| 出生 | 干岸闸内 `0,64,0` 朝 +Z |
| 房1 | z 6～16 沿岸平台刷点 |
| 过渡桥 | z≈18～22 可开桥 |
| 房2 | z 26～36 对岸/折桥厅 |
| Boss | z≈44 闸厅平台中心，须可绕；水在边缘不挡走位 |

### 4.3 建议波次（怪物岗 · 数值一次平衡）

| 阶段 | 建议 MM（**新建**，前缀 `EmberDailyTide*`） | 数量感 |
|------|---------------------------------------------|--------|
| 房 1 | `EmberDailyTideZombie`（潮蚀尸） | 5～6 |
| 房 2 | 潮蚀尸 + `EmberDailyTideSkeleton`（浪矢骷，桥栏后射） | 3+3 或 4+2 |
| Boss | `EmberDailyTideBrute`（潮闸蛮兵）：池边冲锋/拍水感；Display/装备/技能名独立 | 1 |

> **勿**复用 `EmberAsh*` / `EmberCrypt*` / 庭院日怪冒充差异；亦勿与深渊 `EmberAbyss*`、挂机 `EmberAfk*` 撞 id。

### 4.4 节奏备注

桥面窄 → 走位重要，但 Boss 厅必须够绕。假支路最多 **1** 条短死桥（10～15 秒），不要运河迷宫。

## 5. 线 E · 余烬窟·断塔回廊

### 5.1 一句话

半塌的了望断塔：一层层往上爬，缺口栏外是风，顶台还站着最后一个塔卫。

### 5.2 地图规格

| 元素 | 规格 |
|------|------|
| 垂直 | **至少 2 段上阶**（总抬升建议 **8～12**）；三层语义：塔底 → 中层环廊 → 塔顶 Boss |
| 水平 | 底层厅 ≈14×14；中层环廊外径 ≈12～14、廊宽 2～3；顶台直径 ≈10～12 |
| 门 | 底清完 → 开上阶；中清完 → 开顶门（≥2 道真门） |
| 主材 | 风化 `stonebrick` / `cobble` / 木梁·脚手架感 / 缺口铁栏；顶台可露天 |
| 边缘 | 允许「看得见落差」；**必须**有栏或宽台防误坠秒杀；坠落后应有落点或轻伤回爬，禁虚空死循环 |
| 禁 | 与地窖同「向下挖」；复制庭院平层；平板虚空柱 |

**建议本地坐标意图：**

| 点 | 意图 |
|----|------|
| 出生 | 塔底 `0,64,0` 朝上阶 |
| 底层 | y≈64，刷点靠柱 |
| 中层 | y≈70，环廊混编 |
| Boss | y≈76 顶台中心；外围有栏可风筝 |

### 5.3 建议波次

| 阶段 | 建议 MM（前缀 `EmberDailySpire*`） | 数量感 |
|------|-------------------------------------|--------|
| 底层 | `EmberDailySpireZombie`（断塔卫尸） | 4～5 |
| 中层 | 卫尸 + `EmberDailySpireSkeleton`（裂隙箭骷，环廊对射） | 3+3 |
| Boss | `EmberDailySpireWarden`（断塔守望）：顶台压迫 + 偶发推离；与庭院蛮兵 / 焦核 / 残誓 / 潮闸 **五别可辨** | 1 |

### 5.4 节奏备注

上爬 = 地窖的镜像，验收时务必拍 **向上剖面**。楼梯口可卡点但 **禁止** 卡怪无法过门。顶台无栏 = 挑刺必 FAIL。

## 9. 验收硬条（S3）

1. 选本菜单 D/E **可进**；各扣 **30** 体力（数值未改表）。  
2. 两线均为：安全落点 → ≥2 次清房开门 → 独立 Boss 厅。  
3. 通关落在 **5～8 分钟**（抽检）。  
4. 与庭院 / 焦骨 / 地窖 **俯视或进本 5 秒可区分**；潮蚀≠焦骨直筒；断塔剖面为 **向上**（≠地窖向下）。  
5. 玩家可见路径 **无** `/dp` `/corerpg` `/hub` `/mvtp`。  
6. 仍为 **本服** MV + DP 实例。  
7. 挑刺抽检：水道无秒杀虚空；断塔有栏/可回爬；Boss 有风筝空间；怪 id 前缀不撞。
