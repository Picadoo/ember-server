# D193 Boss Moves Pack 5 破招（打断蓄力）（设计 + 上线，2026-10-05）

## 0. 一句话

Q06 霜封统领、Q07 炉锁巨卫半血后各加一个**原地蓄力 3 秒**的大圈（霜潮汲取 / 炉心聚爆，以首领为中心半径 5 / 5.5 格）。蓄力期间**全队打掉它 6.5% 最大生命**就打断：这一招不落下，首领踉跄 0.3 / 0.5 秒；打不够就落在还站在圈里的人身上（伤害 30 / 36，挑战 = heavy）。给近战一个「贴身爆发打断 or 跑出圈」的选择，装备够、敢贴身的人能直接破招。

## 2. 规则

- runs yml 新字段 `break_hp`（0～0.5，最大生命比例）、`break_stun`（≤2 秒，默认 1）；冲撞、分摊招不可用（解析为 0）。挑战副本复制伤害时保留。
- 蓄力开始：需求 = 首领当前最大生命 × break_hp（组队时首领生命 ×(1+0.65(n−1))，需求跟着涨），计数清零；聊天一行「蓄力期间全队打掉它 N 点血可打断（踉跄 s 秒）· 打不动就跑出圈」。
- 计数：`EntityDamageByEntityEvent` MONITOR，伤害来源（含投射物射手）是玩家才算，取 finalDamage；每 0.25 秒向在场玩家发动作栏「破招 63%（120 / 190）」。
- 达到需求：立刻作废（不落地、无伤害），解除蓄力定身，首领踉跄 break_stun 秒（与 D188 / D192 同一个 stunUntil：不放招、普攻取消、定身，排队的后续招顺延）；聊天「破招！…被打断」，日志 `[P1 run] <run> break <招名> <done>/<need> stun <s>s`。
- 未达到：照常落地，打中圈内所有人。
- 半血门（below 0.5）；排在招表最后，所以别的招到点时它让位；HP 门一开就会尽快出一次，之后每 25 秒。
- **余烬连战不出**这两招（def.rush 时永不到点）：连战有自己的倍率和调好的招表（见 §4）。团本 r01–r03 用自己的招表，不动。Q01–Q05 不动。挑战 / 深渊沿用（伤害走 heavy 覆盖）。

## 3. 模拟（`tools/p1sim/breakmove.py`，原始 `tools/p1sim/out-breakmove-d193.md`）

单人模型：3 秒窗口内挥刀数 = 3 × 0.85 / 0.64 ≈ 4，每刀 B × 暴击；打满 → 不受伤 + 首领后推踉跄秒数；否则按普通预警招判躲避。基线 = 现网 1.65.30（这两招不存在）。

**门禁（上线值）：Q06 最大 0.5pp、Q07 最大 1.6pp（上限 3.0，建议 ≤2.0）→ within range。** 参考装单人全力贴身每次都能打断（4 刀 ≥ 6.5%），装备低于参考或不贴身就得跑——这是装备 / 投入检查，不是白送踉跄。

扫参：0.06 / 1 秒太容易（Q06 +4.9）；0.075 挑战永远打不断，每 25 秒吃一记 61 → −4～−6；0.09 以上普通也打不断，纯加伤害；Q06 踉跄 0.4 秒起挑战 0.5 格 +3.5～+4.4 超门 → Q06 0.3 秒、Q07 0.5 秒。

## 4. 余烬连战

招表里带上这两招时 rushsim：Q07 参考 T2+8 躲 0.7 83→81；T3+6 躲 0.3 24→31（踉跄 0.3～0.5 一样，0 秒回到 24：低躲避格的出招相位效应）。连战不加：Java `def.rush` 时这两招永不到点，rushsim 同样剔除，输出与现网基线逐格一致。

## 5. 漏洞检查

| 风险 | 结论 |
|---|---|
| 奖励重复领取 / 刷 | 无奖励、无计数、无领取，只改战斗 |
| 非玩家伤害凑数（环境、岩浆、宠物） | 只算来源为玩家（含其投射物）的 finalDamage；首领蓄力定身，拉不进岩浆 |
| 外人帮打 | 副本是独立实例世界，只有本局队员 |
| 踉跄锁死首领 | 每 25 秒最多一次、≤0.5 秒；和撞墙 / 落空共用 stunUntil，不叠加延长（取最后一次） |
| 组队人越多越容易 | 需求按最大生命比例，生命随人数涨；人多输出更高 → 更容易，符合组队收益，可接受 |
| 连战绕周上限 / 重试 | 连战不出此招；周上限逻辑未动 |
| 永久强度 | 无新属性 / 槽位 / 倍率 |
