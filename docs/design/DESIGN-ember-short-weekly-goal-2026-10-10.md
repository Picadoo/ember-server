## 3. 可落地（方案 M）§2

### 2.1 目标规格（钉死）

| 项 | 钉 |
|----|----|
| 内部 id | **`short`**（周目标键；**可选**，入 `OPTIONAL`，**不**入 `GOALS`） |
| 玩家名 | **周目标 · 短征**（可选） |
| 解锁 | 与现网周目标同：**本人 Q07 首通**后才 `addGoal`（`EmberSeason.addGoal` 现闸） |
| 计数事件 | 短征 **有奖通关**（发放 S40–S44 结算包的那次；**第 4+ 次无结算不计**） |
| 跨本合计 | sx01–sx05（及日后同 `short.*` 键）**共用**一个周进度；**不**按本拆五个周目标 |
| 目标 N | **`weekly_goals.targets.short: 5`**（荐）· 约「一周里随便挑本刷满约两天日帽量级的有奖趟」· 施工可 ±1 但须 STATUS 旁注 |
| 单次进度 | 每有奖通关 `addGoal(u, pd, "short", 1)` · 封顶 N |
| 完成奖励 | 与现网一致：`reward`（现 **15**）余烬徽 · **S19** · **不算**「全部完成」· **不**触发 bonus |
| 文案禁 | 禁「不耗体力」；禁旧日常窟；禁 sx06；禁暗示发币/印记/装备；禁抬挂机产 |

**为何可选而非必做：**

- `core` 已树立「可选 +15、不进全完成」玩家预期；短征同轨零教学成本。  
- 必做会把「全部完成」从 4→5，改变 bonus 节奏与周压力——须另号经济论证，本窗不绑。  
- 短征日帽已给材料；周钩只补**外观向**拉回，避免「材料双计周压」。
