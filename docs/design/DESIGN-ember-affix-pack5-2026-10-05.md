## 0. 一段话裁决

重打已首通的普通主线时，发光词缀精英多两种：**旋光**（`arcane`，精英脚下亮一道紫色起始线和它将扫过的半圆，1.5 秒后光束在 3 秒里转半圈，扫到的人吃 1 次 1.0×atk；退到 5 格外、或站到另外半边就没事）和**火链**（`firechain`，精英和身边最近的一只同房怪之间连一条火链，碰到 = 0.3×atk，每人每秒最多 1 次；被连的那只死了，火链 1.2 秒烟线预警后换到下一只；房里只剩精英就没有火链）。都是走位 / 击杀顺序上的侧向花样：不加玩家永久数值、不加乘区、不加新货币 / 掉落 / 怪，击败奖励仍是现网 `affix_shard: 2`。

## 1. 白话版（给服主 / 玩家）

- 重打已通的普通图，发光精英还可能是：
  - **旋光**：它脚下会先亮一条紫线和一个紫色半圆（光束要扫过的那半边），1.5 秒后光束转过去。退到 5 格外，或者站到没亮的另一半边就打不到你；每次最多挨一下。
  - **火链**：它和旁边一只怪之间连着一条火。别站在两只怪中间；先打掉被连的那只，火链会冒烟 1.2 秒后换到下一只。房间里只剩它自己时就没有火链。
- 打掉照样给余烬碎片 +2，别的都不变。

## 2. 规则（实现）

yml（`ember-v1-runs.yml` → `variety:`，两份一致，balance_version 57）：

```yaml
  affixes: [blazing, split, shield, regen, charge, frost, mortar, molten, venom, jailer, arcane, firechain]
  arcane: {every: 8.0, warn: 1.5, length: 5.0, width: 1.2, sweep: 180, spin: 3.0, dmg: 1.0}  # D196 旋光
  firechain: {warn: 1.2, width: 1.0, tick: 1.0, dmg: 0.3, range: 10}                     # D196 火链
```

钳位（`EmberRunMaps.Variety`）：arcane every ≥ 4、warn ≥ 1.2、length 2–6、width 0.5–2、**sweep 30–180（永远不超过半圈 → 永远有安全半边）**、**spin 1.5–6（≤ 120°/秒）**；firechain warn ≥ 1.2、width 0.5–2、**tick ≥ 0.5（每人每秒最多 2 次）**、**dmg ≤ 1.0 atk**、range 3–12。未知 id（如 `orbiter` / `waller`）解析时丢弃。

- **旋光**（`EmberRunDirector.affixTick`）：8 格内有玩家才起手；原点 = 精英脚下（锁定，精英走开也不跟）；起始角 = 最近玩家方向 − sweep/2 × 转向，所以最近玩家正好在扫过弧的中间（不会出现「起手就打脸」或「永远扫不到」）。预警 1.5 秒：紫色（SPELL_WITCH）起始线 + 扫过半圆的外缘弧。之后 3 秒内光束（END_ROD）从起始角匀速转 180°。命中用**扫掠区间**判定：每 tick 检查玩家极角是否落在 [上一 tick 角, 本 tick 角] ± 光束半宽对应的角宽内（距离 ≤ length、高度差 ≤ 2.5）——所以一个 tick 内走一步也跳不过光束；站在精英脚下（< 0.6 格）算中。**每次施放每人最多 1 次**（`arcaneHit` 集合）。每次施放后转向翻转（顺 / 逆时针交替）。日志 `[P1 run] <runId> arcane ccw|cw hit=N`。
- **火链**：精英出现约 2.7 秒后（1.5 + warn）与**同房**最近的活怪（不是首领、不是护宝兔、不是自己，range 10 内）连链；新链先以烟（SMOKE_NORMAL）显示 `warn` 1.2 秒，之后转火（FLAME）才会烧。玩家水平距离到链段 ≤ width/2（且在两怪高度带内）→ `0.3 × 精英 atk`，**每人每 `tick` 秒最多 1 次**（`chainBurnAt`）。被连的怪死亡 / 消失 / 被拉出 range+4 → 立刻重找下一只并重新走 1.2 秒烟线预警；没有可连的怪 → 没有链（每秒重找）。精英死亡 → 链随 Tracked 消失（无实体、无方块，无残留）。日志 `[P1 run] <runId> firechain link <role>`。
- 两条伤害都走 `svc.skillHit(..., "mob")`，与毒十字 / 禁锢同一路径（受 D191 无伤事件 MONITOR 计数、受 raid dmgFactor 等现网规则约束）；kb 0（Q04 水边不推人）。
- 进房提示各一句打法；名牌 `§6[旋光]` / `§6[火链]`；图录 / 冒险菜单词缀列表 十选一 → 十二选一。
- 测试钩子（泛型，无需新命令）：`/corerpg p1 runs variety arcane[:rN]` / `firechain[:rN]`（`Variety.KNOWN.contains`）。

## 3. 门禁（offline sim）

p1sim `affix_mob`：旋光按「每次施放 1 次预警命中 + 躲避」走与炽热 / 毒十字相同的路径，周期 = every + spin = 11 秒；火链 sim 没有站位，假设玩家 1/3 时间碰链（`FIRECHAIN_EXPOSURE`），即每 3 秒 1 次 0.3×atk 的可躲命中，而且**整个精英存活期都算**（真机上房里只剩精英时没有链 → sim 偏保守）。

压力预算（命中即吃满，每秒期望 atk 倍数）：投弹 1.0/(5+1.2) ≈ 0.161；毒十字 1.0/(6+1.3) ≈ 0.137；**旋光 1.0/(8+1.5+3) ≈ 0.080**；**火链 0.3/1.0 × 1/3 ≈ 0.100**（站在链上不动的上限 0.3，与禁锢落地 0.5×atk/8.2 s 同量级以下）。两条新缀都 ≤ 现网投弹。

`tools/p1sim/affixpack5.py`（结果 `tools/p1sim/out-affixpack5-d196.md`，§8 填数）：

- Part A：Q01–Q07 × 书参考装 / T3+6 × 躲避 0.3 / 0.5 / 0.7，每格 1,500 局 × 3 种子，词缀强制为单一 id。基线 = 投弹（p1sim 从未给投弹建模圈伤，D181 Stage C deferred → 在 sim 里等于普通发光精英，即「无词缀压力」基线），对照 = 毒十字（已建模的现网词缀）。门槛：新词缀通关率与基线差 ≤ 3.0 pp（每格）。
- 压力列：`p1sim.AFFIX_STRESS = True` 让毒十字 / 禁锢 / 旋光 / 火链的首发提前到开房 + 1.5 秒（sim 清房太快，普通列里旋光几乎放不出来）；门槛：新词缀不比同条件的毒十字难 3.0 pp 以上。
- Part B：p2econ 120 人 × 12 周，躲避 0.5，新 12 缀池 vs 旧 10 缀池，所有百分比列 max |Δ| ≤ 3.0 pp。

## 4. 漏洞 / 滥用审查

| 风险 | 处理 |
|---|---|
| **双领 / 重复结算** | 奖励键、数量完全不变：击败词缀精英 → `svc.onAffixDone` 只置标记，结算 `varietyGrants` 按布尔发一次 `affix_shard 2`；新 id 不新增任何发放点。单测 `varietyPack5ArcaneFirechain_D196` 断言 `affixShard == 2` |
| **复制（dup）** | 两条新缀**没有任何实体 / 方块 / 物品**（只有粒子 + 伤害），不碰资产路径（仓库存取 / 断线 / 重启 / 拆解 / 撤销 / 快照 / 扭蛋 / 补发全部未改）→ 无复制面，不需要 persist-roundtrip |
| **周 / 日上限绕过** | 花样委托仍按日 cap、仍是同一个「击败词缀精英」计数；池子变大只改「出哪种」不改「出几只」（每局仍 1 只，`affix_rate` 不变） |
| **重进 / 放弃重来（挑词缀）** | 词缀绑定 `subSeed(seed,"variety")`，同一局重连不重抽；放弃 = 本局无结算（只有开战前离开才退体力），重开是新局新种子；新词缀不比基线更容易（§8），挑词缀没有收益 |
| **旋光：卡 tick 穿光束** | 扫掠区间判定（上一 tick 角 → 本 tick 角），不是只看当前位置；单测覆盖 ±π 接缝与「全程扫不到身后半边」 |
| **旋光：连中多次** | `arcaneHit` 每次施放每人最多 1 次；转速钳 ≤ 120°/秒、半圈上限 |
| **火链：站链上连续掉血锁死** | 每人每 `tick`（≥0.5 秒，配置 1.0）最多 1 次，dmg 钳 ≤ 1.0 atk（配置 0.3）；链有 1.2 秒烟线预警才烧；不定身、不减速、kb 0 |
| **火链：连到首领 / 护宝兔 / 别的房** | `chainPartner` 只找同 `roomId`、非 boss、非 `varietyEscort` 的活怪；首领区没有词缀精英 |
| **火链：分裂小怪 / 事件怪凑链** | 分裂只在精英死后出现（那时链已随精英消失）；房间事件不刷怪（D191 起） |
| **AFK 挂机** | 词缀精英只在主线普通重打房间里；挂机庭（`ember_afk`）不是主线副本，不出词缀 |
| **残留** | 无实体 / 方块；Tracked 随精英死亡或 `finish()` 清理 |
| **挑战 / 深渊 / 团本 / 连战 / 首通** | 闸门不变（D138）：只在全队已首通的普通主线重打 |
| **旧存档 / 进行中的局** | session 只存 affix id 字符串；新 id 只影响新局；回滚到 1.65.33 时未知 id 会被 `Variety` 丢弃（不在 KNOWN），旧局的精英按普通发光精英处理 |

## 8. 门禁结果（已跑，`tools/p1sim/out-affixpack5-d196.md`）

- **Part A**（1,500 局 × 3 种子 / 格）：旋光、火链与基线（普通发光精英）的通关率差，所有 42 格最大 **0.8 pp**（Q06 书参考 d0.5 火链 −0.8）→ cap 3.0 内。旋光在普通列里全部 +0.0：sim 清房比真人快，11 秒一轮的光束在精英倒下前几乎放不出来（实测每局 0.00 次，毒十字 0.29–0.35 次，火链 0.52–0.67 次）。
- **压力列**（新加 `p1sim.AFFIX_STRESS`：首发提前到开房 + 1.5 秒，界定最坏情况）：新词缀比同条件的现网毒十字**难**的最大值 **0.4 pp**（实际两者都比毒十字容易：Q01 书参考 d0.3 毒十字 63.1% / 旋光 64.6% / 火链 67.1%，基线 69.4%）→ cap 3.0 内。
- **Part B**（p2econ 躲避 0.5，新 12 缀池 vs 旧 10 缀池）：120 人 × 12 周 MAX_ABS_DPP **3.0**（第 6 周「两件极品」22% vs 25%）；300 人复核同样 **3.0**（第 6 周两件极品 23% vs 26%），方向一致是新池略慢、从不更肥；W12 币中位 58195 / 58010（120 人）、57705 / 57740（300 人），±0.4%；T3 目标族两件 ±1 pp。两件极品是最稀有、噪声最大的一列（D189 同列 −3…+4 pp）。
- 裁决：**within range**（按业主政策，「在范围内」即可，终调等真人数据）。真人数据回来后若某个新词缀房死亡率明显高于其他词缀，只允许放宽参数（旋光 `spin` +0.5 / `length` −0.5；火链 `dmg` −0.1），**不允许加奖励**。
