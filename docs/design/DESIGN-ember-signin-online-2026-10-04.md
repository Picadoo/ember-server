# DESIGN — P1 每日签到 + 在线时长奖励（D180）

日期：2026-10-04 · 作者：signin-online 执行者 · 研究：`RESEARCH-ember-signin-online-2026-10-04.md`
业主（19:06）：「每日在线时长奖励做了吗？每日签到奖励等等？」——P1 里原来没有（D63 把旧 签到 / 活跃 / 悬赏 从 P1 菜单拿掉，
因为它们发的币不在模拟器经济里）。业主授权自行决定，下面全部是定稿。

## 0. 一句话
**主菜单新格「签到 · 在线」→ 一页里两件事**：
1. **月历签到**：每天点一下「今天」那格；按**本月第 n 次签到**发奖（漏签不清零），第 7 / 14 / 21 / 28 次是大格（首领徽记 / 锻造印记）；
   每月可补签 3 次（先签今天 + 今天有效在线满 60 分钟，每天 1 次，自动补最早漏的那天）。
2. **在线时长**：今天**有效在线**满 15 / 30 / 60 / 120 分钟各领一档；5 分钟没任何操作停表；**挂机庭里的时间不算**（挂机庭自己结算）。

只发**账号绑定**的东西：余烬币、余烬经验、锻造印记、首领徽记。**一天最多 ≈ 93 币 + 25 经验**（一次通关的基础是 300 币 + 120 经验），
外加每月 2 个首领徽记 + 2 个锻造印记。变强仍然靠打本。

## 2. 改动 D63 的那条规则
D63 / 书 §19.4：「P1 收入只来自通关。」D177 已修订为「装备、材料（碎片 / 核心 / 骨尘 / 胚料）、印记仍只来自通关」。
**D180 再修订一处**：余烬币、余烬经验之外，**锻造印记**每月最多 2 个、**首领徽记**每月最多 2 个可以来自签到（都是账号计数）。
装备、NI 材料仍然只来自通关。旧 签到 / 活跃 / 悬赏 的**旧发币**在 P1 下关闭（§6）。

## 3. 入口（零命令）
- 主菜单 `ember_hub` 第 4 行第 1 格（原来是空格）新图标「签到 · 在线」（绿宝石；今天没签时闪光 + 标题提示）→ 新菜单 `ember_p1_sign`。
- `ember_p1_sign`（6 行）：
  - 第 1 行：本月签到（已签 n 次 / 今天签没签 / 下一格奖励 / 漏签天数 / 补签剩余 / 29–31 次奖励）、规则、今日在线（有效分钟、计时状态、下一档、一键领取）。
  - 第 2–5 行：28 格月历（格子数量 = 第几次）。已领 = 绿色玻璃；**今天可签 = 闪光箱子，点了就签**；未到 = 纸（大格 = 金锭）。
  - 第 6 行：补签按钮（能补时闪光并写出补哪天、给什么；不能补时写原因）、在线 15 / 30 / 60 / 120 四档（已领 / 可领闪光 / 未到）、返回。
  - **奖励文字全部来自 PAPI**（`%corerpg_p1_sign_r<n>%`、`%corerpg_p1_online_r<i>%` = `ember-v1.yml`），菜单不写死数字。
    生成器 `tools/menus/gen_ember_p1_sign.py`。
- **进服提示**：今天没签到时，进服 5 秒后聊天栏一行「今天还没签到 · 本月第 n 次：…… [去签到]」（点按钮打开页面）+「不用打命令：主菜单 → 签到 · 在线」。
- **在线到档提示**：满 15 / 30 / 60 / 120 分钟的那一分钟，聊天栏「可领：…… [去领取]」。
- 旧命令 `/corerpg sign` 在 P1 下改成 P1 签到（不再发旧的 100 币）；`/corerpg activity` 打开本页；`/corerpg bounty` 提示 P1 委托在主线本里。
- PAPI：`%corerpg_p1_sign_<on|today|count|month|head|next|mk|mkcan|mkleft|missed|d<n>|k<n>|r<n>>%`、
  `%corerpg_p1_online_<on|min|can|state|next|d<i>|k<i>|m<i>|r<i>>%`。

## 4. 签到表（`ember-v1.yml signin:`）
| 本月第 n 次 | 奖励 |
|---|---|
| 1–6、8–13、15–20、22–27 | 余烬币 20 + 余烬经验 5 |
| **7** | 余烬币 40 + **首领徽记 ×1**（已首通的最靠后的签名图；还没首通任何签名图 → 改发 60 币） |
| **14** | 余烬币 40 + **锻造印记 ×1**（已首通主线的最高阶 T1 / T2 / T3；没首通 → T1） |
| **21** | 余烬币 40 + **首领徽记 ×1** |
| **28（全勤）** | 余烬币 80 + **锻造印记 ×1** |
| 29–31 | 余烬币 10 + 余烬经验 5 |

- 一个月签满 30 次：**700 币 + 130 经验 + 2 首领徽记 + 2 锻造印记**（≈ 每天 23 币）。
- 补签：`makeup_per_month: 3`、`makeup_needs_online: 60`；每天最多 1 次；只补本月；必须先签今天；自动补最早漏的那天；补签拿的是「第 n+1 次」那格。
- 月份 = 服务器时钟 Asia/Shanghai 的自然月；一天 = 体力日（0 点，`DailyService.today()`）。

## 5. 在线时长表（`ember-v1.yml online:`）
| 今日有效在线 | 奖励 |
|---|---|
| 15 分钟 | 余烬币 10 |
| 30 分钟 | 余烬币 15 + 余烬经验 5 |
| 60 分钟 | 余烬币 20 + 余烬经验 5（**也解锁今天的补签**） |
| 120 分钟 | 余烬币 25 + 余烬经验 10 |
| **一天合计** | **70 币 + 20 经验**（120 分钟后不再有） |

**有效在线怎么算**（`EmberSignService`，每 60 秒一次）：
- 在线、**不在挂机庭**（`exclude_worlds: [ember_afk]`）、最近 5 分钟（`idle_minutes`）有**真实输入** → 记 1 分钟。
- 真实输入 = 转视角、左右键 / 交互、点任何界面（含 TrMenu）、攻击、聊天、命令、切快捷栏、潜行。**只是位置变了（水流、活塞、被怪推）不算**——
  MC 经典的「水流挂机池」骗不到。主线本里打怪自然一直在计。
- **挂机庭（D177，自动战斗挂机，COORD-afk-p1 正在改版）里的分钟一律不计**：那段时间挂机庭按自己的规则结算，一份时间不拿两份奖；
  挂机庭外的城镇 / 主线本 / 深渊 / 团本时间都算。离线时间不算（离线补偿归挂机庭）。
- 档位到了要**点领取**（页面一键领全部）；**没领的过 0 点自动补发**（下一分钟计时 / 下次进服时结算前一天，聊天提示），不丢也不重复。

## 6. 漏洞审查（exploit review）
| 风险 | 做法 | 结论 |
|---|---|---|
| **小号**（养一堆号签到 / 挂在线） | 只发账号计数：余烬币（P1 无转账：无交易 D73、旧寄售 P1 关闭 D177、`/corerpg mail` 发送要 `corerpg.mail.send` 玩家没有）、余烬经验、锻造印记、首领徽记（`p1_mark_t*` / `p1_sigmark_*` 计数，不是物品）。**不发碎片 / 核心 / 骨尘 / 胚料**：它们进仓库后能取出成 NI 物品、能丢在地上给大号捡。 | 小号拿到的只能小号自己用。不做 IP 限制（同 D177：家庭 / 网吧误伤，而收益不可转移）。 |
| **挂机机 / 宏刷在线** | 只计真实输入；位置变化不算；挂机庭不算；每天 120 分钟封顶（70 币 + 20 经验）。能模拟转视角的宏最多拿到和普通玩家一样的封顶值。 | 封顶后为零；不做踢人 / 验证码（误伤 > 收益）。`player-idle-timeout=0` 保持。 |
| **改时钟 / 跨天** | 全部用服务器时钟（客户端改不了）。**服务器时钟倒退**：签到存「上次签到日」，今天早于它就暂停签到 / 补签；在线计数存「计数属于哪一天」，倒退时冻结计时与领取，直到时钟追上（不会「回到昨天」把已被清掉的计数重刷一遍）。 | 只有管理员改系统时间才可能触发，触发了也只会少给。 |
| **0 点前后卡点** | 签到看「本月掩码里今天那一位」，0 点后是新的一天、新的一位，同一天第二次点直接提示已签；在线跨 0 点：先把前一天到了没领的档补发、再开始新的一天。 | 每个体力日正好一次。 |
| **补签刷格** | 每月 3 次、每天 1 次、必须先签今天、只补本月已过去的漏签日、要今天有效在线 60 分钟。补签只是把「第 n 次」往前推一格，不会超过当月天数。 | 一个月最多 30 / 31 格，和每天都来的人一样多。 |
| **重连 / 双击 / 菜单连点 双领** | 签到：先把今天那一位写进 `p1_sign_mask@<月>` 并 `flushMutation`，再写账本行 `p1sign-<yyyy-MM>/n<k>c|x|m|s`；在线：先写 `p1_on_claim@<日>` 的位并落盘，再写 `p1online-<日>/m<分钟>c|x`。账本行是**唯一键**（`EmberRunService.grantRow`，同键第二次写入不生效），由现有 `deliverQuiet` → `deliver` 发放（PENDING → DELIVERED，掉线 / 背包无关，币 / 经验 / 印记 / 徽记都是计数）。TrMenu `Min-Click-Delay: 300`，主线程串行。 | 崩溃最多丢一格（**只少不多**）。重连后计数还在（角色数据），再点只提示「已签 / 已领」。 |
| **在线奖励自动补发和手动领取撞车** | 两条路都走同一个「先置位再写行」，行键相同（`m<分钟>`）。 | 一档一天最多一份。 |
| **旧命令漏洞（现存）** | P1 下 `/corerpg sign` 原来每天直接加 100 旧币 + 活跃 + 旧通行证经验；`/corerpg activity` 能领活跃宝箱币；`/corerpg bounty claim` 能领旧悬赏币——都是 D63 隐藏但还能打的命令，币就是 P1 余烬币。**P1 下：sign → P1 签到；activity → 提示 + 打开本页，不发宝箱；bounty → 提示，不发币。** 旧模式（P1 关闭）不变。 | 漏洞关闭。 |
| **账本行被清理后重领** | 行会被定期清理（codex 注释），所以**真正的一次性守卫是角色计数**（月掩码 / 日领取位）；行键只是第二道。 | — |
| **新号月底进服** | 月底注册也能签 + 补 3 次 = 第 1–4 格，正常。 | — |
| 资产路径 | 没有新的物品路径（只用现有账本行 coin / xp / mark / sigmark 种类）。 | `persist-roundtrip.sh` 不需要重跑。 |

## 7. p1sim 检查（只用离线模拟；「在范围内」即可）
工具：`tools/p1sim/signin.py`（**直接读 `plugins/CoreRpg/ember-v1.yml` 的 signin / online**，和配置不会漂移；包装 `Player.bounty`，
每个体力日：签到第 n 次那格 + 在线 ≤ `--online` 分钟的档位；印记进 `p.marks[已首通最高阶]` 走 p1sim 的正常兑换；首领徽记只计数
——p1sim 没有烙印模型，被 D174「签名从第 1 天就戴上」的 W30 上界覆盖）。`--afk DIR --afk-share s` 同时装上挂机庭的 `afk.py`，
签到 + 在线 + 挂机一起算。**上界：每天都签、每天都满 120 分钟（`--online 120 --sign-share 1.0`）**。

原始输出 `tools/p1sim/out-signin-d180.md`（规则 balance_version 38 树 = 主线 1.65.14 + 挂机庭 1.65.15，再加本版签到 / 在线）。

### 7.2 动态首通 21 格（Q01–Q07 × 躲避 0.3 / 0.5 / 0.7，±2pp；上界：每天签 + 每天满 120 分钟）

## 9. 验收（冒烟，几分钟）
新号 FreshQ260+：进服看到「今天还没签到 [去签到]」→ 主菜单「签到 · 在线」→ 点今天的格子 → 到账（币 / 经验）且格子变已领 →
再点提示已签 → 重连再点仍提示已签、余额不变 → 补签按钮显示原因（在线不足 60）→ 在线计时（测试时临时 `idle_minutes` 不变、管理员加分钟）→
领 15 分钟档 → 重连不重复 → `/corerpg sign` 不发旧 100 币 → `/corerpg activity` / `bounty claim` 不发币。
