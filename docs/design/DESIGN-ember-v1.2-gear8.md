## 0. 给服主的话（一页看懂）

**一句话：** 装备从 2 格变 8 格，但**满配角色的强度和现在一模一样**。现有地牢（Q01–Q07、R01–R03、挑战、深渊、连战）的调校不用重做；变化的是"凑齐一身"的过程更长、更有追求感，以及多了"整套 / 4+2 混搭"的选择。

- **8 格：** 刃（主手）、焰灯（副手，火焰棒外形）、头、胸、腿、靴（原版 4 件甲，按套装颜色染色的皮甲）、护符、戒指（后两件放背包里"选定"就生效，和现在的护符一样）。
- **攻击和生命分开：** 攻击只来自刃（50%）+ 焰灯（25%）+ 戒指（25%）；生命 / 防御来自护符和 4 件甲。**甲不给攻击。** 8 件全部同阶、同成色、同强化时，数值与今天"刃 + 护符"**分毫不差**（模拟逐项核对）。
- **套装：** 刃、护符、头、胸、腿、靴这 6 件计套（和 D169 同一套 6 个部位），焰灯和戒指不分族、随便穿。
  - **4 件同族 = 主套：** 套装效果（焚烬燃烧 / 烬爆爆炸 / 炽愈回血）**开始生效**，最高到觉醒 II；只有 4 件时效果打 92 折（一层"共鸣"）。
  - **再凑一对 = 满共鸣：** 另一族成对（2 件），**或者**主套第 5 件，补上第二层共鸣 → 效果 = 今天的满值。所以 **"4 件 + 另一族 2 件"、"5+1" 和 "6 件全齐" 在觉醒 II 以内一样强**，混搭完全能玩，而且从 4+2 换成 6 件的路上不会"先变弱"。
  - **6 件全齐 = 全套：** **只有 6 件全部 T3 +9 才能觉醒 III**（今天两件就行）——这是毕业追求；外观加全套描边。
  - **不加第 4 套。** 三族（燃烧 / 爆发 / 续航）已经覆盖输出、群伤、生存三条路，新套装只会多一个必须平衡的乘区（理由见 §3.6）。
- **掉落：** 每局通关照旧掉 1 件"主件"（刃或护符，规则和概率**一点不变**），**另外多掉 1 件"配件"**（焰灯 / 戒指 / 4 件甲之一）。**每张图都能掉全部 8 个部位**，只是每张图**重点掉** 3 个配件部位（概率约 2.3 倍），所以每张图都有自己的"刷它的理由"，但不会出现"靴子只有后期图才有"（尊重您否决过的"按图锁部位"）。
- **保底：** 锻造印记按部位定价（刃 6 枚，护符 / 焰灯 / 戒指 / 胸 / 腿 3 枚，头 / 靴 2 枚；整身 25 枚，今天 2 件 16 枚）；另加**按部位的缺口保底**：某个部位连续 8 次通关没掉到你要的，下一局必出（模拟里很少用上，是给倒霉玩家的保险）。
- **花费：** 强化 / 精工 / 成色 / 升阶 / 洗练按部位分量打折（刃 ×0.70，中件 ×0.35，头 / 靴 ×0.25）。8 件全部 +10 的期望花费是今天 2 件的 **约 1.48 倍**。
- **要多久：**（模拟中位，每种操作水平 60 人；详见 §9.3）首通 Q07：普通水平 **第 7 天（不变）**，手慢的玩家 **第 23 天（今天第 19 天）**。首通 Q07 以后：一身 T3 同族 **1–2 周**（今天 1 周），觉醒 III **2–3 周**（今天 1–2 周），全身 +10 **5–6 周**（今天 3–4 周），全身卓越 + 精工满 **6–7 周**（今天 3–4 周）。合起来，新号到"全身毕业"从约 **5–6 周变成约 7–8 周**（多 2 周左右，约 +35%）：能感觉到更长，但不算刷不完。"全身极品"是长线收藏，30 周内大多数人凑不齐；极品比卓越只多 4%，与今天"两件极品"的强度差相同（§9.4）。
- **不需要迁移：** 没有真实玩家，旧 P1 装备直接退役，测试号重置即可。

### 2.2 统一公式（只把"一件"换成"求和"）

```
g_s = 1 + e[enh_s] + q[qual_s] + f[craft_s]                     （每件自己的强化 / 成色 / 精工）
B   = Σ_s a_s · A[t_s] · g_s + 0.2 · (L − 10)
H0  = 20 + Σ_s h_s · h[t_s] · g_s + (L − 10)                   ；炽愈主套时 H = H0 × (1 + (sustain_hp − 1) · amp)
D   = Σ_s d_s · D[t_s]                                          （与今天一样只看阶级，不吃 e/q/f）
M   = max(0.5, 40 / (40 + D))
A = 12/24/42/70，h = 20/50/95/165，D = 2/6/10/14，q = 0/.04/.08/.12，f = 0/.02/.04/.06，e = 0…0.60
```

**守恒证明：** Σa = Σh = Σd = 1。若攻击侧 3 件都等于今天的刃（阶 / 强化 / 成色 / 精工），生命侧 5 件都等于今天的护符，则 B、H0、D 逐项等于今天。`slots8.py --check` 对全部 `REF_GEAR` × 3 族 × 3 组成色精工 × 4 种套装型逐项断言相等（误差 <1e-9）。

**混阶边界：** 因为是线性求和，任何混阶 / 混成色都落在"全 T(t) 与全 T(t+1)"之间；不存在比"8 件全满"更高的组合。

### 2.3 每件的"可感"在哪里
单件甲只占 15–25% 生命，换一件 T2→T3 甲只多约 +4–7% H。和 RESEARCH §6.2 一样要先说清楚：**体感来自套装层数 / 觉醒 / 词条组合，不来自单件数值**。装备页显示"这件占你攻击 / 生命的 x%"和"换上后 B / H / EHP 变化"（`EmberCompare` 已有整套比较，扩到 8 格）。

## 3. 套装：2 / 4 / 6 件（共鸣层）

### 3.1 计数
- 计套槽：刃、护符、头、胸、腿、靴（6 件）。只有 **T1 及以上、属于三族之一** 的件才计数。焰灯、戒指没有族。
- 可能的分布：6、5+1、4+2、4+1+1、3+3、3+2+1、2+2+2 等。

### 3.2 规则

| 件数 | 名称 | 效果 |
|---|---|---|
| 某族 ≥4 | **主套** | 该族被动（焚烬燃烧 / 烬爆爆炸 / 炽愈回血 + 炽愈生命）生效，自带第 1 层共鸣；同一时间**最多一个主套**（4×2 > 6） |
| 另一族 ≥2，或主套 ≥5 | **共鸣成对** | 第 2 层共鸣 → 主套效果满值；装备页显示两族纹样 |
| 主套 =6 | **全套** | **觉醒 III 只有全套才能开**；外观：全套描边（不加数值） |

```
L      = 0                         （没有主套）
         1 + [另一族有 ≥2 件 或 主套 ≥5 件]   （有主套；最多 2）
amp    = (1 + 0.10·L) / 1.2        # L=2 → 1.000 ; L=1 → 0.917
觉醒 k = I   ：主套成立（≥4 件 T1+）
         II  ：主套里 ≥4 件 T2+ 且 +6
         III ：主套 6 件全部 T3 且 +9
焚烬每跳 = burn[k] × amp × B ；烬爆 = burst[k] × amp × B ；炽愈每次回复 = sustain_pct[k] × amp × H ；
炽愈生命 = H0 × (1 + (sustain_hp − 1) × amp)            # sustain_hp 现行 1.12；growth-sidegrades 的 S2 = 1.00 也直接适用
```

**为什么上限不变：** amp 最大是 1，k 最大是 III，系数表 burn / burst / sustain_pct 原样复用 → 任何组合的套装强度 ≤ 今天同觉醒的两件套。觉醒 II 及以下时 **A6、A5+B1 与 A4+B2 都正好等于今天**（42/42 格 st 完全相同，§9.1）。

**单调、无"低谷"：** 4+1+1（0.917）→ 4+2 / 5+1（1.000）→ 6（1.000，且可 III）。第一版草案用"每个成对的族 +1 层、6 件再 +1 层"，模拟发现 4+2 → 5+1 会掉到 0.917，贪心换装的玩家里 >10% 卡在 4+2 永远凑不成 6 件（`set3` / `awk3` P90 = 30 周内未达成）；改成现规则后该低谷消失（§9.3）。

**谁更强：**
- A6（全套）= 今天的两件套，且能到 III（今天两件 T3+9 就能 III；现在要 6 件 T3+9 → 毕业更晚，但满值一样）。
- A4+B2 / A5+B1 = 今天的 II；**不能到 III**。终局差距见 §9.2。→ "全套强、混搭可玩"。
- A4+1+1 = 一层共鸣（×0.917）。
- 3+3 / 2+2+2 = 没有主套（无族效果），只适合过渡期。

**备选旋钮（模拟里都跑了）：**

## 4. 词条（每件 1 个词条槽，按部位分池）

### 4.1 规则
- T1 及以上每件 1 个词条槽（与 D143 一样）；档位上限仍被成色截断（标准 1 / 精良 2 / 卓越 3 / 极品 4），洗练第 6 次保底不变。
- **攻击池**（刃 / 焰灯 / 戒指）：现行刃池（猎缀纹 `b_affix`、余烬纹 `b_set`；裂身纹 `b_split` 已退池）。
- **防御池**（护符 / 4 件甲）：现行护符池（定身纹 `c_tele`、分核纹 `c_share`、抗缀纹 `c_affix`）。
- **数值按部位份额缩放：** 一件的词条值 = 今天单件的值 ×（该件份额 ÷ 同侧份额和）。攻击侧份额 = a（刃 0.50 / 焰灯 0.25 / 戒指 0.25），防御侧份额 = h（护符 .25 / 胸 .25 / 腿 .20 / 头 .15 / 靴 .15）。
- **同 key 叠加只加差值，不连乘：** `mult(key) = 1 + Σ_s (v_s − 1)`（减伤类 `1 − Σ(1 − v_s)`）。所以把同一个词条洗满一整侧 = 今天单件满档，**不会更高**；把两个词条各放半侧 = 各得一半（总"词条预算"守恒）。
- 示例：猎缀纹 4 档今天 ×1.16。刃上 4 档 = ×1.08，焰灯 / 戒指 4 档各 ×1.04；三件都是猎缀纹 4 档 = ×1.16（= 今天）。

### 9.4 极品
- 极品只靠掉落（成色养成只到卓越；D167 也否决了"锻造出极品"）。今天"两件都极品"在本模型里中位 9–12 周；本文"8 件里 4 件极品"中位 9–10 周，"8 件全极品" 30 周内几乎没人做到。
- 极品比卓越只多 +4% 的 g，摊到 8 件上每件只值 0.6–2% B 或 H；全身极品与全身卓越差 4%（与今天两件极品 vs 两件卓越的差完全相同）。
- **建议：不给确定性出口**（与 D167 一致），把"全身极品"定位为长线收藏，装备页显示"极品 x / 8"。如服主希望 30 周内可达，再评估"同部位 3 件极品材料合成"一类转化（会动 W30 指标，须重跑）。

## 11. 风险与未决

1. **与 D169 的分歧**（8 vs 6 槽、共鸣层 vs core2）要总控 / 服主拍板；本文所有数值部件两种都能用。
2. **单件体感弱**：甲每件 15–25% 生命；要靠装备页的"套装进度"和"同 key 合计"让玩家看得见。
3. **混搭惩罚**：4+1+1 比 4+2 弱（×0.917），过渡期常见（模拟里大部分玩家首通 Q07 时是 4+x）。若真人觉得"差一件被罚"，把 `layer_step` 降到 0.05（L=1 时 ×0.955）。
4. **极品长线**：全身极品在 30 周内多数玩家达不到（§9.4）；需要服主决定是否给确定性出口。
5. **点击量 / 背包压力**：每局多 1 件 → 自动入库阈值上调、一键强化；需真人看。
6. **NI 的 AttributeModifiers 写法**要在测试服实测；失败则在 `EmberItems` 生成物品时用 NMS 写 NBT（`NmsNbt` 已有）。
7. **模拟没覆盖**：团本组队、深渊周常、精选周加成、词条（两边都没建模，比较是对称的）；growth-sidegrades 的天赋 / 炽愈 S2 需在 8 槽下复跑（`--sustain-hp 1.00` 已支持）。
