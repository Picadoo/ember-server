## 2. 方案表

### 2.1 方案 M（**荐** · 城内决策密度）

| 窗 | 改什么 | 不动什么 | 热更 |
|----|--------|----------|------|
| **W1a · 进本前一眼** | 日刷 / 挑战（及已有冒险进本页若同入口）在**有签名穿着且 Q07 已开**时，lore 增 1～2 行：`本局生效：刃·原版|调律 · 护符·…` + 短代价（复用 `badOf` / 现有 PAPI 思路，可新增薄键如 `p1_sig_runpreview`） | 不改体力 / 掉率 / event_rate | TrMenu + 可选 PAPI jar |
| **W1b · 装备/签名页对照** | 签名页已穿着行或装备摘要：在「生效中」旁标 `原版`/`调律`，并露出「另一版代价」一行（调律页已有 `o_`/`t_`，外提到穿着摘要） | 不改烙印流程 | TrMenu ± PAPI |
| **W1c · 可选进本确认（prepare）** | **默认关或轻量：** 仅当账户「本周首次进日刷/挑战且至少一件已解锁调律」时，进本前弹一次短确认面板（TrMenu）：展示本局生效两行 +「去调律」/「就这样进本」；之后同周不再打断 | **非**战斗热换；确认态仍城内；取消则不开跑 | jar 账户 flag + TrMenu |

**期望：** 不碰数值键；玩家把「装哪一版代价」从调律页深链拽到**进本决策面**；通关率预算零移动（只 UX）。

**荐批：** **先批 M（W1a+W1b；W1c 可同批或续窗）**。

### 2.2 方案 R（每局 prepare 锁定 · 仍非战斗热换）

| 项 | 内容 |
|----|------|
| **做什么** | 每次进日刷/挑战 **prepare 态**：强制或半强制打开「本局调律确认」：对已解锁调律的穿着签名勾选「本局用原版 / 调律」→ 写入**本局临时覆盖**（或确认当前 `sigalt` 快照）；开跑后至出本不可改 |
| **与烙印/换装** | 进本后换装仍走现有规则；若换上另一件签名，本局覆盖键按「新件当前 `sigalt`」或「无覆盖=账户默认」——**须施工规格写死**，禁止战斗中再开确认 |
| **风险** | 每局多一次点击 → 日刷三次摩擦；与「城内随时切、下一局生效」文案需对齐（变为「本局快照」） |
| **相对 M** | 决策更「硬」、可感更强；成本与打断更高。**建议：仅当批 M 施工后真人仍喊「进本前看不见/懒得进调律页」再开 R**，或总控直接批 **M+R** |

### 2.3 方案 W（**否决默认** · 战斗中热换）

| 项 | 内容 |
|----|------|
| **提议（不采纳）** | 副本内允许改 `p1_sigalt_*` / 调律页可点 |
| **否决理由** | ① 现行 `inRun` 与烙印同门，热换破坏「下一局生效」心智；② 代价键（`dmg_boss` / `taken_tele` / `potion` 等）中途翻转 → **B 预算与 42 格标定失效**；③ 烙印件 + 双签名 + 同 tag 排除的结算一致性难保；④ 易变成「Boss 前临时换脆档」的最优解，抬有效强度而非侧移 |
| **结论** | **默认否决**；本稿批注不提供「批 W」勾选 |
