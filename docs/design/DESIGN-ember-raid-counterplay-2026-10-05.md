## 0. 一段话裁决

三个团本首领本来就是主线首领的招式组合（P2-5 / P2-6 / D137：「只用现有招」），但主线首领 D188 / D192 已经学会的「破绽」到了团本里却没有，玩家在 Q07 学会的「引它撞墙」、在 Q02 / Q05 学会的「全员躲开它会踉跄」在团本里反而失效。本包让每个团本首领**继承它来源首领的那一个破绽**：

| 团本首领 | 招式（来源） | 破绽 | 伤害 |
|---|---|---|---|
| R01 炉锁巨卫·团 | 冲撞（= Q07 冲撞） | `wall_stun 1.5`：被真实的墙截短 → 眩晕 1.5 秒（同 D188） | 79 → **94** |
| R02 霜封统领·团 | 半血砸地（= Q02 砸地） | `whiff_stun 0.5`：预警开始时有人在圈里、落下时一个都没打中 → 踉跄 0.5 秒（同 D192） | 79 → **88** |
| R03 断塔斧卫·团 | 斧刃横扫（= Q05 斧刃横扫） | `whiff_stun 0.5`：同上 | 79 → **84** |

团本是 3～5 人：落空要**圈 / 扇里的所有人都躲开**才算，这正是团本该练的配合；撞墙要有人背靠墙把冲撞引过去，其他人别站在冲撞线上。伤害上调抵消破绽带来的通关率上升（门禁见 §3），所以这是**玩法上的横向变化**，不是削弱团本。

## 1. 参考（为什么这样做）

| 参考 | 做法 | 本服取用 | 不取 |
|---|---|---|---|
| WoW 团本 / 地下城的「同一个首领机制在不同难度里保持一致」（普通 → 英雄 → 史诗沿用同一套机制，只改数值 / 加段落） | 玩家在低难度学会的应对，到高难度仍然有效 | 主线学会的破绽在团本里同样生效；团本只改数值 | 不加团本专属新形状 |
| 《怪物猎人》冲撞类怪（D188 已引用） | 引它撞墙 → 硬直输出窗 | R01 冲撞同 Q07 | 不给撞墙额外伤害倍率 |
| FF14 / WoW 多人「全员躲开」检查 | 多人时躲招成功要所有人都做对 | 团本落空 = 圈里的人全躲开 | 不做「有人没躲 → 全队惩罚」 |
| 本服 D188 / D192 的取舍 | Q07 冲撞上调 36→40 抵消眩晕 | 同样做伤害抵消，模拟器定数 | — |

否决：给团本加 D193 破招蓄力（新招 + 预警叠加，团本已经三条招 + 增援 / 烬核，留给以后单独评估）；给 R01 重砸 / R02 刀气也加落空（一张图只给一个破绽，和主线一致；招越多读招越乱）；破绽时首领受伤 ×N（新乘区，硬限制）；破绽掉奖励（刷法）。

## 3. 门禁（offline sim）

`tools/p1sim/p1party.py` 新增 `RAID_STUN`（默认开）：
- 落空：被点名的人一定在形状里（Java 只在预警开始时有人在里面才武装），波及概率沿用 `SPLASH`；落下时命中人数 = 0 → 首领近战和所有招式计时整体后移 `whiff_stun` 秒（与 p1sim 单人模型一致）。
- 撞墙：每次冲撞期望眩晕 = `wall_stun × 存活队员平均躲避 × p1sim.WALL_STUN_K(0.5)`（同 D188 单人模型）。

`tools/p1sim/raidwin.py`：同一玩家池、同一阵容、同一入场随机流，对比 **旧**（1.65.32：伤害 79、无破绽）和 **新**（本包），躲避 0.3 / 0.5 / 0.7，人数 3 / 4 / 5，每格 1,500 局。结果见 `tools/p1sim/out-raidwin-d195.md`：

| 躲避 | 最大 \|Δ 通关率\| | 说明 |
|---:|---:|---|
| 0.3 | 0.7 点 | 三个团本 3–5 人都在 ±1 内 |
| 0.5 | **2.5 点**（R01 3 人 63% → 65%） | R02 3 人 +2.0，R03 ≤ 0.5；4–5 人 R01 −0.9 / −1.9 |
| 0.7 | 0.0 点 | 旧新都 100% |
| 0.5 `--upper`（每次冲撞都撞墙，参考） | R01 3 人 +10.7 | 只是上限；真实撞墙率按 躲避 × 0.5 计 |

**MAX_ABS_DPP 2.5（上限 3.0）→ 在范围内。**

不加伤害抵消时（只加破绽）躲避 0.5、3 人：R01 +6.2 / R02 +4.3 / R03 +3.5 点，超出 ±3 → 按 D188 先例加伤害抵消（扫过 88/86/84 与 92/88/86 两组后取 94/88/84）。

## 4. 漏洞 / 滥用审查

| 风险 | 处理 |
|---|---|
| 刷奖励 / 双领 | 破绽不发任何奖励；团本掉落、T3 印记、合计周 3 次、结算一次，全部不变 |
