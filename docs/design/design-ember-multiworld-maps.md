## 0. 一句话结论

现网玩法能跑，但**观感是「空中平台 + 共用小石砖房」**。挂机②～④明确是 `afk build` 空中平板；日/周/深渊/灾厄/团本/精英共用克隆模板与出生点 `-40,65,270`。  
本文件只定：**现网盘点 → 目标世界表 → 推荐改造序 → 占位可玩 vs 换图才验收**。施工（WE/prefab/坐标对齐）交给插件+地图执行岗，策划不落盘世界文件。

### 1.3 「平面感」问题点汇总（玩家一眼能骂的）

1. **挂机②～④空中平板** — 无高低差、无掩体、无入口门廊；与「真实地形多世界」直接冲突。  
2. **副本五本+精英共用小房间模板** — 日/周/深渊/灾厄/团本/精英「换皮同房」。  
3. **深渊无垂直感** — 阶段 4 做到 9～12 层，地形仍是单平面，层数全靠 HUD/播报。  
4. **撤离动线弱** — 深渊有菜单「上浮撤离」；挂机/周/精英多依赖 `/hub` 文案或关本传送，缺场景内「出口锚点」。  
5. **枢纽未成「家」** — `ember_hub` 有世界无完整主城叙事空间（工坊/引路人/回廊）。

### 2.1 动线最小集（每张图都要有）

1. **入口**：菜单落地后 3 秒内能看见「往哪打」与一块说明牌/全息（不依赖打指令）。  
2. **战斗区**：高低差或掩体至少一处；刷点落在可站开放格（防窒息，延续 critic 教训）。  
3. **撤离锚**：牌/按钮语义「回枢纽」或「上浮撤离」；底层可 `hub` / `dp leave`，**lore 不教玩家手打**。

## 3. 优先级（**已拍板**）

序（**先日常眼皮 → 再高压本 → 再低频本**）——总控 2026-09-27 确认：

| 序 | 对象 | 理由 | 预估体量 |
|----|------|------|----------|
| **P0** | 挂机②③④去空岛，贴地实景分区 | 每日必进；平面感最刺眼；改坐标+rebuild 即可，不动平衡 | 中（同世界分区） |
| **P1** | `ember_hub` 最小主城 | 第一印象；引路人/工坊/菜单叙事落点 | 中 |
| **P2** | `ember_abyss` 竖井多层 | 深渊 9～12 已玩法落地，地形滞后会显得「假冲层」 | 大 |
| **P3** | `ember_weekly` + 精英独立视觉（优先新 map 或强主题标记） | 周循环；精英现复用 weekly | 中～大 |
| **P4** | `ember_daily` 庭院主题 | 日本高频但短，可第二波 | 中 |
| **P5** | `ember_event` 祭坛盆地 + raid 大厅通道 | 低频/团本；逻辑已通 | 中～大 |
| P6 | arena / 原版维度整理 | 非内容里程碑 | 小 |

**不推荐：** 一上来全换 prefab 大图却不改挂机空岛——玩家每天骂的还是平板。

**可并行：** P0 挂机分区（插件改 `afk_tiers` 坐标 + 地图岗建造）与 P1 hub 广场。

## 4. 占位可玩 vs 换图才验收

### 4.1 占位图可继续玩法（不挡数值/脚本验收）

| 场景 | 说明 |
|------|------|
| 阶段 4.x 脚本、票、掉落、TTK、quest 事件 | 地图丑不影响 PASS/FAIL |
| 精英试炼暂共用 `ember_weekly` | 玩法可验收；**视觉验收不记 PASS** |
| 灾厄窗在平坦祭坛 | Boss 窗逻辑可测 |
| ①灰坡现状 | 已有地表起伏，可暂留 |

### 4.2 必须换图（或等价实景改造）才算「地图里程碑验收」

| 门槛 | 标准（建议写入测试报告主观项） |
|------|--------------------------------|
| **挂机去平面** | ②③④ 不再是 y≈110 空中屏障平板；有入口与撤离望向；有至少一处掩体/落差 |
| **深渊垂直可读** | 玩家不看层数 HUD 也能感到「又下一层」（平台落差或井壁变化） |
| **副本可辨** | 日 / 周 / 深渊 三张图俯视或进本 5 秒内主题可区分（材质+布局，不只告示牌） |
| **精英≠周本房** | 独立 map 或不可混淆的中轴/地板标识 |
| **枢纽像家** | hub 有明确广场+至少一处功能锚（工坊/灰烛），不是空出生点 |
| **动线** | 每本有入口落点与回枢纽/撤离语义，玩家全程不靠聊天打指令 |

### 4.3 明确不在本里程碑

- 平衡数值、掉落率、票价  
- Paper/NMS、新维度生成器插件大改造（除非总控另开）  
- 商城/外观地图彩蛋
