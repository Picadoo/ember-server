**一句话问题：** 七线终厅已「看提示→拉开可躲」，选线菜单却仍只写地形——玩家进门前不知道能躲。

**为何选本债、排除其它：**  
- **工坊←挂机：** D375 单向够用；盘密。  
- **软身份加厚：** D305 已齐；禁抬产量。  
- **使魔等级同屏：** 无 pet level PAPI。  
- **再开 Cast / 改伤：** =复述 D374/D379；硬禁。  
- **本债：** 明文后置升主 + 实扫菜单零「可躲」；TrMenu-only；机制已在盘 ≠ 假平面。

### 3.2 文案铁栅（统一口径 · 主题微差）

**统一语义（七线必须同义）：** 终厅 Boss 有**短提示/读条** → 出**环伤** → **拉开可躲**。

**荐半行模板（施工可微调色码，禁改语义）：**

| 线 | 荐半行（插在地形句与体力块之间，前可空行） |
|----|---------------------------------------------|
| 庭院 S | `§a终厅 · 读条提示后环伤 · 拉开可躲` |
| 焦骨 A | `§c终厅 · 读条提示后环伤 · 拉开可躲` |
| 残誓 C | `§8终厅 · 读条提示后环伤 · 拉开可躲` |
| 潮蚀 D | `§3终厅 · 读条提示后环伤 · 拉开可躲` |
| 断塔 E | `§7终厅 · 读条提示后环伤 · 拉开可躲` |
| 霜晶 F | `§b终厅 · 读条提示后环伤 · 拉开可躲` |
| 锈轨 G | `§6终厅 · 读条提示后环伤 · 拉开可躲` |

**灰态：** 同一半行复制进体力不足子 lore（色可用 `§8` 或保留主题色；语义不得删「可躲」）。

**禁写：**

| 禁 | 理由 |
|----|------|
| 「测岗已 PASS / 已签字」玩家面 | 残誓测未回；运维词不上菜单 |
| 「伤害 1.2 / r5 / delay 25 / CD8」 | 数值暴露过厚；易与调参脱节 |
| 「站着挨烫已删除」对比旧版 | 无旧玩家义务；易负向 |
| 教 `/mm` `/dp` 或 Cast 技能 ID | 玩家不打指令 |
| 只写某线「可躲」、其它线空白 | 破坏七线齐口径 |
| 在机制未挂 Cast 的线上写可躲 | **本窗前提 = 七 Cast 已在盘**；若批 A 时发现某线回滚，该线半行必须同步撤或改「筹备」 |

**残誓口径钉死：** 菜单可写「终厅读条可躲」（Cast 已落 = 非空许愿）。**勿**写「抽测已过」。测岗另走 STATUS，与本债宣传脱钩。
