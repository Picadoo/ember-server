4 件效果 · 护甲词条 / 词条叠加 · 同部位转化 · 印记扩部位 · 刃型 / 第 3 主动 · 饰品袋 · 外观 / 粒子 · 甲的工坊成色 / 精工提升 · 任一样本 R · Pack6 · 改 D308 门槛 · 动副手（D309 A）· 动刃 / 护符掉率与基础价表（护符 × 0.85 强化升阶系数除外，且只在 Stage1 bv 内）。

| 利 | 弊 |
|----|----|
| 给 HOLD 一个到期条件，结束「前置已满足 vs 不做」假悬空 | 施工面大（插件 + 物品 + 菜单 + 迁移 + loss/dup），占岗 |
| 回应服主「稍微灵活」：原版甲位可穿可换、每局多一件掉落；副手关后唯一正规横向槽位 | **Stage1 单件体感薄**（5%），「太单调」要到 Stage 2 才真正缓解 |
| T0 离线、现成工具、失败即回 HOLD，线上零风险 | bv58→60 漂移可能让 T0 不过，白跑一轮 |
| 打开 Stage 2（4 件行为效果）的唯一通路 | 上线会改变 H 分布（甲落后时），须避开样本 R 同周 |

### 2.4 荐选

**荐：方案 B（显式开工规格；本窗零代码；批 B 只授权另号 T0，T1 起每阶总控签字）。**

理由（据 §0 证据）：

1. **硬前置已满足，且已核实：** 权威 §9 原文「Stage 1 前置已满足，代码待总控 / 服主显式开工」；D246 w80_cap 已落为设计行 + 可复现 JSON；权威稿与 staged plan 口径一致。HOLD 的设计本义是「**等开工令**」（E1），不是否决。  
2. **「六槽不做」的作用域已过：** 加固原文是「**本窗**明确不做」「**本阶段**不要什么」「**本派单**硬约束」，而加固 1→5 主债已全关（E11–E12）；近档 D301–D311 的「六槽 HOLD」都在**禁止夹带进 R 窗**的语境里（E13），独立开工令不触 D308 红线 7。  
3. **副手路已关，甲槽是唯一正规横向槽位：** D309 钉死灰粮副手永不进 P1 B/H（E14）；服主「稍微灵活」（E15）若还要在 P1 内回应，**只能**走 D169 甲槽。  
4. **T0 便宜、可回退：** p1sim 已有完整六槽模型（P1–P2），T0 = 按 bv60 复跑现成命令 + 两处小接线（挂机 / 团本）+ 取整复验；不过 → 回到 HOLD，线上零变化。批 A 反而让前置随 bv 继续老化。  
5. **不碰样本窗：** 批 B 不开任何 R、不改门槛；T0 纯离线，T3 上线避开样本 R 同号同周。

**须如实接受的代价：** Stage1 单件体感薄（每件 5%），**「太单调」主要靠 Stage 2 四件效果才真正缓解**；批 B 是开通路，不是立刻解决单调。若总控判断当前施工岗应全力保样本窗、不愿承担 T1–T3 的插件 / 物品 / 迁移工作量，则选 **A**（附 §2.1 重开条件），不选 W。
