### 0.4 落后来自哪（逐项判定 · 读 `p1sim.py` 规则 + 上述数字）

| 候选来源 | 机制（p1sim 现规则） | 判定 |
|---|---|---|
| **甲掉落节奏**（每局 1 件、4 部位均匀） | 团本池生成 = `to_q07` + `phase2` 2 周（`raidcomp.players`，`raid=False`，刷挑战 / Q07 普通 = T3）；体力 90 / 30 = 3 局/日 → 窗内 ≤42 局，每个部位约 10 次 T3 掉落；20 次通关时「某部位 0 件 T3」概率 ≈ 4 × 0.75²⁰ ≈ 1.3% | **不是主因**：T3 甲「来得到」；但**新到的 T3 甲从 +0 起**，替换后要重新强化 → 产生**瞬时强化落后** |
| **升阶上限 ≤ 护符**（`arm_cap`） | 甲阶 ≥ 护符阶即跳过；Q07 首通时护符多为 T2 → 甲被压在 T2，等护符 T3 后才能升 | **次因（时间差）**：护符 T3 那一刻起，甲有一段 T2 时间 |
| **投入顺序**（p1sim 的玩家策略） | 升阶循环按「阶低者先、刃 > 护符 > 甲」排序，**一件买不起就 `break`** → 刃还在 T2 攒升阶时，甲的廉价升阶也被堵住；强化循环每次取「强化最低的件、平局刃优先」，**一件买不起就停** → 甲的强化 ≤ min(刃, 护符)，刃落后护符时甲跟着落后 | **主因（强化落后的来源）**：甲的步子本身几乎免费（c1a0：+1～+3 为 0，T2→T3 = 3 碎 / 1 核 / 0 胚 / 90 币），但排在刃后面 |
| **费用** | c1a0 下甲费用已近零；变体 B（甲份额 −20%）H 缺口只缩 17%、团本只缩约 4% | **不是瓶颈**：再打折没东西可打 |
| **团本 / 深渊不出甲** | 团本池生成时 `phase2(raid=False)`，池内不打团本 → 「团本不出甲」**不影响**本次 G8 结果 | **不是本次缺口的原因**；但上线后团本 / 深渊周确实不给甲进度（远期再议，见 §2 档 R） |
| 成色 / 精工 | 甲成色比护符低约 0.12～0.19 档（≈0.5–0.8% g，乘 20% 份额 ≈ −0.1～−0.15% H） | 小项 |

**一句话：** 缺口 ≈ −4 H（−1.28%），主要是团本窗内**甲的强化（与部分阶级）跟不上护符**。原因在**投入排序 + 新件从 +0 起 + arm_cap 时间差**，不在掉落数量，也不在价格。所以修法应该让**甲的有效阶级 / 强化跟随护符**，不能靠多掉甲或打折。另外 3–4 人团本对 H 很敏感：本例约 **3pp / 1% H**，而单人静态约 0.5pp / 1% H。变体 B 的结果（H 缺口缩 17%，团本只缩约 4%）还说明团本差**不完全由 H 中位决定**，尾部（队里一个落后很多的人）和刃的投入挪用都可能有份 → T0″ 必须加逐人落后分布（§2.2 工具改动 ④）。

### 1.1 荐选：**档 F（全跟随 · 共鸣）**，T0″ 同跑 E 作对照

**为什么是 F：**
1. **对症：** §0.3–0.4 的数据指向「甲的强化 / 阶级跟不上护符」，来源是投入顺序和新件 +0，**不是掉落、不是价**。F 直接拿掉甲的强化 / 阶级轨，缺口在规则层面消失，不依赖 p1sim 的投入策略，也不依赖真人怎么点。
2. **不碰团本 / 掉率 / 价：** 只动六槽自身规则（策划原倾向）；护符费用回到 ×1.0，**比 D312 已批 B（×0.85）还少改一条价**；不开任何 R。
3. **不伤已过项：** 甲不再领先、也不再吃资源，单人 / 动态 / W30 / 挂机都往 2 槽靠；G2 贴边格和 G4 轮换+团本 −0.47 预计都往回收（**待 T0″ 验**）。
4. **纸面够补 ~4pp：** 残差 ≈ −0.05～−0.1% H → 3–4 人格 ≈ −0.3～−0.5pp（线性折算；B 变体提示团本不完全线性，所以必须 T0″ 实测）。

**为什么不首选 E（策划原倾向的「强化追平」）：** E 只拿掉强化轨，阶级时间差还在。逐人阶级落后分布在现有文件里**拿不到**（raid JSON 只存了中位）。纸面上每人平均 0.5 件低一阶就会越线，**无法用证据保证够补 4pp** → 照实改荐 F，E 放进 T0″ 作对照臂：若 E 也过，总控可以选 E（甲多保留一点「升阶」玩法）。

**F 的代价（如实写）：**
- **改了 D169 Stage1 的一条：** 原来是「每件独立阶级、强化、成色、精工」，F 改为「阶级 / 强化随护符，成色 / 精工 / 族独立」。须总控认可为 **D169 修订**。依据：研究 §6.2 / D246「甲体感靠 4 件效果 / 部位特性，不靠数值」，D246 里每件甲本来就只有 5%。
- **甲的养成玩法变薄：** 不能单独强化或升阶甲。甲的价值 = 掉落时的成色 / 精工 / 族，加上 Stage 2 四件套（「4 件均 ≥T2」用**甲件自身掉落阶级**判定，掉落阶级因此仍有意义）。
- **对服主「认真做」：** 槽位是真的。原版甲位能穿能换，每局多掉一件，挑成色 / 精工 / 族，4 件效果的通路也打开了。但 Stage1 的数值体感仍然薄（与 D246 结论一致），**「更多传统槽位的手感」主要在 Stage 2 兑现**，这一点不能夸大。
