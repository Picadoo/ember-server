## 1. 玩家感知目标（≤3）

1. **招式起手一眼知道躲什么/站哪：** 蓄力开始有与真实 shape / warn 秒 / 破绽键一致的短反馈（不靠新招、不靠长 lore）。  
2. **半血或增援/烬核到来前有诚实短线索：** 相位切换与 YAML 真实钩（`below` / `adds` / `share`）一致；不假预警、不提前喊「增援」却无加怪。  
3. **七图 Q01–Q07 + 团本 R01–R03 同口径：** 起手/相位短签形统一；不靠 Pack6 / 新图 / 抬体力掉落堆辨识。

## 2. 方案表

### 2.1 方案 M（**荐** · 菜单/短签 + 揭示既有机制 · 零经济 · 零新 Pack）

> **原则：** 先把「起手可读 + 相位诚实」做进可感层；**禁止**纯 lore（文案宣称躲法、与 skill 键/时长/形状不对齐）。复用 `startWarn` / `shapeHint` / counterplay 尾缀 / D303 相位钉 / 图录数字，不新开招。抽 D283「短闪通道」+ D300–D303「短签+真实揭示」形。

| 窗 | 做什么 | 不动 |
|----|--------|------|
| **W1a · 起手短签口径表（必做）** | 定一张**玩家面口径表**（设计钉死、施工照表）：通道优先级建议 **ActionBar（起手每次或每招种本局首次）+ chat 保留现状**；短签模板例——`§e蓄力 · «名» · {形状一句} · {warn}s`；破绽尾缀与键一致：`wall_stun>0`→撞墙句；`whiff_stun>0`→落空句（见 W1c 诚实规则）；`break_hp>0`→破招句；`share`→靠拢分摊。图录/冒险名片半行可与表对齐（可选同批） | skills 数值 · every/warn/dmg · HP |
| **W1b · 相位短线索统一（必做）** | Q01–Q07：半血进入时按图钉 **≤1** 行诚实短签（对齐真实钩）——例有 `adds`→增援；有半血破招（霜潮/炉心）→「半血破招 · 蓄力圈可打断」；仅有 `below` 轻招→「半血 · 招式变强」。团本继续/核对 D303 `halfHpCue`（R01 增援 / R02 转阶段）；R03 烬核保持 share 预警诚实（绿圈+靠拢），不另堆假相位。禁止「提前喊半血」若 HP 门未到 | 不改 `below` 阈值、不改 adds 组成、不改 share 伤 |
| **W1c · 预警诚实规则（必做）** | 钉死三条：① **有键才写**（无 `wall_stun` 不写撞墙）；② **whiff 尾缀**：要么「预警开始有人在圈内才提示落空」（现状）并在口径表注明「先踩进圈再躲开才算破绽」，要么改为「有 whiff 键即常驻提示、是否 armed 只影响结算」——**荐后者更易读**（文案诚实说明条件，不假装每次都能踉跄）；③ **假预警禁**：charge 0 格跳过（B2.165）不发蓄力短签 | 不改 wall/whiff/break 数值窗 |
| **W1d · 菜单轻对齐（可选同批）** | 冒险/挑战七图或图录：半血/破招/增援一句与 W1b 同词；团本三格已有 D303 名片则只核对齐、不重写长 lore | 进本指令 / 解锁 / cost |

**期望：** 蓄力起手 HUD/短签与真实形状时长一致；半血/增援/烬核短线索挂在真实钩上——可感来自**短签 + 诚实揭示**，不是新 Pack。

**荐批：** **批 M**（W1a+W1b+W1c 必做；W1d 同批或可砍）。
