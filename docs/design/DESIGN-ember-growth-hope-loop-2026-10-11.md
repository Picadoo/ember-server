## 1. 诊断（定稿，不讨论）

| 症状 | 根因 | 不是根因 |
|------|------|----------|
| 运气挫败 | 成色/精工/徽记 chase **缺可见 pity**；随机旁路看起来像主轴 | 掉落「每局 1 件」本身（这是保底供给） |
| 看不到希望 | 强化/洗练 pity 散落；成长 HUD 未合成「下一档必出」叙事 | 数值预算太紧（预算要对，但要**可读**） |

**总控裁定：** 停用「再贴粘性路径当变强」当主叙事；希望环走本 DESIGN 三阶段施工。粘性路径可继续作便利，**不计入变强途径**。

## 2. 五大支柱（已拍板）

### P1 · 可见保底表盘（Pity / Deterministic meters）

对下列每条**随机或半随机**成长，统一「计数 → 满则必出 / 可兑」+ **枢纽一眼可见**：

| 轨 | 现状 | 目标 |
|----|------|------|
| 强化 | 有 `MAX_TRIES` 保底 | 工坊/成长格显示「本档第 n/N · 下次必成」 |
| 洗练词条档 | 有 pity + D458 一眼 | 保留；与成色表盘同风格 |
| **成色** | 掉落/随机锻造成色权重 | **新增：** 同件或账号级「未达目标成色」计数；满则下次工坊升成色必出（或碎+币确定升一档） |
| **精工** | 有升精工消耗 | **新增：** 失败/未升计数可见；或材料确定升一档旁路 |
| **地图徽记 / 签名 chase** | 有 chase 文案 | **新增：** 每图徽记进度条；满则兑换/保底签名尝试（**不锁通关**） |

原则：RNG 旁路旁边永远有一条 **AFK/日环材料 → 确定 +1**。

### P2 · 技能分叉（F 不再「一个键到毕业」）

沿 skill-kit 定稿，**不重开伤乘键**：

| 阶 | 玩家感受 | 约束 |
|----|----------|------|
| 已有 | Q02 烬突 · Q04 形状 · Q05 身法变体 | 保持；加强**解锁里程碑提示** |
| **本环 Stage B** | **套装专属主招手感**：焚/爆/承 在 F（或 潜行+F）上有可感分叉（形状/落点/短控），系数仍走共享充能预算 | p1sim within range；禁 third independent DPS CD |
| 后置 | 守招若重开须新 S0（历史守招全 ❌） | 本环 **不做** 守招 |

玩家叙事：「下一张图开新操作」>「下一件装 +3%」。

### P3 · P1 孔石进公式（有帽）

完全服从 [`DESIGN-ember-p1-socket-gems-2026-10-11.md`](DESIGN-ember-p1-socket-gems-2026-10-11.md)：

- Stage1 数据（可并行）→ **本环 Stage C = 宝石 Stage2** flat A/D + 吸血/移速受控 + p1sim  
- 不复开 legacy socket；无新 % 伤乘孔

### P4 · 地图装备身份 ≠ 通关门

| 做 | 不做 |
|----|------|
| 每图结算固定 1 装（已有）= **每局必变强一点** | 「不出某套就过不了」 |
| 图身份 = 签名改打法 + 徽记进度 + 刷装族偏向 | 把首通奖改成纯赌 |
| 差装可分解→胚→工坊确定养 | 逼玩家重复刷「唯一掉落」才能推进主线 |

### P5 · AFK / 材料永远喂工坊

- AFK 效率表 **不抬**（硬禁）  
- 现有 AFK→碎/骨/胚 → 强化/升阶/成色确定档 **必须在 UI 写清**「挂机在养这件」  
- 禁止把扭蛋/外观/纯赌抽当主变强口（外观已暂停）

## 4. 分期施工（实现顺序 · 已定）

### Stage A — 希望表盘（优先 · 零乘区）

**目标：** 玩家打开枢纽成长格，立刻看到「离下一档变强还有几步」。

| 切片 | 建议号 | 交付 | 验收 |
|------|--------|------|------|
| A1 强化+洗练表盘统一 | **D601** | 成长格/工坊：强化 n/N、洗练 pity、下次必成文案同风格 | 单测+冒烟；**不改** RATE/pity 数值除非另批 |
| A2 成色确定旁路+可见计数 | **D602** | 材料/碎 确定升成色一档 **或** 连续未升计数满必升；入口明示 | 经济 p1sim/手算 within；无极品抽卡唯一口 |
| A3 精工确定旁路+可见计数 | **D603** | 同上精工轨 | 同 A2 |
| A4 地图徽记/签名进度条 | **D604** | 每图 chase 进度可见；满可兑保底尝试；**通关不读此条** | 首通逻辑 git diff 空（或证明无关） |

**Stage A 成功标准：** 新人口述「我知道下次强化/成色什么时候稳了」；问卷式挫败「纯靠脸」下降。

### Stage B — 技能希望（套装分叉感）

| 切片 | 建议号 | 交付 | 验收 |
|------|--------|------|------|
| B0 设计锁形状 | （本文批注） | 焚/爆/承 各 1 条 F 或副招分叉规格；共享充能；无独立伤乘 | 批 A·M |
| B1 p1sim | **D605** | out-skill-hope-*.md within range | 达标才写码 |
| B2 落地 | **D606** | CoreRpg 套装分叉 + 主线/技能页提示 | 冒烟；表未抬 skill_mult 主系数 |

**Stage B 成功标准：** 三套装上手 30 秒能说出「我这套 F/副招和别套不一样」；非「数字大了」。

### Stage C — 孔石公式（变强旁路 · 有帽）
