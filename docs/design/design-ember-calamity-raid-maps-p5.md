## 2. 灾厄 · `ember_event` 祭坛盆地

### 2.1 独立视觉

**一句话：** 凹盆地里的开放祭坛——中央抬高台、环阶看台、四角火盆柱；进场能感到「往下走进仪式场」，不是出生点旁一块平地。

| 元素 | 目标 |
|------|------|
| 盆地 | 外沿相对祭坛台 **落差 3～6**；缓坡或台阶下到战斗环 |
| 中央祭坛 | 约 **11×11**，抬高 **2**；Boss 站台中心 |
| 战斗环 | 半径约 **20** 开阔可走；有少量柱/盆作掩体，勿密林挡视线 |
| 看台 | 边缘 **1～2 级**；可站观战，不刷怪 |
| 主材 | 石英/石砖台 + 灵魂沙/地狱岩环 + 火盆；与日庭院（灰石回廊）、团本（旗厅暗廊）可辨 |
| 禁 | 整盘同 y 平板；屏障盒围栏当主视觉 |

### 2.2 动线（入 / 战 / 撤）

```
[菜单奔赴] → 盆地外沿落点 → 台阶下到环 → 中央台打灾厄使 → 菜单「回枢纽」
```

| 阶段 | 要求 |
|------|------|
| **入** | 落地在 **南侧入口平台**（建议相对 Boss：南偏 12～16 格），面向祭坛；3 秒能看见中央台 |
| **战** | Boss 仍用现配置中心（现网约 **-96.5, 64, 266.5**）；改造后 **保留 XZ 或整盆平移后同步改 `calamity.yml` boss.x/y/z**（数值逻辑不动，只改坐标） |
| **撤** | 入口旁牌：`§e回枢纽 §7打开枢纽菜单返回`；菜单底层可 `hub` / `corerpg` 回城，**lore 不写请打 /mvtp** |

现 MV `ember_event` spawn ≈ (-96.5, 64, 266.5) 与 Boss 同点——**P5 应把玩家落点与 Boss 台分开**（落点南侧，Boss 台中央），避免开门撞脸。

建议（可微调，落地写进 STATUS）：

| 锚 | 建议 |
|----|------|
| Boss 台中心 | 保持或微移后写回 `calamity.yml` |
| 玩家奔赴落点 | Boss 南 **~16** 格，同 y 或高 1（看台沿） |
| MV spawn | **改为玩家落点**（与奔赴一致），勿再 spawns 在 Boss 脚上 |

### 2.3 玩家单门（防双入口混乱）

| 入口 | 玩家可见？ | 说明 |
|------|------------|------|
| `/ember` → 灾厄 → 奔赴 | **是** | 唯一正式门 |
| DP `EmberCalamity` / map `ember_calamity` | **否**（仅测试按钮，lore 写「仅管理/测试」） | 视觉可与公共祭坛 **同源缩小版**，或施工后期再同步；**不**当第二正式玩法门 |
| 手打 `/mvtp ember_event` | **不写进** 玩家 lore | 无权限玩家本就走 `calamity join` |

### 2.4 站岗

| 场景 | 结论 |
|------|------|
| `ember_event` 内 | **不强制** 长期 Ady（窗短、人多）；用 **入口牌 + 全息/牌「灾厄使·中央台」** 即可 |
| 枢纽 | **不** 为灾厄单开第五 NPC；枢纽四人稿够用 |
| 可选（非本验收） | 窗开时临时提示实体——后期美化，不挡 P5 |

## 3. 团本 · DP `ember_raid`「大厅 → 通道 → 终厅」

### 3.1 独立视觉

**一句话：** 集结大厅（旗/地毯）→ 向 +X 主通道（可 ±Z 支路）→ 终厅缩小祭坛感；进本 5 秒知「先集结再分路」，不是日周同款石盒。

| 区段 | 体量（约） | 观感 |
|------|------------|------|
| 大厅 | **28×28** | 出生、回城牌、简短说明；明亮石砖+旗 |
| 主通道 | 长 **~40**，宽 7～9 | 偏暗圆石；左右可有浅龛作「左道/右道」 |
| 终厅 | **24×24** | 中央 Boss 垫；材质可近灾厄祭坛缩小版，但布局是厅不是盆地 |
| 禁 | 与 `ember_daily`/`ember_weekly` 同尺寸同房；无通道的「一室四波」 |

现网小房约 13×13 → **必须扩建**；刷点左右错开要有 **真实左右空间**（文案分路不够，复盘要求动线可感知）。

### 3.2 动线（入 / 战 / 撤）

```
[大厅落点] → 左道清卫兵 → 右道压射手 → 汇合精英门 → 终厅使徒 → 结算回枢纽
```

| 波（数值不动） | 地形意图 |
|----------------|----------|
| wave1 左道 | 刷点在通道 **−Z 或左侧龛** 开放格 |
| wave2 右道 | 射手在 **+Z / 右侧**；卫兵可偏左 |
| wave3 汇合 | 通道末端门前中央 |
| boss | **终厅垫** 中央开放格（防卡边环，延续 critic 教训） |

本地坐标建议（施工后对齐 option/monster）：

| 点 | 建议本地 |
|----|----------|
| 大厅出生 | `0,65,0` |
| 通道中轴 | +X 方向 |
| 终厅 Boss | `40,65,0`（或厅中心） |
| 现占位 | `-40,65,270` 整簇 → 废弃 |

`EmberGuildBoss` 同 map：跟团本终厅/大厅约定走，**另文不改公会数值**；刷点随新图开放格重对齐。

### 3.3 入口 / 撤离菜单语义

| 路径 | 玩家可见 | 底层 |
|------|----------|------|
| 进本 | `/ember` → 团本 | `dp start EmberRaid`（勿写进 lore 当教学） |
| 大厅牌 | `§e回枢纽 §7打开枢纽菜单` | 可选本内离开按钮 |
| 通关 | 自动回 `ember_hub` | 维持现结算 |

**TrMenu：** `ember_raid.yml` 去掉「➥ /dp start…」「tell 命令：/dp start…」等玩家可见教学句（底层 command 可留）。  
**灾厄菜单：** lore 勿再写「➥ /mvtp ember_event」；测试钮保持灰色「仅测试」。

### 3.4 站岗

| 场景 | 结论 |
|------|------|
| 团本实例内 | **不强制** Ady；大厅用 **告示/全息**：「左道卫兵 · 右道射手 · 汇合后终厅」 |
| 枢纽 | 不新增团本 NPC；菜单进本 |

## 5. 验收 checklist

### 5.1 灾厄 `ember_event`（一票否决）

- [ ] 盆地/环阶/中央抬高台可辨，非空平板  
- [ ] 玩家落点 ≠ Boss 脚；面向祭坛  
- [ ] 入口有回枢纽菜单语义牌（不教打指令）  
- [ ] 正式入口仅菜单奔赴；DP 测本不进玩家主路径  
- [ ] Boss 仍能按窗刷新；日箱/缩放逻辑未改  

### 5.2 团本 `ember_raid`（一票否决）

- [ ] 大厅 / 通道 / 终厅三段可辨  
- [ ] 左右道有真实空间差，非同点刷怪换文案  
- [ ] 与日常庭院、周本廊 **观感可区分**  
- [ ] 刷点开放格、Boss 不卡边环  
- [ ] 团菜单无玩家可见 `/dp start` 教学  
- [ ] 通关回枢纽；票/人数/奖励数值未改  

### 5.3 债务

- [ ] STATUS 写明：改造前「观感未完成」；改造后勾选 5.1/5.2 才可宣称 P5 地图完成
