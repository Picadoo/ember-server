| 从 wt `cp`/`checkout --` resources→主仓 plugins 盖 live | 违 D344 |
| 把「cwd 清单批 A / wt 已就位 / toplevel 对了」当开闸 | 违 D362；开闸真源仍 D341 §2.1 |

### 2.7 含义（给动手的人）

1. **认树先于动手：** 先 C0–C2，再路由。  
2. **观察 docs 只出自主仓：** wt 缺新 DESIGN 不稀奇——去主仓读。  
3. **wt plugins ≠ 观察 live：** 值班/复跑只碰主仓 plugins。  
4. **批 A ≠ 开闸：** 禁混用只防呆；开闸仍走 D341 §2.1。  
5. **与 D359：** D359=怎么就位；本页=就位后怎么不混。
