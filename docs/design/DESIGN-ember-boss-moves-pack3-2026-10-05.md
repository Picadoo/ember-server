# Ember Boss Moves Pack 3：撞墙破绽（D188，2026-10-05）

> 状态：**CoreRpg 1.65.27 / balance_version 50**（routine-0547）。门禁 `tools/p1sim/out-wallstun-d188.md`；发布 `docs/status/RELEASE-ember-1.65.27.md`。
> 前置：D140（每首领 +1 预警招）、D173（半血转阶段）、B2.165（冲撞条带按墙距裁剪，`clearRunGrid`）。
> 范围：只动主线 **Q02 守炉蛮兵「焦冲」**（半血后）和 **Q07 炉锁巨卫「冲撞」** 两条会真的冲出去的首领招。挑战 / 深渊复用这两个首领，余烬连战（Q07）和连战·前哨（Q02）沿用主线招式，所以也带上。团本 r01 的冲撞（独立 yml 条目）**不动**。

## 0. 一段话裁决

首领冲撞被**真实的墙**截短时（不是看不见的首领区边界，也不是悬崖边），冲完后**眩晕 1.5 秒**：不放招、不普攻、定在原地，头顶出暴击星 + 铁砧声，全队一行「撞墙！… 眩晕 1.5 秒 · 破绽，趁现在输出」。蓄力提示末尾加一句「让它撞上墙会晕 1.5 秒」，图录两格同步。玩家能学的操作：**背靠墙站，等预警亮完最后一刻侧移**，首领一头撞墙。为抵消「白送输出窗口」，Q07 冲撞普通版伤害 36 → 40（挑战 / 深渊走 heavy 覆盖，不变）。不加任何玩家永久数值、乘区或新货币。

## 1. 参考（为什么是这个机制）

| 参考 | 做法 | 本服取用 |
|---|---|---|
| 《怪物猎人》角龙这类冲撞怪 | 冲撞撞上墙 / 岩壁会卡住，给一段输出窗 | 只取「撞墙 → 硬直」这一条，硬直短（1.5 秒）|
| MMO / 动作游戏常见的冲锋首领打法 | 把冲锋首领引到柱子 / 墙上让它硬直 | 「站位引导首领」→ 奖励是时间窗，不是伤害加成 |
| 《塞尔达》/《黑魂》类冲锋首领 | 侧闪让它撞墙，硬直是主要反击点 | 预警条带本来就画好了（B2.165），玩家能看见它会停在哪 |
| 本服 D141 | 「被预警招打空 = 闪避」已有判定 | 不改；眩晕独立，不和天赋窗口叠乘 |

否决：「撞墙后首领受到伤害 ×N」（新乘区，违反硬限制）；「撞墙后掉额外奖励」（刷法：故意拖时间撞墙刷奖励）；给所有首领加冲撞（预警叠爆，D173 已定 Q04–Q07 不加第 4 条独立计时）。

## 2. 规则（实现）

- yml：技能条目新键 `wall_stun`（秒，只对 `type: charge` 生效，钳到 ≤ 3 秒；其他形状读成 0）。
  - Q02 `焦冲`：`wall_stun: 1.5`（仍 `below: 0.5`，半血后才有）。
  - Q07 `冲撞`：`wall_stun: 1.5`，`dmg 36 → 40`。
- 判定（`EmberRunDirector.crashGrid`）：冲撞条带长度 < 配置长度时，取条带终点**再往前 0.25 格**，用和 `clearRunGrid` 相同的中心 + 两侧 + 前沿 4 个探点；任意一点脚 / 头高度是**实心方块** → 撞墙。条带跑满、停在悬崖边（脚下没地、但不实心）、停在首领区看不见的边界（空地）都**不算**。
- 生效时机：蓄力时算好（锁定方向后不再变），冲完落地（`execute` 后）才眩晕。挨没挨打都晕（站墙边没躲开也会被打中，然后它晕）。
- 眩晕期间：`recoverUntil` 推到眩晕结束（不放任何招，到期招排队、不跳过）；如有 follow，延到眩晕后；首领 SLOW 10 定身；首领的**普通近战**在 `EmberCombatListener.playerVictim` 里取消（`EmberRunService.bossStunned`，只认普攻，招式伤害 `skillDepth>0` 不拦）。
- 日志：`[P1 run] <runId> wall stun <招名> 1.5s`（冒烟用）。

## 3. 门禁（offline sim，`tools/p1sim/wallstun.py`）

p1sim 新增 `wall_stun`：冲撞后首领普攻和其他招的下一次时间整体后推 `wall_stun × 撞墙比例`（取均值，不抽随机数，成对模拟不走样）。撞墙比例默认 = 躲避 × 0.5（会躲的人也更会引墙），`--upper` = 每次都撞墙（上界，仅参考）。基线 = 同一份配置去掉 `wall_stun` 并还原 Q07 冲撞 36。

结果见 `tools/p1sim/out-wallstun-d188.md`：门禁（躲避挂钩）和余烬连战对比都在范围内；上界只作参考（真实大厅里每次都引到墙不现实，且上界本来就是「会躲 + 会引」的高手）。

探索记录（2 种子 × 1500 局）：Q07 眩晕 2.0 秒 → 普通 0.5 躲 +2.8pp（贴顶）；1.5 秒 +1.5；1.5 秒 + 伤害 40 → 最大 +1.1（选定）；1.5 秒 + every 12 → 挑战 −4.0（否决）。Q02 2.0 秒 → 挑战 0.5 +2.7；1.5 秒 +0.7（选定）。

## 4. 漏洞 / 滥用审查

| 风险 | 处理 |
|---|---|
| 连续眩晕锁死首领 | 只在它自己的冲撞后触发；冲撞每 14 / 18 秒一次，眩晕 1.5 秒，到期招排队放出，不可能连锁 |
| 撞墙给奖励被刷 | 不给任何奖励 / 掉落 / 计数，只是时间窗 |
| 首领卡进墙里 | 终点仍走 B2.165 `clearRunGrid`（盒子不进墙），眩晕不改位置 |
| 悬崖 / 首领区边界误判 | 只认实心方块；单测覆盖「跑满 / 悬崖 / 空地边界」三种不晕 |
| 眩晕中首领被打死 / 离场 | `le.isDead()` 检查；`bossStunned` 只认当前首领实体 |
| 和 D141 天赋（闪避后窗口）叠乘 | 眩晕不是伤害乘区，不触发任何天赋；天赋照旧只看「打空」 |
| 团本 | r01 冲撞条目没有 `wall_stun`（单测断言），团本机制不变 |
| 挂机 / 机器人 | 与挂机庭无关；只在副本首领上 |

## 5. 白话版（给玩家）

- 守炉蛮兵（半血后）和炉锁巨卫的冲撞，如果一头撞到墙上，会**晕 1.5 秒**：不出招、不打人，正好输出。
- 做法：背靠墙站，看到冲撞条带亮起，最后一刻往侧面闪。
- 撞空地 / 冲满全程不会晕。炉锁巨卫的冲撞普通版伤害略升（36 → 40），躲不开会更疼一点。
