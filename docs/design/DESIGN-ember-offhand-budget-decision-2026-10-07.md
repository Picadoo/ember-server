## 2. 双轨风险

加固稿 §5 风险条 5：「副手 / 六槽 / P1 公式双轨 — 灰粮副手走 StatService，P1 走 EmberFormula；长期双计风险。→ **要么声明副手永不进 P1 B/H，要么替换预算并轨；禁止默默叠**。」

| 风险 | 表现 | 债 |
|------|------|-----|
| **玩家认知分裂** | 套装页写「副手生效」，P1 状态 / 挂机层只看刃护符；玩家以为「又加了一截战力」实际只动旧 HP/物防表层 | 客服口径难统一；教学要两套话 |
| **数值叠床架屋** | 若日后把副手物伤 / 暴击悄悄接进 EmberFormula，等于第三 DPS 轴；与「不抬通关率预算」冲突 | p1sim 门禁失真；须整表重校 |
| **菜单入口分裂** | 灰粮卖饰 vs 装备页卖刃护符；若再开「P1 正式副手」而不收口，hub 多一条半死不活的成长线 | TrMenu 维护债 |
| **后续施工债** | 六槽 Stage1 若再開，会再抢 Off Hand / 套装件数叙事（staged plan 护符预算迁出甲） | 与本页决策打架 → **先拍 A/B，再谈六槽** |
| **测口径漂移** | 灰粮件 PASS 时验收是 rg+目视 Stat；P1 门禁是 42 格 ±2pp — 两套验收互不覆盖 | 「副手变强了」无法用 p1sim 证明或证伪 |

**禁止路径：** 默默让 StatService 副手与 EmberFormula 双计伤害 / 暴击 / 技能系数。

## 3. 方案 A · 永不进 P1 B/H（展示 / 微量生存）

### 3.1 声明（产品口径）

1. 灰粮副手（守腕 / 生坠 / 灰箍）**只做**：Off Hand **展示选择感** + **微量生存**（现行物防 / 生命量级封顶，远低于 T0 护符）。  
2. **永不计入** P1 的 **B**（攻击）与 **H**（生命预算主轴）。说明：StatService 的 `max_health` / `phys_defense` 可继续刷新原版血条 / 表层减伤观感，但**不**进入 `EmberLoadout` / `EmberFormula` / 挂机层判定 / 觉醒条件。  
3. **禁止**副手进：物伤、暴击、技能倍率、套装觉醒件数、签名槽、烙印目标。

### 3.2 菜单怎么说（TrMenu · 勿教指令）

| 位置 | 建议文案方向（批后文案窗再落字，本稿不定 YAML） |
|------|--------------------------------------------------|
| `ember_set` / hub 装备行 | `§7副手饰品 · 放副手槽 · 微量守势` + `§8不计入主线刃/护符战力` |
| `ember_life` 守腕/生坠 | 保持「副手饰品 · 放副手槽生效」；补半行「§8生存薄样 · 非主线毕业」 |
| P1 状态 / 图录装备 | **不**把副手画进 2 槽格子；避免「第三格战力」错觉 |

玩家路径：枢纽灰粮 / 套装页 **点选**；后台 `corerpg life buy …` 仅菜单 action，**不对玩家教学**。

### 3.3 验收口径（若批 A · 仍可不改代码）

| # | 检查 | 期望 |
|---|------|------|
| 1 | 文档 / 菜单文案（另开薄窗） | 无「提升主线战力 / 挂机层 / B·H」类承诺 |
| 2 | 静态 `rg` NI `acc_ember_offhand_*` / `part_ember_ash_brace` lore | **无**物伤 / 暴击 / 技能系数键 |
| 3 | `EmberLoadout` / p1sim | **零 diff**；42 格基线不动 |
| 4 | 目视 | 副手装卸仍只动 Stat 表层；P1 状态刃护符数字不变 |

**本方案不要求**改 p1sim、不要求迁移灰粮经济、不要求废弃获取口。

### 3.4 利弊

| 利 | 弊 |
|----|-----|
| 对准加固「本阶段维持展示/微量生存」；零数值债 | 副手永远成不了「P1 正式横向」 |
| 不碰六槽 HOLD；不抬通关率 | 双轨认知仍在，靠文案诚实压风险 |
| 灰粮 / B-flex PASS 资产可保留 | 若日后总控改口要正式副手，须再开方案 B |

## 4. 方案 B · 替换预算并轨

> 仅当总控明确要「P1 正式副手」时选用。施工面远大于 A；**批 A 后另开数值+插件窗**，本稿只定替换表与验法。

### 4.1 原则

- **总预算守恒**：参考角色同阶同成色同强化时，B / H / EHP 与现行 2 槽一致（对齐 staged plan「预算守恒」口径）。  
- **禁止新增轴**：副手数值必须从既有 **charm（H 侧）** 和/或 **套装 / 精工软帽** 挪出；**不得**从刀刃 B 再开第三条攻击来源。  
- **废弃灰粮独立轴**：并轨后 Off Hand 白名单件要么改读 EmberItemData 副手槽字段，要么降级为纯外观；StatService 副手战斗加成关闭，避免双计。

### 4.2 从谁扣（默认建议）

| 扣源 | 建议 | 理由 |
|------|------|------|
| **B（刃攻击）** | **不扣** | 副手叙事是生存薄饰；动 B = 变相 DPS 轴 / 重校全图 TTK |
| **H（护符生命）** | **主扣源** | 与 ward/vita/灰箍「物防·生命」同侧；从 charm 基表挪 X% 给 offhand 槽 |
| **D / 减伤软帽**（若公式有独立防） | **次选软帽** | 仅当 H 挪完仍超 EHP 容差时，用护符防向系数软帽封顶 |
| **套装系数** | **不优先** | 动套装 = 三族平衡另案；勿与副手并轨捆 |

**默认建议（若批 B）：** 从 **护符 H 预算** 挪出固定份额（例：同阶参考装 H 的 **8～12%** 封顶给副手满配）→ 护符基表同步下调同额 → 副手满配（守腕或生坠或灰箍择一生效）补回；**双件不同时叠满**（仍一槽 Off Hand）。

> 具体百分数 **本稿不钉死**；批 B 后由数值窗用 p1sim 扫一版再冻。

### 4.3 替换表（结构 · 非落地 YAML）

| 阶级参考装 | 现行 charm 贡献（概念） | 挪出 → offhand 上限 | charm 下调后 | 合计 H |
|------------|-------------------------|---------------------|--------------|--------|
| T0 起步 | H0 | ≤ r·H0 | H0·(1−r) | ≈ H0 |
| T1 / T2 / T3 | 同左按阶 | 同 r 或阶梯 r | 同左 | ≈ 原参考 H |

- **r**：替换比（待数值窗）；建议全阶同一 r，免阶梯教学。  
- **互斥：** Off Hand 同时只认一件白名单；与现网一致。  
- **灰粮价 / 周限：** 可保留获取口，但 lore 改为「P1 副手槽 · 占生存预算」；价是否上调另窗。

### 4.4 p1sim 怎么验

| 步 | 做法 | 门禁 |
|----|------|------|
| 1 | 扩 `p1sim.stats`（或等效）：可选第三参 `offhand=None`；有则 H 按替换表，无则与现网逐位相同 | selfcheck：`offhand=None` 与现基线 **逐位不变** |
| 2 | 参考装矩阵：刃+护符±副手满配；扫 42 首通/挑战格 | 通关率相对现基线 **±2pp**（加固 / skill-kit 侧移容差） |
| 3 | EHP / B 不变断言 | B 全格 **0 漂移**；H 在「有副手」与「无副手但 charm 未下调」对比中按设计表对齐 |
| 4 | 挂机层 | 层门槛仍只读 Loadout；副手并轨后层判定与主动局同一套 H |
| 5 | 报告 | 入库 `tools/p1sim/out-offhand-merge-*.md`；不过门禁不施工线上 |

**明确不做（方案 B 窗内）：** 六槽模型（`P1SIM_SIX`）、新 DPS 词条、改基础掉落张数。

### 4.5 迁移 / 废弃灰粮独立轴

| 步骤 | 内容 |
|------|------|
| M1 | 文档宣布：StatService `stats.offhand` 战斗加成 **日落日**（与发版绑定） |
| M2 | 插件：Off Hand 改读 P1 物品字段 **或** 将现 NI 迁成 `ember_v1_*_offhand` 模板（另开物品窗） |
| M3 | 关闭双计：同一帧不得 Stat 物防/生命 **且** Ember H 双加 |
| M4 | 菜单：灰粮 / 套装 / P1 装备页三处口径统一为「副手占生存预算」 |
| M5 | 回归：旧号已购守腕/生坠/灰箍 → 继续占 Off Hand；数值按新表，不删物 |

### 4.6 利弊

| 利 | 弊 |
|----|-----|
| 一条战力话术；可进挂机/主线同一公式 | 须动护符基表 + p1sim + 可能 NI 迁模板 |
| 真正「横向替换」符合 P1 书 | 工期与回归面大；易与六槽未来抢叙事 |
| 可关 Stat 双轨债 | 批前若偷工 = 默默叠，正是加固禁止项 |

## 5. 荐选

### **荐：方案 A（永不进 P1 B/H）**

**理由（短）：**

1. 加固批 A §3.2 原文已建议本阶段「维持灰粮饰品为展示 / 微量生存」；本页是把建议写成**可批决策**。  
2. 体验加固主线在反馈 / 付费诚实 / 挂机到顶 / 成长诚实（§8-1～4）；副手并轨是防债，不是本周手感主菜。  
3. 方案 B 必动 H 基表与 p1sim，且与六槽 HOLD 叙事易缠；在六槽未开、真人反馈未回前，**过早并轨成本高**。  
4. 方案 A 用文案诚实堵住「第三 DPS 轴」口子，保留灰粮 PASS 资产，零抬通关率预算。

**若总控改批方案 B：** 默认扣源按 §4.2 — **只从护符 H 挪，不扣 B**；先出 p1sim 报告再动线上。
