## 2. 可落地（方案 M）

### 2.1 定位与命名

| 项 | 钉 |
|----|----|
| 内部 id | **`sx01`**（短征 short expedition · 第一本） |
| 玩家名 | **烬门哨岗**（短征） |

| 与七线关系 | **并列新产品**；旧日常保持收起；help 可另号加半行「短征在冒险页」——**禁止**写「旧日常已开放」 |
| 与主线关系 | 补「短时多房刷材料」循环；**不**替代 Q01–Q07 首通/签名/徽记主进度 |

### 2.2 可达（P1 入口 + 门闩）

| 步 | 路径 | 说明 |
|----|------|------|
| 解锁 | **本人 Q01 首通**（`%corerpg_p1_q01done% >= 1`） | 保证「今天能打」出现在最早主线之后；未通灰显+tell 原因 |
| 菜单 | `ember_hub` 增「短征」格 **或** `ember_p1_adventure` 增短征区 → 子菜单 **`ember_p1_short`** | TrMenu 点选；**禁止**教玩家手打 `/dp start` |
| 进本 | 封装 `command: corerpg p1 enter sx01`（或等价 `enter sx01` 若路由已统一） | 走 **EmberRunService / P1 pass** 路径；**不**走 `TicketEntryService` DAILY |
| 体力 | **消耗 30**（与主线同池、同 `stamina_cost` 量级） | 不足灰显；文案对齐「主线 30」 |
| 日奖帽 | **每日最多 3 次有奖通关**（计数器例 `p1_sx01_day` / 体力日 Asia/Shanghai） | 第 4+ 次：体力仍可扣但 **无结算包**（或拒进有奖——施工择一，须菜单诚实）；**禁**无限刷崩工坊价 |
| LegacyGate | **不**把 `daily` 加入玩家白名单；**不**改 `gate_daily` 对旧本为 yes | 旧七线保持关 |

玩家面**禁止**写「请执行 /corerpg … /dp start …」；底层可用 `command:` / `menu:`。

### 2.3 结构（多房 · 5～8 分钟 · Cast）

| 房 | 内容 | 时长感 |
|----|------|--------|
| R1 | 小怪清场（1～2 波）· 短走廊/院角 | ~1.5–2.5 min |
| R2 | 精英或轻压力怪 + 可选轻事件（**可后置**；首航可固定精英） | ~1.5–2.5 min |
| R3 | Boss 终厅 · **Cast 预警环**（范式对齐 `EmberFrostNovaCast`：message→粒子→delay25→damage r≈5） | ~2–3 min |

| 项 | 钉 | 禁 |
|----|----|----|
| 目标通关 | **5～8 分钟**（熟练向中位；菜单不写死秒数承诺） | 写成 15+ 分钟长本；假「一键秒清」 |
| Boss 可读 | 必挂 1 个 `…Cast`；文案含「拉开」 | 无预警静默环当终厅唯一机制 |
| 人数 | 单人（可预留 1～2，首航 **1**） | 强绑 3～5 团本体量 |
| 复用 | MM 技能范式、门宽/间隔可参考日更 S 档铁栅 | 直接 `dp start EmberDaily`；复制旧 mmgive 旧币表 |

### 2.5 经济回盘（薄表 · S40）

**目标：** 通关有收获 → 材料/币进 **现网账户**（币 + vault 白名单材料）→ 玩家去工坊花（C03/C05/C06）；**显式不**动 `afk.daily_kills` / `afk.tiers`。

| 账户 | 方向 | 说明 |
|------|------|------|
| 余烬币 | 发 | 短征结算包 |
| `mat_ember_shard` / `mat_ember_bone_dust` | 发（vault / 绑定口径对齐主线发放） | 喂强化/精工/成色 |
| 核心 / 胚料 | **薄或首通才给** | 避免短征压过主线首通包 |
| 装备 / 印记 / 徽记 / 签名 | **默认不发**（首航） | 留给主线/挑战/残响；防短征替代开荒 |
| 挂机日表 | **不动** | 硬禁 |

**薄表草案（设计钉 · 金样须另号数值模拟后写入 `ember-v1-economy.yml`）：**

| 触发 | 草案数量（待 sim 闩） | 周期 |
|------|----------------------|------|
| 有奖通关（≤3/日） | 币 **80** + 碎片 **4** + 骨尘 **3** | 每次有奖通关 |
| 生涯首通（一次） | 另加 币 **200** + 碎片 **8** + 胚料 **1** | once |
| 无奖通关（日帽后） | 币 **0** 材料 **0**（或仅极薄币 — 施工与菜单须一致） | — |

| 登记 | 要求 |
|------|------|
| 新来源 | **S40 短征通关（sx01）** · 写入 REG + `EmberEconomy` + source-map；标签须进 p1sim **或** 明示「另号补模型」 |
| 消耗侧 | **不新开商店**；回盘 = 现有工坊/仓 |
| 门禁 | 批 A 后施工可落代码与菜单；**金样数字**若偏离草案 >20% 须再批或记 STATUS；**禁止**借短征抬挂机产量「找补」 |
