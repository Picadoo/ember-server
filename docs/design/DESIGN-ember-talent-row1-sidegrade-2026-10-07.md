## 2. 目标

1. **条件型侧移**：三节点对应三种打法标签（与 D291 对齐）——**机动 / 站桩 / 压上**；收益取决于躲没躲开、扛没扛住、预警招后有没有压上。  
2. **不抬通关率预算**：相对**现行**节点，42 格通关率变化落在 **±2pp**（见 §5）；整局用时可小幅摆，但不得做「净 +伤」永久乘区。  
3. **2 槽复跑**：growth-sidegrades 原稿标注「待 6 槽复核」——**六槽不做 → 本稿权威口径改为在现行 2 槽（刃+护符）下用 `sidegrade.py` 复跑**；旧 ±3pp 历史数字仅作候选形状参考，**不以旧跑数当过线证明**。  
4. **可感优先单次命中**：允许「窗口内每一击 +25～40% / 被预警招 −15%」级单次可感；整局用时 1～6% 可接受（sidegrades §2 诚实说明）。

## 5. 门禁（p1sim / sidegrade）

### 5.1 格子与对照

沿用 `tools/p1sim/sidegrade.py`：

- **容差格：** 7 图 ×（普通首通书参考装 `r` / 挑战 T3+6 `c`）× 躲避 0.3/0.5/0.7 = **42 格** / 套；三套分跑。  
- **对照：** 每个候选与其**现行节点**配对（同种子、同局）；报告 Δ 通关率 pp。  
- **可达子集（须另报）：** 一排 1 点，最早 Q03 后 → 去掉 Q01–Q03 首通 = **33 格**（sidegrades §1.1）。全 42 与 33 都过线才算 ✅。  
- **体感格：** Q04/Q07 普通重打、Q07 挑战 × 三档躲避；目标指标：机动=躲后窗口伤；站桩=预警招受伤；压上=窗口内伤占比。

### 5.2 过关线（对齐 skill-kit，收紧于旧 sidegrades ±3）

依据 `DESIGN-ember-skill-kit-2026-10-06.md` §1 + 加固「42 格 ±2pp / 侧移择优」：

| 级 | 定义 |
|----|------|
| **✅ 过关** | 每格通关率相对现行节点 **∈ ±2pp**；三套 ×（42 与 33）均满足 |
| **🟡 硬线内** | 平均 \|Δ\| ≤ 1 且无格超过 ±3** — **本返工不接受 🟡 上线**；只许作为收窄方向的中间试跑 |
| **❌** | 任一格 \|Δ\| > 3，或大量格越 ±2 |

**侧移择优：**

- 条件型节点 = 「打法对齐才赚」：择优 = 在**该节点适合的行为切片**上取收益，与「乱按 / 错打法」对比。  
- 要求：对齐打法时单次命中可感（≥10% 窗口内或 −15% 预警招）；**错打法不得净赚通关率**（窗外 / 未躲代价必须把平均拉回 ±2）。  
- 若择优 ≈ 0 且体感指标 <5% → **设计失败**（同 skill-kit「永远不值得」）。  
- 若只有低躲避格白送通关 → **❌**（同均匀乘区病）。

### 5.3 不过线怎么办

1. 先收窄：↓ `dodge_dmg` / `win_dmg`，或 ↑ 窗外代价（↓ `dmg_boss` / ↑ `win_out` 偏离 1），或缩短窗口秒数。  
2. 仍越界在「低躲避挑战」固定格 → **换机制**，禁止继续盲抬系数（build-diversity §7 诚实结论）。  
3. 留出种子 17/19/23（容差）与 777（体感）复跑；边缘格写入 T0 报告。  
4. **不过线 → 不开 T1 施工。**
