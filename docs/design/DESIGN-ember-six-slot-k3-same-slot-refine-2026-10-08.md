## §2 规则钉死（K3）

| 项 | 口径 |
|----|------|
| **对象** | 仅 **P1 护甲**（head/chest/legs/boots）；刃 / 护符 **不做**本熔炼 |
| **同部位** | 目标与材料 `slot` 必须相同 |
| **精工** | `craft_目标' = max(craft_目标, craft_材料)`；已达 `MAX_CRAFT`（3）则拒「精工已满」或 no-op 提示，**不毁材料**（建议：若 max 不提升则拒绝并提示「不会提高精工」） |
| **材料** | 材料件**销毁**；审计记账（uid、前后 craft、操作者、时间）；不可恢复 |
| **零价** | 不扣胚 / 骨 / 币 / 碎片；**不**改 `refineCost` / `qualityCost` / enhance 价表 |
| **不碰** | 成色 quality、族 family、**掉落阶** tier、强化 enhance（甲强化本就 F 跟随、字段可留 0）、绑定、source、origin、签名 / 词条 |
| **不产生极品** | 不成色提升；不创造 quality=3 |
| **合法件** | 仅本人绑定的有效 v2 P1 甲；`source=migrate` 可作目标或材料（与可分解性无关——熔炼≠分解）；禁止他人件 / 无效签名 |
| **穿着中** | 目标可为穿着甲；材料须在背包（或菜单明确的材料槽）；材料若穿着则先拒绝或要求先脱（荐：**材料不得为穿着件**，防误熔） |
| **幂等 / 确认** | 菜单先预览（目标精工 旧→新、材料将销毁）→ 二次确认；中途关服不半毁（事务：确认前不改） |
| **与 K0** | K0「工坊拒绝对甲精工按钮」**保留**；K3 是**新入口**，不是打开 C05 refine |
| **与 Stage2** | 不改 ×0.97 / set_bonus / 四件套计数（掉落阶不变故套装进度不变） |
| **开关** | 建议 `gear.six_slot.k3_refine`（名施工定），默认 **false**；须 `enabled=true` |

**纸面效果（沿 T1 §1.3，未跑）：** 团本期穿戴甲 E[精工] ≈1.2→≈2.2，精工差 1.77→≈0.8，H 中位 −0.46%→≈−0.27%；白板产出略降（材料不再分解）。**以 T0‴ 为准。**

**一句话（菜单用）：** `同部位两件甲：留下精工更高的，另一件熔掉（不花钱）。`

## §3 菜单草图（示例 · TrMenu · 不教命令）

**入口（二选一，施工定一主一辅）：**
- **主荐：** 工坊 `ember_p1_forge` 新增一列 **M**（熔炼）——手持/点选目标甲后，打开材料选择子页；甲的强化/精工/成色钮仍灰显 K0 文案。  
- **辅：** 护甲页 `ember_p1_armor` 加「熔炼」钮 → 同流程。

```
'#########'
'# 目标甲 #'     ← 预览：部位 · 族 · 成色 · 精工 旧→新 · 掉落阶（不变）
'# 材料甲 #'     ← 点选背包同部位候选（精工更高或相等才列出；相等则提示无提升）
'# 预览  确认#'  ← 预览只说话；确认才执行
'#   返回   #'
'#########'
```

**文案示例（标示例）：**
- 预览：`§7熔炼：§f胸甲 精工 二 → 三` / `§c将销毁：§7胸甲（精工 三）` / `§8成色 / 族 / 掉落阶不变 · 不花钱`
- 成功：`§a熔炼完成 · 精工 三`
- 拒绝：`§7同部位才能熔炼` / `§7不会提高精工` / `§7材料不能是正穿着的` / `§7护甲熔炼尚未开放`（开关关）
