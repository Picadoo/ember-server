| 维 | sx01 烬门哨岗 | sx02 锈灯栈道 | **sx03 霜雾闸廊（本债）** |
|----|---------------|---------------|---------------------------|
| 情绪 | 半露天石砖哨墙 · 灰火盆 | 锈铁栈道 · 灯笼/栏杆 · 潮气木板 | **霜雾深廊 · 铁闸门序列 · 青灰深板岩+碎冰点缀** |

### 2.6 经济回盘（薄表 · S42）

**目标：** 通关收获 → 币/材料进现网账户 → 工坊花；**显式不**动 `afk.daily_kills` / `afk.tiers`。

| 账户 | 方向 | 说明 |
|------|------|------|
| 余烬币 | 发 | 短征结算包 |
| `mat_ember_shard` / `mat_ember_bone_dust` | 发 | 喂强化/精工/成色 |
| 核心 / 胚料 | **薄或首通才给** | 避免压过主线首通 |
| 装备 / 印记 / 徽记 / 签名 | **默认不发**（首航） | 同前两本 |
| 挂机日表 | **不动** | 硬禁 |

**薄表草案（设计钉 · 金样可另号数值模拟后写入 `ember-v1-economy.yml`）：**

| 触发 | 草案数量（待 sim 闩） | 相对 S40/S41 差异意图 |
|------|----------------------|----------------------|
| 有奖通关（≤3/日） | 币 **70** + 碎片 **5** + 骨尘 **3** | 略少币、**略多碎片**——工坊强化向；总期望与 S40 同量级（±15% 内） |
| 生涯首通（一次） | 另加 币 **160** + 碎片 **8** + 胚料 **1** | 略薄于 sx01、与 sx02 首通同量级偏下，避免三本首通洪水 |
| 无奖通关（日帽后） | 币 **0** 材料 **0**（行为与前两本一致） | — |

| 登记 | 要求 |
|------|------|
| 新来源 | **S42 短征通关（sx03）** · REG + `EmberEconomy` + source-map；标签进 p1sim **或** STATUS 写明「另号补模型」 |
| 消耗侧 | **不新开商店**；回盘 = 现有工坊/仓 |
| 门禁 | 批 A 后施工可落；金样偏离草案 >20% 须再批或记 STATUS；**禁止**借短征抬挂机产量 |
