## 0. 闭环定义（玩家路径）

```
选图（身份可见）→ 进本 → 清房 → 偏置基装 ±12% 签名烙
      → +徽记 →（满 5）烬炉烙印 /（Q07）调律
      ↔ 残响 / 前哨 / 誓约（徽记加速旁路）
      → 换主力件 → 回本图再刷
```

「闭环」= 每张图有 **可农场目标**（基装偏置 + 本图签名）+ **获取→消耗**（徽记→烙印/调律）+ **晚游戏仍值得回刷**（换件重烙 / 残响）。  
对照：WoW 首领饰品、D4 威能拓印、D3 旧幕刷图场（D174 已引）。

## 2. 断环点（只列结构 · 不列 UI densify）

1. **Q07 缺 loot.slot** — 七图唯一无部位身份；与「每图自己的装备值得刷」不一致。  
2. **图鉴齐之后的结构下一环** — 身份 have/need 齐后，FarmCue/afterHit 仍偏工坊成色；追烙/烙印路径已有（D464/D653 等），但 **图鉴齐 ∧ 有追烙** 时未统一把「下一环」指到签名消耗（结构指针，非新进度条）。  
3. **非断环（定案）：** Q05 偏置刃+烬爆 vs L10 符爆 — 主招牌是 L09 形状刃，偏置正确；勿改 yaml「纠偏」成 charm。
