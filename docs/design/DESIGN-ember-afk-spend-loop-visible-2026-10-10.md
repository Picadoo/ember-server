**一句话问题：** 玩家看得见「今日挂了多少、这层养什么」，看不见「这些材料点哪里花」——消费闭环在挂机页断链。

**为何不跳过挂机可见化：** 总控点名优先；E1–E4 证明产齐、花断，非空转；日更第三拍已另交待批。

## 1. 方案表

| 方案 | 内容 | 评价 |
|------|------|------|
| **A · 只改 I 格 lore 半行** | 战况加「材料进仓库去工坊花」但**无可点跳转** | 止黑箱一半；仍要玩家自己找枢纽工坊；**不荐独批** |
| **M · 可见化 + 可点跳转（荐）** | 挂机页加「战利品去哪花」格 → 工坊；lore 产→花对照；可选仓库半跳；Open tell 半行；**零改产量** | **荐** — 闭环可点；复用现入口；对齐 TrMenu UX |
| **L · 抬挂机日表 / 加魂尘 / 新消耗系统** | 抬 `daily_kills`/层每日量，或新「挂机币商店」 | **否决** — 硬禁抬表；新 sink 过厚；本债是可见化不是经济窗 |

**批 A = 采纳方案（荐 M）。批 A ≠ 施工 ≠ 关观察 ≠ 抬挂机表 ≠ 开 R ≠ 开 K3。**

## 2. 可落地（方案 M）

### 2.1 玩家路径（TrMenu · 零裸指令教学）

| 步 | 路径 | 说明 |
|----|------|------|
| 看产 | 枢纽 → 挂机庭 → 战况 I / 层名片 | **保留** D305/D285；本窗不改层表数字 |
| 看花 | 挂机页新格 **「战利品去哪花」**（荐键位 `S` 或 Layout 空位，施工择一不挤 F/H） | lore 对照表 §2.2；点击 → `menu: ember_p1_forge` |
| 查仓 | 同格右键或邻格「材料仓库」 | 可选 W1c：`menu: ember_storage` 或封装 `corerpg p1 vault`（玩家不看见斜杠教学） |
| 满额 | F 仍「体力还在 · 去冒险」 | **钉死** D285；消费格**不得**盖过满额主按钮语义 |

玩家面**禁止**写「请执行 /corerpg p1 forge …」；底层可用 `command:` / `menu:` 封装。

### 2.2 产→花对照短签（设计钉死 · 施工照表）

挂机日表键 → 玩家面「去哪花」（对齐现网工坊/仓，**不**新造虚假用途）：

| 产出键 | 玩家短签（≤1 行） | 真入口 |
|--------|-------------------|--------|
| 币 `coin` | 工坊强化/升阶等费用 | `ember_p1_forge` |
| 经验 `xp` | 角色成长（非工坊材料） | 不强制跳；lore 半句即可 |
| 碎片 `shard` | 强化等材料（进仓库） | 工坊 / 仓库 |
| 骨尘 `bone` | 强化等材料（进仓库） | 工坊 / 仓库 |
| 核心 `core` | 升阶等材料（进仓库） | 工坊 / 仓库 |
| 胚料 `blank` | 精工·成色·升阶用（进仓库） | 工坊 / 仓库 |
| ~~魂尘~~ | **不写挂机产**（D373） | 生活·钓鱼；本格可半行「魂尘≠挂机」防误读 |

**禁止**写「挂机产魂尘」；**禁止**暗示升层/换更高层会改日表公式（只揭示真实对照）。
