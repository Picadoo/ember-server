# RESEARCH — 每日签到 + 在线时长奖励（D180 · 2026-10-04）

业主 19:06：「每日在线时长奖励做了吗？每日签到奖励等等？」——答：P1 里没有。旧模式的 签到 / 活跃 / 悬赏（`/corerpg sign|activity|bounty`）
在 D63 从 P1 菜单拿掉了，因为它们发的币不在模拟器经济里。业主要求先研究成熟做法再设计，不要拍脑袋；本文是研究，设计见
`DESIGN-ember-signin-online-2026-10-04.md`。所有条目都是公开页面上能核对的具体规则（2026-10-04 查）。

## 1. 每日签到（登录日历）

### 1.1 HoYoLAB 每日签到（原神 / 星穹铁道，网页签到）
来源：Genshin Impact Wiki「HoYoLAB Community Daily Check-In」规则原文；traveler.gg 汇总；HoYoLAB 帖子 17176443。
- 每天签一次；**按本月累计签到次数发奖**（不是按日期）。每月 1 日 0 点重置，本月次数不带到下月。
- 漏签不清零，下次签到接着下一格（Business Insider：「missing a day won't break the cycle」）。
- **补签**：只能补本月；**每天最多 1 次、每月最多 3 次**；**自动补本月最早漏的那天，不能自选日期**；补签卡要先做一个小任务拿。
- 量级：前 28 天合计 60 原石（每累计 7 天 20 原石）+ 经验书 / 摩拉 / 强化矿 / 食物；**长月份第 29 天起每天只给 5000 摩拉**。
- 对照：日常委托 4 个 + 凯瑟琳 = 每天 60 原石——**一天的委托 = 一整个月签到的原石**。签到只是「来了就有一点」，主收入在玩。

### 1.2 黑色沙漠 每月登录奖励（2026-10 主机版公告 boardNo=19869）
- 每天登录领一格，Day 1 … Day 26 各不同，**Day 27–31 统一一件小东西**（瓦尔克斯的呐喊 ×1）。
- 大格穿插在第 14 / 21 / 23–26 天（活动币、强化辅助箱）。
- **按「家族」（账号）领一次**（小号不能多领）；**漏的天不能补**；角色 7 级以上才稳定发放。
- 周六日「游戏超过 1 小时」可以再领第二格——**在线时长当签到的加码条件**。
- 活动物品「交易 / 出售 / 有效期各有绑定」。

### 1.3 失落的方舟 出勤日历（官网 2022-03 更新说明；韩服 STOVE 2025-06 出勤活动页）
- 每月一条 25 格的登录轨道，**累计 10 / 15 / 20 天另有里程碑奖**（精炼材料选择箱）。
- 日常格是战斗消耗品 / 货币箱 / 卡包这类「辅助」，里程碑格才是成长材料。
- 另一个关键做法——**休息奖励**：混沌地牢每天 100 共鸣，没用完的每 100 折 +20 休息值，满 40 下一次通关双倍，上限 200。
  **不在线的补偿作用在下一次真玩上**，而不是直接发东西（D177 已引用，这里只作对照）。

### 1.4 国内 MC 服务器签到插件（MineBBS / 九域 / Gitee 原文）
- **LiteSignIn**：日历 GUI、**每月累计签到奖励**、**总累计签到奖励**、连续签到奖励、补签卡、PAPI（`%litesignin_statistics_of_month%`、
  `%litesignin_cards_amount%` 等）。
- **PaiSign**：日签 + 连签里程碑 3/7/15/30/60/100 天 + **月签宝箱 7 / 14 / 21 / 28 天四档** + 全勤大礼；补签「补签卡 / 金币 / 点券」，
  **仅限当月**；断签归零阈值可配；「玩家离线自动走邮件兜底，绝不丢奖」。
- **TRMonthSign**：累计签到 30 / 50 天奖励，按日期（10 号 / 20 号）的特殊奖；无补签。
- 共同点：**日历界面点格子签到**（不是打命令）、**按当月累计次数给里程碑**、补签有上限。

### 1.5 小结（签到）
| 做法 | 谁这么做 | 我们取舍 |
|---|---|---|
| 按「本月第 n 次」发奖，漏签不清零 | HoYoLAB、黑沙、方舟、LiteSignIn | **采用**（忙碌玩家不被惩罚——业主说很多人没时间） |
| 每 7 次一个大格 / 7·14·21·28 里程碑 | HoYoLAB（每 7 天 20 原石）、PaiSign 月签四档 | **采用** |
| 长月份 29–31 只给小奖 | HoYoLAB 5000 摩拉、黑沙 Day 27–31 | **采用** |
| 补签：当月、每天 1 次、每月 3 次、自动补最早那天 | HoYoLAB | **采用**；补签条件用「今天有效在线满 60 分钟」代替 HoYoLAB 的小任务 |
| 连续签到（断签归零） | PaiSign、DailyRewards 连签倍率 | **不做**：惩罚忙碌玩家，FOMO；累计制已经给了「来得多拿得多」 |
| 付费 / 金币补签、补签卡道具 | PaiSign | **不做**：P1 无商城；补签卡做成物品会被小号转移 |
| 按账号领一次 | 黑沙「once per Family」、HoYoLAB「per HoYoverse Account」 | P1 以角色 UUID 为账号单位，奖励不可转移（§3） |

## 2. 在线时长奖励

### 2.1 国内 MC 在线奖励插件
- **QZOnlineReward**（MineBBS 16292）：每日档位示例 **30 / 60 / 120 / 180 分钟**，GUI 点击领取，**每个档每天只能领一次**，到重置时间清空今日时间和领取状态；另有「累计领取次数」奖励。
- **TimeRewards**（MineBBS 17236）：默认 16 档每日奖励 20 … 720 分钟；手动或自动领取；**「奖励领取先原子记录再发放」**防并发 / 多服重复领。
- **Time Is Money**（土豆MC）：每 10 分钟发一次，`max_payout_per_day` 日上限，**`afk_payout: false` 挂机不发**，还有「同时游玩多个账号（同 IP）不发」的提示。
- **LSE onlineReward**：每 30 分钟 100 金币；可选「原地挂机限制：小周期内累计未移动秒数达到比例就不发或发一半」。

### 2.2 国外插件（SpigotMC / GitHub）
- **PlayTime+**：只计**有效在线**，`anti-afk.threshold: 300`（5 分钟没动就停表）；里程碑例 15 / 30 / 60 分钟；「Rewards can't be claimed twice」。
- **PlaytimeRewards**：`afk-threshold-seconds: 120`，挂机后停止累计；GUI 按里程碑领取。
- **TDRPlaytime**：可配「AFK 时间算不算在线」，可接 Essentials AFK。
- **JetsAntiAFKPro**：在线 5 分钟 / 1 小时 / 1 天发奖，另有 AFK 检测与踢出。

### 2.3 大作里的「在线时长」
- **黑色沙漠**：周末「游戏超过 1 小时」解锁第二格登录奖（§1.2）——时长只是加码，不是主奖池。
- **原神 / 星铁 / FF14 / WoW / 失落的方舟都没有「挂着就发」的在线时长奖**：
  - 原神日常委托（4 个 + 凯瑟琳 60 原石）、星铁每日实训（**每天 500 活跃度，100/200/300/400/500 五档合计 60 星琼**）——按**做了什么**给，不按时长。
  - FF14 每日随机任务：**每类当天第一次通关**才有大额奖励。
  - WoW 商栈（Trading Post）：每月自动 500 商栈币 + 完成当月旅行日志活动再给最多 500。
  - 失落的方舟：混沌地牢每天 1 次 + 休息奖励（§1.3）。
- 结论：大作把「每日目标」挂在**真玩的动作**上；时长奖励是国内私服的传统，成熟插件都**排除挂机时间**、**设每日上限**、**先记账再发**。

### 2.4 小结（在线时长）
| 做法 | 谁 | 我们取舍 |
|---|---|---|
| 每日档位 15 / 30 / 60 / 120 分钟 | 业主举例；QZOnlineReward 30/60/120；PlayTime+ 15/30/60 | **采用 15 / 30 / 60 / 120** |
| 只计有效在线，几分钟没操作停表 | PlayTime+ 300 秒、PlaytimeRewards 120 秒、Time Is Money afk_payout false | **采用 5 分钟**；而且**只看真实输入**（转视角 / 点击 / 攻击 / 聊天 / 切栏 / 潜行 / 命令），**只是位置变了不算**（水流 / 活塞 / 被推的挂机池骗不到） |
| 挂机区时间另算 | 国内服挂机池与在线奖励分开 | **挂机庭（D177）时间不计在线时长**：那段时间由挂机庭自己结算，一份时间不拿两份奖 |
| GUI 点击领取，过期自动补发 | QZOnlineReward（过期清空）/ PaiSign（邮件兜底不丢奖） | **点击领取**；没领的**过 0 点自动补发**（不丢奖，也不给第二份） |
| 先原子记录再发放 | TimeRewards | **采用**：状态计数先落盘，再写唯一键账本行，由现有 P1 发放路径到账 |
| 同 IP 多号不发 | Time Is Money | **不做**：同 IP 家庭 / 网吧会被误伤；我们的奖励账号绑定、不能转移，限 IP 没有收益（同 D177） |

## 3. 防刷（各家怎么做 → 我们怎么做）
- **小号**：黑沙 / HoYoLAB 按账号领一次。我们：每个角色只能拿自己的；**只发账号计数**（余烬币、经验、锻造印记、首领徽记），
  P1 没有转账（无交易 D73、旧寄售 P1 关闭 D177、邮件发送要权限）。**碎片 / 核心 / 骨尘 / 胚料不发**：它们是能从仓库取出、
  能丢在地上给别人捡的 NI 物品，小号签到 → 丢给大号就成了刷材料。
- **挂机机**：插件做法是 AFK 检测 + 日上限。我们：真实输入才计时 + 每天 120 分钟封顶 + 收益小（§设计 §6）。
- **改时间 / 跨天**：全部用服务器时钟（`DailyService.today()`，Asia/Shanghai 0 点）。服务器时钟倒退时冻结签到与计时，避免「回到昨天再领一次」。
- **重连 / 双击**：状态在角色数据里，领取先推进计数并落盘再写唯一键账本行（TimeRewards「先原子记录再发放」；我们 D162 / D177 同一条路）。

## 4. 对 P1 的约束（不是参考游戏，是本项目的硬条件）
- 玩家不打命令：签到、补签、领在线奖全部在 TrMenu 里点；进服提示带可点按钮（`ConfirmTokens.sendButton`）。
- 不做化妆品（粒子 / 光环 / 宠物 / 扭蛋外观暂停）。
- 平衡只用离线模拟：21 格首通率 ±2pp、W30 两件极品 ±0.5 周，并且**和挂机庭的收入一起算**。
- 旧 `/corerpg sign|activity|bounty` 在 P1 下仍能打出来并发旧币（签到 100 币 / 天、活跃宝箱、悬赏币）——这是现存漏洞，本次一起关。
