## 1. 目标结构（相对 RESEARCH §4）

### 1.1 槽位与预算

| 槽 | 攻击 | 生命 / 防御 | 计套 |
|---|---|---|---|
| 刃 | 全部 A（不变） | 无 | 核心 |
| 护符 | 无 | 预算约 40%（Stage 0 定） | 核心 |
| 头 / 胸 / 腿 / 靴 | **无** | 各约 15%（Stage 0 定） | 4 件用（任选 2 件同族） |

同阶同成色同强化时，参考角色的 B / H / EHP 与现行 2 槽一致（总预算守恒）。

### 1.2 掉落与保底

- 刃 / 护符：现行每局 1 件逻辑与目标族偏向保留。
- 护甲：每局 **+1 护甲件**（另掉），部位可有权重偏向但任何部位权重不为 0；缺口加权只做权重、不做必出。
- 印记：扩到 6 部位（护甲兑换价可低于刃 / 护符）；后期加同部位跨族转化 + 每周限速（Stage 2）。
- **没有**「某图只掉靴子」一类规则。

### 1.3 套装

- **2 件**：刃 + 护符同族 → 现行焚烬 / 烬爆 / 炽愈被动与 I / II / III 觉醒，**一字不改**。
- **4 件**：核心 2 + 同族护甲任意 2 → 行为型效果（候选见 RESEARCH：焚烬连锁燃烧已过 ±2pp；烬爆 / 炽愈另设计）。要求「4 件均 ≥T2」与觉醒 II 同里程碑。散件 vs 套装件取舍保留（另 2 甲位可穿异族高成色）。

### 1.4 锻造与主动（Stage 2–3 才做）

- 烬砧：选族 + 选部位；可选钉词条类型；档位随机；次数有上限（烙纹等，细节 Stage 3 定）。
- **8 枚印记兑换**指定件保留为地板。
- Stage 3：刃掉落 / 兑换时带刃型 → F 键 烬斩（扇）/ 烬突（直线）/ 烬震（圆），同一 1.5B 级预算；不加第 3 个主动键。

**门禁：** 任一阶段失败 → 停在上一阶段，不捆下一阶段「凑平衡」。Stage 1+ 每次上线：短冒烟（能进本、能清、无功能 bug）+ 存取 / 分解 / 撤销路径的 loss/dup 回归。Stage 0 **只做离线模拟与文档**。
