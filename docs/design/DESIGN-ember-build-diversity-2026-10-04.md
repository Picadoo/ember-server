# Ember 构筑多样性：换配装后，玩法到底变没变？（2026-10-04）

> 状态：分析 + 提案，**没有改任何线上配置或 CoreRpg 源码**。所有数字来自离线模拟器 `tools/p1sim`（balance_version 29，规则快照 sha256 `9806c4d10d1fc270`），并且是在本日修正了模拟器自身的 4 个模型问题（审查 M01/M02/M03/M06，见 `tools/p1sim/out-simfix-m01-m06.md`）**之后**跑的。
> 模拟器只能告诉我们"数字差多少"，**不能告诉我们好不好玩**。凡是"玩家会不会觉得不一样"的判断，都是用一条启发式阈值把数字翻译过来的，必须用真人观察去验证（§8）。

## 0. 一页结论

1. **真正改变打法的只有"穿哪套"。** 三套之间：首领用时差 18–20%，杂兵房用时差 9–14%，每局喝药差 9–18%，同一装备水平下通关率差 32–34 个百分点（Q04 / Q07 普通重打）。这是明显可感的差别，也是唯一一个在**所有**进度、所有情境都可感的选择。
2. **天赋第一排（回身斩 / 稳桩 / 踏步回气）三个选项玩起来一样。** 任何情境、任何指标的差别 ≤ 2.2%（首领用时），通关率 ≤ 1.4 个百分点；唯一的边缘例外是"炽愈 + 踏步回气"自我回复 +4～6%。花 800 币换来的东西感觉不到。
3. **天赋第二排（破缀 / 守缀 / 拆分）是唯一"在那一下"可感的成长选择，但只在主线重打的那 1 只词缀精英身上生效。** 精英击杀用时：破缀 −17～−31%（明显），拆分 +10～+17%（明显变慢）。摊到整局只有 1～2%；首通、挑战、团本、深渊里完全不生效（这些地方没有词缀精英）。
4. **拆分是死选项，修好 B01 也救不回来。** 在所有目标上被破缀或守缀可感地支配；B01 补丁（分身真正 +50% / 本体 −20%，已在 CoreRpg 1.65.2 cac6bc6 实现、未部署）对分裂精英击杀用时只有 0～−2.3%，因为分身只是半只普通近战怪。
5. **词条里，只有猎缀纹（4 档）可感**（精英击杀 −10%，同样只在重打）。余烬纹（≤ +1% 套装事件伤害 ≈ 总伤 +0.2%）、定身纹（≤ −2% 预警招伤害）、裂身纹（分裂精英 ≤ −2.3%）都在阈值以下；分核纹 / 抗缀纹只在团本 R03 / 词缀精英时有意义。
6. **正常进度时（例如 Q04：2 个天赋点、词条封顶 1 档），除了套装以外的所有选择都在阈值以下**：每套 27 个实际生效构筑合并成 **1 个**"感觉不同"的类。最高投入时（T3+10 极品、词条 4 档、6 点），每套也只有 **3 个**可感类（由第二排决定），81 个结构里 58～72 个被另一个构筑"可感地支配"。
7. **勋记（D142）是经济系统，不是构筑系统**：结算币 +4%（封顶）、每次 +1 碎片、深渊层费 −5%，战斗上只有"深渊老手"深渊受伤 −2%。
8. **成本 vs 体感（B02）**：天赋三排 6,800 币 ≈ 1 周金币收入，买到的战斗变化只有第二排可感；把余烬纹洗到 4 档每件约 6,200 币 + 1,130 碎片（锁定路线），换总伤 +0.2%。
9. 模型修正后，**多人焚烬团本**被旧模型少算了 7～15 个百分点（R01–R03），R02/R03 全焚烬队已与混编持平或更好；R01 仍偏弱。**不建议现在调焚烬**，见 §6。

## 1. 问题与做法

问题（策划原话）：玩家换天赋（D141，3×3，6 点）、余烬勋记（D142）、词条 / 洗练 / 锁定（D143）、套装（焚烬 / 烬爆 / 炽愈）、护符、遇到词缀精英时，**打法真的会变吗？还是收益小到感觉不到？**

做法：
- **先修模拟器**（审查 §04–§06）：显式随机种子、每局独立随机流 + 固定团本阵容（M01/M02），按 (施加者, 目标) 的离散焚烬燃烧、与 Java `EmberBurnBook` 逐跳对拍（M03），所有入口读同一份规则快照并校验哈希（M06）。修正前后对照见 `out-simfix-m01-m06.md`。
- **穷举所有合法结构（M04）**：套装 3 × 第一排 3 × 第二排 3 × 刃词条 3 × 符词条 3 = **243** 种（第三排由所穿套装决定：别的两个第三排节点对该套无效）。每个结构按**真实生效**处理：天赋点不够的排不生效（Q04 前只有 2 点 = 只开第一排），词条档位被装备成色封顶（`growth.py` 的 `tier_cap`：标准 1 / 精良 2 / 卓越 3 / 极品 4），生效完全相同的结构合并。
- **两种进度分开报**：正常推进（Q04 普通重打 T1+6 标准成色、Q07 普通重打 T2+8、Q07 挑战 T3+6，词条 1 档）和最高投入（T3+10 极品，词条 4 档，6 点，勋记全开）。
- **按目标找极值**：单体（首领用时）、清群（每个杂兵房用时）、词缀精英（精英击杀用时）、续航（自我回复、喝药）、承伤（受伤 ×H）、经济 / 推进（通关率 —— 体力制下失败 = 白花体力）。每格 3,000 局；同一种子下所有结构共享房间 / 受击 / 暴击 / 刷怪随机流，所以差值**按局配对**，报 95% 区间；另用一个**留出种子**（777）复跑每个目标的最佳 / 最差结构（M05）。
- 团本另跑：1 号位穿被测构筑、队友固定（`out-build-diversity-raid.md`）。
- 输出：`tools/p1sim/out-build-diversity-m04.md`（主表）、`-b01-split.md`（拆分补丁）、`-proposals.md`（提案校准）、`-raid.md`（团本）、`-b03-b04.md`（成长成本与双极品周）。

## 2. "感觉得到"的阈值（启发式，不是实测）

| 量 | 感觉不到 | 可能感觉到 | 明显 |
|---|---|---|---|
| 时间 / 次数的相对变化（首领用时、杂兵房用时、精英击杀用时、喝药、受伤） | < 5% | 5–10% | ≥ 10% |
| 通关率 | < 2 个百分点（同一档） | 2–5 | ≥ 5 |
| 伤害来源占比（节奏变化） | < 5 个百分点 | | ≥ 5 |

理由与局限：
- 5% / 10% 是策划给定的启发式。时长判断的韦伯分数在几秒到几十秒的区间大致是 10–20%（人对"这次比上次快了一点"并不敏感），所以 5% 是偏宽松（偏向"可能感觉到"）的下限，10% 才比较稳。
- **相对与绝对要一起看**：词缀精英从 3.1 秒降到 2.1 秒是 −31%，在那一下很明显；但整局 60 秒只少 1 秒（−1.7%），"刷了一晚上"层面感觉不到。本文对第二排同时报两者。
- 判"可感"时用的是**配对 95% 区间的下沿**，不是点估计：下沿 ≥ 10%（率 ≥ 5pp）记"明显"，≥ 5%（率 ≥ 2pp）记"可能"。
- 通关率 ±2pp 是"同一档"的线；设计容差（提案不能改变强度）同样用 ±2pp。

## 3. 发现

### 3.1 套装：唯一一直可感的选择

| 情境 | 首领用时（最快 vs 最慢套装） | 杂兵房 | 喝药 / 局 | 通关率 |
|---|---|---|---|---|
| 正常 · Q04 普通重打 | −18.3% [−18.3, −18.2]（焚烬 vs 炽愈） | −9.3% | −18.2% | +34.3 pp（炽愈 vs 烬爆） |
| 正常 · Q07 普通重打 | −18.9% | −13.5% | −9.9% | +32.4 pp |
| 正常 · Q07 挑战 | −20.4% | −11.1% | — | — |

（`out-build-diversity-m04.md` 各节"跨套"行；留出种子结果在 ±0.7 内一致。）三套的定位清楚：焚烬 / 烬爆快，炽愈稳（喝药少、通关率高，代价是首领慢 18–20%）。**这个层面的多样性是健康的**。需要注意的是炽愈在正常推进下通关率高出 30 多个百分点 —— 对"刚到 Q04 的普通玩家"来说炽愈几乎是唯一理性选择，这是套装平衡问题，不在本文范围（建议单独看）。

### 3.2 天赋第一排「应变」：三个选项玩起来一样

| 情境 | 首领用时差（同套内最大） | 喝药 | 受伤 | 通关率 |
|---|---|---|---|---|
| Q04 普通 | 1.3–1.4% | 0.4–0.7% | 0.2–0.6% | 1.0–1.2 pp |
| Q07 普通 | 1.2–2.1% | 0.8–1.1% | 0.2–0.6% | 0.4–1.0 pp |
| Q07 挑战（预警招最重） | 0.5–2.2% | 0.7–2.7% | 0.5–0.9% | 0.0–1.0 pp |
| 最高投入 Q07 挑战 | 0.5–1.5% | 0.7–2.4% | 0.5–0.9% | ≤ 0.2 pp |

（各节"单个选择的边际效应"表。）全部 < 5%。唯一越过 5% 的是"炽愈 + 踏步回气"自我回复 +4.6～+5.7%（炽愈本来就靠回复）。**结论：第一排是"三选一但选什么都一样"**，玩家不会因为它改变打法：回身斩不会让人更贪刀，稳桩不会让人敢站桩，踏步回气不会让人用躲代替喝药 —— 模拟里换打法（谨慎 / 贪刀 / 硬吃）的收益在三个节点下几乎相同。

### 3.3 天赋第二排「猎手」：唯一"那一下"可感的成长，但范围很窄

- 只作用于**主线普通版重打**里每局 1 只的词缀精英（炽热 / 分裂 / 厚甲各 1/3）。首通、挑战、深渊、团本没有词缀精英，第二排和猎缀纹 / 裂身纹 / 抗缀纹在那里**完全不生效**（M04 挑战节边际效应全是 0.0%）。
- 精英击杀用时（同套内，正常 Q07 普通重打）：破缀 −17.5～−31.0%（明显）；拆分 +10.0～+17.1%（明显变慢）。最佳 vs 最差 −26～−40%，留出种子一致。
- 摊到整局：全程用时只差 1～2%，通关率差 ≤ 3.3 pp（焚烬，主要是拆分拖慢）。
- 最高投入时（T3+10 极品，精英本来就一两秒倒）：第二排对精英击杀的边际效应降到 8–9%，仍在"可能感觉到"。
- 守缀（受到精英伤害 −25%、对精英伤害 −15%）：承伤 −0.4～−1.2%、喝药 ≤ −2.4%（整局），只在最高投入焚烬喝药上到 −6.8%（可能）。它的价值是"怕精英的人更安全"，但精英伤害在整局里占比太小，几乎感觉不到。

### 3.4 拆分：死选项（B01 修好也一样）

- 现行（分身净 +20%）和策划意图（已在 CoreRpg 1.65.2 / cac6bc6 实现，未部署）（分身 +50% / 本体 −20%）在模拟里几乎相同：分裂精英击杀用时 0 ～ −2.3%，通关率与全程用时逐局一致（`out-build-diversity-b01-split.md`）。原因：分身 = 半只普通近战怪（`EmberRunDirector.splitAdds`），一两下就倒，分裂精英的时间几乎全在本体上。
- 本体 −20% 的代价却是真的：厚甲精英击杀 +50%、炽热精英 +150%（焚烬 Q07 普通），分裂精英本身只比不点快 7%。
- M04：最高投入 Q07 普通重打里，每套 81 个结构有 58–72 个被另一个结构"可感地支配"，绝大部分是因为带了拆分或裂身纹。

### 3.5 第三排「套装专精」：没有选择，效果也小

第三排由所穿套装锁定（每套只有一个能生效），所以不构成"选择"。效果：燎原 杂兵房 −1.1～−1.9%；反震 首领 −1.3%；扛核 自我回复 ±4%（团本 R03 烬核分摊另算，见团本表）。都低于 5%。4,000 币买的是"不改变任何东西"。

### 3.6 词条（D143）

| 词条 | 4 档数值 | 实测作用（最高投入，同套内边际） | 判定 |
|---|---|---|---|
| 猎缀纹（刃） | 对词缀精英 +16% | 精英击杀 −10.7%（焚烬 Q07 普通） | 可感，仅重打 |
| 余烬纹（刃） | 套装事件伤害 +1% | 首领 / 杂兵 ≤ 0.2% | 感觉不到 |
| 裂身纹（刃） | 对分身 +20% | 分裂精英 −2.3%，其他 0 | 感觉不到（死） |
| 定身纹（符） | 预警招伤害 −2% | 喝药 ≤ 1.7%，受伤 ≤ 0.8% | 感觉不到 |
| 分核纹（符） | 烬核自己那份 −4% | 只在 R03（见团本表） | 场景限定 |
| 抗缀纹（符） | 受词缀精英伤害 −16% | 喝药 −6.8%（最高投入焚烬，与守缀叠） | 边缘，仅重打 |

正常推进时词条封顶 1 档（标准成色），所有词条的作用 ≤ 2.1%（烬爆 猎缀纹1 精英 −2.1%）。

### 3.7 勋记（D142）

结算币 +2% ×2（封顶 +4%）、每次结算 +1 碎片、深渊层费 −5%、洗练币 −10% / −5%（图录，模拟不建模）、深渊受伤 −2%（只在深渊）。都是**经济**加成，不影响打法；在模拟里勋记全开对通关率的作用落在噪声内（旧报告"只开勋记也动了 +1.8"是 M01 噪声，修正后同类对照不再移动）。

### 3.8 有几种"感觉不同"的构筑？

按 5% / 2pp 把同套内的实际构筑合并（任意两者在所有目标上差都 < 阈值 = 同一类）：

| 情境 | 每套实际生效构筑 | 感觉不同的类 | 被可感地支配 |
|---|---:|---:|---:|
| 正常 · Q04 普通重打（2 点，词条 1 档） | 27 | **1** | 0–9 |
| 正常 · Q07 普通重打（6 点，词条 1 档） | 81 | **5** | 72 |
| 正常 · Q07 挑战 | 81 | **1** | 0 |
| 最高投入 · Q07 普通重打（词条 4 档） | 81 | **3** | 58–72 |
| 最高投入 · Q07 挑战 | 81 | **1** | 0 |

**一句话：在挑战 / 首通 / 团本这些"主要难点"里，同一套装下所有构筑都是同一个构筑；只有主线重打里那只词缀精英能让第二排的选择被感觉到。**

另外：真实成本模拟（§5）里，大多数玩家在 Q07 后 12 周内只有 4–5 个天赋点（第 6 点要团本首胜 + 深渊第 5 层都做到），第三排在大部分路线上根本买不到；M04 的"6 点"情境是上限。

### 3.9 支配 / 死 / 相同

- **支配选项**：第二排破缀（精英击杀和通关率都最好）；刃词条猎缀纹（唯一可感的刃词条）。
- **死选项**：拆分（第二排）、裂身纹（刃）。余烬纹、定身纹不是"更差"，而是"什么都没有"。
- **玩起来相同**：第一排三个节点；符词条三个（除特定场景）；正常推进下所有天赋 / 词条组合。
- **低于阈值的系统**：第一排、第三排、余烬纹、定身纹、裂身纹、全部 1 档词条、勋记（战斗上）、拆分（修好后也是）。

## 4. 成本 vs 可感收益（B02）

| 投入 | 成本（模拟用的现行规则） | 买到的可感变化 | 评价 |
|---|---|---|---|
| 天赋第一排 | 800 币 + 1 点 | 无（≤ 2.2%） | 白花（但便宜） |
| 天赋第二排 | 2,000 币 + 2 点 | 重打词缀精英击杀 −17～−31%（破缀）；整局 1–2% | 唯一值得的天赋 |
| 天赋第三排 | 4,000 币 + 3 点（第 6 点要团本首胜 + 深渊 5 层） | ≤ 2%（R03 扛核另算） | 最贵、最没感觉 |
| 重置 | 2,000 币 | — | 因为选什么都一样，玩家没有理由重置 |
| 余烬纹洗到 4 档（极品 T3，锁定路线，从空槽开始） | 期望 6.2 次 ≈ 6,200 币 + 1,130 碎片 / 件 | 总伤约 +0.2% | 成本与收益严重不匹配 |
| 不锁定直接洗指定 4 档 | 期望 15.8 次 ≈ 15,800 币 + 1,890 碎片 / 件 | 同上 | |
| 猎缀纹 4 档 | 同上（≈ 6,200 币 + 1,130 碎片 / 件） | 重打精英击杀 −10% | 可感，但只在重打 |

（洗练期望次数按 `EmberAffix.roll` 的规则蒙特卡洛：类型在 3 个里均匀、档位按 50/30/15/5 权重截断到成色上限、连续 5 次未到上限第 6 次保底、锁定后只洗档位 + 锁定碎片；审查给的"已有目标词条后锁定 5.30 次 ≈ 5,298 币 + 1,272 碎片"与此一致。）作为参照：按每天 3 局、每局结算约 300 币粗算，一周约 6–7 千币；碎片每局约 24 个，一周约 500 个 —— 两件余烬纹 4 档的碎片 ≈ 4–5 周的碎片收入（碎片还要用于强化与升阶）。真实成本模拟（§5）里玩家 12 周内平均洗练 15–17 次、花掉 13–17 千币和 2.6–3 千碎片。

**结论：** 昂贵精修（第三排、高档细词条）是"花大钱买不到感觉"。按审查建议，不靠文案解决，也不建议直接把数值抬高（会膨胀强度）；建议见 §7：要么让它改变行为（同强度不同玩法），要么降低成本 / 简化掉。

## 5. 成长对"双极品"推进的影响（B03 / B04）

### 5.1 两件事分开（B03）

旧的 `out-growth-d141-d143.md` 把"第 1 天就拥有完整成果"的构筑丢进经济模拟，得到的是**上限效果检查**，不是玩家真实的成长曲线。现在拆成两个输出：

| 输出 | 工具 | 回答的问题 |
|---|---|---|
| 上限效果检查 | `growthrun.py p2econ <构筑>` | 如果成长**免费且从第一天就满**，推进最多快多少？（ub：稳桩 + 守缀 + 套装第三排，勋记全开，刃 b_set / 符 c_tele 4 档） |

### 5.2 指标改名与补充（B04）

旧名"两件极品最快周"其实是"若干候选策略里，达到 30% 拥有率最早的那条策略的插值周"——它既不是"最快的玩家"，也不是"一般玩家"。现在：

- **W30** = 候选策略中达到 30% 双极品拥有率的最早插值周（时钟从玩家自己的 Q07 首通算起，整周行线性插值）；
- 同时报该策略的 **P50**（一半玩家拥有）、**P90**、以及 **第 12 周仍未拥有双极品的比例**。

300 名玩家 × 12 周，`--abyss --raid --goals --every-week`，同一批玩家 / 掉落 / 战斗随机流（成长 RNG 单独一条流），规则快照 `9806c4d10d1fc270`：

| 躲避 | 无成长 W30 | 上限 ub W30（Δ） | 真实成本 rg W30（Δ） | 真实成本 rw W30（Δ） | 最佳策略 P50（off / ub / rg / rw） | P90 | 第 12 周未拥有（最佳策略，off / ub / rg / rw） |
|---|---:|---:|---:|---:|---|---|---|
| 0.3 | 7.00 | 6.33（−0.67） | 7.17（+0.17） | 6.57（−0.43） | 10.0 / 9.8 / 10.7 / 10.0 | 全部未达 | 40% / 40% / 42% / 40% |
| 0.5 | 5.22 | 4.92（−0.30） | 5.64（+0.42） | 5.50（+0.28） | 7.4 / 6.7 / 7.8 / 7.6 | 全部未达 | 23% / 23% / 24% / 21% |
| 0.7 | 4.31 | 4.00（−0.31） | 5.00（+0.69） | 4.78（+0.47） | 5.8 / 5.6 / 6.8 / 6.5 | 全部未达 | 12% / 14% / 16% / 11% |

（各策略的完整行见 `tools/p1sim/out-build-diversity-b03-b04.md`。）

读法：
1. **P90 在所有方案、所有躲避下 12 周内都达不到**；最佳策略下第 12 周仍有 11–42% 的玩家没有两件极品（最差策略 44–52%）。W30 只描述"前 30%"的人，单看它会严重高估一般玩家的进度。
2. **上限**：即使成长免费且第一天就满，W30 也只提前 0.3–0.7 周。
3. **真实成本**：W30 不提前，反而推迟 0.2–0.7 周（rw 在 0.3 时提前 0.4）。原因是天赋（2,800–6,800 币）和洗练（到第 12 周中位 15–17 次、13.5–17k 币 + 2.6–3k 碎片）与强化抢同一份币 / 碎片。
4. **噪声**：300 名玩家下 W30 的标准误约 0.35 周；同一方案内不同策略之间的 W30 摆动可达 0.9 周。留出种子复跑见 b03-b04 输出。上表所有 |Δ| ≤ 0.7 周 —— **成长对双极品时间线的影响在 ±0.5～0.7 周量级，大致在 ±0.5 周容差边上、并且接近噪声**。
5. **天赋点**：真实路线下大多数玩家只有 4–5 点（首通 3 + 挑战 / 团本）。第三排需要 6 点（团本 + 深渊 5 层），只有"团本 + 周目标"路线在第 8–12 周买齐（89–100%）；"深渊 + 周目标"有 6 点但只有 2% 买第三排（币先交深渊层费）。**也就是说，第三排对大多数玩家在前 12 周里根本不存在** —— 这本身就削弱了"第三排让套装玩法不同"的设计意图。
6. 局限：`p2econ.raid_once` 用固定的团本通过率表，成长**不影响**该模拟里的团本成功率；团本里的成长效应单独见 §6 与 `out-build-diversity-raid.md`（≤ 2pp）。

## 6. 团本与"多人焚烬"：哪些旧结论变了

**模型修正（M03）后旧结论被推翻的部分：**
- 旧模型用怪物身上单一的 `burn_by`，后点燃的人覆盖前一个人的燃烧，多人焚烬被系统性少算。同池同阵容对照：3 人全焚烬 R01 / R02 / R03 = 27→35 / 54→69 / 57→64；5 人全焚烬 R02 78→92、R03 90→94。扣掉同池无焚烬队的变化，"全焚烬 − 无焚烬"在 3 人时比修正前高 +13.7 / +21.5 / +14.7pp。
- 修正后 3 人全焚烬 vs 无焚烬：R01 34.6 vs 60.8、R02 68.5 vs 60.3、R03 64.3 vs 61.5；5 人：57.5 vs 87.2、91.9 vs 84.9、93.9 vs 92.8。**"焚烬叠人在团本里吃亏"在 R02 / R03 不再成立；R01 仍明显偏弱**。原因是 R01 首领 50% 血量时加怪、单下 79 伤，全焚烬 3 人队没有炽愈，这是团本机制问题，不是模型误差。
- D137 里"第 2 周 3 人 52 / 54 / 49%"是单个玩家池的数字。6 个留出池修正后的均值为 R01 60.7 / R02 62.8 / R03 62.5，池间标准差 3–4pp；单池数字不能当精确值。
- D141–D143 成长表里"团本 ±3 内"只对点估计成立：7 池聚类后 R01 / R02 稳桩 3 人 +2.5 [+1.7, +3.2] / +2.2 [+1.5, +3.0]，区间上沿越过 +3。单人仍越界的只有 Q03 普通 0.5 焚烬（+3.7～+3.9）。

**团本里的构筑差异（`out-build-diversity-raid.md`，1 号位换构筑、队友固定，每格 1500 局）：**
- 1 号位换套装：R01 0.5 通关 焚烬 37% / 烬爆 47% / 炽愈 52%，R03 72 / 71 / 84%。这是可感的。
- 1 号位换天赋 / 词条（第一排三选一、稳桩 + 守缀 + 第三排、分核纹 4 档、定身纹 4 档）：通关率 ≤ 2pp，首领用时 ≤ 1 秒。**团本里天赋和词条感觉不到**。
- 唯一"行为上"可见的是扛核：炽愈扛核 1 号位分摊的烬核伤害 0.47→0.57 ×H（+21%），即"我成了接核的人"，但通关率不变；全队都点扛核时 0.41→0.43、通关率不变 —— 扛核只有在"有人不点"时才有意义。

**建议：现在不调焚烬。** 理由：R02 / R03 修正后全焚烬与混编持平或略好，差值在池效应（±3～4pp）同量级；R01 弱是缺治疗而不是焚烬太弱。上线后按队伍构成统计实际通关率（§8）：若全焚烬 R02 比混编高 10pp 以上，再考虑"同一目标燃烧施加者上限"之类的措施（只是方向，不是数值）。

## 7. 建议（只是提案，没有改任何线上配置）

## 8. 模拟器量不到的东西，以及要看真人的地方

**模拟器量不到"好不好玩"。** 它用固定的行为模型（躲避率 0.3 / 0.5 / 0.7、几种站位倾向），不会因为换了天赋就改变打法。真人会：拿了稳桩的人可能更敢站桩，拿了破缀的人可能会专门先打精英，这些适应可能放大或抵消本文的数字。本文的"可感"是用 5% / 10% 启发式阈值翻译出来的，不是测出来的。所有"感觉得到 / 感觉不到"的结论，都要用下面的真人观察来验证或推翻：

| # | 观察点 | 怎么看 | 支持 / 推翻本文的信号 |
|---|---|---|---|
| 1 | 玩家能否说出第一排三个节点的区别 | 访谈 / 问卷："你点的是哪个？和另外两个有什么不同？" | 说不出区别 = 支持"第一排一样"；能说出且行为不同 = 模拟器漏了行为适应 |
| 2 | 第一排的选择分布与理由 | 服务端统计 D141 节点购买 + 简短问卷 | 接近 1/3 随机分布、理由是"名字好听" = 无意义选择 |
| 3 | 是否洗点（2,000 币）、洗点后换了什么 | 洗点日志 | 几乎没人洗点 = 选择不重要或洗点太贵；洗完只在第一排内换 = 在找感觉 |
| 4 | 有没有人选拆分；选了之后多久洗掉 | 节点购买 + 洗点日志 | 选的人在下次洗点时离开 = 死选项被玩家发现 |
| 5 | 词缀精英击杀"那一下"是否被注意到 | 录屏 / 旁观：破缀玩家是否改为先打精英 | 有"先打精英"行为 = 第二排是真的行为改变（模拟器假设不变） |
| 6 | 洗练投入 vs 满意度 | 洗练日志（次数、币、碎片）+ 问卷"值不值" | 花了 6k 币洗余烬纹 4 档后觉得"没区别" = 支持 §4 的成本-体感失衡 |
| 7 | Q04 新玩家的套装选择 | 套装穿戴统计（按进度分组） | 炽愈占比远超 1/3 且通关率明显更高 = 支持 3.1 的套装平衡提示 |
| 8 | 团本按队伍构成的实际通关率（特别是全焚烬） | 团本结算日志按构成分组 | 全焚烬 R02 比混编高 10pp 以上 → 考虑燃烧上限；R01 全焚烬低很多 → 考虑 R01 的治疗需求提示 |
| 9 | 扛核是否被"指定一个人点" | 团本组队观察 | 只有一个人点、其他人不点 = 扛核作为"职责"成立 |
| 10 | 第三排拥有率随周数 | 天赋点 / 购买统计 | 前 12 周大多数人没有第三排 = 支持 §5 第 5 点 |
| 11 | 提案上线（若上线）后的节奏变化 | 破绽窗口：窗口内伤害占比；铁壁：吃预警招的次数 | 窗口占比没有上升 = 玩家没有改变出手时机，提案没有达成目的 |
