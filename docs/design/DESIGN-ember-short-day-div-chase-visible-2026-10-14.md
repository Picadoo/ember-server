## 1. 玩家感知目标（≤3）

1. **一眼进度：** 选页见「日差本可冲」与今日已有奖通关不同本数（如 `2/3` 展示向；**零发奖**）。  
2. **一点换本：** 点 L 真进「今日尚未有奖通关且仍有日奖」的已解锁短征。  
3. **灰态诚实：** 无可冲本（全日奖满 / 已覆盖全部有奖本 / 未解锁）时灰；不假承诺。

## 3. 可落地（方案 M）

### 3.1 条件与键（钉死 · 只读）

| 项 | 口径 | 纪律 |
|----|------|------|
| 进度 n | 今日 `rewardedToday(map)≥1` 的已解锁短征本数（distinct） | **禁**发额外币/料；禁改日帽 cap |
| 展示目标 | 软目标 **3**（仅 UI；命中不发奖、不改 `weekly_goals`） | 禁把软目标写成经济行 |
| chase | 已解锁 ∧ `dayLeft>0` ∧ `rewardedToday==0`；稳定序 `SHORT_KEYS`；可选：若今日推本已有奖则跳过优先下一本 | 禁改 todayKey 算法 |
| chase_ok | chase 非空→1 否则 0（单条件灰） | 吸取 TIP-CE/CG |
| done | n≥3 **或** 无合格 chase（全日奖尽/已覆盖）→1 | 只读展示 |
| enter | `corerpg p1 enter short-div`（别名 `short-day-div`）→ 进 chase 本；门禁同该本 | 禁教裸指令当主 UI |
| Cast/Aid/variety | **零改** | 本债≠打磨 |
