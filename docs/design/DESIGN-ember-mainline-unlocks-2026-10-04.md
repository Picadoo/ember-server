## 1. 为什么这么做（对照调研）

- **两层掉落**（调研 §0.1）：WoW 每个首领自己的饰品 / 特效武器 [M1]、命运 2 每个地下城只从最终首领掉的异域 + 本本独有套装 [M2]、PoE 首领专属暗金 [M6]、DNF 专属史诗 [M7]——都是「基础件到处有，招牌只在这里」。Ember 的基础件（刃 / 护符 / 将来的 4 件甲）照旧每张图都掉，服主早上否决的「按图锁部位」不做。
- **招牌是效果不是数值**（调研 §0.2）：WoW 同一件随难度升装等 [M1]、D4 威能拓印到新装备 [M3]——效果可以搬到当前阶级的底子上，所以早期图的签名不会因为阶级过时；也正因为只放效果，签名**不推高基础属性预算**，不触发 6 槽报告里的「词条叠加膨胀」。
- **保底是本地材料**（调研 §1「读出的四件事」）：徽记只在这张图出，攒够必得——随机签名掉落是惊喜，徽记是保底，两条路都指向「回这张图刷」。
- **解锁接在里程碑后面、而且回头用到旧图**（调研 §2）：PoE 万神殿 1 主 1 次 [M10] → 「最多 2 条、同 tag 不叠」；D3 冒险模式把旧幕变刷图场 [M12] → 首领残响 / 连战·前哨让 Q01–Q03 在 T2 还有事做；哈迪斯契约 [M13] → 自选誓约。
- **不学的**：无帝之国的「魄 / 身份卡 / 图鉴加属性」[M9]（无限累积数值）、D3 式大倍率地图套装、外观奖励（暂停中）。

## 2. 签名传奇：规则

### 2.1 是什么
- **签名 = 一件普通 P1 件 + 一条签名效果。** 底子的阶级 / 族 / 部位 / 成色 / 精工 / 强化 / 词条和同图普通件完全同分布；签名效果存为这件 uid 的一个计数（`p1_sig_<uid>` = 签名编号），和 D143 词条一样**跟着 uid 走**：升阶（保留 uid）、强化、洗练都不丢；分解掉就没了（分解不退徽记）。
- **族绑定**：标「焚烬 / 烬爆 / 炽愈」的签名，只在那套成套生效时生效（它用的本来就是套装事件键）；标「通用」的任何套都生效。
- **部位绑定**：刃签名只能在刃上，护符签名只能在护符上。6 槽护甲上线后：护符签名改叫「防具签名」，可以落在护符或任意一件甲上，**但 5 件防具里同时只算 1 条**（和 6 槽报告「同一种词条只算一次」同一个原则）。

### 2.2 同时生效
- 最多 **2 条**：生效刃上的 1 条 + 生效护符上的 1 条。背包 / 装备库里的不算。
- **同 tag 不叠**：刃和护符 tag 相同时只算刃那条。
- **和天赋同 tag 不叠**：残门焚斧（burn，同天赋「燎原」）、门楼余烬（dodgeheal，同「踏步回气」）、炉心护符（hitburst，同「反震」）——选了那个天赋，这条签名显示「与天赋 X 同类，不生效」。理由：它们用的是同一个修饰键，加法键（`burn_spread / dodge_heal / hit_burst`）叠起来会翻倍（§8.4 有不排除时的对照）。
- **Q03 首通前只有 1 条生效**（「双签名」是 Q03 的解锁）：两条都有时，刃那条生效。

### 2.3 从哪来
| 来源 | 给什么 | 条件 |
|---|---|---|
| 这张图**首通** | 两件签名进**签名图鉴**（可以烙印）+ **3 枚**本图徽记 | 每个角色每张图一次（按图计，不按内容版本——内容版本升级重发首通包时不重发徽记）|
| 这张图**普通重打**通关 | **1 枚**本图徽记；本局的基础掉落件如果部位（和族）对得上本图某件签名，**12%** 是签名件 | 本人已首通；挑战、团本、深渊、连战、活动本都不给（第 2 阶段的「首领残响 / 连战·前哨 / 誓约」另算）|
| **烬炉烙印**（Q02 首通后）| 把图鉴里的一条签名烙到自己**正在用的**同部位件上（覆盖原来那条，不能取回）| 5 枚这张图的徽记 + 300 × 阶级 币；T1+ 件；需确认 |

- 只给基础掉落那 1 件打签名（额外宝箱的件不打），所以**每局件数不变、成色分布不变**——两件极品时间线的「件数 / 成色」输入完全没动，这是 W30 结构不变的根据。
- **概率**：通用签名 = 刃 / 护符 50% × 12% ≈ **6% / 局**；族签名再乘这张图掉到那个族的概率（目标族 60% / 其它族 20–25%）≈ 1.5–3.6% / 局。徽记保底：首通 3 枚 + 重打 2 局 = **第一次烙印最多 2 次重打**；之后每换一件新的主力件（比如从 Q04 刷到更好的 T2 刃），再烙一次要 5 局。
- **为什么值得刷、而且不会刷爆**：每次换主力件都要回签名所在的图 5 局（WoW 大秘境「过渡货→目标货」、D4 拓印的同一种节奏），但效果本身封顶（§8），刷再多也只是「把同一条效果搬到新件上」。

## 6. 漏洞检查

| # | 可能的漏洞 | 处理 |
|---|---|---|
| 1 | 签名件复制 / 转手 | 签名记在**拥有者**的数据上（`p1_sig_<uid>`），不在物品 NBT；件被别人拿到不带签名。和 D143 词条同一存法，没有新的复制面 |
| 2 | 分解后撤销把签名「洗」到别的件 | 撤销恢复的是同一个 uid，签名照旧；分解不退徽记；烙印是唯一的「搬」法，而它消耗徽记 |
| 3 | 洗练拿签名件当重复件 / 批量分解吃掉签名件 | 签名件算「有投入」：洗练不拿它当重复件，批量分解跳过它（和有词条的件同一规则）；单件分解确认页多一行「这件有签名 X，分解后消失」|
| 4 | 烙印扣费和写签名不同步（崩服 / 断线）| 徽记、币、签名三个都在同一份 PlayerData 上，一次 `flushMutation` 落库；先扣后写，同一 tick；写之前再核对件还在、uid 没变 |
| 5 | 烙印覆盖后取回旧签名 | 不支持取回，确认页明写；没有「拆出效果」的操作 |
| 6 | 重复结算刷徽记 / 签名 | 都是结算账本行（`sig_mark` / `sig_stamp`），按 run id + key 幂等；签名的随机数来自本局种子 + 玩家，重结算结果相同 |
| 7 | 首通包随内容版本重发 → 重发徽记 | 首通徽记另记 `p1_sigfc_<map>`，每图只发一次 |
| 8 | 高阶玩家带新人刷 Q01 徽记 | 允许（这就是「回去刷」）；每人每局 1 枚，受体力限制；徽记只能烙签名，不换别的东西 |
| 9 | 叠效果：两件同 tag / 签名 + 同 tag 天赋 / 3 条以上 | `mods()` 里只取生效刃 + 生效护符各 1 条、同 tag 只留刃、和已选天赋同 tag 的跳过；Q03 前只算 1 条 |
| 10 | 局内换件刷冷却（躲招回血 15 秒一次）| 冷却记在玩家身上，不在件上，换件不重置；局内换装本来就受 loadout 规则限制 |
| 11 | 签名在深渊 / 团本 / 挑战里过强 | 42 格含挑战版；团本 / 深渊不在 42 格里，但签名只用已有的事件键、都有代价，和 D141 天赋同一量级 |
| 12 | 6 槽上线后防具签名 ×5 | 规则已定：5 件防具里只算 1 条（§2.1）|
| 13 | 新钩子叠乘（L07/L09 形状 + 天赋多段、护盾无限叠）| 形状只改烬斩打到几个目标（上限 3），不加倍率；护盾每次施放按命中数算、封顶 1% 最大生命、5 秒后消失，不跨施放累加；低血加速只在生命 < 40% 时把炽愈的触发间隔减 2 下（每次回复量 ×0.99 不变） |
| 14 | 首领残响 / 连战·前哨重复结算 | 结算行按 run id 幂等（`rush_paid`、`rush_practice`、`rush_sig_<map>`）；每人自己的周计数（残响 4 个入口共用一个），领完之后是练习、不发东西 |
| 15 | 借别人的首通进前哨 / 残响 | 入口查**每个队员**本人的首通（要求图 + 链上每张图）；通行按地牢判（`passd_EmberQ0B2`），本局是哪种模式由会话决定，换入口不换奖励 |
| 16 | 誓约刷老图徽记 | 允许：挂两条 = 每局 +2，老图重打的徽记翻 2–3 倍；但徽记只能烙签名（侧向），仍受体力限制，不改掉落；只能挂 D94 审过的普通本规则（限药 / 逆行）；首通局、周规则图不生效（`pledge_sigmark` 按 run id 幂等）|
| 17 | 前哨的 T2 印记 | 每周 1 个（自己的 claim），量级小；W30 上界见 §8.5 |
| 18 | 残响 / 前哨共用 `EmberQ0B2`，进错本领错奖 | 会话绑到地牢实例时记下入口 key；`onChangedWorld` 按会话图的地牢匹配，奖励按会话入口结算 |

## 8. 模拟（p1sim，离线）

方法：`tools/p1sim/mainline.py`，在 `builddiv.measure` 上给参考装（`set` = 三套各一）加签名修饰键，量 42 格（Q01–Q07 × 首通参考装 r / 挑战版 c × 躲避 0.3 / 0.5 / 0.7）通关率，和**同种子**的基线比。每格 2000 人 × 2 组种子。判定：✅ = 42 格都在 ±2pp 内；🟡「范围内」= 平均 |Δ| ≤ 1pp 且没有一格超过 ±3pp（不相交种子组之间的噪声上限是 +1.7pp）；❌ = 都不满足。

### 8.1 怎么判
- 每格 2000 人 × 2 组种子；基线是同种子、同套装、不戴签名。候选扫描用种子 7/11，最终数值用**不相交的** 13/17 复测（单条）。

## 11. Q07 方案：签名调律（提案 2026-10-04；**已上线 1.65.18**，见 §13）

### 11.1 为什么 Q07 需要一样东西
Q07 首通现在开的是挑战版、深渊、团本、余烬连战、天赋第 3 排、T2→T3 升阶——全是「更难的内容」，签名这条线到 Q06 就停了：Q01–Q06 的徽记在烙完想要的签名之后没有去处，2b 的三个模式（残响 / 前哨 / 誓约）产的徽记后期会堆着。Q07 应该给签名线一个**收尾**：不加强度、给构筑多一个选择、给徽记一个后期出口。

### 11.2 是什么
首通 Q07 后，签名图鉴里每件**有代价**的签名多一个「调律版」：**好处不变，换一种代价**。每件签名的调律版用那张图的 **10 枚徽记**解锁一次（之后永久），在城里的图鉴页随时切换（和烙印同一个城镇限制，副本世界里不能切），同一件签名同时只有一个版本生效，下一局起作用。
- 参照 1：哈迪斯「夜之镜」——每格天赋有红 / 绿两个版本，镜子前随时切，一次只生效一个（[Hades Wiki · Mirror of Night](https://hades.fandom.com/wiki/Mirror_of_Night)）。
- 参照 2：命运 2 打造武器的「重塑」——同一把枪每列词条换另一个已解锁的选项，而不是叠两个（[Destiny 2 Wiki · Weapon Shaping](https://d2.destinygamewiki.com/wiki/Weapon_Shaping)）。
- 和我们的规则一致：签名不加基础属性、不加新乘区；调律只换代价那一半。

### 11.3 候选调律版与模拟检查（`tools/p1sim/mainline.py try`，种子 13/17，2000 人，可达格；原版来自 §8.2 / §8.4 同种子表）
