## 1. 使魔（宠物）

| 项 | 定案 |
|----|------|
| 定位 | 收集 + 出战 1 只；**默认偏外观**，属性 ≤ 总战力 5% |
| 获取 | 掉落蛋 / 碎片合成（挂机、日周本、团本副产） |
| 升级 | 吃「魂尘」（挂机副产）；不耗核心 |
| 氪 | 皮肤、经验瓶；**不卖满级战力宠** |
| 菜单 | `ember_pet.yml` · hub **D** → `menu: ember_pet` |
| 命令占位 | `/corerpg pet list` · `summon` · `feed` |

首批使魔 ID（草案，怪物/物品岗可改名）：

| ID | 显示名 | 倾向 |
|----|--------|------|
| `pet_ash_wisp` | 灰烬精灵 | 外观 / 微光特效 |
| `pet_bone_pup` | 骨尘幼崽 | 微量移速展示分 |
| `pet_ember_cub` | 余烬幼兽 | 微量吸血展示分 |

**已落 NI 外观蛋 stub**（`plugins/NeigeItems/Items/ember-pets.yml`，出战未接）：

| ID | 显示名 | 倾向 |
|----|--------|------|
| `pet_ember_ashling` | 余烬灰灵 | 外观 / 微光 |
| `pet_ember_cinder` | 余烬烬火 | 外观 / 余火 |

## 2. 图录（图鉴）

| 册 | 内容 | 登记条件 |
|----|------|----------|
| 怪物 | 地窟 / 深渊 / 灾厄 / 团本 MM | 首次击杀 |
| 装备 | 刃 / 护符 / 饰品 | 首次获得 |
| 使魔 | 与使魔图鉴共享 | 首次收集 |

**阶段奖（示意）：** 称号、余烬币、天赋点（对齐总纲「收集强迫症」日活）。  
**菜单：** `ember_bestiary.yml` · hub **F** → `menu: ember_bestiary`（使魔册可跳 `ember_pet`）。

## 3. 接线与验收

| 岗 | 活 |
|----|-----|
| 菜单（本期） | hub 去掉「即将点燃」；开子菜单壳 |
| 插件 | CoreRpg `pet` / `bestiary` 模块；PAPI 进度 |
| 物品 | 魂尘 NI、使魔蛋/碎片 |
| 测试 | hub 入口无「即将点燃」；子菜单可开可回；命令未装时 tell 不崩 |

验收：

1. `/ember` → 使魔 / 图录 lore **无**「即将点燃」，打开对应菜单。  
2. 图录「使魔图鉴」可进 `ember_pet`。  
3. 不改 `CoreRpg.jar`、不破坏既有日/周/深渊 DP。
