## 1. 玩家感知目标（≤3）

1. **装上后防御手感可感侧移：** 预警落地前后有「要不要按守招」的短决策；成功有反馈（招架音效 / 短字 / 破势反打），失败无白嫖。  
2. **不是白送通关、也不是没人按：** 乱按浪费独立 CD；对齐时机才赚；错开窗不得净赚通关率。  
3. **仍认得与身法 / 烬斩分工：** 身法=位移躲；烬斩/烬突=进攻二选一；守招=防御时机键——TrMenu 技能页短文案写清；玩家不打指令。

## 2. 方案表

### 2.1 方案 M（**荐** · 换资源 / 触发 · 预警落地短窗招架）

> **原则：** 去掉「预警整段均匀 −red」与「共享身法 / 花烬斩充能」旧代价对；改为 **时机窗触发** + **独立守招 ICD** + **单次非永久效用**（招架本次预警伤 / 或破势固定额反打）。数值只服务新形状；**禁止**再交仅改 `kit_guard_cd/secs/red` / `kit_q_shared` / `kit_guard_charge` 小数的半页。

| 项 | 硬意向 |
|----|--------|
| **招名（展示）** | 守招 · **余烬招架**（可改展示名；内部 id 意向 `kit_guard_parry`） |
| **装配位** | 技能页 TrMenu：解锁后显示「守招 · 余烬招架」说明 + 好/坏打法一句；**不**开六槽、**不**新 Pack kind |
| **按键** | 解锁后 **单按 Q** 进守招（替换扔刃）；未解锁仍扔刃（与 D212「过线才动 X8」一致）。备选（仅批注允许）：潜行+某键——默认仍荐 Q，避免再增输入分流 |
| **触发** | Boss **预警招落地短窗**（意向 `parry_win` ≈ 0.35～0.55s，自落地 cue / tele resolve 起算）：窗内按 Q → **招架成功**；窗外按 → 空按（启动独立 CD 或轻失败 CD，防刷） |
| **成功效用（三选一主效用 · T0 可测 1～2 档）** | **A（主荐）** 本次预警伤 **一次无效**（非均匀 `taken_*` 乘区；仅该命中）；**B** 本次预警伤改 **固定额反打**（flat，禁永久 `dmg_*`）；**C** 短硬直打断 / 破势（非通关率敏感优先；若 p1sim 难建模则后置真人窗） |
| **代价键（新）** | **独立** `kit_guard_parry_cd`（例 22～28s，Boss 战内约 1～2 次机会）；**默认去掉** `kit_q_shared`（共享身法）、`kit_guard_charge`（花烬斩充能）、均匀 `kit_guard_red` 永久/整窗乘 |
| **与身法分工** | 招架**不**给位移、**不**给无敌帧覆盖非预警伤；踏步/后撤仍管走位 |
| **玩家一句话** | 「预警砸下来那半秒按对了就扛住；按早按晚白丢 CD」 |
| **禁什么** | 均匀减伤永久乘；预警整段 −red 覆盖普攻；共享身法税当平衡钮；花烬斩充能；无窗口全局减伤 |

**W1 切分（批后模拟 / 施工）：**

| 窗 | 做什么 | 产出 |
|----|--------|------|
| **T0（换机制模拟）** | 在 p1sim **临时登记**新 cand（例 `G_parry_A` / `G_parry_B`），**不改**线上 yml/Java；建模招架窗 + 独立 CD + 单次无效/flat；跑 **42±2** + 择优 + 留出 | STATUS · ✅/❌ |
| **T1（过线才开）** | 仅当 T0 ✅ 且总控批施工：CoreRpg 守招键 + 解锁条件 + TrMenu 文案；单按 Q 改绑 | jar/yml · CN |
| **T2** | 静态 rg + 技能页目视 + 轻测招架窗 | 测报 |

**p1sim 怎么验（门禁写死 42±2）：**

1. **新键进屏幕：** ≥1 条（可 2 档 CD / 窗长）cand；对照基线（无守招）。  
2. **建模要求：**  
   - 仅 `parry_win` 内按才吃效用；窗外按无减伤。  
   - 成功只影响**该次预警命中**（A）或 **一次 flat**（B）；**禁止**整段 `taken_all` / 永久 `taken_*`。  
   - 独立 CD 耗尽前不可再触发；always-press / 最优时机 / 从不按 三分行为入表。  
3. **过关线：** 三套装 ×（全量 **42** + 可达子集若沿用 skill-kit/侧移惯例）通关率 Δ ∈ **±2pp**；无格 \|Δ\|>3；**择优成立**（会用的人可感侧移，乱按不净赚通关）；规则哈希写入 T0 报告。  
4. **禁：** 放宽 ±2；用均匀 `red` 冒充招架；未建模时机窗却宣称过线；夹带抬通关率预算。  
5. **与 D212 关系：** T0 仍是离线门禁；过线才谈真人手感——**不**用「手感可能更好」开例外。

**荐批：** **批 M**（预警短窗招架 + 独立 CD + 单次效用进 T0；不过线不开 T1）。
