## 2. 三区地形意图（短）

### ② 荒原（废墟台地）

- **贴地碎砖缓坡**，不是浮空盘。  
- 半截石砖墙 / 乱石作掩体（至少 2～3 处）。  
- 地面主材：平滑石砖 + 草/砂砾点缀（可继续用 `SMOOTH_BRICK` 作地板主题，但要有起伏，勿整盘同 y）。  
- 围挡：矮墙或自然断崖即可；**少用/不用屏障盒**当视觉边界。

### ③ 焦土（焦裂谷地）

- 黑石 / 下界砖露头，落差 **4～8**。  
- 熔岩仅装饰沟（栏杆或加高一格，防误伤挂机）。  
- 墙材可沿用 `NETHER_BRICK` / 栅栏主题，贴地展开。

### ④ 烬原深处（洞穴庭）

- **入口竖井或坡道** → 扩厅；厅内柱 + 高低台。  
- 仍须开阔可站，刷点不贴墙（防窒息，对齐副本教训）。  
- 灯：海晶灯等；主材红下界砖主题可保留。

## 3. 入口 / 撤离牌（每层必做）

每层入口旁各放：

1. **入口牌**（面向玩家落地朝向）  
   - 行1：`§a挂机庭 · ②荒原`（③④同理）  
   - 行2：`§7打开 /ember → 挂机庭 可换层`  
   - 行3：`§8死亡回本层入口 · 不掉落`  
2. **撤离牌**（同区可见，建议入口对面或侧翼）  
   - 行1：`§e回枢纽`  
   - 行2：`§7打开枢纽菜单返回`  
   - **不要**写「请打 /hub」；若接方块命令，用菜单或底层 `hub`，lore 只说菜单。

可选：入口地面地毯/压力板无逻辑，仅视觉锚。
