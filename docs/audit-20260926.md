## B. 检查过、没问题的
- **`<player.name>` 类占位符**：DP 里剩下的只有注释，以及 `DungeonPlus/config.yml` 的队内聊天前缀（DP 原生变量，有效）。MM 的 `<trigger.name>` / `<target.name>` 是 MM 原生变量，有效。
- **PAPI 占位符**（菜单和全息）：`%corerpg_*%`、`%ember_*%`、`%player_*%` 都有对应扩展。README 里提到的 `%ember_daily_left%` / `%ember_weekly_left%` 没有被任何菜单实际使用。
- **NI 物品 ID**：配置和 CoreRpg 源码里引用的全部 `*_ember_*` 以及 `ni give` 物品，在 `NeigeItems/Items` 里都有定义（剩下的 3 个匹配是配置键名，不是物品 ID）。
- **MM**：DP / CoreRpg 引用的怪物 ID 都存在。技能引用都存在。`~onCombat >0 0.12` 在战斗中恒真（有效）。`>0` 几率掉落已在第三刀修复。
- **DP 击杀数 / 刷怪数**：6 个正式副本逐波核对过，mobname 与 Display 一致（第二刀）。
- **CoreRpg 管理子命令**：`coin give`、`cash give`、`talent grant`、`enhance set`、`ladder set/refresh`、`calamity forceopen/forceend`、`abyss progress/settle <玩家>`、`raid grant-ring`、`admin`、`reload` 都检查 `corerpg.admin`。只有 `spawn` 漏了（见 A1）。
- **菜单命令逐条执行**（非 OP 新号，61 条）：除 A4/A5 外全部正常返回（买东西余额不足、需要手持装备等都属于预期）。
- **启动日志**：没有 ERROR。WARN 只有离线模式提示、SLF4J NOP、Adyeshach 重复类定义（插件内部问题，无影响）、配方书「non existent recipe」（CoreCraft 移除原版配方后的正常提示）。
- **今日运行日志**：`玩家 <player.name> 不在线` 共 48 + 6 次，全部发生在第二刀修复之前。`玩家 Unknown 不在线` / `玩家 余烬深渊·骨潮 不在线` 是怪物被非玩家击杀时（`/mm mobs kill`、怪物互伤）MM 的 `<trigger.name>` 解析不到玩家，给不出东西，无害。`mm mobs listactive <id>` 的 NPE 是 MM 4.11 自身的 bug。
