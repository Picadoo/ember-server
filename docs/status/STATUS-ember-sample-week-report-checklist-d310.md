## 示例指针（勿当本周实填）

### 空周（DESIGN §2.1.2 · 2026-10-08 量级）

| 项 | 示例填 |
|----|--------|
| weekKey | （例）`2026W41` 半周 / 日级 |
| A1 完整 P 周 | **否** |
| A2 `p1_pf_runs` | 例：`4`（**< 30**） |

| D 排除表 | 若 `exclude_uuids: []` 且有冒烟 → 标「不全/脏风险」 |
| E 各 R | **全部勾「未满 · 不得开」** |
| G 总控 | **仅收悉**；**不**批准进入任一 R 债待批 A |

### 半满周（DESIGN §2.1.3 · 仍不得开）

| 项 | 示例填 |
|----|--------|
| A1 | 是（第 1 个完整周） |
| A2 | 例：`22`（仍 **< 30**）→ A2 不勾 |
| 或 A2=`35` 且 A1 勾 | B/C 已抄录；B4/C5 人感 **无** → 事件/调律仍 **不得开** |
