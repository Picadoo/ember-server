## 这扇窗做什么

离线自检里一直挂着 3 条红灯（不算玩法问题，是文档/工具规范）。本窗把它们修掉，方便以后一眼看出新问题。

**不改战斗数值，不开六槽护甲，不停服。**

## 改了什么

| 红灯 | 原因 | 改法 |
|---|---|---|
| 图录数字对不上 | Q06「霜潮汲取」、Q07「炉心聚爆」伤害行缺「预警 3.0 秒」（配置里预警就是 3 秒，文案漏写） | 菜单两行补上 `预警 3.0 秒 ·` |
| 模拟脚本乱用随机 | `gear6.py` / `gear6diag.py` 用了 `np.random.default_rng`（规范要求只用带种子的 `random.Random`） | 改成 `random.Random(种子)` 再抽下标 |
| 签到模拟直接读配置文件 | `signin.py` 自己 `miniyaml.load`，绕过统一入口 | 改走 `rules.data('p1')` |
