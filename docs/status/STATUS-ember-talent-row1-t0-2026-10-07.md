## 6. 结论与下一步

- **T0 结论：❌** — 不得开 T1（yml / Java / `win_*` 钩）。
- **边缘集中区：**
  - **D1**：多套 `q03r d0.5` 上冲（最高约 +8.9pp 烬爆）——首通书装 + 中躲避把躲后窗口吃满；挑战侧亦有 +3～5。
  - **F7**：烬爆/焚烬接近线内，**炽愈**低躲避挑战（`q01c/q02c d0.3`）白送 +5pp 级——站桩减伤在低躲被预警招吃满时过强。
  - **W6↔t1c**：`q06c` / `q02r d0.7` 下砸 −3～−4pp；窗外 `win_out 0.94` 相对踏步回气基线偏亏，且 |Δ|>3 硬失败。
- **按 §5.3 收窄方向（下轮 T0 复跑，仍禁改工具「好看」）：**
  - D1：↓ `dodge_dmg`（如 1.40→1.30～1.35）或 ↓ 窗口秒 / ↑ 平时 `dmg_boss` 代价（更低于 0.92）。
  - F7：↓ 预警减伤幅度（0.85→0.88～0.90）或 ↑ `taken_boss` 代价；优先盯炽愈低躲挑战格。
  - W6：↑ `win_out` 接近 1（减轻窗外亏）或 ↓ `win_dmg`；**保持**相对 t1c 配对复跑。
- **禁止：** 均匀乘区回潮、宣称旧 ±3 跑数已过、跳窗开 T1。
