## 可改（别扭）

1. **锈轨「支洞侧袭」是清完再刷，不是边打边袭。**  
   - **现象：** `EmberDailyRail` wave2a 主巷尸×3 清完 → delay2s → wave2b 支洞 (8,64,20)/(10,64,20) 矿矢×3。插件 STATUS 自承「侧袭体感靠坐标+文案」。  
   - **为何别扭：** 文案喊「当心支洞侧袭」，实际是主巷清空后的补课；老玩家第二次变成「主巷清完走两步进支洞」。门代价是真的（测岗 PASS），压迫感偏假。  
   - **复现：** 进 `daily_rail` → 房2 先清主巷三尸 → 听「支洞矿矢骷压上」→ 再进支洞。对照霜晶：左刷后 ≈3s 右刷、未清右门不开（真交错）。

2. **进本撞 `start-interval` 时 chat 仍可能空白懵。**  
   - 菜单已写 5 秒；enter 层不捕获 DP 冷却拒进。连刷七线体验时若没读 lore，会以为进本坏了。  
   - **复现：** 通关 leave → 立刻点另一线进本（不看 T/R lore）。

3. **奖励预览仍是「悬停看 lore」，点了无反馈。**  
   - `ember_daily.yml` 图标 P：lore 已对齐通关箱+装备机会，但无 actions。比上次「点一下聊天嘲讽」好，仍占一格死按钮。可留 lore、删点击期望，或做真预览页。

4. **宏观仍是「房1→门→房2两段→门→Boss」复印机骨架。**  
   - 差异落在「改哪一房 / 先骷后尸 / 计数含岔洞」——够用、可感知，但肝完三条后脑内时间轴仍相似。下迭代若要「爱玩」再动第二房或 Boss 前压，不挡本轮收口。

5. **通关箱七份 YAML 仍 diff≈0。** 同池设计可接受；风味只在 Boss 小料（shard/bone_dust），别指望通关箱讲故事。
