## 2. 一句话问题

毕业后重打只剩「赌极品成色 / 精工」：工坊升档贵且成色 3 不可工坊，玩家感觉进步慢、目标糊——要让「这局值不值得打」在菜单 / 结算侧更短反馈，且**不**抬掉率 / 单局币、**不**新增永久乘区。
