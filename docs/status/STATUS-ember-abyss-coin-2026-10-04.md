## 为什么判「不卡」

1. **追装不慢反快**：两件极品第 8 周 56～74%（深渊）对 38～40%（不打），只有 0.3 档层费优先持平（39% 对 40%）。Q07 首通在深渊之前，完全不受影响。
2. **1.4k 是策略结果，不是缺口**：模型里的深渊玩家每局都进「付得起、能过 50%」的最高层，币一过底仓就变成层费。换成「先精工、再交层费」后，精工 / 成色做满的周和不打深渊的一样（0.3 / 0.5 档第 4 / 第 3 周；0.7 档第 4 对第 1 周，是因为深渊玩家多换了好几件新极品要重新精工，累计精工 9.6k 对 6.75k），卡精工周数中位相同（3 / 3），B 中位相同（134.6），两件极品仍比不打深渊高 6～23 点。层费从来不是必付：第 0 层（普通挑战）免费，结算同样 300 币。
3. **降层费造不出余币**：60 人 0.5 档、层费优先策略，全表 ×0.75 / ×0.6 / ×0.5、只砍 5～10 层，第 8 周币中位分别 1387 / 1545 / 1900 / 1490（原 1380）——层费是弹性出口，便宜了就打更多更高层，余币几乎不涨；×0.5 时两件极品 55%→58%、卡币天数 15.6→12.6，只是让深渊更快。和 D111「再降会让 0.5 档快约 2 周」同方向。
4. **深渊的回报**：每层结算和挑战一样（300 币 + T3 件 + 印记），层费买的是更高成色表（极品 3～12% 对挑战 2%）。上表 2. 里两件极品领先就是这笔钱换来的。

所以不加深渊结算币、不降层费；D135 继续成立。

## 代价 / 注意

- 「因币不够没进下一层」天数先精工时更高（0.5 档 16.9 → 20.1 / 56 天）：这是先买精工、晚一点爬层，追极品仍更快。
- p2econ 默认深渊策略（层费优先）会让「深渊列精工均值」偏低（0.5 档 2.0 对 3.0）；看精工 / 战力别用那列下结论，用 `--abyss-forge-first` 或 `abysscoin.py --forge-first`。默认没改，以保留历史表可比。
- 以后如果加新的必需币消耗（不是外观），先跑 `abysscoin.py` 三档 × 两种策略，看「先精工」列的卡精工周数和做满周是否还跟不打深渊一致。
