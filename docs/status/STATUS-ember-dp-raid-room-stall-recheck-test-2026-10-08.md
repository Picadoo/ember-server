1. **跳过观战 bot**：每一步只让 `gameMode !== 'spectator'` 且还有血的 bot 行动。weaken、取怪、进房、进首领厅都用存活的 bot 执行，不再假定 bots[0] 是队长。

4. **房清判定只看 `active=`**（`next=下一房 && active=-`），不看 `alive=`。`alive=` 包含额外精英和宝箱怪，只用于判断「有没有进展」。
5. **卡房的定义**：120 s 内既没有清房，导演的存活数也没有下降，就记 1 次卡房（`STALL_MS` 可调）。记完后用控制台 `kill` 解锁该房，继续测后面的房间，并标记 `unblockedByConsoleKill`；本次没有触发。每房最长 240 s。
6. 每步额外记录 `tps` / `rangedPulls` / `minUpBots`（该房最少几个 bot 活着）。
