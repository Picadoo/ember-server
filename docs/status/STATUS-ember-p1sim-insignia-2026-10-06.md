## 结论

1. **够不够烙 / 调：在范围内（主体）。** 每档都能在 Q07 后 1–2 个月内两槽都有签名；Q01–Q04 的 4 个调律版（L01b/L02b/L06b/L08b）Q07 后约 4–8 周全部解锁。
2. **明显堆积：Q01–Q04 徽记。** 残响（~6 / 周）+ 前哨（6 / 周）全进 Q01–Q04，W30 每人约 **300+ 枚死币**（只剩 40 枚调律和偶尔低图烙印可花）。不影响战力（徽记分图、不可互换），只是「看着很多却没用」。
3. **饥饿：Q07 和 Q05/Q06。**
   - Q07 后玩家主要刷挑战 / 深渊，**这些都不发徽记**；熟练档（0.7）几乎不重打普通 Q07，Q07 徽记只剩签到 ~2 枚 / 月 → 换件后丢签名要等很久才能重新烙上 Q07 签名（中位 6–7 次烙印，Q07 结余常在 2–7）。笨拙 / 一般档因 Q07 首通后有几周刷普通 Q07，Q07 徽记够用。
   - Q05 / Q06 首通后没有任何周常来源（残响只到 Q04、前哨只到 Q03），结余停在 2–6 → **L10b / L12b 调律版 30 周内基本解不开**（调律次数全档卡在 4）。
4. **誓约（上界 +2 / 局）** 只帮还在重打普通图的人（0.3/0.5 档 Q07 结余 ~45）；熟练档几乎不变 —— 不是熟练档 Q07 饥饿的解。
5. **刷法 / 漏洞角度：没有绕过周上限的路。** 残响 3 次 / 周共用 `p4_echo_claim`、前哨 1 次 / 周 `p4_outpost_claim`，之后都是不发奖的练习；重打 / 誓约按局发，被体力（3 局 / 天）封住（单图最多 21 + 誓约 42 / 周）；徽记按图记账、没有跨图兑换，所以低图的堆积买不到 Q05–Q07 签名。誓约是会话级：队长誓约时全员各得 +N（代码如此，设计内）。

## 建议（只记录，不改 CoreRpg）

- R1（Q07 / Q05–Q06 饥饿）：考虑给 Q07 后玩家一个**每周、有上限的高图徽记来源** —— 例如残响按「本人已首通的最高签名图」发（与签到 S23 同规则），或补 Q05–Q07 残响厅；或允许 N:1 把 Q01–Q04 徽记换成高图徽记（周上限）。任何一种都要先在本模型里跑 W30 再定。
- R2（低图堆积）：只要徽记仍是「只换效果、不加倍率」的签名用途，堆积无害，可以不动；若做 R1 的兑换，自然消化。
- 不建议加「挑战 / 深渊发徽记」—— 会把徽记变成又一条主刷收益，偏离「主线图各有可刷装备」的方向。
