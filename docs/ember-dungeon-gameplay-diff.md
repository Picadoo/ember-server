# 五套副本玩法差异（一页纸）

**日期：** 2026-09-13（Asia/Shanghai）  
**依据：** `DESIGN-ember-growth-curve.md` §2～4 · `DESIGN-ember-map-plan.md`  
**目的：** 讲清「为什么不是同一套波次换皮」——机制差异，不只数字。

---

## 总览

| 本 | 空间 | 核心机制（玩家在干什么） | 失败代价 | 社交 |
|----|------|--------------------------|----------|------|
| **日 EmberDaily** | DP 实例 | **清潮**：短线清波 → 单 Boss；读怪站位即可 | 扣日票；无层进度 | 1～2 人可单刷 |
| **周 EmberWeekly** | DP 实例 | **加压走廊**：房间换机制（杂兵→混合→守卫链）；要走位与续航 | 扣周票；整周尖峰没了 | 1～3；建议组 |
| **深渊 EmberAbyss** | DP 实例 | **风险层数**：无尽下潜；自选撤离点；层越高怪越狠 | 票已扣；按**最高层**结算 | 1～2；冲榜肝帝 |
| **灾厄** | **MV `ember_event`（目标）** | **公共窗事件**：闹钟集合、抢阶段、全服同分氛围 | 错过窗口；日箱限 1 | 全服可集 |
| **团 EmberRaid** | DP 实例 | **分工通道**：集结→分路清杂→终厅机制战 | 扣周团票 | **3～5 强制协作** |

挂机庭 / 悬赏 = 日常底盘，不进本表。

---

## 1. 日常 · 灰烬庭院（EmberDaily）

**一句话：** 十分钟「吃饭本」——机制简单、收益稳、服务强化材料。

| 维度 | 设计 |
|------|------|
| 机制 | 回廊刷怪 → 中央垫 Boss；无分路、无减防阶段 |
| 技能压力 | 低；蛮兵砸击可走位躲开即可 |
| 装备角色 | **T0 材料本**；通关箱核心+晶；Boss 低概率 T0 装 |
| 认知负担 | 「打完三波拿箱」 |
| 地图情绪 | 明亮庭院，一眼看清 |

**不要做成：** 深渊式无尽、团本式分路。

---

## 2. 周常 · 深核廊（EmberWeekly）

**一句话：** 周末高潮——更长、更挤、有「房间记忆」。

| 维度 | 设计 |
|------|------|
| 机制 | 前厅清杂 → 中核混合波 → 深室**双蛮兵链**（或守卫→终局） |
| 技能压力 | 中；需要奶装/风筝或两人分工 |
| 装备角色 | **T0 保底刃** + 高核心；开始掉 **T1**（低～中概率） |
| 认知负担 | 「这一室和上一室不一样」 |
| 地图情绪 | 长廊压迫、核心灯 |

**与日本差在：** 不是多两波僵尸，而是**节奏换挡 + 终盘压力**。

---

## 3. 深渊 · 下行竖井（EmberAbyss）

**一句话：** 赌自己能撑到第几层——进度可见、撤离有策略。

| 维度 | 设计 |
|------|------|
| 机制 | 层循环（潮/骨/混/蛮/看守）；系数随层涨；**可主动上浮结算** |
| 技能压力 | 中→高；高层逼孔石与强化 |
| 装备角色 | **孔石主产**；高层结算箱；T2 装仅高层/看守低概率 |
| 认知负担 | 「再下一层还是撤？」 |
| 地图情绪 | 竖井、层数叙事 |

**与日周差在：** 没有固定「通关」；奖励绑**决策**与层榜。

---

## 4. 灾厄 · 公共祭坛（ember_event + DP 测 Boss）

**一句话：** 世界事件——人多、窗口、仪式感；不是又一个私人副本。

| 维度 | 设计 |
|------|------|
| 机制 | 限时开窗；公共世界集合；Boss 阶段削甲→添头→狂暴 |
| 技能压力 | 中（人多分摊）；强调阶段播报 |
| 装备角色 | **灾厄余烬 / 外观碎片**；日箱；T3 碎片级掉落（见掉落表） |
| 认知负担 | 「几点开？进没进场？」 |
| 入口 | **主路径：`/mvtp ember_event`（窗内）**；DP `EmberCalamity` **仅测 Boss** |

**与 DP 本差在：** 社交可见、错过即没；不占日周票逻辑。

---

## 5. 团本 · 大厅+通道（EmberRaid）

**一句话：** 唯一「必须说话」的本——分路与终厅机制。

| 维度 | 设计 |
|------|------|
| 机制 | 大厅集结 → 主道/支路清杂（可并行）→ 终厅 Boss（点名/砸地/添头，怪物岗做技能） |
| 技能压力 | 高；缺人难硬撸 |
| 装备角色 | **套装饰品 `acc_ember_raid_*`**、T2/T3 装、称号进度 |
| 认知负担 | 「谁清左道？谁拉 Boss？」 |
| 地图情绪 | 大厅社交 → 暗道 → 终厅祭坛 |

**与周本差在：** 人数门 + 空间分路 + 饰品/套装主产，不是「更胖的周本」。
