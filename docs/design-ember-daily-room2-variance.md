## 1. 问题一句话

必改4已让「改动房」可感知，但宏观仍是 **房1→门→房2两段等清→门→空厅 Boss**；肝完三条后时间轴仍像亲戚——本试点在 **不拆开门骨架** 的前提下，用 **Boss 前门压** 或 **房2链式重叠** 打断复印机节拍。

### 2.2 本试点选型

| 试点 | 改什么 | 理由 |
|------|--------|------|
| **庭院** | **Boss 前门压** | 房2已改过对射→涌；door2 后仍「空厅直接 Boss」——加终厅门槛压，不冲掉房2 |

**未选焦骨房2：** 焦骨房2仍旧序，本可作「第二房」候选；但派工优先庭院+潮蚀+断塔，且焦骨房1假岔已是强记忆点，本轮先试点「Boss 前压 / 房2重叠」两类杠杆。若试点有效，下轮可扩焦骨房2。

## 5. 三条试点可执行方案

约定：

- `delay` 单位秒；`$kill` **按 monstergroup 独立**，禁止跨组合并数量。
- 链式开门先例：**霜晶**（wave1 start→wave1b delay3；开门在 wave1b end）、**锈轨**（wave2a start→wave2b；开门在 wave2b end）。
- Display 去色名一字不改；**不加血、不改掉落、不改 Boss HP**（各方案末再声明）。

### 5.1 庭院 `EmberDaily` · **Boss 前门压**

| 项 | 内容 |
|----|------|
| 线名 / id | 余烬窟·庭院 / `EmberDaily` |
| 改哪 | **door2 开后 → Boss 前**（新组 `boss_prep`）；**不动房2** 对射→涌尸 |
| 现网一句话 | 回廊清完开门 → delay → **空厅直接蛮兵** |
| 改后一句话 | 开门进终厅 → **先被门槛两侧尸贴脸** → 清完才出蛮兵 |

**组表（相对现网）：**

| 组 | 时机 | MM（去色名） | 数量 | 刷点（现网邻域） | `$kill` | 开门 / 下一段 |
|----|------|--------------|------|------------------|---------|----------------|
| wave1 | 进本（**裁 1**） | `EmberDailyZombie`（灰烬庭院僵尸） | **4**（现 5） | 保留两侧壁龛；**删**中央 `(0,65,10)` 那 1 只 | ×4 → door1 | 同现网 door1 @ z=13 → wave2a |
| wave2a / wave2b | **不动** | 骷×2 → 尸×4 | 2+4 | 现网柱后 / 涌点 | 同现网 | door2 @ z=25 |
| **boss_prep**（新） | wave2b **end**：door2 AIR 后 `$monstergroup{boss_prep;delay=2}`（**不要**直接调 boss） | `EmberDailyZombie`（灰烬庭院僵尸） | **2** | 终厅门槛内侧两侧：建议 `(-3,65,27)` `(3,65,27)`（door2 z=25 与 Boss z=31 之间；柱侧贴脸） | 灰烬庭院僵尸 ×**2** | end → `$monstergroup{boss;delay=2}` |
| boss | prep 清完 | `EmberDailyBrute`（灰烬庭院蛮兵） | 1 | 现网 `(0,66,31)` | ×1 | COMPLETE（文案可加「门槛已清」一句，可选） |

**门序：** door1（wave1）→ door2（wave2b）→（无第三门）→ Boss。骨架不变。

**与必改4叠加：** 房2 仍「先躲柱清射再涌尸」；本条只改 **door2 之后**，不冲掉对射→涌尸。

**声明：** 不加小怪/Boss 血；不改掉落/箱；不改体力。小怪合计 **4+2+4+2=12** + Boss。

### 5.3 断塔 `EmberDailySpire` · **第二房链式重叠**（打「两段等清」）

| 项 | 内容 |
|----|------|
| 线名 / id | 余烬窟·断塔回廊 / `EmberDailySpire` |
| 改哪 | **房2 时序**：由「对射全清 → 再卫尸」改为 **霜晶/锈轨式 start 链式**；**刷点/数量/门位不动** |
| 现网一句话 | 上环廊先清双侧箭 → **等清完** 再出卫尸 → 开门 |
| 改后一句话 | 一上环廊双边挨箭的同时 **卫尸已在内侧压上**（重叠压）；仍要清完两组才能开顶门 |

**组表（相对现网，只改触发关系）：**

| 组 | 时机 | MM | 数量 | 刷点（**坐标不变**） | `$kill`（按组） | 门 / 链 |
|----|------|-----|------|----------------------|-----------------|--------|
| wave1 | **不动** | 断塔卫尸 | 5 | 现网塔底 | ×5 → door1 @ z=4 y64 | → wave2a |
| wave2a | 上中层后 | `EmberDailySpireSkeleton`（裂隙箭骷） | 2+2=4 | `(-6,70,0)` `(6,70,0)` | 裂隙箭骷 ×**4** | **start** 即 `$monstergroup{wave2b;delay=2}`；**end 不开门、不调 boss**（对齐霜晶左台） |
| wave2b | wave2a start 后 delay **2s**（对射未必要清完） | `EmberDailySpireZombie`（断塔卫尸） | 2 | `(0,70,-6)` `(0,70,2)` | 断塔卫尸 ×**2** | **end**：顶门 AIR @ z=4 y70 → boss delay=3 |
| boss | **不动** | 断塔守望 | 1 | `(0,76,0)` | ×1 | COMPLETE |

**链式写法（对齐锈轨/霜晶，施工备忘）：**

```
wave2a.start: message + $monstergroup{group=wave2b;delay=2}
wave2a.end:   仅「对射侧已清」类提示 + heal；禁止 door / boss
wave2b.end:   顶门 ×9 AIR + heal + $monstergroup{boss;delay=3}
```

**禁止：** 把 `$kill{裂隙箭骷;amount=4}` 与卫尸合并进同一 condition；禁止 `kill-any`。

**与必改4叠加：** 双侧对射几何与数量 **原样保留**；只把「等清两段」改成「重叠压」——专打软尾巴宏观「房2两段」，不换皮重做房2内容。

**声明：** 不加血；不改掉落/箱/体力；小怪合计仍 **5+4+2=11** + Boss（本线不增 prep）。
