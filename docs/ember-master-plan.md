# 余烬服 · 总体设计（Master Plan）

2026-09-27 CST。本文把全服当成**一个系统**来看：核心循环、资源的产出与消耗、装备阶梯、战斗数值、现有系统状态，以及后续扩展的顺序。

- **数字来源：** 全部来自当前线上配置（`server-runtime/plugins/**`，CoreRpg 1.10.0）和本周 bot 实测。
- **标记：** 标注 **（估）** 的是推算值，推算依据写在同一行或表后。
- **本文不改任何配置。** 第 6、7 节是提案，落地前需逐项确认。
- **2026-09-27 阶段 1（CoreRpg 1.12.0）已落地：** 锻造保底（6.1）、凝核来源、断供补源、付费轨收紧（7.2）；第 2 节总账已按新数字更新（标 **1.12.0**）。
- **阶段 2（CoreRpg 1.13.0）已落地：** 装备被动、同袍共鸣、誓约属性开启（吸血改为只算技能），Boss 按 bot 实测重调（第 3.2、4 节，标 **1.13.0**）。

## 0. 结论先行

1. **余烬币严重通胀，并且几乎没有消耗口。**
   - 产出：活跃免费玩家不挂机约 540 币/日（估），挂机按击杀计且无上限（每只 1 币）。
   - 消耗：只有建盟 5000（一次性）、材料仓扩格（一次性）、寄售税 10%（只是转移）。
   - 结果：币很快失去意义。
2. **挂机庭的碎片、骨尘、币都没有日上限。**
   - MM `~onDeath` 的 `mmgive` 不受任何日上限约束，只有经验有日顶（击杀 100 / 精英 150）。
   - 3 个刷怪点合计约 13.5 只僵尸 + 5 只骷髅/分钟，全服共享。
   - 一人独占挂 1 小时约 800 碎片、300 骨尘、1100 币（估），足以把 +1～+6 强化变成免费。
3. **T3 装备严重稀缺，没有保底。**
   - 团本终厅 Boss 掉 T3 刃 8% / 护符 6%，只给尾刀者；灾厄、盟 Boss 尾刀各 1%。
   - 3 人团每周 1 张团票：非尾刀者期望 30 周以上才出一把 T3 刃（估）。
   - 相反，T2 泛滥：深渊周首通必给 T2 刃 + 护符，第 4 章还送一把。
4. **死物资：只有来源、没有去处。**
   - 凝核 `core_ember_compact`、灾厄余烬 `mat_calamity_ember`、外观碎片 `cosmetic_calamity_shard`。
   - 核心碎片和附魔晶大量盈余：活跃玩家约 11 碎片/日，而正常消耗只在 +7 以上强化。
5. **断供：系统存在，但玩家拿不到材料。**
   - 重铸石 `mat_ember_reforge_stone`：重铸系统等于不可用。
   - 使魔本体和魂尘 `mat_ember_soul_dust`：只有战令 Lv15 给 3 个。
   - 稳定符（+10 强化必需）只有 5% 掉落。
6. **Lv35 以后内容断档。**
   - 主线 6 章在团本（Lv35）结束。
   - 天赋点在 Lv30 封顶 20 点。
   - Lv35～60 需要约 12,600 经验，但没有任何新目标和奖励节点。
7. **技能在 1.10.0 按普攻倍率重做，已受上限约束。**
   - 烬斩 1.5×、灰印 +20%、壁垒抗性 II 加嘲讽，单击上限为普攻 2.5×。
   - 按当前 TTK 估算，技能约加 10～15% 输出（估），不会把 Boss 打穿。
   - 第 3 节提到的被动（引燃、暴击回复、烬爆、同袍共鸣）**1.13.0 已上线**，誓约属性同时开启（烬刃吸血只算技能伤害），Boss 已按实测重调。

**建议阶段顺序：**

| 阶段 | 内容 |

## 1. 核心循环与玩家旅程

### 1.1 核心循环

```
签到 / 悬赏 / 活跃（币、战令经验）
   ↓
挂机庭（碎片、骨尘、击杀经验，日顶 100）──→ 强化 +1～+6
   ↓
日本 ×3/日（核心碎片、附魔晶、碎片，T0～T1 概率）──→ 附魔、+7～+9
   ↓
周本 ×1/周（T1 周首通保底）→ 深渊 ×1/周（T2 周首通保底）
   ↓
灾厄公共窗 12:00 / 20:00 / 22:00（日箱：核心碎片、晶、灾厄余烬）→ 团本 ×1/周（团戒、T2/T3 概率）
   ↓
盟 Boss ×1/周（贡献 20，靠捐碎片 / 骨尘换贡献）
   ↓
战令 30 级 / 天梯（只展示）/ 竞技（币、外观碎片）

生活支线（1.11.0，喂给战斗，不替代战斗）：
钓鱼（鱼 / 遗物 / 宝珠，生活经验）→ 补给商代烤 / 熔炉烤鱼 → 食物（回血前提）
                                  → 熬回复药（副本消耗品）
                                  → 遗物 ×5 → 重铸石（每周 5）；宝珠 ×3 + 核心碎片 ×3 + 300 币 → 稳定符（每周 1）
补给商：面包 / 钓竿（纯币消耗）
```

### 1.2 等级曲线（`progress.yml ember_xp`）

- **每级所需经验：** 60 + 12 × (L − 10)。新号从 Lv10 起。
- **累计经验：**

  | 目标等级 | 累计经验 |
  |---|---|
  | Lv20 | 1,140 |
  | Lv25 | 2,160 |
  | Lv30 | 3,480 |
  | Lv35 | 5,100 |
  | Lv40 | 7,020 |
  | Lv50 | 11,760 |
  | Lv60 | 17,700 |

- **主线定额经验：** 6 章合计 4,710（每章依次 520 / 580 / 630 / 820 / 1,100 / 1,060），不受日顶限制。
- **活跃免费玩家（估）：** 约 515/日。
  - 签到 20，日本 3 × 60 = 180，悬赏 40，击杀 100（到顶）。
  - 精英/首领约 85（日本蛮兵 3 × 15，另约 40 来自灾厄或周本 Boss）。
  - 周本 200、深渊 80、团本 250、盟 Boss 100，合计 630/周，摊到每日约 90。
- **休闲玩家（估）：** 约 175/日。
  - 签到 20，日本 1 次 60，击杀约 50，精英 15，周本摊到每日约 29。

## 8. 生活玩法（1.11.0，阶段 0 已上线第一版）

### 8.1 审计（2026-09-27）

| 插件 | 状态 | 产出 | 消耗 / 前置 | 问题 |
|---|---|---|---|---|
| CoreFish | ✅ 可用（原先没有钓竿来源） | 鱼 80%（鳕 60 / 鲑 30 / 河豚 10）；宝藏 10%（遗物 70 / 宝珠 30）；垃圾 10%；40～120 tick 一竿 | 任意钓竿 + 水 | CoreCraft 清掉了原版配方，玩家拿不到钓竿；产物没有用途；宝珠原为末影珍珠材质（会被扔出去）→ 已改成海晶砂粒 |
| CoreSmelt | 🟡 桩 | 余烬铁 / 金锭、碳晶、余烬牛排 | ore_* / raw_ember_flesh | 输入全部没有来源；燃料也没有来源 |
| CoreBrew | 🟡 桩 | 迅捷 / 力量 / 夜视药水 ×8 | 疣 / 烈焰 / 晶 + 余烬水瓶 | 原料没有来源；药水本身不带效果，喝了等于水 |
| CoreCraft | 🟡 | 铁板、铁棍、凝核（碳晶 + 金锭）、附魔晶（3 碎片 + 1 骨尘 / 1 核心碎片 + 2 碎片 → 2） | 同左 | 只有附魔晶配方真正有用 |
| CoreAnvil | ✅ | 修理 | 碎片 / 核心碎片 + 原版等级 | 没有币手续费 |

结论：四个生活插件之前都是技术演示，唯一真实的问题是「没有食物」—— 饱食度 < 18 不自然回血，玩家在挂机庭饿着打。

### 8.2 设计原则

1. **喂战斗，不替代战斗。** 生活只产：食物（回血前提）、回复药（副本消耗品）、少量补源材料（**每周上限**）。不产装备、碎片、核心碎片、经验。
2. **需要战斗材料的配方挂在战斗产出上。** 稳定符要核心碎片（副本产），所以钓鱼再久也绕不过副本。
3. **币消耗优先。** 面包、钓竿、代烤、熬药、兑换都收币。
4. **生活等级只解锁配方，不给属性。** 实现只是一个计数器（PlayerData 通用计数），成本很低。
