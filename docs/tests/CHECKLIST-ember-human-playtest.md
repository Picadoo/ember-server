## 成长手感（换一件事，再打同一张重打本）

每次只改一项，打 1～2 局同图同难度：

| 改动 | 打法有变吗？ | 清怪更快/更慢？ | 更稳还是更脆？ | 这点天赋/词条还想留吗？ |
|---|---|---|---|---|
| 换套装（例：烬爆 → 炽愈） |  |  |  |  |
| 换第 1 排天赋（稳桩 / 回身斩 / 踏步回气） |  |  |  |  |
| 换第 2 排（破缀 / 拆分 / …） |  |  |  |  |

「打法有变」= 你站位、技能节奏、要不要聚怪，至少有一样真的变了，而不是只看面板数字。

## 资产（各做一次，断线或重进服后再查）

- [ ] 材料进仓 → 断线 → 重登 → 数目还在
- [ ] 装备库存入 → 取出 → 背包一件、库内状态正确
- [ ] 批量分解 → 撤销 → 件与胚料回到预期
- [ ] 快照恢复 → 背包对得上；仓库材料按预览差异，不凭空复制

## 余烬连战（每周一次认真打即可）

- [ ] 失败后再进：不被「本周次数用完」挡住
- [ ] 本周第一次通关有奖；同周再通关提示练习、不发奖
- [ ] 入口和结算文案读得懂

## 不要用来下数值结论的情况

- 创造 / 无敌 / 削弱怪 / 站桩机器人通关率
- 只看面板总分、不看自己有没有换打法

那些给模拟器与冒烟用；真人清单只回答：**想不想继续玩、换成长有没有感觉、哪里想关游戏。**
