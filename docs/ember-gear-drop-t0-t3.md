## 2. 成长回流（回顾）

```
挂机材料 → 附魔晶/修理
     ↓
日/周本核心 → 强化 +1～+6（T0/T1 装）
     ↓
深渊孔石 → 镶嵌
     ↓
周本/团本稀有装 → 词缀 + 套装件
     ↓
灾厄变异材 → 外观/重铸 + T3 低概率
```

---

## 3. 分本掉落表

概率为**单次击杀或单次通关箱**口径；「保底」= 通关必给。与现网已跑通的日/周箱**对齐数量**，只**加阶**不推翻材料量。

### 3.1 挂机庭（∞）

| 产出 | 概率 / 规则 |
|------|-------------|
| `mat_ember_shard` / `mat_ember_bone_dust` | 按怪种必掉 |
| T0～T3 装备 | **不掉**（或 ≤0.2% T0，默认关） |
| 孔石 | **不掉** |

### 3.2 日常 EmberDaily

| 来源 | 产出 | 数量 / 概率 |
|------|------|-------------|
| 小怪 MM | 碎片 / 骨尘 | 1 |
| Boss 蛮兵 | `mat_ember_core_fragment` | 1 必掉 |
| Boss | `gear_ember_blade` / `charm`（T0） | 12% / 8%（维持现网量级） |
| Boss | **`gear_ember_t1_blade`** | **3%** |
| Boss | **`gear_ember_t1_charm`** | **2%** |
| 通关箱 | 核心×1 · `crystal_ember_enchant`×1 · 碎片×5 | 保底（现网） |
| 通关箱 | T1 任一件 | **5%**（与 Boss 不互斥） |

**不做：** 通关箱出 T2/T3。

### 3.3 周常 EmberWeekly

| 终局 | T0 刃/护符 | 28% / 20%（可逐步降权） |
| 终局 | **T1 刃 / 护符** | **18% / 12%** |
| 终局 | **T2 刃** | **3%** |

## 4. 票与装的关系（防刷）

| 本 | 票 | 成品装期望（粗） |
|----|-----|------------------|
| 日×3 | 日票 | 碎 T1；材料够强化 |
| 周×1 | 周票 | **T1 保底** + 赌 T2 |
| 深渊×1 | 深渊票 | 孔石 >> 装；高层才赌 T2 |
| 灾厄窗 | 窗口 | 外观材 >> T3；T3 很稀 |
| 团×1 | 团票 | **饰品保底** + T2/T3 主坑 |

氪金只卖票/保护券/外观，**不卖 T3 成品**（经济红线）。

## 6. 验收（策划）

1. 日本通关箱仍有核心+晶+碎片；可额外出现 T1，**无 T2+**。  
2. 周箱保底为 T1 刃+护符（已落地）。  
3. 深渊结算无 T3；孔石为体感主产。  
4. 灾厄日箱限 1；公共世界入口文案指向 `ember_event`。  
5. 团本周首通必给 `acc_ember_raid_ring`。
