## 1. 问题一句话

地窖中层「高台远程优先」已立住记忆，但 **房2 仍「誓印骷清完 → 再窖卫尸」两段等清**，竖井下阶本该有的夹击感变成排队清怪；试点+焦骨已证链式重叠有效，本轮把该杠杆扩到地窖房2，且不冲掉高台先箭。

## 3. 杠杆比选（推荐结论前置）

| 候选 | 做法摘要 | 利 | 弊 | 本轮 |
|------|----------|----|----|------|
| **A. 房2链式重叠** | `wave2a.start` → delay2 `wave2b`；开门仍在 `wave2b.end`；**仍先刷高台骷** | 直打「两段等清」；**零增怪**；不冲掉必改4「远程提前」；断塔/焦骨同杠杆已 PASS；**竖井夹击**（上箭+下贴）可感 | 与断塔/焦骨同杠杆族（但地窖是 **BOW 高台 + 近战地面 + 落差**，手感可分） | **推荐** |
| B. door2→Boss 前压 | 新 `boss_prep`；需裁别房 ±1～2 | 庭院/潮蚀已证前压有效；圆厅可风筝，空间比焦骨鼓室宽 | 与庭院/潮蚀 **同杠杆族**；竖井记忆点在中层落差而非再加门槛；裁额度易伤上层或中层远程压；圆厅 y 落差刷点需地图核 | **不优先**；仅当批准方坚持前压时备选（§6.6） |
| C. 仅挪刷点 | 高台/地面坐标侧移 | 改动极小 | **不打断时间轴**；等清尾巴未解 | 可作 A 的可选微调，不作主杠杆 |

**推荐：A · 房2链式重叠。**  
**竖井气质理由：** 地窖卖点是 **多层下潜 + 中层高台对射**。把「等清再出尸」改成「箭未停、尸已贴」= 下阶被夹，强化竖井压迫；Boss 前压更像「门槛关卡」，庭院/潮蚀已用，扩到地窖会削弱「中层才是竖井高潮」的差异。焦骨 §10 / 断塔试点已证链式开门挂末组、重叠 Δ≈2s 可测。

## 6. 可执行方案（推荐 · 房2链式重叠）

约定：

- `delay` 单位秒；`$kill` **按 monstergroup 独立**，禁止跨组合并数量 / `kill-any`。
- 链式开门先例：**断塔**（试点 PASS）、**焦骨**（`2ad874e` PASS）、霜晶 door1、锈轨房2。
- Display 去色名一字不改；**不加血、不改掉落、不改 Boss HP**。
- **wave1 / door1 / boss 组内容与门坐标一律不动。**
- **仍先刷高台誓印骷（wave2a），再链式出地面尸（wave2b）** — 禁止改回「先尸后骷」。

### 6.1 组表（相对现网，只改触发关系）

| 组 | 时机 | MM | 数量 | 刷点 | `$kill`（按组） | 门 / 链 |
|----|------|-----|------|------|-----------------|---------|
| wave1 | **不动** | `EmberDailyCryptZombie` | 5 | 现网上层 | 窖卫尸 ×5 | door1 @ z=18 y72 → wave2a delay=3 |
| **wave2a** | door1 后 | `EmberDailyCryptSkeleton` | 3 | **坐标默认不动**（高台） | 誓印骷 ×**3** | **start** 即 `$monstergroup{wave2b;delay=2}`；**end 不开门、不调 boss**（仅提示+heal） |
| **wave2b** | wave2a start 后 delay **2s**（高台未必要清完） | `EmberDailyCryptZombie` | 3 | **坐标默认不动**（地面） | 窖卫尸 ×**3** | **end**：door2 ×9 AIR @ z=40 y66 → boss delay=3 |
| boss | **不动** | `EmberDailyCryptWarden` | 1 | `(0,60,48)` | ×1 | COMPLETE |

小怪合计仍 **11** + Boss（不增 prep、不裁上层）。

### 6.2 链式写法（施工备忘 · 对齐断塔 / 焦骨）

```
wave2a.start: message（中层·高台重叠压）+ $monstergroup{group=wave2b;delay=2}
wave2a.end:   仅「高台箭侧已清」类提示 + heal；禁止 door / boss / 再调 wave2b
wave2b.start: message（地面尸重叠压上 · 清完开底层门）
wave2b.end:   door2 ×9 AIR @ z=40 y66 + heal + $monstergroup{boss;delay=3}
```

**相对现网关键 diff：** 现网 `wave2a.end` 含 `$monstergroup{wave2b;delay=5}` → 改为 **start** 调 `wave2b;delay=2`；`wave2a.end` 去掉调波；文案按 §6.4。

**禁止：** 把 `$kill{誓印骷;amount=3}` 与 `$kill{窖卫尸;amount=3}` 合并进同一 condition；禁止 `kill-any`；禁止把 wave2b 改成先于 wave2a 刷出。

### 6.3 可选刷点微调（非必须；批准时可勾选）

若希望重叠时更有「下阶夹击」几何（主杠杆仍是时序），允许 **仅挪 wave2b 1～2 个刷点** 靠近下阶落点邻域，例如：

| 现网 | 可选改为 | 意图 |
|------|----------|------|
| `(-5,66,30)×2` | 保留 1 + 侧移 1 至约 `(-3,66,28)` | 左近阶贴脸 |
| `(4,66,30)×1` | 约 `(3,66,28)` | 右近阶贴脸 |

须落在现网可站格；若占格被挡，地图岗最多补 1～2 开放格。**默认推荐：坐标不动，只改链式**（改动量最小、与断塔/焦骨对照最干净）。

### 6.4 建议文案（可施工时微调，须保留可测关键词）

| 节点 | 文案意图 |
|------|----------|
| wave2a.start | `【中层·高台】誓印骷对射 —— 窖卫将交错从地面压上` |
| wave2a.end | `高台箭侧已清`（**不要**写开门） |
| wave2b.start | `【中层·地面】窖卫尸重叠压上 —— 清完开底层门` |
| wave2b.end | `中层已清 · 底层门开了`（可保留） |

### 6.5 与房1 / 必改4 如何叠加不冲掉

| 段 | 记忆点 | 本轮 |
|----|--------|------|
| 房1 上层 | 窖卫×5 → 下阶门 | **零 diff** |
| 房2 中层 | （必改4）**先高台远程再地面近战** | **顺序保留**；只把「等清」改成「重叠」 |
| Boss 圆厅 | 空厅残誓守墓 | **零 diff**（推荐方案无 prep） |

玩家时间轴应变为：**上层清门 → 下中层高台箭+地面尸夹击 → 门 → 圆厅 Boss**，而非「中层有趣的远程提前、后半又变排队等清」。

### 6.6 备选（不推荐本轮）：Boss 前压

若总控驳回链式、改批前压，最小草案如下（**默认不施工**）：

| 项 | 草案 |
|----|------|
| 链 | wave2b end：door2 后 → `boss_prep` delay=2 → boss delay=2（**不要**直接调 boss） |
| prep | `EmberDailyCryptZombie`（窖卫尸）×**2** @ 圆厅入口内侧，建议约 `(-3,60,42)` `(3,60,42)`（door2 z=40@y66 与 Boss `(0,60,48)` 之间；**y 落至 60**，须地图核可站） |
| `$kill` | 窖卫尸 ×2（独立组；禁与 Boss 合并） |
| 额度 | 现 11+2=13 **超标** → 裁 wave1 5→**4**（删中央或一侧 1 只）→ 合计 **4+3+3+2=12** + Boss |
| 手感意图 | 下圆厅先被门槛尸贴脸再出守墓；与庭院门槛尸同族、与潮蚀浪矢射可分 |

**为何仍不推荐：** ① 竖井高潮应在中层夹击，前压把记忆挪到圆厅门槛；② 与庭院同构风险；③ 须裁上层且 y 落差刷点有占格风险；④ 链式零增怪、已有双线 PASS 先例。
