## 1. 问题一句话

**日常 / 周本 / 团本 / 深渊已有可点「奖励预览」真分页；灾厄同名 P 点了只 chat 一句空壳 tell——与已还清的四入口预览债不对齐；且日箱≠尾刀，必须写清两套展示，不能空许愿「参战人人有」。**

---

## 2. 现网事实（调研 · 本稿未改）

| 项 | 现网 / 证据 |
|----|-------------|
| 入口 | `ember_calamity.yml` Layout：`# S P R #`；P = chest「奖励预览」 |
| P 现行为 | lore 已摘要日箱 + 尾刀 T3；`actions` = sound + **1 行 tell**（**无**子菜单） |
| 范式 | `ember_daily_rewards` / `ember_weekly_rewards` / `ember_raid_rewards` / `ember_abyss_rewards`（均 PASS） |
| 日箱（`calamity.yml` `daily_chest`） | 限 **1/日**：核心碎片×**2** · 附魔晶×**1** · 灾厄余烬×**2**；保护卷约 **10%**；**每周首次**日箱额外凝核×**1** |
| 尾刀（MM `EmberCalamityBoss` · `mmgive`→**最后一击玩家**） | **必给**：灾厄余烬×1 · 凝核×1 · 核心碎片×2 |
| · 概率 | 锋利石 **30%**；稳/汲/疾孔石各 **2%**；稳定符 **5%**；外观碎片 **20%**；T3 刃 / 护符各 **1%** |
| 父 lore 口径差 | lore「参战：核心、灾厄余烬、外观碎片」易读成全员参战奖；现网 MM 为 **尾刀** 结算 → 真分页须写「尾刀」 |
| 精英入口 | `ember_hub` 图标 `2`：**一点** `corerpg elite start`；**无**独立 `ember_elite` 菜单、**无** P「奖励预览」 |

### 展示结构可行性

| 展示结构 | 是否可行 | 判定 |
|----------|----------|------|
| **摘要页 · 日箱 + 尾刀同屏** | **是（荐）** | 两套来源清晰；体量 ≤ 周团一页 |
| **只加厚 tell** | 弱 | 仍无真页；与四入口范式仍裂 |
| **本窗兼做精英预览** | **否** | 精英无父菜单 P；需先造子菜单壳，超出「空壳 P→真页」薄窗 |

**本窗定调：** 对齐四入口范式 = **灾厄一页摘要**；日箱限领 + 尾刀概率分栏；禁写成「全场参战人人掉 T3」。

## 3. 方案 A / B

| 方案 | 做法摘要 | 利 | 弊 | 本轮 |
|------|----------|----|----|------|
| **A. 摘要真分页（推荐）** | 新建 `ember_calamity_rewards`；P 改 `sound` + `menu:`（**删**空壳 tell）；页内：**头** + **日箱** + **周首次凝核** + **尾刀必给** + **尾刀概率（含 T3 1%）** + 返回 `ember_calamity`；数量/概率 **只展示现网** | 与四入口体感一致；校正「参战→尾刀」口径；专岗清晰；热更；零改数 | 一页分区略密（仍 ≤ 深渊摘要） | **推荐** |
| **B. 本轮继续挂 / 仅加厚 tell** | backlog 挂债；或 tell 改多行仍无子页 | 零 / 更小 diff | 「假预览」债继续；与四入口范式仍裂 | 备选 |

### 方案 A · 施工意图（批准后 · 插件可微调同义布局）

**入口（`ember_calamity` P）：**

```
actions:
  all:
    - 'sound: BLOCK_CHEST_OPEN-1-1'
    - 'menu: ember_calamity_rewards'
# 无 tell 空壳；无 join / 无给物 / 无 dp start
```

**预览页 `ember_calamity_rewards`（示意分区 · 布局可仿深渊 6 行）：**

| 区 | 展示意图（展示名为主；可选附 NI 管理行同日常） |
|----|----------------------------------------------|
| 头 | 灾厄奖励预览 · 公共窗 · 纯展示不奔赴 |
| 日箱 | 核心碎片×2 · 附魔晶×1 · 灾厄余烬×2 · **每日限 1** |
| 日箱附 | 保护卷约 **10%**；**本周首次**日箱额外凝核×1 |
| 尾刀必给 | 灾厄余烬×1 · 凝核×1 · 核心碎片×2（**最后一击**；非全员） |
| 尾刀概率 | 锋利石约 30% · 其它孔石各约 2% · 稳定符约 5% · 外观碎片约 20% |
| T3 | 刃 / 护符各约 **1%** · **不保底** · 禁写成必掉 |
| 底栏 | 返回 `ember_calamity` |

**不施工：** 精英预览；改 `calamity.yml`/MM/`loot.yml`；改窗期；教 `/corerpg loot` / `/dp start`。

## 4. 验收（≤5）

1. **批准前：** 本稿落盘；`calamity.yml` / MM / `loot.yml` / 体力 / `over_chance*` **零 diff**（本 commit 仅文档）。  
2. **若批 A：** 灾厄 P 点开 `ember_calamity_rewards`（有声），**非**仅 chat 空壳；底栏返回 `ember_calamity` 且 **未**奔赴、**未**开 DP 测本、**未**发物。  
3. **若批 A：** 页内可见 **日箱数量 + 日限 1** + 保护卷~10% + 周首次凝核 + **尾刀**必给/概率（含 T3 各 1%）；**无**「全员参战保底 T3」假写。  
4. **若批 A · 禁项：** 未改掉落/窗期/奔赴；玩家路径 **无** 新增斜杠教学；口径与 `calamity.yml`+MM **一致**。  
5. **若批 B：** backlog 明文「灾厄奖励预览本轮不批」；不得把四入口预览 PASS 写成「进本类菜单预览已全齐」。
