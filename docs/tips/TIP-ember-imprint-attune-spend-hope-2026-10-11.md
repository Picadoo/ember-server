# tip · 烙印/调律花费希望表盘（D615）

> **状态：** 已批 A · 方案 M · 2026-10-11

## 缺口

烙印页有 cost 行，但签名页/调律页缺统一「徽记 have/need + 币 + 下一步确定花」希望表盘。

## 方案 M

| 项 | 内容 |
|----|------|
| HopeMeter | `imprintSpend` / `attuneUnlock` 同风格 glance |
| PAPI | `%corerpg_p1_sig_imprint_hope%` · `%corerpg_p1_sig_attune_hope%`（追烙目标图；调律页看当前追烙或汇总） |
| UI | 签名页 / 烙印 Open / 调律 Open 挂行；就绪时明示「可确定花」 |
| 禁 | 不改 IMPRINT_MARKS / ALT_MARKS / 币价 / STAMP_RATE |
