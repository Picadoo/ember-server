## 还行（可留）——真好玩的点

1. **五线地形气质能分清。** 庭院回廊垫、焦骨窄甬+假岔、地窖下潜三层、潮蚀棱柱水道、断塔上攀顶台——不是「一块石砖换个名」。进本 5 秒观感差异够用（测报 anvil/材质对照也站得住）。
2. **清房开门手感对。** 铁栅挡路 → `$kill` 齐 → AIR 开门 + 短句播报（「前厅已清 · 门开了」「桥闸开了」等）。这是日常最像 DNF 分房的一段，别砍。
3. **进本主路径零指令。** `ember_daily.yml` 五钮走 `corerpg enter …`，lore/tell 不教 `/dp`；体力顶栏有 `%corerpg_stamina%` / `%corerpg_stamina_cost_daily%`。比票券背包时代清爽。
4. **Boss 有一点点个性。** 焦核灼烧、残誓点名+减速、潮闸减速光环、断塔轻推离——不是纯换 Display。断塔顶台有栏、潮蚀落水有石底，不整虚空秒杀，良心。
5. **体力同池 30 语义清楚。** `cash.yml` 五线 `daily*` 全是 30；失败进本退还、通关不退——私服老玩家能接受「花出去的冒险」。

## 必改（痛点）

### 1. 庭院 Boss 独占装备表，同体力下理性只肝庭院

- **现象：** 五线通关箱完全同一套（`mat_ember_core_fragment×1` + `crystal_ember_enchant×1` + `mat_ember_shard×5` + `xp 3L` + `daily_clear`），见五份 `option.yml` 的 `dungeon-reward-script`。但 **Boss 死亡掉落不对齐**：
  - 庭院 `EmberDailyBrute`：核心 + **`gear_ember_blade` 0.12 / `gear_ember_charm` 0.08 / `gear_ember_t1_blade` 0.03**
  - 焦骨 / 潮蚀 Boss：核心 + 碎片（无装备）
  - 地窖 / 断塔 Boss：核心 + 骨尘（无装备）
- **为何烦：** 体力同池 30、上限 90≈日 3 次。老玩家会立刻算：装备只在庭院滚 → **另外四线是风景区**。地图再漂亮也变「换皮观光」，肝点全砸一条，数值膨胀感从「日刷装」单通道爆出来。
- **复现：** 打开 `plugins/MythicMobs/Mobs/EmberDaily.yml`（Brute Skills）对照 `EmberDailyAsh.yml` / `EmberDailyCrypt.yml` / `EmberDailyTide.yml` / `EmberDailySpire.yml` Boss 段；再对照五份 `dungeon-reward-script`。菜单「奖励预览」还写统一「Boss 核心 + 通关箱」，**不提庭院独占装**，更阴。
- **建议方向（不写具体数值）：** 五线 Boss 掉落哲学对齐——要么都有同池装备机会，要么庭院去掉独占装、把装移到通关箱/周本；菜单预览必须和真实表一致。**禁止**「风景线同价体力、掉落矮一截」。

### 2. 枢纽「日常」按钮文案还在骗：日限次数 + 只提庭院

- **现象：** `plugins/TrMenu/menus/ember_hub.yml` 图标 `H` lore：
  - `§7短本冲击核心与附魔晶，日限次数`
  - `§8灰烬庭院 · 回廊清潮后上中央垫`
- **为何烦：** 体力制都上了还喊「日限次数」→ 玩家以为还有票/次数槽；五线都开了还只写庭院 → 点进去才发现一排本，像半成品入口。私服最恨入口撒谎。
- **复现：** `/ember` → 看「日常 · 余烬窟」lore → 再进 `ember_daily` 见五线。
- **建议方向：** 改成体力语义（消耗 / 当前体力 PAPI）+ 一句话提五线气质或「选本」；别再提日限次数；别只绑庭院文案。

### 3. 体力不足时选本钮不灰显，点了才吃瘪

- **现象：** 设计稿明确：体力不足 → **按钮灰显 + 短提示**。现行 `ember_daily.yml` 五线图标 **无** `condition` / 灰态分支，一律 `点击进本`；不足时靠 `StaminaService.consumeForEnter` 回「体力不足（需 …）」——关菜单后才知道。
- **为何烦：** 顶栏明明写着体力，按钮还绿着叫你点；点一下关 GUI 再报错，手感像坑。菜单套娃感也从这儿来——不是层数多，是 **无效点击**。
- **复现：** 把体力弄到 &lt;30 → 打开 `ember_daily` → 五钮仍显示「➥ 点击进本」→ 点任一线。
- **建议方向：** TrMenu 按 `%corerpg_stamina%` 做充足/不足双态（不足灰显 + lore「体力不足，0:00 回满」）；底层仍可保留进本校验。**不要**教玩家打 `/corerpg stamina`。

### 4. 波次脚本五线同构，玩过一条等于玩过五条

- **现象：** 五份 `monster.yml` 同一骨架：`wave1 尸×5 → wave2a 尸×3 → wave2b 骷×3 → boss×1`，门 AIR、回血、delay 几乎复制粘贴；只换坐标 / Display / 门 z。
- **为何烦：** 地形差异被 **同一清怪节拍** 抹平。焦骨假岔、地窖高差、潮蚀桥面、断塔环廊本该逼出不同走位，结果都是「清 5 → 清 3 → 清 3 → 砍 Boss」。老玩家第二轮开始刷手机。
- **复现：** 并排打开 `EmberDaily/monster.yml` 与 `EmberDailyAsh|Crypt|Tide|Spire/monster.yml` 的 groups 结构。
- **建议方向：** 保持分房开门骨架，但按线改 **一房节奏**（例：假岔垃圾波、桥面先清射手、环廊对射、中层高差远程段提前出现等）——动的是编组与刷点时序，不是盲目加血。**本条不要求改体力/通关箱数量。**

## 可改（别扭）

1. **奖励预览是空壳。** `ember_daily.yml` 图标 `P` 只 `tell: §6[日奖励] …`，不按线区分，也不提庭院装。要么做真预览页，要么删掉假按钮，别占格。
2. **枢纽→日常仍多一跳。** 相对精英「一点进本」，日常必须 hub→子页→选线。五线同页可接受；但 hub 文案修好后，可考虑子页顶栏更醒目的「今日体力还能打几次」体感（用已有 PAPI 算，勿再发明次数系统）。
3. **门吏 NPC 未落地。** 设计债：无 `ember_dungeon_clerk` 时只能标 UI 可用。现在全靠 `/ember`，萌新找不到「日常在哪」时只能翻主菜单大海。场景锚可还债，勿再套一层无意义菜单。
4. **连刷五线撞 `start-interval`。** 测报已记：leave 后立刻进下一条会冷却。玩家想「一天体验五条」会被莫名挡一下。方向：菜单/播报给冷却提示，或日常短间隔特例——别让人以为进本坏了。
5. **庭院门宽 4 格（AIR×12），其余门宽 3 格（AIR×9）。** 手感不统一；小问题，顺手对齐观感即可。
6. **骷髅远程策略不统一。** 庭院/焦骨近战木剑（S1 验收被迫近战化），地窖/潮蚀/断塔仍 BOW。主题上说得通，但庭院播报曾写「先清远程」类 flavor 债（retest2 已改部分）。统一「哪条该远程」的文档口径，避免下轮又为 `$kill` 砍弓。

## 吐槽（情绪向）

- 通关箱五份 YAML 能 `diff` 出 0 差异——策划写「可同池」，实现写成「复印机」。地图组加班做垂直水道，掉落组在午睡。
- 奖励预览按钮：点了就聊天栏回一句，这叫预览？叫「嘲讽」。
- 日限次数文案还留着，像没人告诉枢纽菜单体力上线了。入口文案是脸，脸脏了地图再美也像私服半成品。
- 假岔（焦骨）若没有 1～2 只垃圾怪或小奖励，就是纯浪费 10 秒走路——老玩家第二次直接无视，主题浪费。
- 体力 30×3＝日免费三趟，结果理性最优解是「庭院庭院庭院」。恭喜，四条新线做成了庭院的加载画面。
